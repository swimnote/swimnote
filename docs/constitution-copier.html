■ 헌법 10조 요약

1조 — 설계 고정: 승인 없이 설계 변경·기능 추가·다음 WP 선행 구현 금지

3조 — WP별 사전 설계 승인: 설계서 제출 → 사용자 승인 → 구현 순서 필수

5조 — 오류 은폐 금지: .catch(() => {}) 후 계속 진행 금지, 실패 즉시 throw
6조 — 일반모드 보호: 기존 기능(로그인·출결·일지·AI 등) 변경 금지
7조 — 운영 변경 통제: Migration·Commit·Push·OTA·배포·서버 재시작은 별도 승인 후
8조 — 범위 외 작업 금지: 현재 WP 외 선행 구현 금지
9조 — 사용자 승인 없는 자동 결정 금지: 상태값·삭제정책·결제·threshold 등
10조 — 문서·코드 불일치 보고: 임의로 맞추지 말고 형식대로 보고

§11 — 헌법 최초 확인 요청 세션 최초 1회

GPT가 헌법을 읽었는지 확인하는 체크리스트. 답변 전 이것부터 요청.

위 헌법을 읽었다면 먼저 다음 7가지만 답하십시오. 그 외 추가 설명 없이 확인 여부만 답하십시오.

1. v3.3.4 기술 설계를 유지한다는 확인
2. 실행순서만 PART 1·2·3으로 재배치됐다는 확인
3. 중간 설계 변경·기능 추가를 하지 않겠다는 확인
4. 모든 WP 전 Repository 조사와 설계서를 제출하겠다는 확인
5. 모든 WP 후 실제 코드·테스트 증거를 제출하겠다는 확인
6. 현재는 WP0 조사와 WP1 설계서만 하겠다는 확인
7. 코드 수정·Migration 실행·Commit·Push·배포를 하지 않겠다는 확인

확인 후 WP0 Repository 조사에 들어가십시오.
