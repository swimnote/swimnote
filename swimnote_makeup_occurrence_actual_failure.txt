7. eligible-classes vs eligible-occurrences 조건 비교
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[A] eligible-classes WHERE (teachers.ts:687–690):
  WHERE cg.swimming_pool_id = ${poolId}
    AND cg.is_deleted = false
    AND (cg.is_one_time = false OR cg.is_one_time IS NULL)
    AND (${showAll} OR cg.teacher_user_id = ${userId})
  HAVING GREATEST(0, capacity - current_members) > 0

  앱 호출: /teacher/makeups/eligible-classes?all=true → showAll=true → teacher 필터 없음

[B] eligible-occurrences WHERE (teachers.ts:752–757):
  WHERE cg.id = ${class_group_id}
    AND cg.swimming_pool_id = ${poolId}
    AND cg.is_deleted = false
    AND (cg.is_one_time = false OR cg.is_one_time IS NULL)

비교표:
  항목                      | eligible-classes       | eligible-occurrences
  --------------------------|------------------------|----------------------
  swimming_pool_id 필터      | 동일 (poolId)          | 동일 (poolId)
  is_deleted 필터            | 동일 (false)           | 동일 (false)
  is_one_time 필터           | 동일                   | 동일
  teacher_user_id 필터       | showAll=true → 없음    | 없음
  co_teacher_ids 필터        | 없음 (is_mine 표시만)   | 없음 (is_mine 표시만)
  available_slots 필터       | HAVING > 0 있음        | 없음
  class 특정                 | 없음 (전체 목록)        | cg.id = ${class_group_id}

판정: 조건 불일치 있음

  차이 설명:
  - eligible-classes는 HAVING available_slots > 0 — 정원 마감 반 미표시
  - eligible-occurrences는 available_slots 필터 없음 — 정원 마감 반도 CLASS_NOT_FOUND가 아님
  - 단, 앱은 eligible-classes에서 반을 선택하므로 available_slots > 0인 반만 선택 가능
  - eligible-classes에 표시된 반을 선택하면 eligible-occurrences에서 CLASS_NOT_FOUND가 발생하는 조건 차이 없음
  - 단, eligible-classes 호출 시점 → 선택 시점 사이에 반이 삭제(is_deleted=true)되면 CLASS_NOT_FOUND 발생 가능

  eligible-classes에는 표시되지만 eligible-occurrences에서 CLASS_NOT_FOUND가 되는 경우:
  1. 반이 eligible-classes 호출 이후 is_deleted=true로 변경된 경우
  2. 반이 eligible-classes 호출 이후 is_one_time=true로 변경된 경우
  3. 반의 swimming_pool_id가 사용자 poolId와 불일치하는 경우 (데이터 이상)

원문 (teachers.ts:286–291):

  function parseDayNums(scheduleDays: string): Set<number> {
    const map: Record<string, number> = { 일: 0, 월: 1, 화: 2, 수: 3, 목: 4, 금: 5, 토: 6 };
    const nums = new Set<number>();
    scheduleDays.split(",").map(d => d.trim()).forEach(d => { if (map[d] !== undefined) nums.add(map[d]); });
    return nums;
  }
