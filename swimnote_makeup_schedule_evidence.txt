lib/db/src/index.ts 정의:
  superAdminDb = drizzle(superAdminPool)  ← SUPABASE_DATABASE_URL 사용 (운영 DB)
  db           = superAdminDb             ← 완전 동일한 객체 (별칭)
  poolDb       = Proxy(superAdminDb)      ← select/insert/update/delete 호출 시 즉시 Error 발생 (차단)
  getBackupDb()= drizzle(_backupPool)     ← POOL_DATABASE_URL (백업 전용)

결론: db와 superAdminDb는 동일한 Pool 인스턴스를 바라봄.
      eligible-occurrences에서 db와 superAdminDb를 혼용하지만 실제로는 같은 DB에 연결됨.

  getMyPoolId           → superAdminDb (middlewares/auth.ts에서 사용)
  makeup_sessions 조회   → db (= superAdminDb)
  class_groups 조회      → superAdminDb (명시적으로 superAdminDb 사용)
  students COUNT         → db (= superAdminDb)
  pool_holidays 조회     → db (= superAdminDb)

import 원문 (teachers.ts 상단 추정):
  import { db, superAdminDb } from "@workspace/db";
  → 실제로는 동일한 Pool 인스턴스
