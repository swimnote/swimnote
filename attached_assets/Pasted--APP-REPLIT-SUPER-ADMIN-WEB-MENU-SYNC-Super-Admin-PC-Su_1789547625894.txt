7. SUPER ADMIN MENU CONSISTENCY

모바일 Super Admin 전체 메뉴와
PC Super Admin Sidebar/메뉴를 비교하여

다음 기준으로 정리하십시오.

A.
모바일에 존재하고
PC에서도 관리자 업무상 필요한 기능
→ PC 메뉴 유지/연결

B.
모바일에서 삭제된 기능
→ PC에서도 제거

C.
모바일 전용 UI/기능
→ PC에 억지로 복제하지 않음

D.
PC 전용으로 필요한 대량/관리 기능
→ 정상 기능이면 유지

즉 메뉴 숫자를 무조건 같게 만드는 게 아니라

“같은 기능을 서로 다른 이름으로 중복 노출”
“폐기된 메뉴가 한쪽에만 남아 있음”

상태를 없애는 것이 목표입니다.
