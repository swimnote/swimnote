[P0 — TOYKIDS X CURRICULUM CANONICAL RE-PROVISIONING]

목표:

토이키즈스윔클럽을 개발 중 강제삽입/override/reconciliation 상태로 두지 말고,
실제 신규 X 수영장이 가입할 때 사용하는
"정상 커리큘럼 업로드 → 구조화 → 활성화 → 학생연결"
canonical flow와 동일한 상태로 다시 맞춘다.

이번 작업은 테스트 pool이 아니다.

실제 Toykids Production pool을
정상 신규가입과 동일한 X curriculum setup 상태로 정규화한다.

단,
운영 중인 회원/반/수업/일지/진도 데이터는 절대 삭제하거나 초기화하지 않는다.

7. global_template_sets prerequisite
━━━━━━━━━━━━━━━━━━━━━━

기존 조사에서:

global_template_sets ACTIVE = 0

때문에 canonical READY transition이 막혔다고 보고했다.

이번에는 절대 READY를 강제로 올리지 말 것.

정상 신규가입 flow에서
global_template_sets ACTIVE가 반드시 필요한 구조라면:

왜 현재 0인지 조사.

필요한 canonical global template set이
원래 시스템에 존재하지만 ARCHIVED 되어 있는 것인지,
신규 X setup 과정에서 생성/활성화되어야 하는 것인지 확인.

정상 신규가입 시스템 자체가
global_template_sets ACTIVE=0 때문에 막힌다면
그것은 Toykids 문제가 아니라 RELEASE BLOCKER다.

그 경우 임의 우회하지 말고 STOP하고 보고.
