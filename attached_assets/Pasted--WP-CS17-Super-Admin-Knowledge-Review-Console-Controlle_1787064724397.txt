[WP-CS17 — Super Admin Knowledge Review Console & Controlled Promotion UI]

목적:

WP-CS16에서 완성된 Human Review / Approval Governance를
Super Admin이 실제 화면에서 안전하게 사용할 수 있도록
Knowledge Review Console을 구현한다.

핵심 목표:

PENDING Knowledge Candidate
→ 상세 근거 확인
→ Source / Role / Mode / Scope / Action / Policy 확인
→ Conflict / Freshness 확인
→ APPROVE / REJECT / EDIT REQUIRED
→ 감사이력 확인

전체 흐름을 Super Admin UI에서 수행 가능하게 한다.

이번 WP는
AI 기능 추가가 아니다.

새 OpenAI 호출 없음.

핵심은:

HUMAN REVIEW UX
SAFE APPROVAL
AUDITABILITY
PARTNER DEMO READINESS

==================================================
0. 절대 원칙
==================================================

1. 새로운 OpenAI/LLM 호출 추가 금지.
2. CS16 approval API/domain logic을 재사용.
3. UI에서 별도 승인 규칙을 만들지 말 것.
4. 최종 권한 검증은 반드시 서버가 수행.
5. CS12 PENDING 21개 자동 승인 금지.
6. 이번 WP에서도 Production DB write 금지.
7. 실제 ACTIVE Knowledge 임의 수정 금지.
8. UI 표시값만 믿고 승인하지 말 것.
9. client-side role check는 UX용이며 보안경계가 아님.
10. Super Admin UI에서 PII/secret/raw prompt 노출 금지.
11. REVIEW_REQUIRED Candidate를 승인 가능 상태처럼 표시 금지.
12. KNOWN_ISSUE Candidate와 실제 Incident를 혼동하지 말 것.

"이미 다른 검토자가 상태를 변경했습니다.
