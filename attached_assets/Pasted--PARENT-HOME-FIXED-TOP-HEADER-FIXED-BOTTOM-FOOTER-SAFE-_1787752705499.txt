==================================================
15. ROLLBACK POLICY
==================================================

실기기 확인 후 문제가 생기면
직전 정상 OTA로 즉시 되돌릴 수 있어야 한다.

Expo 공식 rollback 기능 우선 사용.

현재 EAS CLI에서 지원하는 경우:

eas update:rollback <BAD_UPDATE_GROUP_ID>

또는 명시적인 정상 group 복구가 더 안전하면:

eas update:republish \
  --group <ROLLBACK_TARGET_GROUP_ID> \
  --destination-channel production \
  --platform ios \
  --message "rollback: restore previous stable iOS production update"

정확한 command syntax는
현재 설치된 EAS CLI help 기준으로 확인 후 사용.

중요:
rollback target을 추측하지 말 것.
§11에서 기록한 실제 이전 정상 group ID만 사용.
