==================================================
0. FIXED PRODUCT POLICY
==================================================

X 구독 정책:

- 구매 성공 → pool 전체 X 즉시 활성
- X entitlement는 pool-wide
- pool_admin만 구매/구독관리 권한
- teacher/parent는 구매하지 않음
- paid entitlement가 active면 config와 무관하게 X
- 해지해도 결제기간 종료일까지 X 사용
- 만료 시 Normal
- X 데이터 삭제 금지
- 재구독 시 기존 X 데이터/설정 복구

Basic SWIMNOTE 구독과
X 구독은 완전히 별개.

Basic 해지/갱신일과
X 해지/갱신일을 섞지 않는다.

==================================================
6. RESTORE RESULT CASES
==================================================

A.
valid x_mode entitlement 존재
→ server sync
→ X 활성
→ 성공 안내

B.
X entitlement 없음
→ Normal 유지
→ "복원 가능한 X 구독이 없습니다"

C.
network/transient failure
→ 기존 confirmed mode 유지
→ error 안내
→ retry 가능

D.
wrong Apple ID / no purchase
→ X 신규 생성 금지

E.
server sync failure
→ local entitlement만으로 강제 X 금지
→ retry 제공

==================================================
8. CANCEL POLICY
==================================================

중요:

구독 해지 버튼을 눌렀다고
SWIMNOTE server에서 즉시 X entitlement를 제거하면 안 된다.

정책:

cancel auto-renew
→ 현재 결제기간 유지
→ expiration date까지 X
→ expiration confirmed 후 Normal

예:

8/1 결제
8/20 해지
8/31 기간 종료

8/20~8/31:
X 유지

9/1:
entitlement expired confirmed
→ Normal

필요하면:

"다시 구독 관리"

정도로만 제공.
