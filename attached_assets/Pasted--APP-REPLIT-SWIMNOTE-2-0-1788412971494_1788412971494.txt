3. HOME 버튼과 BACK 버튼 명확히 분리
============================================================

중요.

상단의:

← 뒤로가기 버튼
과
🏠 홈 아이콘

은 서로 다른 기능이다.

[뒤로가기]
→ 바로 이전 페이지

[홈]
→ 관리자 홈

뒤로가기 버튼에서:

router.replace('/(admin)')
router.push('/(admin)')
router.navigate('/(admin)')
router.replace('/(admin)/home')
기타 홈 강제 이동

사용 금지.

홈 아이콘은 기존 홈 이동 유지.

8. 정상 BACK 구현 원칙
============================================================

기본 원칙:

실제 navigation stack이 정상 존재하면
router.back()
또는 현재 프로젝트에서 사용하는 정상 goBack 방식.

단,
해당 화면이 deep link/direct entry 등으로
stack이 없을 수 있는 경우에는

명시적 parent route fallback 사용 가능.

예:

X모드 설명
parent = X모드 메인

X모드 세부설정
parent = X모드 세팅하기

중요:

fallback도 홈으로 보내지 말고
"논리적 바로 이전 부모 화면"으로 보내야 함.

============================================================
9. backTo / explicit parent 사용
============================================================

기존 stack이 불안정한 화면은
현재 프로젝트의 backTo/parent route 패턴이 있다면 재사용.

예:

route params:
backTo

또는

explicit parent route

를 사용해서:

A → B → C

일 때

C back → B
B back → A

가 보장되도록 할 것.

단,
모든 화면을 무조건 router.back()만 넣고
"테스트 PASS"라고 끝내지 말 것.

실제 route 진입 경로 기준으로 parent를 검증.

- 정책

여기서도 back이 home으로 튀는 route가 있으면 같이 수정.
