현재 문제:

1. 상단 집계에는 "발행 완료 1" 표시
2. 하지만 "발행 완료" 필터 탭에서는 0건

3. 발행 완료 필터 수정
━━━━━━━━━━━━━━━━━━━━━━

발행 완료 탭은
상단 발행 완료 count와 정확히 같은 조건 사용.

금지:

- 한쪽은 status='COMPLETED'
- 다른 쪽은 status='SENT'
- 한쪽은 published_at 기준
- 다른 쪽은 sent_at 기준

처럼 별도 조건 사용.

canonical status resolver 1개로 통일.

필터 선택 시:
발행 완료 1
→ 리스트 1건

실제 Production API로 검증.

4. 학생 상세 리포트 내용 연결
━━━━━━━━━━━━━━━━━━━━━━

실제 해당 report row에 저장된

왜 status만 발행 완료인지 root cause 보고하고
잘못된 status라면 canonical 상태 수정.

6. 선생님 검수 상태 연결
━━━━━━━━━━━━━━━━━━━━━━

현재:
선생님 검수 = 미완료
발행 상태 = 발행 완료

이 조합이 실제 정책상 가능한지 확인.

만약 발행 완료 전에 검수가 필수라면
status 데이터가 잘못된 것.

만약 자동 발행이라 검수 없이 발행 가능하면
UI 문구가 잘못된 것.

현재 실제 성장리포트 정책/Production 로직 기준으로
서로 모순되지 않게 표시.

새 정책 만들지 말 것.
기존 서버 로직 확인 후 연결만 수정.
