SwimNote 일지 템플릿 구조 재정의 요청

현재 구현은

관리자 global 템플릿
+
선생님 teacher 템플릿

을 별도 목록으로 보여주는 구조입니다.

하지만 원하는 구조는 단순 복사 구조가 아닙니다.

아래 구조로 수정해 주세요.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
핵심 개념
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

관리자 모드

= 기본 원본 템플릿 관리

선생님 모드

= 관리자 기본 원본을 그대로 받아서 사용

단, 선생님이 수정하면

그 수정은 해당 선생님에게만 적용

관리자 원본에는 영향 없음

다른 선생님에게도 영향 없음

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
작동 방식
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 관리자에서 템플릿 설정

예:

초급

* 물에 대한 적응력이 빠르게 늘고 있습니다.
* 킥 동작을 차분하게 연습했습니다.

중급

* 자유형 호흡 타이밍을 연습했습니다.

이렇게 설정하면

모든 선생님 모드에 동일하게 기본 표시

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. 선생님 모드

처음에는 관리자 템플릿이 그대로 보임

선생님은 그 템플릿을 그대로 사용할 수 있음

그리고 선생님이 특정 문장을 수정하면

그 문장만 해당 선생님 개인 버전으로 저장

관리자 원본은 변경되지 않음

다른 선생님에게도 반영되지 않음

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
예시
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

관리자 원본:

초급 1번
물에 대한 적응력이 빠르게 늘고 있습니다.

선생님 A가 수정:

초급 1번
물에 대한 적응력이 좋아지고 있고, 얼굴 담그기도 편해지고 있습니다.

결과:

관리자 화면:
물에 대한 적응력이 빠르게 늘고 있습니다.

선생님 A 화면:
물에 대한 적응력이 좋아지고 있고, 얼굴 담그기도 편해지고 있습니다.

선생님 B 화면:
물에 대한 적응력이 빠르게 늘고 있습니다.

즉:

관리자 → 선생님 전체 반영

선생님 A 수정 → 선생님 A에게만 반영

선생님 A 수정 → 관리자/선생님 B에게 영향 없음

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
UI 요구사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

선생님 화면에서

[공통 읽기 전용]
[내 템플릿]

이렇게 완전히 분리하지 말 것

대신 관리자 템플릿을 기본 목록처럼 보여주고

선생님은 각 항목을 바로 수정 가능하게 할 것

수정 시 내부적으로는 teacher override로 저장

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
선생님 화면 표시 예시
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

초급

1. 물에 대한 적응력이 빠르게 늘고 있습니다.  [수정]
2. 킥 동작을 차분하게 연습했습니다.          [수정]
3. 호흡 연습이 잘 이루어졌습니다.              [수정]

선생님이 1번을 수정하면

1번만 본인 버전으로 바뀜

수정된 항목에는 작게 표시 가능:

내 수정

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
관리자 화면
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

관리자 화면은 기존처럼 원본 관리

관리자가 수정하면

아직 선생님이 override 하지 않은 항목에는 반영

선생님이 이미 개인 수정한 항목은

선생님 개인 수정값 유지

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
중요 정책
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

관리자 템플릿은 기본 원본

선생님 수정은 override

선생님이 수정한 내용은 관리자 원본을 덮어쓰지 않음

선생님 수정은 다른 선생님에게 보이지 않음

선생님이 개인 수정한 항목을 초기화하면

다시 관리자 원본으로 돌아감

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
필요 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

선생님 모드에서 각 템플릿 항목별 기능

* 수정
* 내 수정 초기화
* 관리자 원본으로 되돌리기

선생님이 새 문장을 추가하는 경우

* teacher scope 신규 문장으로 추가
* 본인에게만 표시

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DB 구조 제안
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 scope = global / teacher 구조를 그대로 사용할 수 있는지 검토

가능하면:

global 템플릿 id를 기준으로

teacher override가 어떤 global 템플릿을 덮어쓰는지 연결 필요

예:

parent_template_id

또는

source_template_id

컬럼 추가 검토

구조:

global template
id = global_1

teacher override
scope = teacher
teacher_id = teacher_A
source_template_id = global_1
content = 선생님이 수정한 문장

조회 시:

global 목록을 불러옴
+
해당 teacher의 source_template_id override가 있으면
global content 대신 teacher content 표시

완료 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 관리자 템플릿은 전체 선생님 기본값으로 표시
2. 선생님은 관리자 템플릿을 그대로 사용 가능
3. 선생님은 각 템플릿 문장을 자기 버전으로 바로 수정 가능
4. 선생님 수정은 관리자에게 반영되지 않음
5. 선생님 수정은 다른 선생님에게 반영되지 않음
6. 선생님은 자기 수정값을 관리자 원본으로 되돌릴 수 있음
7. 관리자 수정은 override 없는 선생님에게 반영
8. override 있는 선생님은 본인 수정값 유지
9. 선생님 화면도 관리자 화면과 같은 구조로 사용 가능
10. “복사해서 내 템플릿 만들기”가 아니라 “기본 템플릿을 개인 수정” 구조로 동작
