==================================================
7. CLIENT SAFE JSON HANDLING
==================================================

서버 문제가 수정되더라도
클라이언트가 HTML/비JSON 응답에서:

JSON Parse error: Unexpected character: <

같은 기술 메시지를 사용자에게 그대로 노출하면 안 된다.

기존 safeJson / response parser convention을 재사용.

reserve 응답이:

- status >= 500
- content-type not JSON
- HTML
- parse failure

이면 사용자에게:

"예약 정보를 불러오지 못했습니다. 잠시 후 다시 시도해주세요."

표시.

raw HTML / JSON parse error 노출 금지.
