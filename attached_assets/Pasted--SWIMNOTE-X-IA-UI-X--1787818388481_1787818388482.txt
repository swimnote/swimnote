5. 디자인
━━━━━━━━━━━━━━━━━━━━━━

X모드 학부모 설정에서 승인된 UI 구조 그대로 사용:

- compact profile row
- section container
- hairline divider
- 큰 rounded card 반복 금지
- shadow 최소화
- icon + title + subtitle + chevron
- expand 방식 동일

단 컬러는 일반모드의 기존 브랜드 규칙 유지.

즉:
구조는 X모드와 동일,
색상만 일반 SWIMNOTE 모드의 기존 header/theme을 따름.

X모드 전용 badge/표현을 일반모드에 가져오지 말 것.
