2. 실제 GitHub origin 상태 확인
━━━━━━━━━━━━━━━━━━━━━━

로컬 origin/main 추적 참조만 믿지 말고
실제 GitHub origin을 fetch한다.

확인:

remote URL
remote main SHA
local main SHA

fetch 후:

local main과 origin/main의
ahead/behind/diverged 상태를 정확히 계산한다.

현재 로컬 보고의
"11 commits ahead"가
실제 최신 GitHub origin 기준으로도 맞는지 확인한다.
