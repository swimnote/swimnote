→ 서버 crash 없음

CASE C
권한 없는 parent
→ 403 또는 설계된 access_denied
→ OpenAI 호출 없음

CASE D
권한 있는 테스트 parent + 긴 diary
→ 200
→ { summary: string }
→ 빈 문자열 아님

CASE E
summary가 요청 max_lines 정책에 맞는지 확인

CASE F
기존 health endpoint 정상

CASE G
기존 핵심 API health/smoke 확인
→ 기존 서비스 장애 없음

서버 검증 실패 시:
OTA 금지.

5. OTA 후 실기기 테스트
━━━━━━━━━━━━━━━━━━━━━━

현재 등록해둔 테스트 일지를 그대로 사용한다.

CASE 1
사진 1장 + 짧은 일지
→ 사진 표시
→ AI 호출 없이 원문
→ Story 정상

CASE 2
사진 10장
→ 10장 전부 실제 이미지 표시
→ +N 없음

CASE 3
사진 10장 + 긴 일지
→ Story Summary 생성
→ 사진 10장 전부 표시
→ 요약문 전체 표시
→ 텍스트 잘림 없음
→ Story 1장

CASE 4
현재 100줄 이상 극단 테스트 일지
→ 요약
→ 1080×1920 한 장 완결
→ 검은 Composer 없음

CASE 5
동일 일지 다시 공유
→ cache hit
→ AI 재호출 없음

CASE 6
Instagram 미설치
→ 기존 정책 유지
→ 이미지/summary 생성 전에 종료되는지 확인
※ 현재 구현 순서를 실제 코드로 확인.
미설치 확인이 summary API보다 뒤로 이동했다면 수정하지 말고 보고.

CASE 7
일반 짧은 일지
→ 기존보다 불필요하게 AI 호출하지 않음
