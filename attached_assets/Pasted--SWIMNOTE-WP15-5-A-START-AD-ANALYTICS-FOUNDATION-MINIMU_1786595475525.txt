10. 광고 KPI 공식 고정
━━━━━━━━━━━━━━━━━━━━

향후 공식 정의를 source-of-truth 문서에 기록:

Impressions
= 광고 creative가 실제 사용자 화면에
노출 완료된 횟수

Unique Reach
= 지정 기간 내 해당 광고를
1회 이상 노출받은 unique user 수

Frequency
= Impressions / Unique Reach

Clicks
= 광고 클릭 action 횟수

CTR
= Clicks / Impressions

External Opens
= destination URL 실제 open action

Conversion
= 향후 정의된 conversion event

분모 0:
항상 0

NaN / Infinity 금지.
