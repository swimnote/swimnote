# SWIMNOTE X — PRODUCT DIRECTION CHANGE
# X MODE SETUP CLEANUP DESIGN AUDIT
# APP FIRST / WEB DASHBOARD LATER

현재 제품 방향이 변경되었다.

이번 작업에서는 즉시 코드를 수정하지 말고,
먼저 현재 APP 구조를 조사한 뒤
"어떻게 정리하는 것이 가장 안전한지"
구현 설계도를 제출한다.

사용자 승인 전 실제 수정 금지.

============================================================
1. PRODUCT DIRECTION CHANGE
============================================================

기존 계획:

X모드 가입 수영장마다
SWIMNOTE가 개별 홈페이지를 제작해주는 서비스

→ 폐기.

더 이상 X모드의 핵심 제공 기능으로
수영장별 홈페이지 제작을 제공하지 않는다.

따라서 홈페이지 제작을 목적으로
수영장 관리자에게 입력/업로드 받던 자료들도
X모드 앱 설정에서 제거할 예정이다.

============================================================
2. 새로운 PC 전략
============================================================

개별 수영장 홈페이지 제작 대신
X모드 사용자는 PC용 관리자 대시보드를 사용할 수 있게 한다.

PC 대시보드 기능 자체는
이미 기존에 구현된 기능이 있다.

추후 업데이트/재배포해서 사용한다.

새로운 진입 구조:

SWIMNOTE 공식 홈페이지
→ 관리자 계정 로그인
→ PIN 번호 입력
→ 해당 수영장의 관리자 권한 확인
→ APP의 관리자 화면/관리 기능을 PC 대시보드에서 사용

즉:

SWIMNOTE WEBSITE
        ↓
ADMIN LOGIN
        ↓
PIN AUTH
        ↓
POOL / ADMIN CONTEXT
        ↓
SWIMNOTE PC DASHBOARD

이 구조.

============================================================
3. SWIMNOTE OFFICE와의 관계
============================================================

향후 별도의 SWIMNOTE Office를 개발할 계획은 유지.

하지만 Office 개발 전에
기존 PC Dashboard를 먼저 활용한다.

단계:

1. 현재 X모드 APP 설정 정리
2. 기존 PC Dashboard 업데이트
3. SWIMNOTE 홈페이지 로그인/PIN 진입 구조 연결
4. X모드 사용자에게 PC Dashboard 제공
5. 향후 SWIMNOTE Office 개발

이번 작업에서는
3~5번 구현하지 않는다.

현재는 준비만 한다.

============================================================
4. 이번 APP 정리의 핵심
============================================================

현재 X모드 설정/세팅 화면에서
"개별 홈페이지 제작"을 위해 받던 항목을 찾아야 한다.

예를 들어 현재 코드에 존재할 수 있는:

- 수영장 소개
- 홈페이지 소개문구
- 대표 이미지
- 시설 이미지
- 시설 설명
- 프로그램 소개
- 강사진 소개
- 홈페이지용 사진
- 홈페이지용 연락처
- 홈페이지용 주소
- 홈페이지용 SNS
- 홈페이지용 브랜딩 정보
- 기타 홈페이지 생성 목적 입력/업로드 항목

등.

주의:
위 목록을 실제 존재한다고 가정하지 말 것.

반드시 현재 코드에서 실제 항목을 전수 조사해서 보고할 것.

============================================================
5. 제거 기준
============================================================

홈페이지 제작만을 목적으로 존재하는 입력/업로드:

→ APP X모드 설정에서 제거 후보.

하지만 다음은 함부로 제거 금지:

- 수영장 기본 운영정보
- 앱에서 실제 사용하는 정보
- 회원관리에서 사용하는 정보
- 커리큘럼에서 사용하는 정보
- AI ENGINE이 사용하는 정보
- 리포트가 사용하는 정보
- 결제/구독이 사용하는 정보
- 관리자 권한에서 사용하는 정보
- 다른 기능과 공유되는 정보

즉 UI가 홈페이지용처럼 보여도
다른 기능에서 실제 사용 중이면 제거하면 안 된다.

반드시 dependency 확인.

============================================================
6. X모드 설정의 새로운 중심
============================================================

X모드 초기 세팅의 핵심은 앞으로:

"커리큘럼 업로드 및 세팅"

으로 집중한다.

커리큘럼 관련 설정은
오히려 현재보다 명확하고 자세하게 유지/정리할 예정이다.

현재 존재하는:

- 커리큘럼 업로드
- 커리큘럼 등록
- 파일 업로드
- 교육과정 설정
- 관련 상태 표시
- 처리 상태
- 업로드 안내
- 적용 안내

등 실제 구현을 조사.

사용자가 X모드 가입 후
커리큘럼을 어떻게 제출하고
어떻게 적용되는지 이해할 수 있는 구조가 되어야 한다.
