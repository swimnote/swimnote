수정 지점 A:
waiting list ownership filter 삭제

현재 존재하는 아래 ownership 제한 블록 전체 제거:

AND (
  ms.handed_to_teacher_id = '${userId}'
  OR (
    ms.handed_to_teacher_id IS NULL
    AND (
      ms.original_teacher_id = '${userId}'
      OR EXISTS (
        SELECT 1 FROM class_groups cg
        WHERE cg.id = ms.original_class_group_id
          AND cg.co_teacher_ids @> to_jsonb('${userId}'::text)
      )
    )
  )
)

복구 후 dcc75830 정상 구조:

WHERE ms.swimming_pool_id = '${poolId}'
  ${statusClause}
  AND ms.cancelled_at IS NULL
ORDER BY ms.absence_date ASC, ms.created_at ASC

목적:

- 다른 반에서 발생한 이월 보강도 waiting 목록에 다시 노출
- expired/carryover 누락 회귀 복구

수정 지점 C:
eligible-occurrences class lookup의 is_one_time 제한 제거

현재:

AND cg.is_deleted = false
AND (cg.is_one_time = false OR cg.is_one_time IS NULL)

변경:

AND cg.is_deleted = false

즉 다음 한 줄만 제거:

AND (cg.is_one_time = false OR cg.is_one_time IS NULL)

목적:

선택된 class_group이 is_one_time=true인 경우에도
eligible-occurrences 조회가 CLASS_NOT_FOUND 404로 실패하지 않도록
dcc75830 정상 동작 복구.
