원인 조사 결과 승인합니다.

확정 원인:

swimming_pools.default_capacity = 5

로 정상 저장되어 있지만,

GET /admin/class-stats에서:

COALESCE(AVG(cg.capacity), 20)

및 응답 fallback:

?? 20

을 사용하여

반이 0개일 때
항상 20명이 표시되고 있습니다.

이제 아래 기준으로 최소 수정하십시오.

1. 최종 표시 의미
━━━━━━━━━━━━━━━━━━━━━━

반이 1개 이상 존재할 때:

→ 실제 class_groups.capacity 평균
→ UI label: “평균 정원”

반이 0개일 때:

→ swimming_pools.default_capacity
→ UI label: “기본 정원”

으로 표시하십시오.

즉 반이 하나도 없는데:

“평균 정원 5명”

이라고 표현하지 마십시오.

그 경우는:

“기본 정원 5명”

이 정확한 의미입니다.

━━━━━━━━━━━━━━━━━━━━━━
2. API 수정
━━━━━━━━━━━━━━━━━━━━━━

GET /admin/class-stats에서
하드코딩 20 fallback을 제거하십시오.

현재:

COALESCE(AVG(cg.capacity), 20)

금지.

가능하면 canonical response에:

total_classes
avg_capacity
default_capacity

를 각각 의미 그대로 반환하십시오.

권장 의미:

avg_capacity:
- 활성 반 1개 이상 → 실제 평균
- 활성 반 0개 → null

default_capacity:
- swimming_pools.default_capacity

즉:

{
  totals: {
    total_classes: 0,
    avg_capacity: null,
    default_capacity: 5
  }
}

형태.

기존 response convention에 맞게
필드명은 조정 가능.

DB migration 금지.

4. 하드코딩 20 제거
━━━━━━━━━━━━━━━━━━━━━━

5. 신규 반 생성 DEFAULT도 정리
━━━━━━━━━━━━━━━━━━━━━━

20

default_capacity로 덮어써지지만,

API 실패 시

API load 실패:
→ 임의 20 사용 금지

새 반 생성 시
센터 설정과 다른 숫자가
