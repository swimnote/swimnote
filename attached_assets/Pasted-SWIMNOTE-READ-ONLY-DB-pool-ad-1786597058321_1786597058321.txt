4. 관리자 영향 확인
━━━━━━━━━━━━━━━━━━━━

같은 전화번호가:

그리고

parent_accounts.phone = 동일 전화번호

인 상황을 가정.

학부모 탈퇴 endpoint 실행 시:

- parent_accounts만 삭제/비활성화되는지
- parent_students만 해제되는지
- users 관리자 row도 삭제되는지
- swimming_pool 관리자 권한에 영향 있는지

코드 기준으로 답할 것.

같은 phone의 parent가

- 해당 pool 연결만 삭제되는지
- parent 계정 전체가 삭제되는지
