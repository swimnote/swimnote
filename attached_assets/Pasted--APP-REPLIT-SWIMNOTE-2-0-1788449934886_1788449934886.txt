============================================================

6. COLOR 문제도 같이 확인
============================================================

첨부사진에서는 글자가 거의 안 보여서
clipping 외에 color/opacity 문제도 배제하면 안 됨.

반드시 확인:

selected tab text color
unselected tab text color
disabled opacity
parent opacity
theme color contrast

selected:
teal background 위에 읽을 수 있는 text

unselected:
white/light background 위에 읽을 수 있는 dark text

이어야 함.

"실제로 글자가 있는데 같은 색이라 안 보이는" 경우도
동시에 검사.

============================================================
7. font family 실제 확인
============================================================

Pretendard 또는 현재 custom font가
이 화면에서 정상 로드되는지 확인.

fontWeight + custom font 조합으로
glyph box가 깨지는지 확인.

필요하면
현재 앱 다른 정상 tab/chip에서
동일 font rendering pattern을 찾아 재사용.

새 font system 만들지 말 것.
