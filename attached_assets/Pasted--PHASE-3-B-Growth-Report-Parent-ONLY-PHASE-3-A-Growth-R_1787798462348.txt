3. Growth Report 댓글 API 실제 Contract 재확인
━━━━━━━━━━━━━━━━━━━━━━

이미 서버에 구현된 API를 현재 코드 기준으로 다시 확인.

GET
/parent/growth-reports/:reportId/comments

POST
/parent/growth-reports/:reportId/comments

DELETE
/growth-report-comments/:commentId

반드시 실제 request/response shape 제출.

특히 POST body:

- studentId가 필요한지
- body field 이름
- reportId 외 추가 context 필요 여부

추측 금지.

GET response:

- threads shape
- root comment fields
- replies fields
- parent name
- teacher name
- created_at
- deleted state 처리

를 실제 route 기준으로 제출.
