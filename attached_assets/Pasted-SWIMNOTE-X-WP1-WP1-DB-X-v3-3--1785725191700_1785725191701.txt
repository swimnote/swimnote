1. 확인된 차단 문제
    ━━━━━━━━━━━━━━━━━━━━━━

제안한 방식:

await initXModeSchema(superAdminDb);
if (backupDb) {
  await initXModeSchema(backupDb);
}

현재 백업 DB의 diary_templates에는 다음 컬럼이 없습니다.

* scope
* global_template_set_id
* level_id
* title
* sort_order
* teacher_id
* source_template_id

반면 현재 runGroup2_GlobalTemplate()의 M-E 사전 검증은 다음 쿼리를 먼저 실행합니다.

SELECT id, scope, swimming_pool_id
FROM diary_templates
WHERE scope NOT IN ('global', 'teacher')
   OR swimming_pool_id IS NULL;

백업 DB에는 scope 컬럼이 없으므로 현재 함수 그대로 실행하면 Group 2에서 실패합니다.

따라서 다음 문장은 현재 상태에서 성립하지 않습니다.

initXModeSchema(backupDb)
→ 백업 DB X 스키마 전체 적용
→ standby sync 복구

이 문제를 해결하기 전에는 WP1 코드를 수정하지 마십시오.
