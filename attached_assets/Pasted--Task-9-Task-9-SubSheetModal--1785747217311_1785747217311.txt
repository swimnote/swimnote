2. Modal 레이아웃 구조 정정
━━━━━━━━━━━━━━━━━━━━━━

설계서의 다음 구조는 그대로 사용하지 마십시오.

```tsx
<Modal>
  <Pressable style={styles.backdrop} />
  <View style={styles.sheet} />
</Modal>
```

`backdrop`과 `sheet`가 단순 형제이고 backdrop이 `flex: 1`이면 시트가 기존과 다르게 배치될 수 있습니다.

다음처럼 전체 화면 컨테이너 안에서 겹쳐 배치하십시오.

```tsx
<Modal
  visible={visible}
  transparent
  animationType="slide"
  statusBarTranslucent
  onRequestClose={onClose}
>
  <View style={styles.modalRoot}>
    <Pressable
      style={StyleSheet.absoluteFill}
      onPress={onClose}
    />

    <View
      style={[
        styles.sheet,
        height !== undefined
          ? { height }
          : maxHeight !== undefined
            ? { maxHeight }
            : null,
      ]}
      onStartShouldSetResponder={() => true}
    >
      <View style={styles.handle} />

      <View
        style={[
          styles.sheetHeader,
          headerPaddingBottom !== undefined
            ? { paddingBottom: headerPaddingBottom }
            : null,
        ]}
      >
        <View style={styles.headerText}>
          <Text style={styles.sheetTitle}>{title}</Text>
          {subtitle ? (
            <Text style={styles.sheetSub}>{subtitle}</Text>
          ) : null}
        </View>

        <Pressable
          onPress={onClose}
          style={styles.closeBtn}
          hitSlop={8}
        >
          <X size={20} color={C.textSecondary} />
        </Pressable>
      </View>

      {children}
    </View>
  </View>
</Modal>
```

스타일 의미:

```typescript
modalRoot: {
  flex: 1,
  justifyContent: "flex-end",
  backgroundColor: "rgba(0,0,0,0.4)",
}
```

Backdrop Pressable은 전체 화면에 절대 배치하고, sheet는 `modalRoot`의 하단에 위치시킵니다.

중요:

* 시트 컨테이너는 `Pressable`이 아닌 `View`
* `onStartShouldSetResponder={() => true}` 유지
* 시트 내부 터치가 backdrop 닫기로 전달되지 않는지 실제 확인
* 기존 iOS ScrollView 스크롤 문제가 다시 발생하지 않아야 함

━━━━━━━━━━━━━━━━━━━━━━
3. Props 확정
━━━━━━━━━━━━━━━━━━━━━━

다음 Props만 사용하십시오.

```typescript
interface SubSheetModalProps {
  visible: boolean;
  onClose: () => void;
  height?: `${number}%`;
  maxHeight?: `${number}%`;
  title: string;
  subtitle?: string;
  headerPaddingBottom?: number;
  children: React.ReactNode;
}
```

검증:

* `height`와 `maxHeight`가 동시에 전달되지 않도록 개발환경 경고 또는 단순 우선순위를 적용
* 신규 validation 라이브러리 추가 금지
* 불필요한 Props 추가 금지
* ScrollView 관련 Props를 공통 컴포넌트에 넣지 않음
* 확인 버튼 관련 Props를 넣지 않음

단순 우선순위를 사용한다면:

```text
height 우선
→ height가 없을 때 maxHeight 사용
```

━━━━━━━━━━━━━━━━━━━━━━
4. 기존 크기와 여백 유지
━━━━━━━━━━━━━━━━━━━━━━

다음 값을 그대로 유지하십시오.

```text
반이동: height="55%"
보충수업: height="60%"
적용시점: maxHeight="45%"
```

기존 공통 시트 스타일도 그대로 유지하십시오.

* 상단 radius: 20
* 배경: #FFFFFF
* 하단 padding: 32
* handle: 36×4
* handle 색상: #D1D5DB
* backdrop: rgba(0,0,0,0.4)

이번 Task에서 `paddingBottom: 32`를 ScrollView의 `contentContainerStyle`로 이동하지 마십시오.

이유:

* 적용시점 모달에는 ScrollView가 없음
* 반이동과 보충수업의 내부 하단 구조가 다름
* 공통화와 무관한 레이아웃 변경이 발생할 수 있음

기존 `cds.sheet`의 시각적 결과를 그대로 재현하십시오.
