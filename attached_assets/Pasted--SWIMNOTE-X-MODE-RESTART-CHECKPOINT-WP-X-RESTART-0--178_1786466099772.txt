10. 체크포인트 생성
━━━━━━━━━━━━━━━━━━━━

안전 조건 충족 시:

현재 정상 코드를 먼저
현재 작업 branch의 origin에 Push하여
remote에 HEAD가 존재하도록 확인.

새 기능 변경은 하지 않는다.

그 후 annotated tag 생성:

swimnote-pre-xmode-stable-2026-08-12

tag message:

"SWIMNOTE stable repository checkpoint before X mode development restart - 2026-08-12"

그리고 origin에 tag push.

중요:

- 기존 tag 덮어쓰기 금지
- force push 금지
- branch history rewrite 금지
- rebase 금지
- squash 금지
- reset --hard 금지
- 기존 makeup stable tag 변경 금지
