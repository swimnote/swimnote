# [PARENT CURRICULUM SEARCH — NO-PROGRESS FALLBACK FIX]

실기기 확인 결과 현재 동작이 잘못됨.

현재:

학생 diary/growth evidence가 0이면
모든 질문에:

"아직 기록된 수업 데이터가 없습니다..."

응답.

이 로직을 수정한다.

==================================================
1. 제품 원칙
==================================================

Parent Curriculum Search는
"학생 진도 검색 전용"이 아니다.

해당 학생이 소속된 수영장의
전체 curriculum을 검색할 수 있어야 한다.

따라서 학생 progress evidence가 0이어도
수영장 curriculum 질문은 정상 답변해야 한다.

==================================================
2. 질문 유형 분리
==================================================

질문을 최소 아래 두 축으로 분리.

A. PERSONAL_PROGRESS_REQUIRED

예:

- 우리 아이 어디까지 했어?
- 지금 어떤 단계야?
- 최근에 뭐 배웠어?
- 자유형 끝났어?
- 다음 수업은 뭐야?
- 접영 시작했어?

이 경우:
student evidence 필요.

evidence 없으면:

"현재 기록된 수업 데이터가 없어
개인 진도는 아직 확인할 수 없습니다."

정상.

--------------------------------------------------

B. CURRICULUM_GENERAL

예:

- 접영 언제 배워?
- 자유형킥은 언제 해?
- 발차기는 어떻게 배우는 과정이야?
- 평영 다음에 뭐 배워?
- 우리 수영장 접영 과정 알려줘
- 빨간 레벨에서는 뭐 배워?
- 자유형 과정 알려줘

이 경우:
student evidence 없어도 정상 검색.

해당 student's verified swimming_pool_id
→ active curriculum_items
→ 해당 질문 관련 curriculum 검색
→ 답변.

==================================================
3. CURRENT BUG
==================================================

현재 progress/evidence 없음이
전체 request를 early-return시키는 위치를 찾는다.

예상:

EvidenceRetriever
또는
ProgressResolver
또는
AnswerBuilder에서

no evidence
→ DIRECT_DB fixed no-data answer

로 너무 일찍 종료.

이 no-data response는
PERSONAL_PROGRESS_REQUIRED intent에서만 사용.

CURRICULUM_GENERAL에서는 사용 금지.

STROKE_PROGRESS

이 중:

CURRICULUM_INFO
및 개인 진도 evidence가 없어도 가능한
일반 curriculum 질문은
curriculum search path로 진행.

필요하면 최소 범위에서
CURRICULUM_GENERAL classification 보강.

Intent 전체 재설계 금지.

==================================================
5. CURRICULUM SEARCH PATH
==================================================

CURRICULUM_GENERAL:

student ownership
→ swimming_pool_id
→ buildXCurriculumScope()
→ 해당 pool curriculum_items
→ 질문과 관련된 curriculum item 검색

→ DIRECT_DB 또는 GROUNDED_GPT

학생 diary evidence 없어도 block하지 않는다.

==================================================
6. PERSONAL 질문의 NO-DATA
==================================================

개인 진도 질문인데 evidence=0일 때만:

개인 진도 확인 불가 안내.

단 가능하면 수영장 일반 curriculum 정보는
추가로 답변할 수 있다.

예:

질문:
"우리 아이 접영 언제 배워?"

개인 progress 없음.

나쁜 답:
"수업 데이터가 없습니다."

좋은 답:
"현재 개인 진도 기록이 없어 정확히 언제 시작할지는 확인할 수 없습니다.
토이키즈 커리큘럼에서는 접영은 [실제 curriculum 검색 결과] 단계에서 진행됩니다."

즉:
개인 사실과 일반 curriculum 사실을 분리.
