# SWIMNOTE 2.1.0 — WP5 FINAL UI SIZE ALIGNMENT

대상:
관리자 → 선생님 관리 → 선생님 카드 → 운영현황

첨부한 최신 iPhone 스크린샷 기준.

현재 상태:
- 탭 글자는 이제 정상적으로 보임
- 하지만 탭 4개의 버튼 크기/세로 정렬이 맞지 않음
- 선택 탭 "담당 회원"과 비선택 탭 "출결 / 수업일지 / 보강"이
  같은 높이/같은 기준선으로 보이지 않음
- 선택 탭은 아래로 더 내려와 보이고
  전체 row가 균일한 segmented chip 느낌이 아님

이번 작업은 오직:
"4개 탭의 높이/세로 정렬/크기 통일"
만 수정.

다른 기능/UI 수정 금지.

============================================================
최종 UI 요구
============================================================

4개 탭:

- 담당 회원
- 출결
- 수업일지
- 보강

모두:

- 동일 height
- 동일 minHeight
- 동일 paddingVertical
- 동일 border width
- 동일 border radius
- 동일 vertical alignment
- 동일 text baseline 느낌
- 같은 row 위에 정확히 정렬

되어야 함.

selected/unselected 차이는
배경색/테두리/텍스트색만 있어야 하고

높이/위치/크기가 달라지면 안 됨.

============================================================
수정 원칙
============================================================

현재 글자 visibility fix는 유지.

다시:
- lineHeight 깨기
- alignItems로 높이 붕괴시키기
- ScrollView 구조 변경
금지.

현재 정상 표시되는 Text는 그대로 두고
chip container size만 정렬.

실제 현재 style 확인 후 최소 수정.

예:

chip:
height: 동일 고정값
minHeight: 동일
paddingVertical: 동일
justifyContent: "center"
alignItems: "center"

selected chip과 unselected chip이
서로 다른 height/padding을 갖고 있으면 하나로 통일.

selected style에서는:
backgroundColor / borderColor 정도만 override.

height / padding / margin / transform override 금지.

============================================================
ScrollView / row 정렬
============================================================

horizontal row도 확인:

- 모든 chip bottom line 동일
- 모든 chip top line 동일
- row 높이 충분
- chip이 row 아래로 튀어나오지 않음

paddingVertical은 row와 chip 중
한 곳에서만 일관되게 관리.

중복 padding으로 선택 탭만 커져 보이지 않게 할 것.

============================================================
실기기 기준 PASS
============================================================

최신 첨부사진과 비교해서:

1. 담당 회원 탭 높이
2. 출결 탭 높이
3. 수업일지 탭 높이
4. 보강 탭 높이

전부 동일.

선택 탭과 비선택 탭:
세로 위치 동일.

텍스트:
모두 중앙 정렬.

버튼 bottom/top:
한 줄로 정확히 맞음.
