0. 이번 작업의 최우선 조건
============================================================

사용자 소유 수영장:

토이키즈스윔클럽

은 SWIMNOTE 본사/직영 운영 수영장이므로
결제 여부와 무관하게 서비스를 전부 사용할 수 있어야 한다.

따라서 다른 작업보다 먼저:

1. 기본 SWIMNOTE 이용권
2. SWIMNOTE X 이용권
3. X 플랜
4. 현재 존재하는 X 기능
5. 향후 추가되는 X 기능

을 Super Admin manual entitlement 방식으로
결제 없이 사용할 수 있도록 보호한다.

중요:

토이키즈 이름을 코드에 하드코딩해서 예외처리하지 말 것.

if pool.name === "토이키즈스윔클럽"

같은 구현 절대 금지.

일반화된:

SUPER ADMIN MANUAL ENTITLEMENT

기능으로 구현하고,
그 기능을 나중에 Production Super Admin UI에서
토이키즈에 적용할 수 있게 한다.
