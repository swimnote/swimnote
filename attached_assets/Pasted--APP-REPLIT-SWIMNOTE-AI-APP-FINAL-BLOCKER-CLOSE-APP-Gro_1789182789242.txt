중요 원칙:

Diary는
"수업기록"이지
"출석의 근거"가 아닙니다.

일지를 작성하지 않았다는 이유로
실제 출석 학생이 누락되면 안 되고,

일지가 존재한다는 이유로
특정 학생의 출석을 자동 인정해서도 안 됩니다.

최종 attendance_count는 실제 수업 event 기준이어야 합니다.

정규수업 출석 판단:

1. 해당 학생이 해당 날짜에 해당 반 재원 상태
2. 해당 반의 실제 schedule상 수업일
3. pool holiday가 아님
4. 실제 휴강/취소 데이터가 존재한다면 제외
5. explicit absent가 있으면 불출석
6. explicit present/late가 있으면 출석
7. attendance row가 없어도
   정상 수업 대상이며 explicit absent가 없으면 출석

반드시 기존 APP의
class schedule / schedule_days / lesson schedule helper를 조사하여
기존 SoT를 재사용하십시오.

새 임의 스케줄 엔진을 만들지 마십시오.
