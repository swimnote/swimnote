[P1 FINAL VISUAL AUDIT — BODY / CARD / CTA / MODAL X THEME VERIFICATION]

현재 상태:

- X theme foundation 완료
- tab contrast 수정 완료
- SubScreenHeader / ParentScreenHeader X-aware 완료
- admin/teacher/parent 일부 핵심 화면 X화 완료

하지만 다음 판정은 잘못되었을 수 있다:

"SubScreenHeader 자동 파급 = FULL_X_THEME"

헤더가 X라고 해서
화면 body 전체가 X UI/UX인 것은 아니다.

이번 작업은 코드 대량 변경이 아니라
실제 screen body의 X 적용 여부를 전수 확인하고
Normal presentation이 남아있는 곳만 최소 수정한다.

==================================================
1. 판정 기준 수정
==================================================

다음 정의를 사용한다.

HEADER_X_ONLY
=
헤더만 X이고 body/card/button/background는 Normal

PARTIAL_X
=
일부 X 적용, 일부 Normal presentation 잔존

FULL_X_THEME
=
최소 다음이 X-aware:

- page background
- header
- primary cards / surfaces
- section hierarchy
- main CTA / selected state
- X-relevant badges/chips
- modal/sheet if used on that screen
- bottom navigation if applicable

semantic colors는 그대로 유지.

단순 SubScreenHeader 적용만으로
FULL_X_THEME 판정 금지.

5. X는 네이비 도배가 아니다
==================================================

X surface hierarchy 유지:

background
→ light X surface
→ elevated surface
→ navy/steel-blue emphasis
→ white/high-contrast CTA

모든 카드 배경을 네이비로 만드는 방식 금지.

전문적이고 밝은 프리미엄 SaaS/AI 교육 플랫폼 느낌 유지.
