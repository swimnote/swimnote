8. SAFE SERVER TEST
============================================================

실제 Kakao access token 사용 금지.

Production에 실제 계정 생성/링크 금지.

서버 route contract에 대해

DB write 없이 안전하게 401/400 확인 가능한 route라면
그 경우만 테스트 가능.

조금이라도 account linking/write 가능성이 있으면
