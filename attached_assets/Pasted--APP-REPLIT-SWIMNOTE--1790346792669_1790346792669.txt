[TARGET A — 일반 연기]

회원이 연기 상태가 되면:

- 수업 스케줄/출석 대상에서 제외
- 기존 student_id 유지
- 기존 일지 유지
- 사진 유지
- 성장기록 유지
- AI 성장리포트 유지
- 교육데이터 원본 유지

재등록하면 동일 회원을 다시 활성화.

신규 student 생성 금지.

[TARGET B — 1개월 이상 장기 연기]

1개월 이상 연기 시:

원본 데이터를 물리적으로 삭제하지는 않음.

하지만 서비스상:

- 현재 교육과정의 연속성 종료
- 현재 진도 연속 기준 초기화
- 누적 피드백 연속 기준 초기화
- 재등록 후 새로운 교육구간으로 시작

과거 원본:

- 일지
- 사진
- 과거 성장기록
- 과거 리포트

등은 내부 archive/history 데이터로 보존.

즉:

“원본 데이터 삭제”와
“현재 수업/피드백 연속 기준 초기화”

는 구분합니다.

[TARGET C — 퇴원]

자동 퇴원 금지.

1개월 이상 연기했다고
시스템이 자동으로 퇴원시키지 않음.

반드시:

선생님 또는 관리자

가 명시적으로
“퇴원 처리”

를 실행한 경우에만
회원 종료/삭제 정책 실행.

회원 교육데이터 삭제 정책을 적용할 예정.

이번 조사에서 먼저 확인.

“1개월 이상 연기 시

- 과거 교육구간 종료

- 필요 시 과거 원본은 archive/history로 보존

의 의미입니다.

수정하지 말고 제안하십시오.

- enrollment cycle
- education segment
- sequence/version
- restarted_at
- feedback baseline date

등.

새 테이블이 정말 필요한지,
기존 field로 가능한지 먼저 판단.
