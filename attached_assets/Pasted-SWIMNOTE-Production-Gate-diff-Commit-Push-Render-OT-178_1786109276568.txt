SWIMNOTE 보강 회귀 복구 — Production 배포 전 마지막 실동작 Gate

현재 복구 diff 방향은 승인한다.

하지만 아직 Commit/Push/Render/OTA 금지.

이유:
이번 장애는 실제 Production에서
1) waiting/expired 누락
2) eligible-occurrences 실패
가 발생한 회귀다.

현재 보고서는 이 두 경로를 정적 코드로만 검증했다.
따라서 실제 운영 Route를 직접 mount한 테스트로 마지막 확인 후 배포한다.

복구 때문에 오늘 만든 날짜 정책이 깨지지 않았는지
실제 Route 기준 최소 확인.

- 오늘 -14일 → 허용 범위
- 오늘 +28일 → 허용 범위
- 오늘 -15일 → MAKEUP_DATE_OUT_OF_RANGE
- 오늘 +29일 → MAKEUP_DATE_OUT_OF_RANGE
- 결석일 이전 → 날짜 때문에는 차단되지 않음

  expired2
]

기대 렌더 구조:

waiting1
waiting2
----------------
기간 지난 보강 (2건)
----------------
expired1
expired2

구분선:
- 첫 expired 앞에서 딱 1번
- expired가 0건이면 없음
- expired가 1건이면 "(1건)"
- 카드별 기존 기간지난 표시 유지

판정은 STATIC_VERIFIED로 표시.
