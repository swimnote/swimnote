==================================================
4. SAFETY
==================================================

실행 전 migration 파일에서 확인:

- 기존 production row DELETE 없음
- TRUNCATE 없음
- DROP TABLE 없음
- DROP COLUMN 없음
- 기존 unrelated column type destructive 변경 없음

예상대로 additive-only가 아니면 STOP.

==================================================
5. EXECUTION
==================================================

가능하면 transaction + fail-fast 방식으로 실행.

repository canonical runner가 transaction을
내부 관리하면 그 방식을 우선.

직접 실행이 필요한 경우에도
중간 오류 후 다음 단계로 진행하지 않는다.

GR1 성공 확인 전:

GR3 금지.
GR5 금지.
