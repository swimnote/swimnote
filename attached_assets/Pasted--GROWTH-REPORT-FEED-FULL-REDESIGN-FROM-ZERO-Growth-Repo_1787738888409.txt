==================================================
1. 핵심 컨셉
==================================================

성장리포트 피드는:

“Instagram의 하나의 긴 게시물”
+
“정돈된 전문 성장리포트”

의 결합 구조로 만든다.

절대:
- PDF를 모바일로 그대로 옮긴 느낌
- 여러 카드가 붙은 느낌
- 대시보드 위젯 느낌
- 병원 검사표 느낌
- 블로그 글 느낌

으로 만들지 말 것.

사용자가 피드에서
자연스럽게 아래로 스크롤하면서
리포트 전체를 읽는 구조가 목표.

==================================================
2. 전체 구조 — 반드시 이 순서
==================================================

하나의 Growth Report Feed Post 내부 구조:

1. TOP IDENTITY HEADER
2. REPORT META STRIP
3. SUMMARY
4. REPORT SECTIONS
5. PARENT SUPPORT
6. ACTION ROW

전체가 하나의 게시물이다.

section마다 별도 카드 생성 금지.

==================================================
3. TOP IDENTITY HEADER
==================================================

상단은 Instagram post header처럼
작고 얇고 간결하게 만든다.

구조:

LEFT:
[사용자가 제공한 실제 SwimNote AI REPORT 로고]

RIGHT:
월간 리포트

아래 작은 metadata:
서태웅
토이키즈스윔클럽

중요:
사용자가 제공한 실제 로고 파일을 사용.

현재 프로젝트 asset:
assets/images/swimnote-ai-report-logo.png

새 로고 생성 금지.
텍스트로 "SwimNote AI REPORT" 대체 금지.
broken image/alt text 노출 절대 금지.

로고:
- 가로 비율 그대로
- 작고 선명하게
- 높이 약 20~24px 범위
- width auto
- header 전체 높이는 약 52~60px 이내

==================================================
4. REPORT META STRIP
==================================================

Identity header 바로 아래에
한 줄 또는 모바일에서는 2줄 metadata 영역.

표시:

2026년 8월
진도 완료율 48.7%

권장 예:

2026년 8월    ·    현재 진도 48.7%

서태웅 / 토이키즈스윔클럽은
identity header에 이미 있으므로
metadata에서 반복하지 말 것.

전체 영역은 작게.

큰 navy block 금지.
큰 월 숫자 금지.
badge 남발 금지.

==================================================

전체 배경:
white

기본 text:
deep navy

accent:

accent line / 작은 badge 정도만 사용.

==================================================
6. TYPOGRAPHY — 완전 고정
==================================================

Growth Report Feed에서는
아래 4단계만 사용.

T1 SECTION TITLE
- 15px
- SemiBold
- deep navy

T2 BODY
- 14px
- Regular
- line-height 22px
- deep navy/blue-black

T3 META
- 12px
- Regular
- muted blue-gray

T4 ACTION
- 12px
- Regular
- muted

절대:
section별 서로 다른 font size 사용 금지.
특정 section title만 18~20px 금지.
본문마다 크기 다르게 금지.

==================================================
7. SUMMARY
==================================================

첫 section:

“이번 달 한눈에 보기”

이 section은 첫 본문이라
약간의 강조만 허용.

구조:

[작은 aqua vertical line]
이번 달 한눈에 보기

본문

가능:
아주 연한 aqua tinted background

금지:
큰 카드
큰 제목
shadow
두꺼운 border

==================================================
8. REPORT SECTION 공통 구조
==================================================

모든 section은 동일한 형태.

예:

│ 수영 교육과정 진행

본문...

-----------------

│ 이전 기간 비교

본문...

-----------------

│ 다음 수업 방향

본문...

구성 규칙:

- section title 왼쪽에 작은 aqua vertical line
- title 15px SemiBold
- body 14px Regular / line-height 22
- title-bottom spacing 일정
- section-bottom spacing 일정
- section 사이 아주 얇은 divider 가능

section마다:
- shadow 금지
- radius card 금지
- 서로 다른 background 금지
- 서로 다른 typography 금지

==================================================
9. EMPTY SECTION
==================================================

아래는 완전히 렌더 제외:

- null
- empty
- whitespace
- "(이번 기간 해당 내용 없음)"
- equivalent placeholder

제목/여백/divider까지 전부 제거.

==================================================
10. 전체 내용 표시
==================================================

리포트는 중간에 절대 자르지 않는다.

금지:
- numberOfLines
- lineClamp
- maxHeight
- overflow hidden
- “더보기” 필수 구조

내용이 길면
post 자체가 아래로 계속 길어져야 한다.

마지막 section까지
피드에서 직접 읽을 수 있어야 한다.

==================================================
11. PARENT SUPPORT
==================================================

“가정에서 함께해요”

same body size

금지:
광고 CTA
큰 버튼
거대한 카드
