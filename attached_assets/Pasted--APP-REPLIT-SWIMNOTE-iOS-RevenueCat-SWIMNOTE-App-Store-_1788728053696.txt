[SWIMNOTE iOS RevenueCat 최종 연결 — SWIMNOTE 기본 구독 구매 활성화]

목표:
App Store Connect / RevenueCat 외부 설정이 완료된 신규 공식 iOS 구독 구조에 맞춰,
현재 비활성 상태인 SWIMNOTE 기본 구독(₩9,900) 구매 CTA를 실제 RevenueCat 구매 흐름에 연결한다.

이번 작업은 RevenueCat 구조 재설계가 아니다.
기존 X 구매 흐름과 기존 sync/restore 로직을 최대한 재사용한다.
불필요한 전체 리팩터링/레거시 삭제/DB 변경 금지.

2. SWIMNOTE 기본 구독 연결
━━━━━━━━━━━━━━━━━━━━━━

현재 실제 코드를 먼저 확인하되 조사 범위는 RevenueCat 구매 관련 파일로 제한한다.

확인 대상:
- lib/revenuecat.tsx
- app/(admin)/subscription.tsx
- 기존 subscriptionService / syncRcToServer 관련 코드

필요 작업:

A.
SWIMNOTE Offering 상수/조회 경로가 없다면 추가:
SWIMNOTE_OFFERING_ID = "swimnote_monthly"

B.
Offering에서 package identifier "swimnote"를 찾아
Product ID가 정확히
com.swimnote.swimnote.monthly
인지 검증한다.

C.
현재 SWIMNOTE 카드의
"구독 신청 준비 중"
disabled CTA를 실제 purchasePackage() 호출로 연결한다.

D.
구매 성공 후 기존 canonical sync 흐름을 재사용:
purchasePackage
→ CustomerInfo 갱신
→ 서버 subscription sync
→ pool/subscription 상태 갱신
→ UI refresh

새로운 별도 결제 상태 시스템을 만들지 않는다.

E.
SWIMNOTE 구매는 절대 x_mode entitlement를 요구하거나 부여하지 않는다.

SWIMNOTE 구매 성공 시 기대 상태:
- subscription tier/plan = swimnote
- 기본 SWIMNOTE 기능 사용 가능
- X300/X500/X1000 전용 X Mode = false
- x_paid_entitlement를 true로 만들지 않음
