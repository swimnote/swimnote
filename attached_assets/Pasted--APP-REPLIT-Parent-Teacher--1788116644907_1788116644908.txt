[보낼 곳: APP REPLIT]

[긴급 버그 수정 — 수영·훈련용어 검색에서 "글라이드" 검색 시 오류 + 다시시도 발생]

현재 실기기 증상:

Parent/Teacher 수영·훈련용어 검색 화면에서
"글라이드" 검색 시
검색 결과가 나오지 않고
오류 UI + "다시 시도"가 표시됨.

중요:
"글라이드"는 현재 Production sample terminology 25개 안에 존재해야 함.

따라서 단순 검색결과 없음이 아니라
Gateway/API/ENGINE 호출 실패로 본다.

이번 작업은
조사 → 실제 원인 확인 → 최소 수정 → 테스트 → commit
까지 한 번에 진행한다.

중간 보고만 하고 멈추지 말 것.

━━━━━━━━━━━━━━━━━━━━
1. 실기기와 동일한 요청 재현
━━━━━━━━━━━━━━━━━━━━

Production APP API 대상으로
실제 인증된 context에서 아래 요청 재현:

GET /api/terminology/search?q=글라이드&limit=30

확인:

- HTTP status
- response body
- Gateway log
- terminology-engine-client log
- 실제 ENGINE 호출 URL
- ENGINE response status

secret 값은 출력 금지.

━━━━━━━━━━━━━━━━━━━━
2. 아래 가능성 전부 확인
━━━━━━━━━━━━━━━━━━━━

A.
APP Gateway route prefix 문제

예:
APP이 /terminology/search 호출하는지
/api/terminology/search 호출하는지

B.
Gateway → ENGINE URL prefix 문제

예:
ENGINE 실제 route:
GET /api/terminology/search

인데 Gateway가:
GET /terminology/search

등 잘못 호출하는지

C.
PROFESSIONAL_ENGINE_BASE_URL trailing slash /
중복 /api 문제

예:
/api/api/terminology
또는
//terminology

D.
service auth 실패

E.
ENGINE 404 / 401 / 403 / 500 / timeout

F.
query encoding 문제
"글라이드" 한글 URL encoding

G.
Gateway error mapping 문제

실제 ENGINE이 200을 줬는데
APP Gateway가 error로 바꾸는지도 확인.

━━━━━━━━━━━━━━━━━━━━
3. 반드시 직접 비교 테스트
━━━━━━━━━━━━━━━━━━━━

같은 Production 환경에서:

1)
글라이드

2)
스트림라인

3)
DPS

4)
negative split

각각 검색.

결과를 비교.

특히:

스트림라인은 성공하고
글라이드만 실패하는지

아니면
모든 terminology search가 실패하는지

명확히 구분.

━━━━━━━━━━━━━━━━━━━━
4. APP UI 오류 조건 확인
━━━━━━━━━━━━━━━━━━━━

TerminologySearchScreen에서
어떤 조건일 때:

"검색 결과가 없습니다."

가 나오고

어떤 조건일 때:

오류 + 다시시도

가 나오는지 확인.

200 + results: []
→ 결과 없음

4xx/5xx/fetch exception
→ 오류

이 구분이 제대로 되어 있는지 확인.

━━━━━━━━━━━━━━━━━━━━
5. 원인이 APP/Gateway면 즉시 수정
━━━━━━━━━━━━━━━━━━━━

APP/Gateway 코드 문제면
최소 수정 후 테스트 + commit.

기존 기능 변경 금지:

- Parent Home 2분할
- Teacher settings
- Detail UI
- Segment renderer
- AI curriculum search
- 1.6.3

━━━━━━━━━━━━━━━━━━━━
6. 원인이 ENGINE이면
━━━━━━━━━━━━━━━━━━━━

APP에서 우회하지 말 것.

아래 증거를 정확히 보고:

- 호출 URL
- ENGINE status
- response error code
- 실패 query
- 성공 query
- Gateway 자체는 정상인지

그리고 APP code는 불필요하게 수정하지 않는다.

━━━━━━━━━━━━━━━━━━━━
7. 테스트
━━━━━━━━━━━━━━━━━━━━

최소:

글라이드 → 성공 또는 정확한 root cause
스트림라인
DPS
negative split

200 results
empty result
ENGINE 503
auth failure

기존 terminology gateway tests 전체 PASS.
