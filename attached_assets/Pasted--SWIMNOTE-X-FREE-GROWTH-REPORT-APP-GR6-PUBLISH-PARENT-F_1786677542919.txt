1. SOURCE OF TRUTH
==================================================

Growth Report Product Source:

growth_reports

중:

product_status = PUBLISHED

인 Report만

절대:

product_status=PUBLISHED

6. FEED ARCHITECTURE
==================================================

==================================================
7. NO CONTENT DUPLICATION
==================================================

가능하면 Feed Item에
Growth Report 전체 report_content를 복제 저장하지 않는다.

권장:

feed item / projection
→ growth_report_id 참조

Parent Feed 조회 시
PUBLISHED report를 join/project.

기존 Feed architecture가
snapshot content 저장을 요구한다면
최소 preview 데이터만 저장하고
canonical Source는 growth_reports 유지.

동일 report_content를 여러 DB row에
대량 복제 금지.

==================================================
8. FEED ITEM CONTRACT
==================================================

최소 Parent Feed Growth Report Item:

{
  type: 'GROWTH_REPORT',

  id: feed_item_id 또는 stable projection id,

  growth_report_id: string,

  student_id: string,

  report_period: 'YYYY-MM',

  published_at: string,

  title: string,

  preview: {
    summary_text?: string,
    headline?: string,
    key_points?: string[]
  },

  share_safe?: boolean
}

실제 Feed Contract에 맞게 조정 가능.

중요:

APP이 새로운 summary를 생성하지 않는다.

preview source:

report_content.summary_text

또는

sns_summary.headline / key_points

만 사용.
