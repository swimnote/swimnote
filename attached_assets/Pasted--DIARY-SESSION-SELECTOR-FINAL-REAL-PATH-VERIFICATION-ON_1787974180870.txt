==================================================

- lessonDate
- classGroupId
- startTime
- hasDiary

더 이상 발생하지 않는지 확인.

2. 8/13 → 8/27 BUG
==================================================

실제 시나리오:

스케줄러
→ 2026-08-13 선택
→ 목 19:00반
→ 수업일지

각 단계 값 출력:

calendarSelectedDate
ClassDetailSheet date
router lessonDate
diary targetDate
diary startTime
selected classGroupId

EXPECTED:

모두 2026-08-13 / 19:00 / 해당 반

8/27이 한 번이라도 나오면 FAIL.
