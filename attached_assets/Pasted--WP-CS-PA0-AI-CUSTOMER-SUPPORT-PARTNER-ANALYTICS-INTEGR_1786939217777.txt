==================================================
0. EXISTING CUSTOMER SUPPORT MASTER — LOCK
==================================================

기존 확정 고객센터 설계 원칙을 유지한다.

핵심:

1. Search First / LLM Second
2. DB / Rule / Solution DB / FAQ / Known Issue / Semantic Cache 우선
3. LLM은 복잡한 문의 / vision / 리포트 관련 등에 제한적으로 사용
4. 근거 없는 답변 금지
5. 답변 근거가 없으면 사람에게 escalation
6. AI → 사람 메시지 상담 → 필요 시 전화 순서
7. production DB를 AI가 임의 수정 금지
8. 환불/결제/계정/분쟁은 audit 필수
9. support events를 제품 개선 데이터로 재사용
10. role / tenant / pool knowledge isolation
11. 기존 support / inquiries / FAQ / notices / X 기능 최대 재사용
12. 고객센터는 독립 모듈로 추가
