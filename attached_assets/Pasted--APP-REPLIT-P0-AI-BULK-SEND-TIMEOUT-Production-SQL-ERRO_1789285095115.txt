4. DB PUBLISH와 PUSH를 완전히 분리

↓
COMMIT
↓
HTTP 200 즉시 반환
↓
notification / push 후처리

HTTP response를 반환하지 마십시오.

Push 실패:
PUBLISHED 유지.
HTTP 발송 성공을 실패로 바꾸지 않음.
