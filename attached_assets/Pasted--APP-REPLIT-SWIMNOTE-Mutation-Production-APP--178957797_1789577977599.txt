수영장 설정
→ 정보 수정
→ 저장

곧 정산 기능을 수정할 예정이므로
관리자/선생님이 정보를 입력하고 저장하는
기본 mutation 경로가 확실히 정상이어야 합니다.

이번 작업 목표:

1. 수영장 설정 저장 오류의 실제 Root Cause 확정
2. 최소 수정으로 Production 복구
3. 정산에서 사용할 가능성이 높은 관리자/선생님 저장 경로가
   동일 원인으로 끊겨 있지 않은지만 제한적으로 확인

- 존재하지 않는 DB column UPDATE
- renamed/legacy field 사용

“가능성이 있다” 수준으로 여러 방향을 계속 조사하지 마십시오.
