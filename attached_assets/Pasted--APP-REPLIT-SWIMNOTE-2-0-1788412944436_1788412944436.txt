1. 먼저 실제 기능 검증
============================================================

추측하지 말고
현재 source와 실제 동작 경로를 확인.

확인 대상:

- 회원 카드/상세에서 학부모 초대 진입점
- 초대 모달
- 카카오톡으로 초대하기
- 문자
- 복사
- 공유
- 초대문구 생성
- 앱 다운로드 링크
- 가입 후 동일 자녀 자동연결 여부

============================================================
2. 가장 중요한 성공 기준
============================================================

이 기능은 단순히
"메시지를 보낼 수 있다"가 끝이 아니다.

진짜 성공 기준:

관리자가 특정 학생의 학부모에게 초대 전송
→ 학부모가 일반가입
→ 전화번호/학생정보 기준으로
→ 해당 자녀가 정상 자동연결
→ 관리자 재승인 불필요
→ 학부모 앱에서 자녀 즉시 확인

까지 이어져야
"학부모 초대 기능 정상"으로 판정.

============================================================
3. 초대 기능이 정상일 경우
============================================================

다음 조건을 모두 만족하면 유지:

- 초대 진입 버튼 정상
- 모달 정상
- 문자 공유 정상
- 복사 정상
- 시스템 공유 정상
- 카카오 공유가 현재 2.0 정책과 충돌하지 않음
- 초대문구 정상
- 다운로드 링크 정상
- 가입 후 자녀 자동연결 정상
- 잘못된 다른 학생 연결 0
- 다른 pool 연결 0

이 경우 기능 유지.

불필요한 리디자인 금지.

============================================================
4. 카카오 관련 특별 확인
============================================================

2.0 정책:

Kakao 로그인:
NO

Kakao 가입:
NO

Kakao OAuth:
NO

Kakao SDK login:
NO

현재 모달의
"카카오톡으로 초대하기"는
단순 메시지 공유 기능인지 확인.

단순 KakaoTalk share/deep share이고
Kakao 계정 로그인/가입과 무관하면
정상 동작 여부 확인 후 유지 가능.

반대로:

- Kakao SDK login 의존
- Kakao auth 필요
- 2.0 제거 정책과 충돌
- 실제로 동작 안 함

이면 해당 버튼 제거.

============================================================
5. 기능이 제대로 안 되어 있을 경우
============================================================

아래 중 하나라도 핵심 flow가 깨져 있으면
"학부모 초대 기능 불완전"으로 판정:

- 초대는 되는데 가입 후 자녀 연결 안 됨
- 잘못된 자녀가 연결됨
- 다시 관리자 승인이 필요함
- invite token/학생 식별이 깨짐
- 링크가 잘못됨
- 앱 다운로드 링크가 잘못됨
- 공유 버튼이 실제로 안 열림
- 카카오 버튼이 정책 위반
- parent auto-link와 연결 안 됨

이 경우
기능을 억지로 복구하지 말고

학부모 초대 진입 UI 자체를 제거.

============================================================
6. 제거 범위
============================================================

기능 불량 판정 시:

- 회원 카드의 학부모 초대/학부모미연결 CTA
  중 "초대 기능" 진입 버튼 제거
- 상세 화면에 동일 초대 버튼이 있으면 제거
- 초대 모달 진입 경로 제거
- 죽은 버튼/빈 모달 남기지 말 것

단:

"학부모 미연결 상태 표시"
자체는 유지 가능.

예:
학부모미연결 badge
→ 상태 정보로 유지 가능

하지만 눌렀을 때 깨진 초대 기능으로 진입:
NO

============================================================
7. auto-link와 혼동 금지
============================================================

학부모 초대 UI를 제거하더라도
기존 전화번호 기반 parent auto-link는 유지.

즉:

부모가 별도로 일반가입
→ 동일 전화번호
→ 기존 자녀 자동연결

이 기능은 계속 살아 있어야 함.

이번 WP에서 auto-link 제거 금지.
