[SWIMNOTE 긴급 수정 — 스케줄러 반 상세 모달 스크롤 원인조사 지시]

현재 SWIMNOTE X 작업은 잠시 중단한다.

긴급 확인 대상은 첨부 화면의 스케줄러 내 반 상세 모달이다.

화면 위치:
- 상단 제목: 스케줄러
- 수업 스케줄러 화면
- 월간 일정에서 특정 반을 선택했을 때 열리는 하단 모달
- 모달 상단에 반명, 삭제, 닫기 버튼 표시
- 반배정 / 수업일지 / 보충수업 버튼 표시
- 반 색상, 정원, 학생 목록 표시
- 학생별 출석 / 결석 / 반이동 버튼이 표시되는 화면

현재 증상:
- 학생 목록이 화면 아래로 더 이어지는데도 모달 내부 세로 스크롤이 움직이지 않음
- 하단 학생 또는 항목에 접근할 수 없음
- 화면 전체가 아닌 모달 콘텐츠 영역이 충분히 위아래로 스크롤되어야 함
- 마지막 학생 아래에도 여유 공간이 있어야 하며, 하단 시스템 내비게이션이나 모달 경계에 콘텐츠가 붙으면 안 됨

중요:
지금은 코드를 수정하지 않는다.
먼저 실제 Repository에서 화면 위치와 원인을 조사해서 보고한다.

2. 반드시 확인할 원인
━━━━━━━━━━━━━━━━━━━━━━

다음 항목을 실제 코드에서 전부 확인한다.

A. 스크롤 컨테이너 부재
- 학생 목록 전체를 감싸는 ScrollView 또는 FlatList가 없는지
- 단순 View 안에 학생 목록을 map으로 렌더링하고 있는지

B. 높이 제한 문제
- 모달 콘텐츠에 고정 height가 지정되어 있는지
- maxHeight가 없거나 화면 높이보다 크게 잡혀 있는지
- flex: 1이 필요한 위치에 빠져 있는지
- 부모 View가 자식 ScrollView 높이를 제한하지 못하는지

C. 중첩 스크롤 문제
- 외부 ScrollView와 내부 ScrollView가 겹쳐 있는지
- nestedScrollEnabled가 필요한 Android 구조인지
- FlatList가 ScrollView 안에 중첩되어 경고 또는 터치 충돌이 발생하는지

D. 터치·제스처 충돌
- 모달 드래그 제스처가 내부 스크롤을 가로채는지
- Pressable 또는 Touchable wrapper가 스크롤 제스처를 막는지
- pointerEvents 설정이 잘못되어 있는지
- react-native-gesture-handler BottomSheet 계열인지

E. Modal/BottomSheet 구조 문제
- 일반 Modal인지
- 직접 만든 absolute bottom sheet인지
- 라이브러리 BottomSheet인지
- BottomSheetScrollView를 써야 하는데 일반 ScrollView를 쓰고 있는지
- contentContainerStyle과 containerStyle이 뒤바뀌어 있는지

F. 하단 여백 부족
- contentContainerStyle에 paddingBottom이 없는지
- SafeArea 하단 inset이 반영되지 않는지
- 마지막 학생이 하단 내비게이션 영역에 붙는지
- 스크롤 끝에 충분한 여유 공간이 없는지

G. Android 전용 문제
- iOS에서는 되고 Android에서만 안 되는지
- nestedScrollEnabled 누락 여부
- removeClippedSubviews 영향
- overScrollMode 또는 scrollEnabled 값
- Modal 내부 높이 계산 차이

3. 요구되는 최종 동작
━━━━━━━━━━━━━━━━━━━━━━

수정 후 목표 동작은 다음과 같다.

- 반 상세 모달 자체 높이는 화면 안에서 유지
- 모달 상단 헤더와 주요 버튼은 정상 표시
- 학생 목록을 포함한 콘텐츠 영역은 세로 스크롤 가능
- 학생 수가 적어도 레이아웃이 깨지지 않음
- 학생 수가 많으면 마지막 학생까지 부드럽게 이동 가능
- 맨 아래에서 추가로 32~48px 이상 여유 공간 확보
- Android와 iOS 모두 동일하게 동작
- 모달 닫기, 삭제, 반배정, 수업일지, 보충수업, 출석, 결석, 반이동 버튼 터치 정상
- 스크롤 중 버튼 오작동이나 모달 닫힘이 발생하지 않음
- 월/주/일 스케줄러 화면의 다른 모달에 영향 없음
- 일반모드와 X모드 모두 동일하게 정상 동작
