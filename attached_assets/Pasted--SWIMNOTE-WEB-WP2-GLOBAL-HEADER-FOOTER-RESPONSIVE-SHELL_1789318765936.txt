2. HEADER DESIGN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

최우선 느낌:

Apple 계열의 정교하고 고급스러운
thin global navigation.

하지만 Apple을 복제하지 않는다.

기본:

- background: white 또는 매우 약한 translucent white
- text: #1D1D1F
- subtle bottom border
- 과한 shadow 금지
- 과한 blur 금지
- 높이 과도하게 크지 않게
- 전체 사이트와 동일 Pretendard
- 요소 간격 정교하게
- 모든 텍스트 한 줄

권장 높이:
Desktop 약 48~52px
Mobile 약 44~48px

Logo:
- 기존 실제 SWIMNOTE logo/icon asset 재사용
- 새 로고 제작 금지
- 과도하게 크게 만들지 말 것

Product tabs:
- 작고 정제된 typography
- active/hover는 subtle
- 색상 난립 금지

PC Dashboard:
- WP1 dashboard button 사용
- compact dark pill
- header에서 유일하게 약간 강한 CTA여도 됨
- 너무 큰 버튼 금지

⋯:
- icon/button 크기 다른 nav와 통일
- circle background 남발 금지
- 필요 시 hover 시에만 subtle surface

- scrollbar는 visually intrusive하지 않게 처리.
- swipe 가능.
- keyboard navigation도 유지.

실제 mobile 접근 차단은 WP9에서 구현한다.

WP2에서는 버튼 존재만 유지.
