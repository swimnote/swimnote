잘못된 endpoint/response parsing으로 전부 숨겨지고 있습니다.

발견된 문제:

A. 재원 회원

현재:
GET /members?status=active&limit=1
→ 배열 반환인데 count/total을 찾고 있음

실제 API contract를 다시 확인하고
정확한 재원 회원 수를 얻는 기존 endpoint/field가 있으면 사용.

전체 회원 배열을 매번 받아 count하는 방식보다
기존 dashboard stats endpoint가 있다면 우선 사용.

B. 오늘 수업

현재:
/class-schedules?date=...

→ 존재하지 않는 endpoint.

기존 Dashboard/API에서
실제 오늘 수업/반 현황을 제공하는 endpoint를 찾아 사용.

C. 미배정 보강

현재:
/extra-classes 응답 구조를 잘못 parsing.

실제 기존 보강 API:

/admin/makeups/*
또는 현재 Backend의 authoritative endpoint를 확인해서 사용.

D. 성장리포트 검수 대기

현재:
/growth-reports

→ 잘못된 route.

실제:
/admin/growth-reports
계열 contract를 확인해서 사용.

중요:

endpoint 이름을 추측하지 마십시오.

기존 API 코드와 Legacy Dashboard가 실제 사용하는 contract를
확인한 뒤 연결하십시오.

API 실패를 0으로 위장하지 마십시오.

"불러오지 못했습니다"
