4. KPI — 교육 커리큘럼
━━━━━━━━━━━━━━━━━━━━━━

V1 KPI는 실제 DB로 정확히 계산 가능한 것만.

권장 4개:

1. 활성 커리큘럼
= curriculum_versions
  WHERE swimming_pool_id = currentPool
  AND is_active = true
  COUNT

2. 커리큘럼 항목
= 활성 curriculum_versions에 속한
  curriculum_items 실제 COUNT

3. 배정 학생
= active student_curriculum_assignments
  기준 DISTINCT student_id

4. 미배정 학생
= 현재 재원 학생 중
  active curriculum assignment가 없는 학생 수

중요:

기존 보고서의 "미배정 반" 대신
실제 assignment가 student_id 기준이므로
V1 KPI는 "미배정 학생"으로 통일.

반 단위 assignment처럼 표현 금지.
