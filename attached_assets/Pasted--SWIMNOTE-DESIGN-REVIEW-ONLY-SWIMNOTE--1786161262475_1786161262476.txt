다시 명확하게 설계하기 위한 검토 단계다.

7. 선생님 요청 Visibility
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

매우 중요.

모든 선생님에게 수영장 전체 학부모 요청을
무조건 보여주는 구조는 금지한다.

어떤 선생님에게 어떤 요청이 보이는지는
현재 실제 담당반/학생 관계를 기준으로 설계한다.

기본 목표:

현재 로그인 선생님이 담당하는
현재 active class 학생의 요청

→ 해당 선생님에게 표시.

공동담임/co_teacher가 실제 현재 담당자라면
동일 정책 적용 검토.

Admin은 pool 전체 요청 조회 가능.

단 실제 DB 구조를 확인한 뒤
정확한 Source of Truth를 제출.

과거 teacher_id만으로 결정하지 않는다.
