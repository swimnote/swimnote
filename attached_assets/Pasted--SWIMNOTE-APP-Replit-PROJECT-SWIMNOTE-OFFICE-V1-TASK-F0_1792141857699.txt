4. 로그인 유지 정책
- 로그인 유지 기본 OFF.
- 사용자가 ON을 선택한 경우에만 최종 인증 token을
  Electron main에서 safeStorage로 암호화해 저장.
- Windows에서 사용되는 암호화 방식과 저장 위치를 확인.
- 비밀번호·PIN·TOTP secret·임시 web_session은 저장 금지.
- renderer의 localStorage 등에 token을 평문 영구 저장 금지.
- 암호화 불가·복호화 실패 시 평문 대체 저장 금지.
  로그인 유지 실패를 알리고 일반 로그인으로 복귀.
- OFF에서는 종료 후 인증정보를 영구 보존하지 않는다.

재실행:
- 저장 token의 서버 유효성·현재 사용자·Pool·역할·
  X 접근 권한을 재검증한 뒤 진입.
- 네트워크 실패를 인증 성공으로 간주하지 않는다.
- 만료·폐기·권한 상실 시 기존 로그인 절차로 복귀.
- 로그인 유지 ON에서 별도 시작 PIN을 선개발하지 않는다.
- 로그아웃 시 메모리와 저장 인증정보를 제거하고,
  기존 서버 로그아웃 계약이 있으면 재사용.
- Windows 시작 시 자동 실행은 이번 범위에서 제외.
