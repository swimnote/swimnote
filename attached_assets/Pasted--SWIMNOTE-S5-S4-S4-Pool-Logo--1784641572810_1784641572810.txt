# SWIMNOTE 디자인 시스템 리뉴얼 — S5 작업 지시

S4 완료 보고서를 검토했습니다.

S4는 승인합니다.

Pool Logo 시스템이 계획대로 적용되었으며 API와 DB를 변경하지 않은 점을 확인했습니다.

이제 S5만 진행하세요.

======================================
S5 — ParentSlimInfoPanel 신규 컴포넌트 제작
======================================

## 목표

기존 ParentChildHeroCard를 대체할 새로운 ParentSlimInfoPanel을 제작합니다.

이번 단계에서는 **새 컴포넌트 제작만 진행**합니다.

기존 Home 화면에는 아직 적용하지 않습니다.

======================================
작업 범위
======================================

1.

새 컴포넌트

ParentSlimInfoPanel

을 생성합니다.

2.

기존 ParentChildHeroCard에서 사용하던 데이터를 그대로 재사용합니다.

새로운 API 호출은 추가하지 않습니다.

새로운 상태관리도 추가하지 않습니다.

3.

표시 정보는 기존 HeroCard와 동일한 데이터를 사용합니다.

예를 들어

- 학생 이름
- 현재 레벨
- 반 정보
- 오늘 수업 여부
- 출석 관련 정보

등은 기존 데이터 그대로 사용합니다.

4.

오늘 수업이 있는 경우에만

작은 라벨(Badge)

을 표시합니다.

오늘 수업이 없으면 라벨을 렌더링하지 않습니다.

5.

컴포넌트는 DESIGN_SYSTEM 기준을 사용합니다.

- Radius
- Shadow
- Typography
- Spacing
- LucideIcon

을 적용합니다.

======================================
이번 단계에서 절대 하면 안 되는 작업
======================================

- Home 화면 교체
- HeroCard 삭제
- FlatList 변경
- Soft Snap
- Banner 변경
- Photo Card 변경
- Diary 변경
- API 변경
- DB 변경
- Theme 대규모 수정
- Typography 전면 교체
- 공통 컴포넌트 리뉴얼
- Publish

이번 단계는 **컴포넌트를 만드는 것**이 목적입니다.

기존 Home은 그대로 유지합니다.
