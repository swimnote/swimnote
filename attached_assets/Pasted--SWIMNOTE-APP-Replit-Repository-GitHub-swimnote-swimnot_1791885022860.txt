1. PC SUPERADMIN X 부여 body 수정
━━━━━━━━━━━━━━━━━━━━━━

파일:
artifacts/swimnote-dashboard/src/pages/super/SuperPoolDetailPage.tsx

현재 잘못된 요청:

{ grant: true/false }

실제 API contract:

PATCH /api/super/operators/:id/xmode

ON:
{
  xmode_entitlement: true,
  x_plan_key: "<선택된 기존 X plan>",
  reason?: "<기존 사유>"
}

OFF:
{
  xmode_entitlement: false,
  reason?: "<기존 사유>"
}

로 맞추십시오.

허용 plan:
- x300
- x500
- x1000

기존 화면에 plan 선택 UI가 이미 있다면 그대로 사용.
없다면 최소한의 plan 선택만 추가하십시오.

임의 plan을 서버에 하드코딩하지 마십시오.

기존 pool에 x_plan_key가 있으면
화면에서 기존 값을 초기 선택값으로 사용할 수 있습니다.
