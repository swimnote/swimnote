[긴급 지시 — OTA 적용 여부부터 확정하고 AI 오류 해결]

현재 실기기 상태:

1. OTA를 배포했다고 보고했으나 업데이트 모달이 표시되지 않음
2. 앱 재실행 후에도 AI 생성 오류가 동일하게 발생
3. 따라서 최신 OTA가 실제 기기에 적용됐다는 근거가 없음

추측성 AI 코드 수정은 중단하십시오.

이번 작업은 반드시 아래 순서로 진행합니다.

==================================================
1. 방금 배포한 OTA 정보 확인
==================================================

다음을 실제 EAS 결과 기준으로 제출하십시오.

- Production Update Group ID
- iOS Update ID
- branch
- channel
- runtimeVersion
- 배포 message
- 배포 시각
- 배포에 포함된 git commit
- 현재 설치된 Production Build가 추적하는 channel
- 현재 설치된 Build의 runtimeVersion

branch만 맞고 channel 또는 runtimeVersion이 다르면
실기기는 해당 OTA를 받을 수 없습니다.

==================================================
2. 실기기 실행 OTA 식별자 표시
==================================================

기기에서 현재 어떤 코드가 실행 중인지 확정할 수 있도록
임시 진단 표시를 추가하십시오.

표시 항목:

- app version
- native build number
- runtimeVersion
- channel
- Updates.updateId
- isEmbeddedLaunch
- 배포 식별 문자열: "AI-FIX-d3b6db3"

설정 화면 하단 또는 관리자에게만 보이는 작은 진단 영역으로 표시하십시오.

콘솔 로그만 요구하지 마십시오.
Mac과 Xcode가 없습니다.

==================================================
3. OTA 모달 실제 연결 확인
==================================================

업데이트 모달 요구사항은 별도 작업이 아니라
이번 OTA 적용 검증에 반드시 사용하십시오.

앱 시작 시:

Updates.checkForUpdateAsync()
→ isAvailable=true
→ 업데이트 모달 표시
→ Updates.fetchUpdateAsync()
→ 다운로드 성공
→ “업데이트를 적용하기 위해 앱을 다시 시작합니다”
→ Updates.reloadAsync()

확인할 것:

- 업데이트 체크 함수가 실제 앱 시작 경로에서 호출되는지
- 설정 버튼에만 연결돼 있지는 않은지
- ON_LOAD 설정만 믿고 모달 구현을 생략하지 않았는지
- 인증 복구 전에 모달이 사라지는지
- 이미 다운로드된 OTA가 있을 때 reload가 실행되는지
- 업데이트 실패를 조용히 무시하는 catch가 있는지

업데이트가 없을 때만 모달이 없어야 합니다.

==================================================
4. 현재 AI 코드가 실기기에 포함됐는지 확인
==================================================

최신 OTA가 실제 적용된 뒤에만 AI를 다시 테스트하십시오.

기기 진단에서 반드시 다음이 확인되어야 합니다.

- 배포 식별 문자열 = AI-FIX-d3b6db3
- updateId = 방금 배포한 iOS Update ID
- isEmbeddedLaunch = false
- 최종 AI path = /api/v1/teacher-diary/generate
- mode = grounded

하나라도 다르면 최신 수정 코드를 테스트한 것이 아닙니다.

==================================================
5. 최신 OTA 적용 후 AI 생성 재시험
==================================================

최신 updateId가 확인된 상태에서 AI 생성 1회 수행.

실패하면 오류 화면에 아래 진단 정보를 직접 표시하십시오.

- causeCode
- HTTP status
- endpoint path
- response key 목록
- request_id
- validation 실패 단계

학생명, 교사 입력, JWT, 생성 내용은 표시하지 마십시오.

“응답 형식 오류”만 표시하고 종료하지 마십시오.
