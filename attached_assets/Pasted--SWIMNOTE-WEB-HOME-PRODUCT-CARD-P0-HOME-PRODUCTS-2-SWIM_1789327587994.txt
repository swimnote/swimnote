[SWIMNOTE WEB — HOME PRODUCT CARD 로고/카피 정리 P0]

현재 HOME의 PRODUCTS 카드 2개(SWIMNOTE / SWIMNOTE X)에서
브랜드 표시가 어색합니다.

반드시 아래 3가지를 수정하십시오.

━━━━━━━━━━━━━━━━━━━━━━
1. 수정 목표
━━━━━━━━━━━━━━━━━━━━━━

A. 로고가 제멋대로 보이는 문제 수정
- 두 제품 로고의 시각적 크기를 일정하게 맞출 것
- 로고 배경이 카드 위에서 어색하게 보이지 않게 처리할 것
- 특히 SWIMNOTE X 로고는 배경 제거/정리 후 사용 여부를 확인할 것

B. 로고 아래 작은 제품명 텍스트 잘림 수정
- "SWIMNOTE", "SWIMNOTE X" 라벨이 세로로 잘리거나 line-height가 눌리지 않게 수정
- overflow/line-height/min-height/font rendering 문제를 실제 코드 기준으로 찾고 고칠 것

C. 카피 수정
- SWIMNOTE는 일반 “수영장”이 아니라 “어린이수영장” 기준으로 소개해야 함
- 따라서 HOME 제품 카드의 SWIMNOTE 설명을 어린이수영장 운영 앱이라는 방향으로 수정할 것

━━━━━━━━━━━━━━━━━━━━━━
2. 로고 처리 원칙
━━━━━━━━━━━━━━━━━━━━━━

현재 제품 카드에서는
앱 스크린샷이 아니라
“브랜드 로고 + 짧은 설명” 구조가 핵심입니다.

따라서 로고는 제품 카드 상단에서
브랜드 식별용으로만 깔끔하게 사용하십시오.

반드시 아래 기준 준수:

1) 두 카드의 로고 박스 크기 통일
- 같은 width/height의 logo frame 안에 배치
- 예: 동일한 72~88px급 시각 영역
- 단순 이미지 원본 크기 그대로 쓰지 말고 “시각적 무게” 기준으로 맞출 것

2) 로고 원본 비율 유지
- stretch 금지
- 찌그러짐 금지
- object-fit / contain 기준으로 처리

3) 배경 처리
- 투명 PNG는 그대로 사용
- 흰 배경이 섞여 있는 로고는 카드 위에서 티나지 않게 정리
- 가능하면 배경 제거한 asset로 교체
- 만약 현재 repo에 배경제거 버전이 없다면:
  - 우선 CSS로 흰 박스가 보이지 않게 처리 가능한지 확인
  - 불가능하면 “추가 asset 필요”로 보고

4) 아이콘형 / 로고형 혼용 금지
- 두 카드가 서로 다른 계열처럼 보이면 안 됨
- “아이콘만 크게” vs “작은 로고타입” 같이 불균형하게 두지 말 것
- 제품 카드에서는 두 로고가 같은 계열의 배치처럼 보이게 정리할 것

━━━━━━━━━━━━━━━━━━━━━━
3. 텍스트 잘림 수정
━━━━━━━━━━━━━━━━━━━━━━

현재 스크린샷상
로고 아래 라벨 영역이 잘리거나 눌려 보입니다.

반드시 실제 원인 찾아서 수정하십시오.

점검 대상:
- line-height
- letter-spacing
- text-transform
- overflow: hidden
- container height
- align-items / flex layout
- margin collapse / absolute positioning
- font rendering

수정 기준:
- 제품 라벨이 한 줄에서 안정적으로 보일 것
- Desktop / Mobile 모두 잘림 없을 것
- 폰트 크기/두께는 두 카드 동일할 것

━━━━━━━━━━━━━━━━━━━━━━
4. SWIMNOTE 카피 수정
━━━━━━━━━━━━━━━━━━━━━━

중요:
SWIMNOTE는 여기서 “수영장 운영의 모든 것”처럼 넓게 잡지 말고
“재래식 운영 구조의 어린이수영장에 적합한 앱”
이라는 포지션으로 잡아야 합니다.

즉, HOME 카드에서 SWIMNOTE 문구는
“어린이수영장” 기준으로 수정하십시오.

현재 문구가:
- "수영장 운영의 모든 것."
- "회원, 수업, 출결, 보강, 일지와 학부모 소통까지 하나의 앱으로."

이 계열이라면,
아래 방향으로 수정:

헤드라인 예시 방향:
- "어린이수영장 운영의 기본."
- "어린이수영장 운영에 맞춘 실전 앱."
- "어린이수영장 운영을 하나의 앱으로."

서브카피 방향:
- 회원등록, 반관리, 출결, 보강, 수업일지, 학부모 소통 등
- “어린이수영장 운영에 필요한 기능을 하나의 앱으로 관리합니다.”
- 과장 없이, 실제 기능 범위 중심으로

문장 확정은 네가 현재 디자인 톤에 맞춰 정리하되
핵심 단어 “어린이수영장”은 반드시 들어갈 것.

━━━━━━━━━━━━━━━━━━━━━━
5. SWIMNOTE X 카피 원칙
━━━━━━━━━━━━━━━━━━━━━━

SWIMNOTE X는 기존 방향 유지 가능:
- 수영 교육을 시스템으로
- 커리큘럼, 수업 기록, 성장 데이터 연결
- 프리미엄 교육 시스템

단,
SWIMNOTE보다 열등/상위라기보다는
용도가 다른 제품처럼 보여야 함.

즉:
- SWIMNOTE = 어린이수영장 실운영에 적합
- SWIMNOTE X = 교육 시스템 고도화 / 성장리포트 / 커리큘럼 중심

이 포지션 차이를 HOME 카드에서 명확히 보이게 해라.

━━━━━━━━━━━━━━━━━━━━━━
6. 디자인 원칙
━━━━━━━━━━━━━━━━━━━━━━

- Apple-like 고급감 유지
- 알록달록 금지
- 카드 2개는 같은 시스템 안에서 보이게
- 로고 / 라벨 / 헤드라인 / 본문 / CTA 정렬 규칙 통일
- 여백 통일
- 버튼 높이/모양 동일
- 카드 높이 가능하면 동일

권장 구조:

[로고]
[제품명 작은 라벨]
[헤드라인]
[설명 1~2줄]
[알아보기 버튼]

앱 스크린샷은 HOME에서 제거 유지.
상세 페이지에서만 활용.

━━━━━━━━━━━━━━━━━━━━━━
7. 꼭 확인할 QA
━━━━━━━━━━━━━━━━━━━━━━

아래 전부 확인 후 보고:

1) Desktop
- 두 카드 로고 크기 시각적으로 균형 맞는지
- 라벨 잘림 없는지
- 카드 높이/정렬 일정한지

2) Mobile
- 로고 축소 시 깨짐 없는지
- 라벨 줄바꿈/잘림 없는지
- 버튼 위치 안 깨지는지

3) Dark/Light 혼합 없음
- 카드 배경 위에서 로고 흰 배경 튀지 않는지

4) 실제 route
- HOME `/`
- 필요시 `/swimnote`, `/swimnote-x`와 톤 연결성 확인
