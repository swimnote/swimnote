[앱]

GROWTH REPORT FEED — VISUAL REFINEMENT ROUND 2

현재 버전은 이전보다 개선되었지만, 아직 최종 승인 아님.
기본 방향은 유지한다.

유지할 것:
- 긴 피드 전체 노출 구조 유지
- 내용 truncation 금지 유지
- 실제 SwimNote AI REPORT 로고 유지
- viewport 100% 사용 유지
- section 패딩 16px 통일 유지
- typography 4단계(T1/T2/T3/T4) 유지
- PDF 렌더러 구조 건드리지 말 것
- AI/API/데이터 로직 수정 금지

이번 Step 목표:
“긴 카드” 느낌에서 끝내지 말고,
“인스타그램 피드 안에서 보는 공식 리포트”처럼 보이도록
리포트 구조감과 시각적 위계를 강화한다.

==================================================
1. HEADER 재정리
==================================================

현재 헤더는 정보는 들어가 있지만 존재감과 위계가 약하다.
헤더를 더 리포트답게 정리하라.

필수 구조:

[1행]
- 좌측: SwimNote AI REPORT 로고
- 우측: 월간 리포트 badge

[2행]
- 메인 제목: "월간 성장 리포트"
  → 헤더에서 가장 먼저 보이게
  → 현재보다 더 분명한 제목 hierarchy 필요

[3행]
- 학생명
- 수영장명
- 해당 월
  → 한 줄 또는 두 줄로 정리 가능
  → 답답하지 않게 정렬

[4행 또는 하단 info row]
- 현재 진도 XX%
  → compact info strip처럼 정리

중요:
- 헤더 높이를 과하게 키우지 말 것
- 하지만 지금보다 “리포트 첫머리” 느낌은 더 강해야 함
- 로고만 커지는 방식 말고, 정보 위계를 정리해야 함

==================================================
2. SECTION SYSTEM 강화
==================================================

현재는 section 제목은 나뉘지만,
시각적으로는 긴 본문 박스가 이어지는 느낌이 강하다.

section을 아래 3종 체계로 정리하라.

[Type A: 핵심 강조 섹션]
대상:
- 이번 달 한눈에 보기
- 가정에서 함께해요

스타일:
- 연한 aqua/mist 배경
- title 왼쪽 accent bar
- 내부 여백 충분히
- 핵심 박스처럼 보이게

[Type B: 일반 분석 섹션]
대상:
- 수영 교육과정 진행
- 이전 기간 비교
- 다음 수업 방향
- 기타 일반 분석 section

스타일:
- 흰 배경
- section 상단 divider 또는 subtle 구분
- title row와 body가 명확히 분리되게
- 박스처럼 보이되 너무 장식적이지 않게

[Type C: 정보 strip]
대상:
- 커리큘럼 진도
- progress bar
- 메타 정보

스타일:
- compact
- 정보형 레이아웃
- 지나치게 넓거나 공백 많은 구조 금지

==================================================
3. TITLE / BODY 위계 강화
==================================================

현재 폰트 크기 자체보다 문제는 hierarchy가 약하다는 점이다.

유지:
- T1 section title
- T2 body
- T3 metadata
- T4 action

수정:
- T1이 section title로 더 명확히 보여야 함
- T2 본문과 T1 제목 간 간격 정리
- 문단 첫 줄부터 너무 답답하게 붙지 않게 조정
- 모든 섹션의 title baseline 통일
- title 왼쪽 accent marker 길이/두께 통일

==================================================
4. PROGRESS AREA 재정리
==================================================

현재 progress는 들어가 있지만 약하다.
“커리큘럼 진도”를 더 정보형으로 정리하라.

필수:
- label: "커리큘럼 진도" 또는 "현재 진도"
- percentage 수치
- progress bar

레이아웃:
- label 왼쪽
- 수치 오른쪽
- progress bar는 그 아래
- 하나의 compact strip처럼 보이게

중요:
- 이 영역은 summary 박스 내부 또는 header 하단 어느 쪽이든 좋지만,
  반드시 “보조 정보”가 아니라 “중요 상태 정보”처럼 보여야 한다.

==================================================
5. REPORT 느낌 강화
==================================================

이 디자인은 단순 블로그형 카드가 아니고 리포트여야 한다.

추가할 것:
- section 사이 간격 규칙 명확화
- 각 항목의 시작과 끝이 보이도록
- divider 시작점/끝점 통일
- 문단 폭과 행간 안정화
- 보고서처럼 차분한 정렬감

하지 말 것:
- 랜덤 색상
- 과한 장식
- 카드마다 다른 스타일
- 귀여운 UI 느낌
- PDF 축소판처럼 만드는 것

==================================================
6. ACTION ROW 정리
==================================================

현재 하단 action row 존재감이 너무 약하다.

구조 유지:
- 좋아요
- 댓글
- PDF 공유

수정:
- 아이콘과 텍스트 정렬 통일
- 너무 흐리지 말 것
- 섹션 종료 후 utility row처럼 보이게
- 얇은 top divider 추가 가능

단,
액션이 메인보다 튀면 안 된다.

==================================================
7. EMPTY SPACE / WIDTH
==================================================

실제 앱 기준으로는 post가 화면을 충분히 써야 한다.

확인:
- 좌우 여백 과도하지 않게
- 콘텐츠 폭이 너무 좁아 보이지 않게
- 텍스트 줄 길이가 지나치게 짧아지지 않게
- section 내부 공백은 적당히

중요:
- web preview 캡처 기준이 아니라,
  실제 모바일 피드에서 읽기 좋은 폭인지 우선 확인할 것

==================================================
8. 검수 기준
==================================================

다음 항목 모두 만족해야 함:

1) 헤더가 리포트 첫머리처럼 보인다
2) 로고가 선명하다
3) "월간 성장 리포트" 제목 위계가 명확하다
4) 학생명 / 수영장명 / 해당 월 / 진도 정보가 깔끔하다
5) section이 항목별로 명확히 구분된다
6) 핵심 요약 / 일반 분석 / 가정 가이드가 서로 다른 역할로 보인다
7) progress 영역이 정보 strip처럼 잘 정리된다
8) 긴 피드지만 읽기 피로감이 낮다
9) 폰트 크기/행간이 통일돼 보인다
10) 하단 action row가 너무 약하지도, 튀지도 않는다
