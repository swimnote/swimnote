[SWIMNOTE — Splash 수정만 선반영 / 다음 Native Build부터 적용]

목표:

현재 운영 중인 앱/OTA/TestFlight에는 영향을 주지 않는다.

이번 작업에서는
iOS/Android Splash 로고 크기와 비율만 수정해 repository에 반영한다.

실제 적용은 다음 새 Native Build부터 되도록 한다.

==================================================
1. 변경 내용
==================================================

현재 Splash 로고가 너무 크게 보인다.

iOS/Android 모두:

- 현재 대비 약 30% 축소
- 동일한 체감 비율
- 중앙 정렬
- contain 유지
- 밝은 배경 유지
- 로고 디자인 자체는 변경 금지

==================================================
2. iOS / Android 통일
==================================================

단순 같은 px 값이 아니라
실제 화면에서 동일한 체감 크기가 나오도록 조정한다.

가능하면 expo-splash-screen의 imageWidth 또는
현재 repo에서 실제 사용하는 splash sizing 설정을 사용.

현재 설정 위치를 repo에서 먼저 확인.

==================================================
3. Splash timing
==================================================

현재 artificial delay가 있는지 확인.

있으면 제거하거나 별도 보고.

단 이번 작업에서는 Splash duration 관련 runtime 동작을
불필요하게 변경하지 않는다.

핵심은 크기/비율 수정이다.
