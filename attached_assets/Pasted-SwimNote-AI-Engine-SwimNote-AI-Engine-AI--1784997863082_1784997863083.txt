SwimNote AI Engine — 시스템 참조 문서
이 문서는 SwimNote AI Engine 어드민 앱의 전체 구조를 AI 에이전트가 이해할 수 있도록 정리한 참조 문서입니다. 작성 기준일: 2026-07-25

1. 프로젝트 개요
SwimNote AI Engine은 수영 지식을 체계적으로 수집·정제·활용하기 위한 지식 관리 + AI 추론 플랫폼입니다.
관리자(코치·전문가)가 수영 관련 문서를 업로드하면, AI 파이프라인이 자동으로 지식을 추출·정규화·임베딩하여
검색·Q&A·진단·교정·커리큘럼 생성 등의 AI 서비스에 공급합니다.

구성:

백엔드: Node.js (TypeScript) + Fastify + PostgreSQL + pg-boss 작업 큐
프론트엔드: React + Vite + Wouter (어드민 전용 SPA)
AI: OpenAI API (GPT-4o mini, text-embedding-3-small)
ORM: Drizzle ORM (멀티 스키마: ai, admin, kf, app)
2. 전체 아키텍처 흐름
[문서 업로드] ──▶ [파싱 파이프라인] ──▶ [청킹] ──▶ [임베딩]
                                                      │
                                                      ▼
[관리자 검토] ──▶ [정규화/정전화] ──▶ [글로벌 병합] ──▶ [지식 발행]
                                                      │
                                                      ▼
                              [검색 / Q&A / 진단 / 교정 / 커리큘럼]

8. 텍스트 직접 입력 — AI 메타데이터 자동 추출 플로우
2026-07-25 구현된 신규 기능:

관리자가 수영 관련 본문 텍스트만 붙여넣기
AI 메타데이터 자동 분석 버튼 클릭
백엔드 POST /api/kf/text-documents/extract-metadata 호출
GPT-4o mini가 본문(최대 4,000자)을 분석하여 반환:
제목 (title)
요약 (summary)
키워드 (keywords[])
태그 (tags[])
영법 (stroke)
기술 분류 (tech_category)
카테고리 (category)
언어 (language)
출처명 (source_name)
저자 (author)
관리자가 생성된 메타데이터 검토/편집 후 지식 DB에 저장 클릭
