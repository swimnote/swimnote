[AI 문의 화면 — 사람 상담 요소 완전 제거 + AI 전용 채팅으로 정리]

첨부된 실제 iPhone 스크린샷 기준으로 수정한다.

이번 화면은 "AI 문의" 기능이다.
사람 상담사/운영팀 연결 기능이 아니다.

최종 목표:
오직 사용자 ↔ AI 상담 채팅만 남긴다.

━━━━━━━━━━━━━━━━━━━━━━
1. 느낌표 아이콘 교체
━━━━━━━━━━━━━━━━━━━━━━

현재 AI 응답 옆에 반복 표시되는
원형 느낌표 아이콘 제거.

warning/error 상태가 아니므로
alert/exclamation 계열 사용 금지.

대체:

- message-circle
- bot
- sparkles
- info

중 현재 디자인 시스템에 맞는
AI/채팅 의미 아이콘 사용.

AI 응답 버블 옆에 꼭 아이콘이 필요하지 않으면
아예 제거해도 됨.

━━━━━━━━━━━━━━━━━━━━━━
2. 상단 "상담사 연결 대기" 제거
━━━━━━━━━━━━━━━━━━━━━━

현재 헤더:

AI 문의
상담사 연결 대기

여기서
"상담사 연결 대기" 완전 제거.

최종:

AI 문의

만 표시.

사람 상담 상태를 암시하는 문구 금지.

━━━━━━━━━━━━━━━━━━━━━━
3. 하단 접수 완료 문구 제거
━━━━━━━━━━━━━━━━━━━━━━

현재:

"문의가 접수되었습니다. 운영팀이 확인 후 답변드립니다."

완전 제거.

운영팀이 확인하는 프로세스 없음.

AI가 답변하면 해당 문의는 AI 응답으로 끝나는 구조.

운영팀/담당자/사람 확인 관련 문구 전부 제거.

━━━━━━━━━━━━━━━━━━━━━━
4. "상담사가 확인 중입니다" 카드 제거
━━━━━━━━━━━━━━━━━━━━━━

현재 하단 보라색 카드:

"상담사가 확인 중입니다. 잠시 기다려주세요."

완전 제거.

사람 상담사 연결 기능 없음.

이 카드에 연결된:

- waiting state
- 상담사 연결 상태
- pending human response UI

가 AI 문의 화면 전용 코드라면 같이 제거.

단 서버의 다른 고객지원 기능이 실제로 사용 중이면
공용 backend 자체를 삭제하지 말고
AI 문의 화면에서만 노출하지 않도록 할 것.

━━━━━━━━━━━━━━━━━━━━━━
5. 상단 "상담사 연결 대기" 상태바 제거
━━━━━━━━━━━━━━━━━━━━━━

화면 상단 목록 영역에:

● 상담사 연결 대기

표시도 제거.

AI 문의에는 human escalation 상태를
사용자에게 표시하지 않는다.

최종 상단은 필요하면:

AI 문의

또는
AI 상담

정도만 유지.

━━━━━━━━━━━━━━━━━━━━━━
6. "새 문의"는 유지 가능
━━━━━━━━━━━━━━━━━━━━━━

우측 "새 문의"는 유지.

동작:

현재 대화 초기화
→ 새 AI 문의 시작

사람 상담 티켓 생성 의미로 동작하면 안 됨.

실제 handler 확인해서
human ticket 생성 API를 호출하고 있다면
AI 대화 reset/new-thread 의미로 정리.

━━━━━━━━━━━━━━━━━━━━━━
7. AI 응답만 남긴다
━━━━━━━━━━━━━━━━━━━━━━

최종 화면 구조:

[AI 문의]

사용자:
질문

AI:
답변

사용자:
추가 질문

AI:
답변

입력창
전송 버튼

끝.

다음 요소는 화면에서 전부 없어야 함:

- 상담사 연결
- 상담사 연결 대기
- 운영팀
- 접수되었습니다
- 확인 후 답변드립니다
- 상담사가 확인 중입니다
- 상담원 대기
- human escalation 상태
- ticket pending UI

━━━━━━━━━━━━━━━━━━━━━━
8. AI가 답변 못하는 경우
━━━━━━━━━━━━━━━━━━━━━━

현재 AI가 모르는 질문에:

"현재 확인 가능한 안내만으로는 이 문의를 정확히 해결하기 어렵습니다..."

같은 AI 한계 안내는 유지 가능.

단 뒤에:

"운영팀에 접수합니다"
"상담사가 확인합니다"
"담당자가 답변합니다"

같은 문구 추가 금지.

AI가 모르면 AI가 다음처럼 종료:

"현재 확인 가능한 정보만으로는 정확한 답변이 어렵습니다."

또는

"질문을 조금 더 구체적으로 알려주세요."

정도로 처리.

━━━━━━━━━━━━━━━━━━━━━━
9. 기존 사람상담 상태 로직 확인
━━━━━━━━━━━━━━━━━━━━━━

현재 화면에 사람상담 상태가 보이는 이유 확인:

- frontend hardcoded
- API response status
- fallback
- support ticket state
- escalation flag

중 무엇인지 확인.

AI 문의에서 더 이상 필요하지 않으면
frontend 노출 로직 제거.

단 다른 화면에서 실제 support ticket 기능을 사용하면
서버 공용 기능 전체 삭제 금지.

이번 범위는 AI 문의 화면.
