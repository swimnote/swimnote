11. PC 대시보드 활성화 화면
============================================================

구성:

------------------------------------------------------------
① PC 대시보드 PIN
------------------------------------------------------------

설명:

"X모드 PIN을 설정하면 PC에서 SWIMNOTE 관리자 기능을 사용할 수 있습니다."

추가 설명:

앱 로그인 비밀번호와 별개의
PC 대시보드용 추가 보안 PIN이라는 의미가 명확해야 함.

사용자-facing 명칭은:

"PC 대시보드 PIN"

권장.

내부 API/DB 명칭:
web_pin
web_pin_hash

그대로 유지.

상태:

- 설정됨
- 미설정

기존:

GET /pools/web-pin-status

재사용.

버튼:

미설정:
[PIN 설정하기]

설정됨:
[PIN 변경]

필요하면 기존 [PIN 해제] 유지.
