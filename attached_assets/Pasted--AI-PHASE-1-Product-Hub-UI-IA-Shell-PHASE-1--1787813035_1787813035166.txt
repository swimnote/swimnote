3. Product Intro
━━━━━━━━━━━━━━━━━━━━━━

최상단:

AI 인사이트 전략 리포트

설명은 짧게:

수업 기록과 누적 성장 데이터,
학부모가 제공한 관찰정보를 함께 분석해
아이의 성장 신호와 잘 되는 조건,
다음 성장 전략을 더 깊게 분석합니다.

특징은 최대 3~4개 compact tag/pill:

- 1회 심층 분석
- 누적 데이터 기반
- 여러 성장 영역 종합
- 근거 있는 항목만 분석

쇼핑몰처럼 과하게 홍보하지 말 것.

━━━━━━━━━━━━━━━━━━━━━━
4. 분석 준비 상태
━━━━━━━━━━━━━━━━━━━━━━

실제 향후 API와 연결 가능한 contract를 먼저 정의.

예:

type InsightReadiness = {
  lessonDataReady: boolean;
  lessonDataCount?: number;

  basicInfo: {
    birthDate: boolean;
    height: boolean;
    weight: boolean;
  };

  parentObservation: {
    answered: number;
    total?: number;
  };

  preflightConfirmed: boolean;
};

이번 PHASE에서는 실제 서버 연결 금지.

하지만 UI 내부에 여기저기 숫자 하드코딩하지 말고
단일 local fixture/state object를 통해 렌더.

향후 API response만 교체하면
UI 수정 없이 동작할 구조.

표시 예:

분석 준비

수업·성장 데이터        준비됨
아이 기본정보           1/3
학부모 관찰정보         미입력
발급 전 확인            미완료

[준비 계속하기]

거짓 수치/실제 학생 데이터 표시 금지.

PHASE 1 fixture는 명확하게 개발용으로만 사용.
