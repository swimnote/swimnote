STEP 5. 오류별 즉시 판정
━━━━━━━━━━━━━━━━━━━━━━

503 / DB_CONNECTION_LIMIT

→ DB 연결 제한 원인으로 확정
→ pool singleton, 실제 connection count, 동시 요청 수 재점검
→ 임의 pool_size 증가 금지

403 / POOL_NOT_FOUND

→ 사용자 계정의 수영장 연결 문제
→ DB 수정 전 원인 보고

403 / MAKEUP_POOL_MISMATCH

→ 보강 세션과 로그인 교사의 pool 불일치
→ handover 데이터 정합성 조사

404 / CLASS_NOT_FOUND

→ 선택한 반의 is_deleted 또는 pool 소속 불일치 조사

500 / ELIGIBLE_OCCURRENCES_FAILED

→ 서버 로그 stage와 stack 기준으로 직접 수정

━━━━━━━━━━━━━━━━━━━━━━
