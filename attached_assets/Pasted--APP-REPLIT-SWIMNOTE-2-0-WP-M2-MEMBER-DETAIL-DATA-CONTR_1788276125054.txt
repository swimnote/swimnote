--------------------------------
C. CLASS / ENROLLMENT INFO
--------------------------------

현재 반:

class_group_id
class_group_name

담당 선생님:

요일/시간:

weekly_count

--------------------------------
D. LEVEL INFO
--------------------------------

반드시 학생 개인 레벨 SoT:

students.current_level_order

기반.

추가 반환 가능:

current_level_order
current_level_name
current_level_color
next_level_order
next_level_name

단 실제 pool_levels 구조에 존재하는 범위만.

class_groups.level은
반 label로 별도 반환 가능하지만
학생 개인 레벨과 혼동 금지.

--------------------------------
E. ATTENDANCE SUMMARY
--------------------------------

Member Detail 즉시 표시용
가벼운 summary만 포함.

예:

current_month_attendance_count
current_month_absence_count

또는 현재 attendance schema에 맞는
최소 summary.

전체 attendance history를
detail endpoint에 넣지 마십시오.

--------------------------------
F. MAKEUP SUMMARY
--------------------------------

전체 보강 목록을 넣지 않고:

makeup_count
pending_makeup_count
available_makeup_count

등 실제 의미가 명확한 count만.

현재 endpoint/API 의미를 조사해서
정확한 count만 추가.

임의 추론 금지.

--------------------------------
G. PARENT ACCOUNT SUMMARY
--------------------------------

연결된 parent account가 있으면
관리자 Member Detail에서 표시 가능한
최소 summary 반환.

예:

parent_account_linked
parent_account_id
parent_account_name

민감 인증정보 반환 금지.

--------------------------------
H. STATUS METADATA
--------------------------------

현재 실제 status:

active
withdrawn
deleted
archived
pending_status_change

및
final-withdraw/access_blocked 관련 metadata가 있다면
기존 값을 그대로 노출.

새 status enum 창작 금지.

5. current_level_order 처리
==================================================

현재:

students.current_level_order

는 raw SQL + auto migration으로 실제 사용 중.

이번 WP에서는:

DB column 추가 migration 금지
schema 구조 대규모 변경 금지

다만 API/type에서는
정식 field로 선언.

Drizzle schema가 실제로 없는 구조라면
억지로 ORM migration 만들지 말고
현재 raw SQL architecture를 존중.

8. DATA LOADING PRINCIPLE
==================================================

detail endpoint에 넣을 것:

- 기본정보
- 현재 수강정보
- 현재 레벨
- guardian summary
- 이번 달 attendance summary
- makeup summary

detail endpoint에 넣지 않을 것:

- 전체 출결 이력
- 전체 일지
- 전체 사진
- 전체 영상
- 전체 성장리포트
- 전체 로그
- 전체 보강 이력

이런 데이터는 lazy/전용 endpoint 유지.
