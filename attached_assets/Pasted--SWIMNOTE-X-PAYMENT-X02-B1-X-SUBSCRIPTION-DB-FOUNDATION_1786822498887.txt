3. DISCOUNT PERIOD
==================================================

기존 X 정책:

선착순 할인은 36개월 고정.

따라서 slot record가 향후 다음을 보관할 수 있어야 한다.

discount_started_at
discount_ends_at

구매 전 RESERVED 상태에서는 NULL 가능.

실제 결제 성공 시 향후 X02-C에서:

discount_started_at = purchase activation time
discount_ends_at = discount_started_at + 36 months

로 기록할 수 있게 schema만 준비.

standard tier는 discount 기간이 필요 없으므로 NULL 허용 가능.

이번 WP에서는 계산/worker/product change 구현 금지.

7. WHY RC TRANSACTION FIELDS ARE REQUIRED
==================================================

다른 pool도 같은:

com.swimnote.x.monthly.tier1

등 product를 사용한다.

따라서 product_id만으로
구매 원래 pool을 식별할 수 없다.

향후 INITIAL_PURCHASE/sync 성공 시:

slot
↔ pool
↔ purchaser user
↔ RevenueCat customer
↔ original transaction

을 고정해서 저장할 수 있어야 한다.

Webhook renewal/expiration에서도
현재 users.swimming_pool_id만 신뢰하지 않고
기존 transaction binding으로 원래 pool을 찾을 수 있게 준비한다.

이번 WP에서는 webhook code 수정 금지.
