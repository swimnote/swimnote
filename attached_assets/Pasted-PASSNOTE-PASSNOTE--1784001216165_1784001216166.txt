PASSNOTE 신규 정책 검증 요청

아래는 PASSNOTE의 최신 보안 및 전달 정책입니다.

서비스 철학은

"온라인 등기우편"

입니다.

사업성보다

운영 안정성

법적 리스크

보안

UX

측면에서 집중적으로 검토해 주세요.

==================================================
1. 전달 완료 정책
==================================================

PASSNOTE는

다운로드와

수령 완료를

다른 개념으로 정의합니다.

다운로드 완료

=

기술적으로 파일이 정상 저장됨

수령 완료

=

수신자가 파일을 확인하고
전달을 완료했다고 승인

==================================================
2. 수령 완료 대기 정책
==================================================

다운로드 완료 후

수령 완료를 하지 않으면

24시간 동안

원본을 추가 보관합니다.

24시간 동안

언제든

수령 완료

또는

추가 다운로드

가능합니다.

24시간이 지나면

자동 삭제됩니다.

자동 삭제 시

상태는

"수령 미확인 자동 만료"

로 기록됩니다.

수령 완료로

자동 처리하지 않습니다.

==================================================
3. 수신자 안내
==================================================

다운로드가 완료되었습니다.

파일이 정상적으로 열리는지 확인해 주세요.

PASSNOTE는

원본 파일의 장기 보관으로 인한

유출 위험을 줄이기 위해

수령 완료 후

서버의 원본 파일을 즉시 삭제합니다.

파일이 정상이라면

[수령 완료]

를 눌러주세요.

==================================================
푸시 알림
==================================================

수령 완료를 눌러야

발신자가

전달 완료를 확인할 수 있으며

원본 파일을

안전하게 삭제할 수 있습니다.

[수령 완료]

버튼을 누르면

해당 전송 화면으로

즉시 이동합니다.

==================================================
4. 불법 콘텐츠 대응 정책
==================================================

PASSNOTE는

불법 콘텐츠에 대해

Zero Tolerance 정책을 운영합니다.

업로드 시

자동 보안 검사를 수행합니다.

적용 예정

- 실행 파일 정책 검사

- MIME Type 검사

- 파일 확장자 검사

- 악성코드 검사

- 적용 가능한 범위의

불법 콘텐츠 Hash 비교

- 비정상 업로드 패턴 탐지

==================================================
신고 시스템
==================================================

수신자 신고

↓

운영자 검토

↓

계정 이용 제한

↓

반복 위반

↓

영구 이용 제한

==================================================
업로드 정책
==================================================

업로드 전

이용자는

다음 사항에 동의합니다.

□ 본 파일은

관련 법령 및

저작권을 침해하지 않습니다.

□ 불법 콘텐츠 업로드 시

계정 이용이 제한될 수 있습니다.

==================================================
Zero Tolerance
==================================================

불법 콘텐츠가

확인되거나

적법한 신고가 접수되는 경우

PASSNOTE는

- 계정 이용 제한

- 계정 영구 이용 제한

- 필요한 기록 보존

- 적법한 절차에 따른

관계 기관 협조

등 필요한 조치를

진행할 수 있습니다.

==================================================
5. 원본 파일 정책
==================================================

PASSNOTE는

원본 파일의

장기 보관으로 인한

유출 위험을 줄이기 위해

수령 완료 후

서버의 원본 파일을

즉시 삭제합니다.

수령 완료가 없는 경우

24시간 추가 보관 후

자동 삭제합니다.
