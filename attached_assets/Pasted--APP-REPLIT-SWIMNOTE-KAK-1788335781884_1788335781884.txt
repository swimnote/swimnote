============================================================

------------------------------------------------------------
A. 관리자
------------------------------------------------------------

관리자 계정은 카카오 신규가입 불가.

관리자 범위:
- pool_admin
- 향후 관리자 계정으로 취급되는 운영자 역할

관리자는 일반 계정만 사용.

카카오로 관리자 가입을 시도하면:

"관리자 계정은 PC 모드 연동으로 인해 소셜계정 가입이 불가합니다.
일반 계정으로 가입해 주세요."

를 표시.

기존 관리자 카카오 계정을 새로 만들거나
기존 일반 관리자 계정에 Kakao provider를 신규 연결하지 않는다.

중요:
이미 Production에 기존 관리자 Kakao 연결이 있다면
임의 삭제/해제 금지.
기존 로그인 호환성만 유지.

------------------------------------------------------------
B. 선생님
------------------------------------------------------------

Kakao 계정 1개
=
SWIMNOTE 사용자 계정 1개

원칙.

한 Kakao provider_id/kakao_id는
하나의 SWIMNOTE user에만 연결 가능.

이미 연결된 Kakao 계정을 이용해
다른 SWIMNOTE 계정을 새로 생성하거나
다른 수영장용 두 번째 계정에 연결:
금지.

선생님이 두 번째 수영장에 가입해야 하면:
일반가입으로 진행.

안내 문구:

"이미 SWIMNOTE 계정에 연결된 카카오 계정입니다.
다른 수영장에 추가 가입하려면 일반가입을 이용해 주세요."

------------------------------------------------------------
C. 학부모
------------------------------------------------------------

선생님과 동일하게:

Kakao 계정 1개
=
SWIMNOTE 사용자 계정 1개

이미 연결된 Kakao 계정으로
두 번째 SWIMNOTE 계정 생성:
금지.

두 번째 수영장 가입이 필요한 경우:
일반가입으로 진행.

일반가입 사용.

7. phone fallback과 kakao_id 우선순위
============================================================

기존 로그인 흐름을 최대한 유지.

원칙:

1순위:
kakao_id direct hit

2순위:
기존 phone match로 최초 1회 link

3순위:
계정 없음 → 신규가입/link 화면

단,
phone match 단계에서
이미 해당 Kakao ID가 다른 SWIMNOTE user에 연결되어 있으면
새 link 금지.

중복 provider 생성 방지.
