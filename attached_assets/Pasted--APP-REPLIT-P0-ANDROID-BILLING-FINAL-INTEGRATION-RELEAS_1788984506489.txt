2. OFFERING / PACKAGE 확인
━━━━━━━━━━━━━━━━━━━━━━

앱에서 실제 사용하는 identifier 확인.

일반:
Offering = swimnote_monthly
Package = swimnote

X:
Offering = x_monthly

Packages:
x300
x500
x1000

Android에서도 iOS와 동일 package identifier로
platform-specific product를 RevenueCat이 반환해야 함.

앱 코드에서 Apple product ID를 직접 비교해
Android 상품을 누락시키는 코드가 있는지 전수 확인.

금지 예:

product.identifier ===
"com.swimnote.x300.monthly"

만으로 Android 상품을 판별.

Android identifier는 Base Plan 때문에
`com.swimnote.x300.monthly:monthly`
형태일 수 있음.

가급적 package identifier / canonical product resolver 사용.
