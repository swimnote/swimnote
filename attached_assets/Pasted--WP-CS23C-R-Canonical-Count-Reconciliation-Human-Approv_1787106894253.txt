[WP-CS23C-R — Canonical Count Reconciliation, Human Approval & Live Runtime Closure]

목적:

CS23C의 Direct Answer Question Library 및 Matcher 구현은 승인한다.

다만 다음 두 사항을 Production 기준으로 최종 확정한다.

1. Canonical Answer 72개와 Production Knowledge row 수의 불일치 해소
2. Render Live 환경에서 Direct DB / GPT / Human 실제 Runtime 검증

이번 WP에서 신규 기능 개발은 하지 않는다.

1. CANONICAL COUNT 불일치 해결

26 + 43 = 69

support-canonical-answers.json을 실제 대조한다.

UNMAPPED

필수:

각 intent가 정확히 한 상태에만 속해야 한다.
