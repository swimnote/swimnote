# SWIMNOTE 2.1.0 — MESSENGER FILE ATTACH FIX + IOS OTA

대상:
관리자 / 선생님 메신저 공통

문제:
메신저에서 첨부 버튼 → "파일 첨부"를 눌렀을 때
iOS 실기기에서 DocumentPicker가 정상적으로 표시되지 않거나
아무 반응 없는 것처럼 보이는 현상 수정.

============================================================
현재 파일 첨부 구조
============================================================

현재 구조는 유지한다.

흐름:

첨부 메뉴
→ 파일 첨부
→ handleFileAttach
→ DocumentPicker.getDocumentAsync()
→ FormData
→ POST /messenger/send-attachment
→ multipart 업로드
→ Object Storage 저장
→ work_messages INSERT
   message_type = "attachment_file"
→ AttachFileBubble 렌더링

이 업로드 아키텍처는 변경하지 말 것.

============================================================
ROOT CAUSE
============================================================

현재 handleFileAttach에서:

setShowAttachMenu(false)

직후 바로

DocumentPicker.getDocumentAsync()

를 실행하고 있음.

iOS에서는 첨부 메뉴 Modal dismiss animation이 끝나기 전에
DocumentPicker를 호출하면 picker가 정상적으로 foreground에 뜨지 않고
백그라운드에서 호출되거나 무반응처럼 보일 수 있음.

============================================================
수정
============================================================

첨부 메뉴를 먼저 닫고,
Modal dismiss가 완료될 시간을 준 다음
DocumentPicker를 실행.

예시 흐름:

setShowAttachMenu(false);

await new Promise(resolve => setTimeout(resolve, 300));

const result = await DocumentPicker.getDocumentAsync(...);

중요:
300ms delay는 picker 호출 직전에만 적용.

업로드 로직 자체는 변경 금지.

============================================================
DocumentPicker
============================================================

기존 옵션 유지.

특히:
copyToCacheDirectory: true

유지.

사용자가 파일을 선택하면
기존 FormData 업로드 흐름으로 계속 진행.

취소하면:
- 에러 표시 금지
- 메시지 생성 금지
- 업로드 요청 금지
