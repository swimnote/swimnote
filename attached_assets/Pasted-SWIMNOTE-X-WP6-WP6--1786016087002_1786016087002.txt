### Confidence V1

다음 값을 WP6 V1 파일럿 기준으로 확정한다.

```ts
reviewThreshold = 0.50
status = "EXPERIMENTAL_V1"
```

정책:

* 0.50 이상인 후보만 응답에 포함
* 모든 후보의 `match_status`는 `"PENDING_REVIEW"`
* `AUTO_ACCEPTED` 사용 금지
* 교사 검토 없이 성장 기록 확정 금지
* 실제 운영 표본 축적 후 별도 WP에서 threshold 재조정
* 이번 값은 검증 완료된 인간 평가 기준이 아니라 초기 검색 후보 필터 기준임을 코드 주석에 명시
* 환경변수 override 금지
* 값 변경은 코드 버전 변경으로만 수행

따라서 `reviewThreshold=0.50 NEEDS_VERIFICATION`은 WP6 구현 차단사항에서 해제한다.

다만 출시 전 표본 검증 항목으로 계속 기록한다.

2. 환경변수 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

구현 전에 다음 환경변수를 설정한다.

### Replit

* `MATCH_TOKEN_SECRET`
* `MATCH_TOKEN_KEY_ID`

### Render

* `MATCH_TOKEN_SECRET`
* `MATCH_TOKEN_KEY_ID`

정책:

* `MATCH_TOKEN_SECRET`는 Replit과 Render에 각각 안전하게 설정
* 값 원문을 로그·보고서·코드·attached_assets에 출력 금지
* Repository에 하드코딩 금지
* `JWT_SECRET` fallback 금지
* `MATCH_TOKEN_KEY_ID` 초기값은 `v1`
* secret은 충분한 엔트로피의 무작위 값 사용
* 명령 출력에 secret이 노출될 수 있으면 명령 결과 원문 제출 금지
* 환경변수 존재 여부만 `SET / NOT_SET`으로 보고

Render와 Replit에서 동일 secret을 사용할지 별도 secret을 사용할지는 다음 원칙을 적용한다.

* 각 환경의 토큰을 해당 환경에서만 생성·검증한다면 환경별 별도 secret 사용
* Replit에서 발급한 token을 Render에서 검증해야 하는 테스트 구조라면 동일 secret 필요
* 현재 Production 앱은 Render API만 사용하므로 Render secret이 운영 기준
* Replit 개발 테스트는 Replit 내부에서 생성·검증 완료
* secret 값 자체는 사용자에게도 출력하지 않는다

환경변수 설정 후 서버 전체 코드를 수정하기 전에 다음만 확인한다.

```text
Replit MATCH_TOKEN_SECRET: SET
Replit MATCH_TOKEN_KEY_ID: SET
Render MATCH_TOKEN_SECRET: SET
Render MATCH_TOKEN_KEY_ID: SET
```

Render 값을 직접 검증할 수 없다면 임의로 SET이라고 보고하지 말고 `NOT_VERIFIED`로 중단한다.

3. 파일 존재 여부 최종 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

구현 전에 다음 명령을 실행한다.

```bash
for f in \
  artifacts/api-server/src/config/growth-confidence-config.ts \
  artifacts/api-server/src/config/ai-pricing.ts \
  artifacts/api-server/src/lib/curriculum-candidate-search.ts \
  artifacts/api-server/src/lib/curriculum-confidence.ts \
  artifacts/api-server/src/lib/match-token.ts \
  artifacts/api-server/src/routes/ai-v1.ts
do
  if [ -f "$f" ]; then
    echo "EXISTS $f"
  else
    echo "NOT_FOUND $f"
  fi
done
```

중요:

* 기존 파일이 존재하면 신규 생성으로 덮어쓰지 말고 수정
* 기존 파일 내용을 먼저 읽고 현재 export·import 사용처 확인
* `curriculum-candidate-search.ts` 또는 `curriculum-confidence.ts`가 이미 존재하면 기존 함수와 호출자를 보존하면서 수정
* 파일이 실제로 없을 때만 신규 생성
* 이름이 다른 대응 모듈이 존재하면 중복 파일 생성 금지
* 조사 결과와 최종 실제 수정 파일 분류를 보고서에 정정

이 확인에서 공식 설계와 중대한 충돌이 발견되면 구현하지 말고 중단한다.

5. 구현 고정 정책
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### student_ref

* `student_ref = students.id`
* 이름 기반 매핑 금지
* JWT pool 기준 DB 검증
* 검증되지 않은 학생은 curriculum match에서만 제외
* 기존 AI 일지 본문 생성은 유지
* 전체 요청 실패 금지

검증 조건:

```sql
students.id = requested student_ref
students.swimming_pool_id = JWT pool_id
students.deleted_at IS NULL
```

### class 검증

* 학생의 정규 `class_group_id` 일치 강제 금지
* 보강·다중반·임시 합류를 허용
* tenant는 pool 기준으로만 강제
* class_id는 수업 context로만 사용

### curriculum 검색

반드시 다음 조건을 모두 적용한다.

```text
student_curriculum_assignments.is_active = true
student_curriculum_assignments.deactivated_at IS NULL
student_curriculum_assignments.swimming_pool_id = JWT pool
curriculum_versions.is_active = true
curriculum_versions.swimming_pool_id = JWT pool
curriculum_versions.archived_at IS NULL
curriculum_items.is_active = true
curriculum_items.swimming_pool_id = JWT pool
```

### Confidence

```ts
version = "growth_conf_v1"
reviewThreshold = 0.50
match_status = "PENDING_REVIEW"
```

* 자동 승인 금지
* threshold 미달 후보는 응답 제외
* config validation 필수
* `NaN`, 비숫자, 0 미만, 1 초과 fail-fast

### candidate_id

```text
cand_ + randomBytes(16).toString("hex")
```

* 요청별 랜덤 ID
* DB PK를 앱에 candidate_id로 직접 노출 금지
* 서버 메모리 candidateMap 금지
* 실제 curriculum_item_id는 서명된 match_token payload 안에만 포함
* 앱이 향후 WP7 저장 요청에서 candidate_id와 match_token을 재전송

### match_token

* HMAC-SHA256
* 24시간 만료
* `MATCH_TOKEN_SECRET` 전용
* JWT_SECRET fallback 금지
* token 원문 로그 금지
* payload 로그 금지
* 학생 이름·전화번호 포함 금지
* 서명 비교는 `timingSafeEqual`
* 최대 길이 2048자
* Base64URL 3부분 구조
* token_id는 `tid_` + 128bit 랜덤값
* 전체 token을 DB에 저장하지 않음
* WP7에서 token_id만 `growth_events.match_token_id`에 저장

WP6에서 금지:

```text

TEACHER_ACCEPTED
TEACHER_REJECTED
DISCARDED
```
