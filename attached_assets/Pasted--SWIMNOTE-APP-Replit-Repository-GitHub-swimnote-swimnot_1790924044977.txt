6. 결과 처리
━━━━━━━━━━━━━━━━━━━━━━

ENGINE COMPLETE + 정상 성장리포트 결과:

→ 기존 growth-report result handler를 재사용
→ 신규 request 결과를 report에 정상 귀속
→ generated 정상 증가
→ original UNKNOWN 감사기록 보존
→ lineage 보존

ENGINE COMPLETE +
result.analysis_status = DATA_ACCUMULATING:

→ 기존 승인된
  INSUFFICIENT_EVIDENCE 처리 재사용

→ generated에는 포함하지 않음
→ insufficient_evidence 증가
→ original UNKNOWN history 보존

PROCESSING:

→ 새 분석을 다시 dispatch하지 않음
→ 동일 recovery_operation_id로 replay/status 확인 가능하게 유지

UNKNOWN:

→ unresolved 유지
→ 자동 retry 금지
→ 새 operation 자동 생성 금지
→ 추가 operator 승인이 있어야만 다음 reissue 가능

확정 retryable failure:

→ 기존 일반 recovery 정책에 맞게 실패 상태로 귀속
→ 이번 UNKNOWN reissue 함수가 임의로 재호출하지 않음

CONFLICT:

→ provider 호출 없이 오류 표시
→ identity/operator investigation 필요
