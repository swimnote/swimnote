각 report가 어떤 teacher와 연결되는지 정확히 추적하십시오.

확인:
- growth_reports 실제 columns
- teacher_user_id 존재 여부
- created_by 존재 여부
- class_id 존재 여부
- student_id만 존재하는지
- report 생성 시 teacher 정보가 저장되는지
- report_fact_package 등에 teacher source가 있는지

만약 report 자체에 teacher가 없다면:

student
→ report_period 당시 class
→ class teacher

로 찾아야 하는지 확인.

현재 active class를 쓰면 과거 report의 teacher와 달라질 수 있으므로
반드시 "해당 report 기간 당시 담당 teacher"를 판별할 수 있는지도 조사.

결론으로:
Growth Report like/comment notification recipient를
어떤 ID로 결정할지 하나로 확정하여 보고.
