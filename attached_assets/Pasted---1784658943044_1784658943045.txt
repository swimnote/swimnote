# 긴급 장애 조사 및 복구 — 관리자·선생님·슈퍼관리자 접속 불가

현재 학부모 앱은 실행되지만 다음 역할의 접속이 정상적으로 되지 않는 것으로 보입니다.

- 수영장 관리자
- 선생님
- 슈퍼관리자

이번 작업은 역할별 접속 장애 조사와 최소 복구만 진행합니다.

학부모 Home UI는 아직 수정하지 마세요.

========================================
작업 시작 전
========================================

현재 정상 학부모 화면 상태를 기준으로 Checkpoint를 생성하세요.

보고:

- Checkpoint ID
- Rollback 가능 여부

9. 초기 index route
10. 권한 검사

15. OTA 이후에만 발생하는 오류 여부
