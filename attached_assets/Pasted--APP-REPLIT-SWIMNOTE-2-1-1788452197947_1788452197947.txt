============================================================
1. TAB BUTTON HEIGHT 명시
============================================================

현재 chip style을 실제 source에서 확인 후
탭 버튼에 충분한 최소 높이를 명시.

권장 방향:

chip: {
  minHeight: 40~44,
  paddingHorizontal: 16,
  paddingVertical: 0,
  justifyContent: "center",
  alignItems: "center",
  borderRadius: 20,
  borderWidth: 1.5,
  flexShrink: 0,
  ...
}

핵심:

- 버튼 자체 minHeight 또는 height를 명시
- 텍스트를 세로 중앙 정렬
- Text가 들어갈 공간을 버튼 자체에서 보장

이번에는 parent 높이에 맡기지 말 것.

============================================================
2. TEXT 높이도 명시적으로 안전 확보
============================================================

chipTxt는 다음 원칙:

fontSize: 13
lineHeight: 18~20
fontWeight: "600"

그리고 필요하면:

includeFontPadding: false
textAlignVertical: "center"

를 iOS/RN 호환 범위에서 검토.

단,
fontSize를 줄여서 맞추는 방식 금지.

============================================================
3. CONTENT CONTAINER
============================================================

ScrollView:

- horizontal 유지
- contentContainerStyle에 paddingHorizontal 유지
- paddingVertical은 있어도 됨
- alignItems 추가 금지
- style prop으로 높이 축소시키는 flexGrow/flexShrink 사용 금지
