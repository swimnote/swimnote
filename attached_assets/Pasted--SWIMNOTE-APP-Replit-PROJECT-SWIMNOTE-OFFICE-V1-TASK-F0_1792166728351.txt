2. 설치 UX
- Windows 10/11 x64 대상, 실제 Windows 11 검증은 미완료 유지.
- 내부 검증용 unsigned installer.
- 사용자별 설치를 우선하고 관리자 권한을 요구하지 않는다.
- 바탕화면·시작 메뉴 실행 아이콘 제공.
- Windows 앱 목록에서 제거 가능.
- 설치 후 실행은 사용자 선택으로 제공.
- Windows 시작 시 자동 실행·자동업데이트 추가 금지.
- 인증정보·회원 데이터·개발 Secret을 설치 파일에 포함하지 않는다.
- 기존 실행본과 userData 식별·저장 위치 관계를 확인.
  임의 변경으로 기존 인증정보를 중복 저장하지 않는다.

3. 재설치·제거
- 기존 앱 실행 중 설치 처리와 중복 프로세스 방지 확인.
- 재설치 시 사용자 설정·인증정보 처리 정책을 명시.
- 제거 시 인증정보·설정의 보존/삭제 동작을 명시.
- 사용자 폴더나 다른 프로그램 파일을 광범위하게 삭제하지 않는다.
- 로그아웃의 token 삭제 정책 유지.
- 미서명 실행 경고가 나올 수 있음을 안내하되
  보안 기능 해제·관리자 실행·강제 우회를 요구하지 않는다.
- 고객용 공개 배포나 서명 완료로 표현하지 않는다.

4. 검증·빌드
- 기존 F05 통과 테스트 재사용.
- 패키징 변경에 필요한 검사·build만 수행.
- installer 생성 1회.
- EXE 아키텍처·설치 구성·포함 파일·source 식별 확인.
- 파일 크기·SHA-256 제공.
- 실제 Windows 설치·제거를 실행하지 못했다면
  정적 검증과 구분하여 미검증으로 보고.

- installer를 받기 위한 추가 설치 도구는 요구하지 않는다.
