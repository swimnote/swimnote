8. 실제 로그인 Runtime

→ HTTP 200

이번 대상과 직접 연관된 READ ONLY route가 있으면 우선:

- 휴일 조회

- 일정/메모 조회
- 학생 등록 요청 조회

route 추측 금지.

super_admin role 때문에 특정 route가
business-level 403이면
RLS 오류와 구분해서 보고.
