4. APP Local 파일 업로드
━━━━━━━━━━━━━━━━━━━━━━

APP FINAL IMPORT 파일을
기존 canonical X setup upload flow로 업로드:

POST /api/x-setup/upload/curriculum

→ Toykids pool 기준 신규 x_setup_files 생성
→ R2 저장
→ content_hash 기록

그 다음:

POST /api/super/x-setup/:poolId/structure

실행.

반드시 신규 Local curriculum_version 생성:

- is_global_reference=false
- swimming_pool_id=Toykids pool
- is_active=false
- import_status='DRAFT'
- source_content_hash 기록

기존 Global/Legacy version overwrite 금지.

5. REVIEW_REQUIRED 처리
━━━━━━━━━━━━━━━━━━━━━━

현재 파일 헤더:

CANONICAL_STATUS=REVIEW_REQUIRED

이므로 structure 후 자동 approve/activate 금지.

서버가 REVIEW_REQUIRED를 정상 인식하는지 확인.

검증:

- canonical node count
- level distribution
- review_required_count
- source trace
- canonical hash
- APP/AI match metadata

현재 파일 기준 예상:

canonical_node_count = 332
review_required_count = 161

레벨 미지정 항목이 존재하므로
status는 검토 필요 상태로 유지.

즉 이번 단계에서 REVIEW_REQUIRED 상태를
억지로 APPROVED로 변경하지 말 것.

━━━━━━━━━━━━━━━━━━━━━━
6. AI ENGINE 파일 검증
━━━━━━━━━━━━━━━━━━━━━━

APP 파일과 canonical identity가 동일한지 비교.

필수 비교:

- CANONICAL_HASH
- canonical_key set
- level_order
- stroke
- domain
- skill_group

- search_text
- aliases
- retrieval_metadata
- embedding_text
- source_hash

APP Canonical을 재해석/재분류 금지.
