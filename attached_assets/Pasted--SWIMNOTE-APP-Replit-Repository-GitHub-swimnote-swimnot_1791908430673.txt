4. 판정
━━━━━━━━━━━━━━━━━━━━━━

CASE A:

picker badge 순서와
result.assets 순서가 동일

→ iOS picker boundary PASS

이 경우 현재 선생님 전체앨범 직접 업로드의
canonical 경로에서는 순서가 깨질 지점이 없음.

따라서 실제 제보가:

- 다른 업로드 진입점
- 재시도
- 저장 개인앨범
- 일지 사진
- 기존 관리자 업로드
- 사용자가 기대한 촬영순서와 선택순서의 차이

중 어느 경로인지 다시 특정해야 함.

CASE B:

picker badge는 선택순서대로인데
result.assets 배열 순서가 다름

→ ROOT CAUSE 확정:

iOS native / expo-image-picker picker result boundary.

CASE C:

result.assets는 정상

→ 이번 진단에서는 client/server 수정 금지.
실제 제보자가 사용한 정확한 화면/경로를 다시 식별.
