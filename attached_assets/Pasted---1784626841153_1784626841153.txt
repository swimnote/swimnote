추가 버그가 있습니다.

현상:
- 학부모 모드로 로그인한 뒤 앱을 완전히 종료하고 다시 실행하면 로그아웃됩니다.
- 관리자 모드와 선생님 모드는 앱을 재실행해도 로그인 상태가 유지되는 것으로 보입니다.

요구사항:
학부모도 사용자가 직접 로그아웃 버튼을 누르기 전까지 로그인 상태가 유지되어야 합니다.

단, 아직 추측으로 수정하지 마세요.
먼저 관리자·선생님·학부모의 세션 저장 및 앱 시작 시 복원 흐름을 비교 조사하세요.

확인 항목:

1. 로그인 성공 후 토큰을 어디에 저장하는지
   - AsyncStorage
   - SecureStore
   - Zustand persist
   - 메모리 상태
   - 기타 저장소

2. 역할별로 저장하는 키 이름이 다른지

3. 학부모 로그인 성공 시 토큰 저장 코드가 실제로 실행되는지

4. 앱 시작 시 세션 복원 코드가 학부모 역할도 처리하는지

5. 학부모 사용자 정보 또는 activeChild 정보가 없다는 이유로
   강제 로그아웃시키는 코드가 있는지

6. 초기 라우팅 과정에서 parent 역할이 누락되어 있는지

7. 토큰은 남아 있지만 인증 확인 API 실패로 로그아웃되는지

8. access token 만료 시 refresh token 갱신 로직이 역할별로 다른지

9. 앱 시작 과정에서 다음 함수가 호출되는 순서
   - hydrate
   - restoreSession
   - validateToken
   - fetchCurrentUser
   - logout
   - router.replace

10. 개발용 초기화 코드 또는 앱 시작 시 storage clear 코드가
    학부모 세션 키만 삭제하는지
