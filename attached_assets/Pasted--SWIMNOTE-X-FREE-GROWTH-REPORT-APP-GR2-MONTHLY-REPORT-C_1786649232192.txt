==================================================
2. MONTHLY CYCLE CONCEPT
==================================================

각 report_period는:

YYYY-MM

예:

2026-08

Cycle은 해당 report_period의 Growth Report 작업단위.

중요:

report_period와
analysis window는 다른 개념.

analysis_from은 여전히 nullable.

GR2에서 임의로:

1일~말일
전월25일~당월24일

중 하나로 확정하지 마라.

==================================================
3. 25TH OPEN RULE
==================================================

매월 25일
Asia/Seoul 00:00 기준 이후:

해당 report_period Cycle을 ACTIVE로 전환 가능.

관련 Product Reports:

NOT_OPEN
→ OPEN

필요 시 생성.

Parent Input:

NONE
→ AVAILABLE

가능.

중요:

25일 이전에는 OPEN 금지.

==================================================
4. 5TH CLOSE RULE
==================================================

다음달 5일
Asia/Seoul 00:00 기준:

해당 Cycle:

ACTIVE
→ INPUT_CLOSED

Parent Input:

AVAILABLE
→ CLOSED

ANSWERED
→ CLOSED

NONE인 경우 정책에 따라 CLOSED 가능.

하지만 Product Report는 닫지 않는다.

특히 금지:

product_status=CLOSED

존재하지 않음.

==================================================
5. QUESTION_AVAILABLE HANDLING AT CLOSE
==================================================

5일 Parent Input Close 시:

product_status = QUESTION_AVAILABLE

인 Report는:

READY_FOR_ANALYSIS

로 전환.

즉 Parent가 답하지 않았더라도
Engine 분석 계속 진행 가능.

Parent answer가 이미 있으면
역시 READY_FOR_ANALYSIS로 갈 수 있음.

==================================================
13. IDEMPOTENCY
==================================================

Scheduler는 동일 날짜에 여러 번 실행돼도
중복 Cycle/Report/상태변경이 생기지 않아야 한다.

예:

25일 job 3회 실행
→ Cycle 1개
→ 동일 Report 중복 없음

5일 close job 3회 실행
→ 상태 중복오류 없이 동일 최종상태

==================================================
14. MISSED RUN RECOVERY
==================================================

Scheduler가 25일 00:00에 정확히 못 돌 수 있다.

예:

25일 서버 다운
→ 26일 복구

이 경우 missed open을 회복해야 한다.

즉 exact timestamp equality에만 의존 금지.

조건:

now >= open_at
AND cycle still PENDING

→ ACTIVE 가능.

동일하게:

now >= close_at
AND cycle ACTIVE

→ INPUT_CLOSED 가능.
