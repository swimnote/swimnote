0. ABSOLUTE PRINCIPLE — EXISTING FUNCTION REUSE ONLY
==================================================

이번 WP에서 가장 중요한 원칙:

"새 기능을 만드는 것이 아니라
기존 기능을 Student Detail에 연결한다."

- 어떤 API를 호출하는지

확인 후 그대로 재사용.

기존 기능과 비슷해 보이는
새 endpoint 생성

새로운 status enum 생성

실제 운영 데이터가 안 바뀌는 fake update
