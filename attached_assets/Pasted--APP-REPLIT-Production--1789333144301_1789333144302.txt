11. 최소 테스트
━━━━━━━━━━━━━━━━━━━━━━

A.
수업피드에 부모가 좋아요

→ DB active reaction 존재
→ 교사 notification 존재
→ 홈 새 소식 표시
→ 전체 알림함 표시
→ reaction detail 좋아요 1명

B.
같은 좋아요를 다시 조회

→ 중복 좋아요/중복 count 없음

C.
좋아요 취소

→ active reaction count 감소
→ reaction detail 현재값 정상

D.
수업피드 댓글

→ 기존 기능 정상

E.
AI 성장리포트 좋아요

→ reaction 저장
→ 관련 teacher notification
→ teacher inbox
→ reaction detail 또는 대응하는 반응 화면에서 표시

F.
AI 성장리포트 좋아요 취소

→ 현재 reaction count 정상 감소

G.
다른 수영장 teacher

→ 다른 pool의 좋아요 접근 불가

H.
다른 학생/다른 날짜/다른 feed가 섞이지 않음

특히 H 중요:

날짜가 같아도 content_id가 다르면
잘못된 좋아요를 가져오면 안 됩니다.
