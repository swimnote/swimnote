SWIMNOTE X 개발 재개 — WP6 AI Diary Pipeline V2 최종 구현 전 조사·설계

SWIMNOTE 일반 앱 버그 수정과 보강 배정 회귀검증이 종료되었으므로 SWIMNOTE X 개발을 재개한다.

재개 기준점:

* WP1 DB Migration 완료
* WP2 X모드 상태·권한 Backend 완료
* WP3 앱 ModeContext 완료
* WP4 X 외형·메뉴·Route Guard 완료
* WP5 POOL_B true/READY 설정 및 공식 로그인·Mode API 검증 완료
* 보강 배정 오류는 현재 Production에서 RESOLVED_CURRENT_VERSION / CANNOT_REPRODUCE로 종료
* 진단 패널은 별도 승인 전까지 유지
* POOL_B 상태는 true/READY 유지
* WP5 teacher·parent 실계정 동적 검증은 출시 전 QA 항목으로 보존

다음 공식 작업은 WP6 AI Diary Pipeline V2다.

이번 단계에서는 코드를 구현하지 않는다.
