[수정 승인 — Story Summary parent student notes SQL 500 수정]

원인 확정:

story.ts parent_account 분기에서

student_id = ANY(${studentIds}::text[])

사용 시 Drizzle sql template이 JS 배열을 PostgreSQL array가 아니라
ROW 형태 ($1, $2)로 직렬화하여 SQL ERROR 발생.

결과:
parent_account 정상 권한 diary → HTTP 500
super_admin → 해당 query 미실행 → 정상 200

이번 수정은 이 SQL 1곳만 최소 수정한다.

━━━━━━━━━━━━━━━━━━━━━━
1. 수정 대상
━━━━━━━━━━━━━━━━━━━━━━

파일:

artifacts/api-server/src/routes/story.ts

현재:

WHERE diary_id = ${diaryId}
  AND student_id = ANY(${studentIds}::text[])
  AND is_deleted = false

이 부분을 Drizzle에서 안전한 IN 조건으로 변경한다.

예:

student_id IN (${sql.join(studentIds.map(id => sql`${id}`), sql`, `)})

단 현재 프로젝트의 Drizzle/sql helper 사용 방식에 맞춰 구현.

문자열 직접 조합 금지.
SQL injection 위험 있는 interpolation 금지.

━━━━━━━━━━━━━━━━━━━━━━
2. studentIds 빈 배열 보호
━━━━━━━━━━━━━━━━━━━━━━

studentIds.length === 0이면
IN () 쿼리를 만들지 않는다.

정책:

parent visibility는 이미 통과했더라도
조회 가능한 student note 대상이 0명이면
student note query를 skip하고
공통 일지만으로 summary 생성 가능해야 한다.

예:

let studentNotes = [];

if (studentIds.length > 0) {
  // IN (...) query 실행
}

빈 배열 때문에 500 발생 금지.
