1. 가장 중요한 아키텍처 규칙
============================================================

AI Engine이 APP 운영 DB를 직접 조회하지 않습니다.

금지:

POST /paid-report/questions/:studentId
→ AI Engine이 studentId로 APP DB 조회

같은 구조.

정상 구조:

SWIMNOTE APP
→ APP API Server
→ APP auth / parent-child / pool 검증
→ APP가 GrowthDataSnapshot 생성
→ Server-to-Server
→ AI ENGINE
→ 분석 결과 반환

AI Engine의 student_id는
추적용 reference일 수는 있지만
운영 DB 조회 key가 아닙니다.

============================================================

생활/환경/반응 맥락을 보충.

- 설명을 들을 때 반응

- 반복 연습에 대한 반응
- 실패 후 다시 시도하는 방식
- 가정에서 아이가 말한 수업경험

등을
실제 evidence gap과 연결.

AI가 무작위 질문목록을 생성하면 FAIL.
