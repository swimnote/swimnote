[앱] X모드 학부모 설정 — 1차 화면 UI 정리 ONLY

이번 작업은 기능 통합이 아니라
설정 첫 화면의 UI/정보 구조 정리만 진행합니다.

중요:
- 기존 메뉴 기능 삭제 금지
- 기존 route 삭제 금지
- 문의 기능 통합 금지
- API/DB 수정 금지
- 세부 설정 화면 기능 변경 금지
- 이번에는 "첫 화면에서 어떻게 보이게 할지"만 변경

1. 목표
━━━━━━━━━━━━━━━━━━━━━━

현재 X모드 학부모 설정 화면은
모든 기능이 큰 카드로 길게 나열되어 있어
설정 항목이 너무 많고 중요도 구분이 어렵습니다.

쿠팡 "내정보관리/설정" 화면처럼:

- 상단 계정 요약
- 자주 쓰는 설정
- 큰 분류 메뉴
- 하단 앱 정보

구조로 단순화하십시오.

설정은 화려하게 만들지 말고
익숙하고 빠르게 찾을 수 있는 UI가 우선입니다.

현재 큰 프로필 카드보다
쿠팡식으로 더 compact하게 정리.

표시:

서경민님
토이키즈스윔클럽 · 자녀 1명

우측 chevron >

탭:
기존 내 정보/프로필 화면으로 이동.

사진/프로필 아바타는
작은 line icon 또는 기존 avatar 정도만.

큰 Hero 프로필 카드 금지.

4. "자주 쓰는 설정" 섹션
━━━━━━━━━━━━━━━━━━━━━━

첫 화면에 바로 노출할 메뉴 3개:

1. 알림 설정
subtitle:
공지 · 수업피드 · 사진 · 좋아요 · 댓글

2. 자녀 관리
subtitle:
연결된 자녀 1명

3. 수업 요청
subtitle:
결석 · 연기 · 퇴원 · 상담 신청

각 항목은 큰 카드가 아니라
쿠팡식 row:

[icon] 메뉴명
       subtitle                         >

형태.

row 사이 얇은 divider.

하나의 section container 안에 3개 row.

5. 큰 분류 메뉴
━━━━━━━━━━━━━━━━━━━━━━

그 아래는 세부 설정을 직접 나열하지 말고
큰 분류 4개로 정리.

A. 계정 및 가족
subtitle:
내 정보 · 보호자 · 로그인/보안

B. 알림 및 소식
subtitle:
푸시 알림 · 공지 · 알림함

C. 수업 및 수영장
subtitle:
수업 요청 · 등록 수영장

D. 도움말 및 문의
subtitle:
AI 문의 · 고객센터 · 약관

중요:
이번 작업에서는
실제 세부 메뉴를 합치거나 route를 변경하지 마십시오.

분류 row tap 시:
현재 연결 가능한 기존 화면/메뉴로 들어갈 수 있는
최소 navigation shell만 구성 가능.

세부 기능 재구성은 다음 단계.

6. 현재 메뉴 보존
━━━━━━━━━━━━━━━━━━━━━━

현재 존재하는 메뉴:

- 부모 정보 수정
- 자녀 관리
- 추가 보호자 관리
- 수업 요청
- 공지함
- 푸시 알림 설정
- AI 문의
- 문의하기(기존)
- 이용약관
- 개인정보처리방침
- 로그아웃
- 회원 탈퇴

기능/route는 모두 보존.

이번에는 첫 화면에서 직접 노출되는 항목 수만 줄이는 것.

중복 문의 통합은 이번 작업에서 하지 않음.

7. 디자인
━━━━━━━━━━━━━━━━━━━━━━

쿠팡 설정 UI의 익숙한 구조를 참고.

기본:

- background: white 또는 매우 연한 neutral
- section title: dark navy/charcoal
- row: white
- divider: neutral #E5E7EB 계열
- icon: navy/charcoal line icon
- chevron: gray
- shadow: 거의 없음
- radius: 최소 또는 section container 정도만
- mint/cyan 사용 최소화

현재처럼 모든 메뉴를
개별 큰 rounded card로 만들지 말 것.

설정 화면에서는
"카드 디자인"보다 "목록 구조" 우선.
