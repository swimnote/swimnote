CASE 1 — 사진 1장

확인:
- 사진이 Story의 주인공으로 크게 보임
- 담당 선생님 이름 없음
- 반 이름 없음
- 날짜 간결
- 한줄평 2~3줄
- footer:
  수영장 이름 / SWIMNOTE
- Instagram Composer 정상

CASE 2 — 사진 4장

확인:
- 4장이 자연스러운 collage
- 버튼/카드 느낌 없음
- 사진 영역 충분히 큼
- 한줄평 과하지 않음

CASE 3 — 사진 10장

확인:
- 10장 모두 실제 표시
- +N 없음
- 5×2 collage 정상
- 사진이 지나치게 작거나 알아보기 어려운지 확인
- 세로사진 crop이 과도하지 않은지 확인
- 한줄평 2~3줄
- footer 정상
- Story 1장

CASE 4 — 긴 원문

확인:
- 긴 보고서형 summary 아님
- 자상한 선생님 한마디 느낌
- 원문 사실 왜곡 없음
- 90자 안팎
- 잘림 없음

CASE 5 — 브랜드

확인:
- 수영장 이름 충분히 읽힘
- 중앙 광고 타이틀처럼 보이지 않음
- footer 좌측에 자연스럽게 위치
- SWIMNOTE 우측 branding 또렷함
- 네이비 충분한 contrast
