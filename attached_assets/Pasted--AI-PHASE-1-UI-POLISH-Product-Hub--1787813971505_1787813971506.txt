2. 전체 X 톤앤매너 polish
━━━━━━━━━━━━━━━━━━━━━━

현재 pale cyan / mint outline이
여러 card에 반복되어 일반 SWIMNOTE 느낌이 남아 있음.

수정:

- NAVY / WHITE / NEUTRAL 중심
- cyan/mint border 반복 최소화
- 카드 border는 neutral gray 중심
- mint는 완료 상태 dot/check 정도만
- amber는 미완료 상태 정도만
- 큰 cyan outline/card chrome 제거

특히:

- 분석 준비
- 정보 준비
- 어떤 리포트가 나오나요?
- 가격/CTA
- 내 리포트

각 카드가 전부 같은 청록 outline으로 보이지 않게 정리.

3. Hero 상품 소개 강화
━━━━━━━━━━━━━━━━━━━━━━

Hero는 현재 구조 유지하되
상품 가치가 더 강하게 전달되도록 문구 보강.

정식 제목:

AI 인사이트 전략 리포트

메인 설명:

수업 기록과 누적 성장 데이터,
학부모가 제공한 관찰정보를 함께 분석해
아이의 성장 신호와 잘 되는 조건,
다음 성장 전략을 더 깊게 분석합니다.

특징 pill은 현재 4개 유지 가능:

- 1회 심층 분석
- 누적 데이터 기반
- 여러 성장 영역 종합
- 근거 있는 항목만

단 pill이 너무 장식처럼 보이지 않게
neutral/navy tinted style로 정리.

━━━━━━━━━━━━━━━━━━━━━━
4. 상품 가치 핵심 카피 추가
━━━━━━━━━━━━━━━━━━━━━━

"평가항목은 넓게,

과한 마케팅 배너처럼 만들지 말고

5. "330개 심층 평가항목" 소개 추가
━━━━━━━━━━━━━━━━━━━━━━

분석에 활용되는 정보 영역 안에
compact row 또는 accordion item 추가.

제목:

330개 심층 평가항목

설명:

수영기술, 운동학습, 집중·자기조절,
학습태도, 자신감, 회복탄력성,
신체협응, 균형·운동능력 등
아이의 성장과 관련된 약 330개의 평가 후보항목을 폭넓게 검토합니다.

반드시 추가 설명:

330개 항목 모두에 점수를 매기는 방식이 아닙니다.

실제 수업 기록과 누적 데이터에서
근거가 확인되는 항목만 선별해
아이에게 의미 있는 성장 신호를 리포트에 반영합니다.

중요:
330 숫자를 Hero에 크게 과장 표시하지 말 것.
상세 설명 영역에서 신뢰감 있게 설명.

━━━━━━━━━━━━━━━━━━━━━━
6. 전문 평가체계 기반 설명 추가
━━━━━━━━━━━━━━━━━━━━━━

같은 상세 설명 영역 또는
ReportPreviewSheet 안에 다음 section 추가.

제목:

전문 평가체계를 AI 분석으로 연결합니다

본문:

AI 인사이트 전략 리포트의 평가항목은
SWIMNOTE가 임의로 만든 질문만으로 구성하지 않습니다.

아동·학습·행동·운동 분야에서 사용되는
전문적인 평가 지표와 관찰 기준을 참고하고,

SWIMNOTE AI가 실제 수업 기록과
누적 성장 데이터를 분석한 뒤,
OpenAI GPT를 활용한 교차 검증 단계를 거쳐
근거가 있는 내용만 부모용 인사이트로 정리합니다.

금지 표현:

- OpenAI 인증
- OpenAI 공식 검증
- OpenAI가 직접 평가
- OpenAI가 보증

정확한 표현:

"OpenAI GPT를 활용한 교차 검증"
또는
"OpenAI GPT를 활용한 검증 단계"

━━━━━━━━━━━━━━━━━━━━━━
7. 행동·학습 분석 가치 강화
━━━━━━━━━━━━━━━━━━━━━━

"어떤 리포트가 나오나요?" BottomSheet 안에
다음 설명 추가.

제목:

수영 기록을 넘어,
아이가 배우는 방식까지

본문:

일반적인 수영 리포트가
영법이나 기록 중심으로 끝나는 것과 달리,

AI 인사이트 전략 리포트는
수업 중 반복되는 행동,
새로운 과제를 받아들이는 방식,
집중과 자기조절,
성공했을 때의 조건,
어려움 이후 다시 적응하는 과정까지
누적 수업 데이터 안에서 함께 살펴봅니다.

이를 통해:

- 무엇을 잘했는가
- 어떤 조건에서 더 잘 배우는가
- 어떤 방식으로 성장하고 있는가
- 다음 수업에서 무엇을 우선해야 하는가

까지 연결된 인사이트를 제공합니다.
