SWIMNOTE X — WP5 일반/X 1차 격리검증 설계 조사 지시

WP4는 코드·Origin 저장·정적 검증 완료로 승인합니다.

현재 미검증 상태:

자동화 테스트: NOT_TESTED
실기기 X UI: NOT_TESTED
Direct Link 차단: NOT_TESTED
일반/X 실제 전환: NOT_TESTED

이 항목들은 WP5 일반/X 1차 격리검증에서 확인합니다.

이번에는 WP5를 구현하지 말고, 실제 Repository와 현재 환경을 조사하여 WP5 실행 설계서만 제출하십시오.

잘못된 역할 → 해당 역할 홈
로그인 없음 → 인증 흐름

━━━━━━━━━━━━━━━━━━━━━━

실행은 최소 단계로 나누십시오.

예시:

WP5-A
안전한 POOL_A·POOL_B와 계정 확정
WP5-B
읽기 전용 기준선 캡처
WP5-C
사용자 승인 후 POOL_B X 상태 변경
WP5-D
Mode API·앱 역할별 검증
WP5-E
수영장·계정 전환 격리 검증
WP5-F
일반모드 핵심 Smoke Test
WP5-G
DB·Audit 사후 검증
WP5-H
상태 원복 또는 샘플 유지 결정

더 단순한 단계가 가능하면 제안하십시오.

19. 실패 시 중단 조건
━━━━━━━━━━━━━━━━━━━━━━

* 실제 운영 pool이 테스트 대상으로 선택됨

* 다른 pool의 X 상태가 변경됨
* 일반모드에서 X 메뉴 노출
* normal에서 x-growth 접근 허용
* x_pending에서 x-growth 접근 허용
* pool 전환 후 이전 X UI 잔존
* 다른 pool 데이터 노출
* DB 예상 외 row 생성
* audit 누락
* 앱 크래시
* 로그인 불가
* 기존 AI 일지 실패
