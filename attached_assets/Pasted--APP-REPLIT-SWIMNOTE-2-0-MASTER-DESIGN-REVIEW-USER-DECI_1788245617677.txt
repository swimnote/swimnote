1. LEGACY 구독자 정책 확정
==================================================

기존 Coach / Premier 구독자는
GRANDFATHERING 정책으로 유지합니다.

정책:

- 기존 Coach/Premier 구독자는 현재 구독이 유지되는 동안 기존 상품/가격/권한 유지
- 기존 legacy 상품은 신규 판매만 종료
- 기존 사용자가 해지/만료하면 기존 legacy 상품으로 재가입 불가
- 해지/만료 이후 재가입은 신규 SWIMNOTE / X 상품만 가능
- 기존 사용자가 X 신규 상품을 별도로 구매하는 것은 허용
- 기존 legacy entitlement / plan_id / tier_group / includes_video / subscription_tier 계약은 1.6.3 호환을 위해 유지

즉:

LEGACY SUBSCRIBER
→ 기존 구독 유지 가능

LEGACY CANCEL / EXPIRE
→ 기존 상품 재가입 불가
→ 신규 SWIMNOTE/X만 가입 가능

이 정책으로 LOCK 준비하십시오.

2. SWIMNOTE 회원수 무제한 정책 확정
==================================================

일반 SWIMNOTE는 사용자 표시상:

회원수 무제한

으로 확정합니다.

현재 member_limit=NULL 시 fallback=5 문제가 있으므로
2.0 구현에서는 기존 공통 로직을 위험하게 변경하지 않고
내부 기술값으로 충분히 큰 숫자를 사용합니다.

확정:

SWIMNOTE member_limit = 999999

UI/상품표시:

회원수 무제한

중요:

- 사용자에게 999999 노출 금지
- 기존 1.6.3 member_limit 숫자 기반 UI와 충돌하지 않게 유지
- 공용 NULL 의미 재정의는 하지 않음

3. STORAGE SOURCE OF TRUTH 확정
==================================================

추가 저장공간의 단일 Source of Truth는:

swimming_pools.extra_storage_gb

로 확정합니다.

향후:

effective_storage_gb
=
base_plan_storage_gb
+
swimming_pools.extra_storage_gb

로 통일합니다.

기존:

pool_subscriptions.extra_storage_gb

는 authoritative source로 사용하지 않습니다.

기존 값이 존재하면
WP2A에서 migration/backfill/동기화 방법을 검토하여
swimming_pools.extra_storage_gb 기준으로 통합하십시오.

4. STORAGE 사용량 계산 정책 확정
==================================================

저장공간 사용량은
사진과 영상을 통합해서 계산해야 합니다.

확정:

used_storage_bytes
=
photo bytes
+
active video bytes

현재 uploads.ts의 photo-only 계산은 수정 대상입니다.

중요:

- 사진/영상이 각각 따로 quota를 소비하는 구조 금지
- 같은 pool의 전체 미디어 저장량을 하나의 quota로 계산
- DATA100 / DATA300도 동일 quota에 적용
- thumbnail 용량 포함 여부는 현재 구조 유지 가능
- orphan/soft-delete는 기존 정책에 맞게 active 자산 중심으로 계산

5. VIDEO RETENTION 정책 최종 확정
==================================================

영상 저장기간은:

14일

로 최종 확정합니다.

현재 구현:

expires_at = NOW() + 14 days

정책을 유지합니다.

즉:

VIDEO RETENTION = 14 DAYS — LOCKED

중요:

- 영상 영구보관으로 변경하지 않음
- 7일로 변경하지 않음
- 14일 유지
- 14일 후 기존 cleanup/expire 정책에 따라 만료
- 만료된 영상은 storage quota에서 제외
- 기존 사진 보관정책은 변경하지 않음
