**AUDIT ONLY — 코드 수정 금지**

계산 대상 Pool:

* 회원: 300명

A. 기본 SWIMNOTE 플랜만 사용하는 경우
B. 동일 Pool이 SWIMNOTE X까지 사용하는 경우

11. FULL-USAGE 정의
━━━━━━━━━━━━━━━━━━━━━━

“풀로 사용”을 임의 해석하지 마십시오.

각 기능마다 다음 중 하나로 표시하십시오.

A. HARD LIMIT

* 코드상 월/일/회원 한도가 존재

B. STORAGE LIMITED

* 별도 횟수 제한은 없으나 storage quota가 한계

C. UNLIMITED

* 코드상 횟수 제한 없음

D. UNKNOWN

* 현재 코드만으로 최대 사용량 정의 불가

C 또는 D이면 하나의 가짜 최대비용을 만들지 말고:

* 단위비용
* 사용량별 공식
* LOW / EXPECTED / HEAVY / EXTREME 시나리오

를 제출하십시오.
