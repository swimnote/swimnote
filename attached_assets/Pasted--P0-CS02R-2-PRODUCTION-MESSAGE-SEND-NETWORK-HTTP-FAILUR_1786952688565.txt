11. FIX RULE

12. ERROR UX도 정확히 보정
========================================

실제 root cause 수정 후
generic error mapping도 확인.

최소 분리:

network/fetch failure
→ 네트워크 연결 오류

401
→ 로그인 정보가 만료되었습니다.

403
→ 접근 권한이 없습니다.

4xx validation
→ 요청 정보를 확인해주세요.

5xx
→ 서버 처리 중 오류가 발생했습니다. 잠시 후 다시 시도해주세요.

사용자에게 raw server error 노출 금지.

이번 root cause와 관계 있다면 같이 최소 수정.
