SwimNote 반 개설 정원 설정 기능 추가 요청

현재 문제:

관리자 모드에서 반 생성 시 정원 설정 옵션이 없습니다.

현재 기본 정원이 20명으로 고정되어 있는 것으로 보입니다.

하지만 실제 수업 운영에서는

* 4명
* 5명
* 6명
* 10명 이상
* 최대 20명

처럼 반 정원이 다양하게 필요합니다.

“반 개설 관리”

설명:

반 정원 및 개설 기본값 설정

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
반 개설 관리 화면
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

항목:

1. 기본 반 정원

* 기본값 5명
* 최소 1명
* 최대 20명

2. 저장 버튼

저장 후 안내:

“반 개설 기본 정원이 저장되었습니다.”

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
적용 범위
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

관리자가 설정한 기본 정원은

* 관리자 반 생성 화면
* 선생님 반 생성 또는 수업 개설 화면

에서 기본값으로 적용됩니다.

단, 반 생성 시 개별 반 정원은 필요하면 수정 가능하게 합니다.

예:

관리자 기본 정원 = 5명

새 반 생성 시

정원 입력칸 기본값 5명

선생님도 반 생성 권한이 있는 경우

기본값 5명 표시

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
기존 데이터 처리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기존 반의 정원은 자동 변경하지 않습니다.

새로 생성되는 반부터 기본값 적용합니다.

기존 반 정원은 각 반 수정 화면에서 개별 변경 가능해야 합니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DB/API 확인 요청
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

작업 전 확인:

1. 현재 class_groups 또는 관련 반 테이블에 capacity/max_students 같은 정원 컬럼이 있는지 확인
2. 현재 반 생성 API에서 정원 값이 고정 20으로 들어가는지 확인
3. 정원 컬럼이 이미 있다면 기본값만 설정값으로 변경
4. 정원 컬럼이 없다면 컬럼 추가 필요 여부 보고
5. 센터/수영장 단위 설정 테이블이 있는지 확인

가능하면 수영장 설정 테이블에 저장:

default_class_capacity = 5

또는 유사한 이름

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
API 요구사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

필요 시 추가:

GET /admin/class-settings

반 개설 기본 설정 조회

반환:

{
default_class_capacity: 5
}

POST /admin/class-settings

반 개설 기본 설정 저장

body:

{
default_class_capacity: number
}

검증:

1 이상 20 이하

완료 기준
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 관리자 설정 > 수업 설정에 “반 개설 관리” 메뉴 추가
2. 반 개설 관리에서 기본 정원 설정 가능
3. 기본값 5명
4. 최대 20명 제한
5. 관리자 설정값 저장됨
6. 새 반 생성 시 설정값이 기본 정원으로 적용
7. 기존 반 정원은 자동 변경되지 않음
8. 반 생성 시 개별 정원 수정 가능
9. 선생님 모드에도 관리자 설정값이 기본 적용
10. 20명 고정 로직 제거
