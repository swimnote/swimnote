2. Migration Validation 정확성 수정
==================================================

현재:

보조 통계로만 사용한다.

실제 migration 누락은 row-level anti-join으로 검증한다.

A. users

기존 users의:

- account id
- swimming_pool_id
- roles[]

에서 생성되어야 하는
(account_id, pool_id, role)

각 조합마다

user_pool_memberships에 실제 row가 존재하는지 검사.

expected membership인데 없는 row:

users_missing = 0

B. parent_accounts

swimming_pool_id IS NOT NULL인 parent account마다:

(account_id, pool_id, parent_account)

membership 존재 확인.

parents_missing = 0

C. duplicates

(account_id, pool_id, role)
GROUP BY
HAVING COUNT(*) > 1

duplicates = 0

D. invalid

account_id 없는 membership
pool_id 없는 membership
지원하지 않는 role

invalid = 0
