[SWIMNOTE - 추가 보호자 연결 UX 개선 작업]

현재 추가 보호자 자동 연결 기능은 정상적으로 동작하도록 설계되어 있지만,
사용자가 연결 방법을 이해하기 어렵기 때문에 가입 후 승인 대기 상태에서 멈추는 경우가 발생합니다.

이번 작업의 목표는
'사용자가 별도의 설명 없이도 자동 연결 방법을 이해할 수 있도록'
UX를 개선하는 것입니다.

※ 이번 작업도 반드시 실제 Production 앱에서 확인하면서 진행하십시오.
코드 수정만 하고 완료라고 하지 마십시오.

==================================================
1. 추가 보호자 관리 화면 안내문 개선
==================================================

기존 안내문을 삭제하고 아래 내용으로 교체하십시오.

제목

추가 보호자 연결 방법

내용

① 이 화면에서 추가 보호자의 전화번호를 먼저 등록해주세요.

② 추가 보호자가 등록된 전화번호로 SwimNote에 가입하면 별도의 승인 없이 자동으로 연결됩니다.

③ 이미 가입하여 승인 대기 중인 경우에도 이 화면에 해당 전화번호를 등록하면 즉시 연결됩니다.

※ 추가 보호자는 최대 3명까지 등록할 수 있습니다.

==================================================
2. 추가 보호자 등록 모달 안내문 추가
==================================================

전화번호 입력 모달 상단에 아래 안내문을 추가하십시오.

추가 보호자의 전화번호를 입력해주세요.

등록한 전화번호와 동일한 번호로 SwimNote에 가입하면 자동으로 연결됩니다.

이미 가입하여 승인 대기 중인 경우에도 등록 즉시 자동 승인되어 연결됩니다.

==================================================
3. 가입 후 '승인 대기' 화면 개선
==================================================

추가 보호자가 가입한 뒤 승인 대기 화면에서 아래 안내를 표시하십시오.

-------------------------

추가 보호자 승인 대기

아직 보호자 연결이 완료되지 않았습니다.

가족 중 이미 연결된 보호자가

설정
→ 추가 보호자 관리

에서 현재 가입한 전화번호를 등록하면
별도의 승인 없이 즉시 연결됩니다.

-------------------------

아래 버튼 추가

[ 연결 안내 보내기 ]

==================================================
4. 연결 안내 공유 기능
==================================================

'연결 안내 보내기' 버튼을 누르면
문자 또는 카카오톡으로 아래 내용을 공유할 수 있도록 하십시오.

-------------------------

[SwimNote 추가 보호자 연결 안내]

제가 먼저 SwimNote에 가입했습니다.

설정 → 추가 보호자 관리에서

제 전화번호를 등록해주시면
별도의 승인 없이 자동으로 연결됩니다.

전화번호 등록 후 바로 사용할 수 있습니다.

-------------------------

==================================================
5. 등록 완료 안내 추가
==================================================

전화번호 등록 성공 시 아래 토스트를 표시하십시오.

추가 보호자 전화번호가 등록되었습니다.

등록된 번호로 가입하거나
이미 승인 대기 중인 계정은 자동으로 연결됩니다.

==================================================
6. FAQ 추가
==================================================

추가 보호자 관리 화면 하단에 FAQ를 추가하십시오.

Q.
왜 승인 대기 상태인가요?

A.
추가 보호자는 연결된 보호자가
전화번호를 등록하면 자동으로 승인됩니다.

별도의 수영장 승인이나 관리자 승인은 필요하지 않습니다.

==================================================
7. UI 개선
==================================================

안내문은 단순 텍스트가 아니라

✔ 단계별 번호

✔ 충분한 줄 간격

✔ 강조 색상

✔ 핵심 문장 Bold

를 사용하여
요즘 앱 스타일처럼 보기 쉽게 구성하십시오.
