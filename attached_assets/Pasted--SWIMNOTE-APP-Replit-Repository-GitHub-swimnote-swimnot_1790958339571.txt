3. 버튼 활성 조건
━━━━━━━━━━━━━━━━━━━━━━

“전체 재시도 승인” 버튼은 다음 조건이면 활성화:

- server eligible count > 0
- 전체 cohort 선택 상태
- approval reason.trim().length > 0
- 현재 batch submit 중 아님
- 서버가 bulk recovery 허용 상태

즉 현재 17건을 전체 선택하고
승인 사유를 입력하면 즉시 버튼이 활성화되어야 합니다.

숨겨진 다른 UI 조건 때문에 막히면 안 됩니다.
