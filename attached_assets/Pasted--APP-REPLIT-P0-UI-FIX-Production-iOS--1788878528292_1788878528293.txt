[보낼 곳: APP REPLIT]

[P0 UI FIX — 수업일지 상단 필터 영역 가림 현상 반드시 수정]

현재 실기기 Production iOS 화면에서
수업일지 상단 필터 UI가 서로 겹치고 가려지는 버그가 계속 발생한다.

이번 작업은 "여백 조금 조정"이 아니다.

반드시 레이아웃 구조를 수정해서
어떤 화면 높이/폰트 스케일에서도
상단 카드/필터/검색/목록이 서로 겹치지 않게 만든다.

━━━━━━━━━━━━━━━━━━━━━━
1. 현재 실제 문제
━━━━━━━━━━━━━━━━━━━━━━

현재 화면:

[수업 일지 / 학생 노트 카드]
↓
[전체 / AI / 일반]
↓
[오늘 / 어제 / 이번 주 / 날짜 선택]
↓
[오늘 섹션]
↓
[검색]
↓
[일지 목록]

이어야 하는데,

실제 실기기에서는
[오늘 / 어제 / 이번 주 / 날짜 선택] 줄이
아래 영역에 의해 잘리거나 가려지고 있음.

특히:

- 오늘 버튼 하단이 잘림
- 어제/이번 주/날짜선택도 동일하게 잘림
- 다음 섹션 "오늘"이 너무 위에서 시작
- 상단 필터 영역과 스크롤 콘텐츠의 vertical layout이 충돌

━━━━━━━━━━━━━━━━━━━━━━
2. 절대 금지
━━━━━━━━━━━━━━━━━━━━━━

금지:

- marginTop 숫자만 임시로 올리기
- paddingBottom 몇 px 추가하고 끝내기
- 기기 하나에만 맞는 magic number
- absolute positioning 유지한 채 zIndex만 조정
- ScrollView contentInset을 임의 숫자로 때우기
- 카드/필터 중 하나를 화면에서 숨기기

이번에는
"겹칠 수 없는 정상 document flow"
로 고친다.

━━━━━━━━━━━━━━━━━━━━━━
3. 상단 영역을 하나의 정상 Flow로 재배치
━━━━━━━━━━━━━━━━━━━━━━

다음 영역을 하나의 vertical container 안에서
순서대로 자연 배치:

A.
상단 통계 카드
- 수업 일지
- 학생 노트

B.
작성 방식 필터
- 전체
- AI
- 일반

C.
기간 필터
- 오늘
- 어제
- 이번 주
- 날짜 선택

D.
기간 제목
- 오늘 / 선택 날짜 / 이번 주 등

E.
검색바

F.
일지 리스트

각 영역 사이에 정상 spacing 사용.

A~F 중 어느 것도
absolute/fixed top positioning으로
다른 영역 위를 덮지 않게 할 것.

━━━━━━━━━━━━━━━━━━━━━━
4. ScrollView / FlatList 구조 확인
━━━━━━━━━━━━━━━━━━━━━━

현재 화면에서:

- ScrollView 안에 FlatList
- fixed header + content
- position:absolute
- sticky header
- negative margin
- transform translateY

등이 겹침 원인인지 실제 코드 확인.

가장 단순한 canonical 구조로 정리.

권장:

FlatList 1개를 메인 스크롤로 사용하고,

ListHeaderComponent 안에:

- 통계 카드
- 전체/AI/일반
- 오늘/어제/이번주/날짜
- 섹션 제목
- 검색바

를 순서대로 넣는다.

그리고 실제 diary rows만
FlatList data로 렌더.

이렇게 하면
header 높이에 따라 자동으로 아래 리스트가 밀리므로
겹침 자체가 불가능함.

이미 유사 구조면
동일 원칙으로 수정.

━━━━━━━━━━━━━━━━━━━━━━
5. Safe Area / Header 높이
━━━━━━━━━━━━━━━━━━━━━━

앱 상단 네비게이션 헤더와
수업일지 콘텐츠 시작점도 확인.

SafeAreaView / useSafeAreaInsets
기준으로 정상 시작.

헤더 높이를 하드코딩해서
content가 위로 들어가지 않게 할 것.

━━━━━━━━━━━━━━━━━━━━━━
6. 실기기 검증
━━━━━━━━━━━━━━━━━━━━━━

반드시 Production iOS build 255 기준 실기기에서 확인.

검증:

전체 / AI / 일반

오늘 / 어제 / 이번 주 / 날짜 선택
