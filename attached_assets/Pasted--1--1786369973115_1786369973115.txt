- 신규 thanks notification 생성 차단 완료
- 선생님 소식알림 설정의 감사합니다 제거 완료

따라서 이 화면에서도 감사합니다를 완전히 제거한다.

4. Historical thanks 데이터
━━━━━━━━━━━━━━━━━━━━━━

중요:

DB의 과거 thanks reaction 데이터는 삭제하지 않는다.

API response에서 thanks가 계속 내려와도 문제없다.

이번 작업 목적은:

"과거 데이터 삭제"가 아니라
"현재 제품 UI에서 폐기된 감사합니다 반응을 더 이상 표시하지 않는 것"

이다.

따라서 DB migration 금지.

Server API 구조 변경도 이번 작업에서는 하지 않는다.

━━━━━━━━━━━━━━━━━━━━━━

7. 검증 CASE
━━━━━━━━━━━━━━━━━━━━━━

CASE 1
좋아요 1명 / 댓글 0개

→ 하트 좋아요 영역만 표시
→ 감사합니다 없음
→ 댓글 0개 정상

CASE 2
좋아요 0명

→ 좋아요 0명 상태 정상
→ 감사합니다 카드 없음

CASE 3
과거 thanks 데이터가 존재하는 일지

→ thanks UI 표시 안 됨
→ crash 없음

CASE 4
historical diary_thanks 알림 클릭

→ diary-reactions 정상 진입
→ thanks 카드 없음
→ 다른 데이터 정상

CASE 5
댓글 존재

→ 댓글/답글 기능 회귀 없음
