1. 이번 웹 리뉴얼의 최우선 디자인 목표
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

최우선 목표:

"Apple 제품 사이트와 비슷한 수준의 절제된 고급스러움"

Apple 사이트를 복제하라는 뜻이 아니다.

가져와야 하는 것은:

- 절제된 타이포그래피
- 정확한 여백과 비율
- 제품 중심의 화면
- 흰색 / 검정 / 짙은 회색 / 옅은 회색 중심
- 매우 제한적인 포인트 컬러
- 통일된 버튼
- 통일된 카드
- 통일된 입력창
- 통일된 모서리
- 통일된 아이콘 스타일
- 과하지 않은 애니메이션
- 한 회사가 만든 제품군이라는 일관성

절대 금지:

- AI가 만든 SaaS 사이트처럼 알록달록한 카드 남발
- 보라/파랑/초록 등을 섹션마다 임의 사용
- 과한 gradient
- 과한 glow
- 과한 shadow
- 페이지마다 다른 버튼
- 페이지마다 다른 radius
- 임의 폰트 크기 난립
- 필요 이상으로 거대한 글자
- 의미 없는 대형 빈 공간
- 긴 keynote 형식 스크롤
- DTA 등의 내부 기술을 홈에 크게 전시
- 각 페이지가 서로 다른 제품/회사처럼 보이는 디자인

"화려한 AI 스타트업"
가 아니라

"이미 완성된 고급 IT 기업의 제품 사이트"

여야 한다.

공개 가능한 수준에서:

- 현재 어떤 기능에 AI가 사용되는가
- 어떤 종류의 분석을 하는가

경쟁사가 복제할 수 있는 세부 설계

AI 성능 역시
근거 없는 수치를 만들어내지 않는다.

예:
"정확도 99%"
같은 검증되지 않은 숫자를 임의로 쓰지 마라.

실제 구현/검증된 범위만 설명한다.

기존 설계는:

- 아이디
- 비밀번호
- PIN 번호

3가지를 입력

로그인 성공 후
각 수영장 계정의 실제 데이터에 연결

PC에서 수정한 정보와 APP 정보가
동일한 backend/data를 사용하여 연동

되는 구조로 구축되어 있었다.

반드시 현재 코드에서 실제 구현 상태를 확인해서 보고할 것.

새로운 로그인 체계를 만들지 마라.
기존 인증을 우선 재사용한다.

PC Dashboard의 디자인 역시
홈페이지와 완전히 다른 관리자 template을 쓰지 않는다.

Typography / Button / Input / Radius / Color 등
동일 Design System을 사용한다.
