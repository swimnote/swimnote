지금까지 확정:

LOGIN_DB_CLIENT = superAdminDb
LOGIN_DB_ENV = SUPABASE_DATABASE_URL

POOL_DATABASE_URL은 로그인과 무관.

이제 코드 수정 없이 실제 Production 환경 차이를 확인한다.

1. Replit(swimnote.kr)과 Render 각각의
SUPABASE_DATABASE_URL에서
비밀정보를 출력하지 않고 아래 식별정보만 추출:

- host
- database
- port
- SSL mode if relevant
- Supabase project identifier를 URL/host에서 안전하게 식별 가능하면 masked form
- fingerprint/hash of full connection target

보고:

REPLIT_DB_HOST =
REPLIT_DB_NAME =
REPLIT_DB_FINGERPRINT =

RENDER_DB_HOST =
RENDER_DB_NAME =
RENDER_DB_FINGERPRINT =

SAME_DB_TARGET = YES/NO

비밀번호/전체 URL 출력 금지.

2. 실제 로그인 실패 계정 1개를 기준으로
양쪽 DB에서 동일 SELECT 수행.

확인:

USER_EXISTS_REPLIT_DB =
USER_EXISTS_RENDER_DB =

USER_ID_REPLIT =
USER_ID_RENDER =

EMAIL_MATCH =
ROLE_MATCH =
ACTIVE_STATUS_MATCH =

PASSWORD_HASH_EXISTS_REPLIT =
PASSWORD_HASH_EXISTS_RENDER =

PASSWORD_HASH_FINGERPRINT_REPLIT =
PASSWORD_HASH_FINGERPRINT_RENDER =

HASH_IDENTICAL = YES/NO

hash 원문 출력 금지.
