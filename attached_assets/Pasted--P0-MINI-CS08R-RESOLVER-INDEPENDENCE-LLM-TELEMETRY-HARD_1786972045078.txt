→ FAQ/KNOWLEDGE
→ KNOWN_ISSUE

frontend-map.v1.ts

screen

==================================================
4. FRONTEND MAP ANSWER
==================================================

Frontend Map match만으로
기능 위치가 충분히 확정되면:

resolution_status = RESOLVED
source_type = FRONTEND_MAP
llm_used = false

screen_id
screen_name
route/deep_link

반환 가능.

Knowledge answer를 반드시 요구하지 않는다.

필요한 안내문은 registry의
검증된 purpose/action metadata 범위에서만
deterministic하게 구성.

없는 사용법 창작 금지.

==================================================
5. GATHER EVIDENCE
==================================================

evidence가 될 수 있다.

단 role/mode/version 필터 필수.

==================================================
6. NO_EVIDENCE LLM_USED BUG
==================================================

현재 보고:

generation_mode = no_evidence
llm_used = true
llm_called = false

이 상태는 금지.

정의 고정:

llm_used =
실제 provider LLM API를 호출했는가

따라서:

NO_EVIDENCE
OpenAI 미호출

이면:

llm_used = false
model = null
input_tokens = null/0 according existing convention
output_tokens = null/0
total_tokens = null/0

이어야 한다.

7. LLM_REQUIRED SEPARATION
==================================================

필요하면 별도 의미를 사용:

실제 호출 여부를 신뢰할 수 있어야 한다.
