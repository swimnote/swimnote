[WP-X0 — X COMMON CONTROL THEME GAP HOTFIX]

목적:

SWIMNOTE X의 Nautic + Yacht Blue 테마는 이미 적용되어 있으나,
감사 결과 공통 UI 일부가 X mode를 인식하지 못해
old navy / Normal mint가 X 화면 안에 남아 있다.

이번 WP는 그 3개 gap만 수정한다.

한 번에 다른 Normal 테마 작업으로 확장 금지.

==================================================
0. CURRENT AUDIT FINDINGS
==================================================

확정된 문제:

1. AppButton.tsx
   - X mode 미인식
   - primary가 기존 Normal old navy #0F2742 사용
   - X에서는 XT.primary #1A4070 계열을 사용해야 함

2. MainTabs.tsx
   - X mode 미인식
   - active가 C.tint #2EC4B6 mint
   - X 화면에서도 mint 탭이 표시됨

3. teacher/today-schedule.tsx
   - X header action button background가
     rgba(255,255,255,0.12) old pattern
   - 현재 X token XT.surfaceNavySoft 사용 누락

이번 작업은 정확히 위 3개만.

==================================================
1. GLOBAL RULE
==================================================

본 작업은 Normal SWIMNOTE + SWIMNOTE X 공통 component 수정이다.

공통 source를 한 곳에서 mode-aware 처리하고
Normal/X 양쪽을 검증한다.

컴포넌트 복제 금지.

==================================================
2. AppButton X MODE SUPPORT
==================================================

components/common/AppButton.tsx 감사 후
현재 variant contract를 유지하면서 mode-aware 처리.

Normal:

primary
→ 현재 기존 동작 그대로 유지

X:

primary
→ XT.primary

중요:

Normal의 최종 Ocean Wave Green 전환은
이후 WP-N 계열에서 별도로 한다.

이번 WP에서 Normal primary 색을 Ocean/Navy로 재설계하지 않는다.

즉:

이번 작업 =
X에서 old #0F2742가 보이는 문제만 수정.

variant 의미:

primary
secondary
tertiary
destructive

는 변경 금지.

destructive semantic color도 변경 금지.

==================================================
3. MainTabs X MODE SUPPORT
==================================================

components/common/MainTabs.tsx를 mode-aware 처리.

Normal:
active = 기존 C.tint 유지
이번 WP에서는 Normal 변경 금지.

X:
active text / indicator / selected state
→ XT.accent 또는 현재 X 디자인 시스템에서
secondary active control에 지정된 Yacht 계열 token 사용.

임의 hex 금지.

inactive:
현재 neutral hierarchy 유지하되
X에서 가독성 부족 여부 확인.

IMPORTANT:

AI Report / AI Curriculum 등
FEATURE_FIXED color를 사용하는 별도 feature tab이 존재하면
강제로 XT.accent로 덮지 않는다.

MainTabs 일반 component의 theme-controlled state만 변경.
