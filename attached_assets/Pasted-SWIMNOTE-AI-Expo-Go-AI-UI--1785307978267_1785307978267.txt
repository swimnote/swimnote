SWIMNOTE AI 앱 개발 자산 전수 회수 작업지시

이번 작업은 코드 수정이나 기능 구현이 아니다.
과거 Expo Go에서 실제 실행되었던 AI 일지 UI와 음성인식 기능을 포함해, 모든 개발 자산을 읽기 전용으로 조사·백업하는 작업이다.

절대 금지
현재 HEAD에 파일 복원 금지
기존 파일 덮어쓰기 금지
코드 수정 금지
merge, rebase, reset 금지
삭제 금지
새 구현 금지
“현재 HEAD에 없으므로 존재하지 않는다”는 결론 금지

사용자는 과거 Expo Go에서 AI 일지 UI와 음성인식 기능이 실제 동작하는 것을 확인했다. 따라서 현재 HEAD뿐 아니라 개발 서버, 작업 브랜치, Git 객체, 체크포인트, 배포 기록 전체를 조사해야 한다.

1. 현재 상태 동결

다음을 원문 그대로 제출한다.

git status --short --branch
git rev-parse HEAD
git branch -a -vv
git remote -v
git stash list
git worktree list
git tag --list

현재 HEAD를 가리키는 백업 브랜치를 생성하되 다른 변경은 하지 않는다.

git branch backup/pre-ai-recovery-376fa37 376fa37

다음 파일과 디렉터리가 존재하는 모든 커밋·브랜치·태그를 조사한다.

3. Expo Go 실행본의 출처 조사

과거 Expo Go에서 실행된 코드가 어떤 브랜치·커밋·작업 디렉터리에서 시작됐는지 조사한다.

확인 대상:

Expo 개발 서버 실행 로그
Replit run/development workflow 설정
.replit
replit.nix
package.json scripts
Expo Metro 캐시 경로
EAS Update 설정
app.json
eas.json
update branch/channel
당시 QR 코드가 가리킨 개발 서버
deployment/checkpoint/snapshot
Replit Agent 작업 브랜치
미추적 파일 또는 과거 working tree

다음을 확인해 제출한다.

find . -maxdepth 4 \( -name '.replit' -o -name 'replit.nix' -o -name 'eas.json' -o -name 'app.json' -o -name 'package.json' \) -print
git log --all --date=iso --oneline -- .replit replit.nix eas.json app.json
git fsck --full --no-reflogs --unreachable --lost-found
git reflog show --all --date=iso

git fsck에서 발견된 dangling commit/blob도 AI 관련 경로와 내용인지 확인한다. 절대 삭제하거나 정리하지 않는다.

5. 후보 코드 별도 백업

발견한 앱 AI 코드 후보는 현재 프로젝트에 넣지 말고 다음과 같은 별도 디렉터리에 추출한다.

/recovery-evidence/
  /git-dfeddc1/
  /git-6c0ea18/
  /git-a63c7ee/
  /git-5f0be03/
  /checkpoint-[id]/
  /development-server-[id]/
  manifest.json

각 후보는 원본 경로 구조를 유지한다.

manifest.json에는 다음을 기록한다.

{
  "source_type": "git_commit | branch | checkpoint | development_server | dangling_object",
  "source_id": "",
  "source_time": "",
  "base_commit": "",
  "files": [],
  "sha256": {},
  "notes": ""
}

후보 파일의 SHA-256도 계산한다.
