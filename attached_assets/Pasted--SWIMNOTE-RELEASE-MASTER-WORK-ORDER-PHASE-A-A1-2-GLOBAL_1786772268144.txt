==================================================
2. MINT RULE
==================================================

Mint #2EC4B6는
Primary CTA 색이 아니다.

사용 범위:

- SWIMNOTE brand accent
- selected
- active
- 필요한 일부 highlight
- brand identity

정도로 제한한다.

일반 저장/등록/다음 버튼을
Mint로 칠하지 않는다.

==================================================
3. ORANGE RULE
==================================================

기존:

C.button = #F97316

을 일반 Primary Action으로 사용하는 정책 폐기.

Orange/Amber는:

- warning
- pending
- attention

이라는 실제 semantic meaning이 있을 때만 사용.

예:

"반 등록"이라는 이유만으로 Orange 사용 금지.

"등록"은 action이므로 Primary Navy.

==================================================
4. GREEN RULE
==================================================

Green은:

SUCCESS
COMPLETED
POSITIVE STATUS

일 때만 사용.

예:

완료 상태
정상 처리 완료 표시
성공 indicator

는 허용.

하지만:

저장 버튼
일반 메뉴 아이콘
navigation entry
일반 CTA
단순 강조

용 green 사용 금지.

==================================================
5. RED RULE
==================================================

Red는:

ERROR
DANGER
DESTRUCTIVE

전용.

삭제
실패
위험
오류

외의 장식 목적 사용 금지.

9. BORDERLESS DEFAULT
==================================================

==================================================
10. BORDER KEEP EXCEPTIONS
==================================================

다음은 유지 가능:

- Scheduler grid
- Calendar boundary
- date/time selection
- segmented control
- form input
- checkbox
- 실제 selected boundary
- table
- chart
- 구조상 경계가 반드시 필요한 영역

즉:

Borderless = 모든 선 삭제

가 아니다.

기능상 경계가 필요한 경우만 유지.

==================================================
18. TYPOGRAPHY HIERARCHY
==================================================

이번 구현에서
193개 파일 전체 typography를
대규모 리팩터링하지 않는다.

하지만 수정하는 P0/P1 화면은
다음 semantic hierarchy를 따른다.

Text Primary
→ Navy / Ink

Text Secondary
→ Slate Gray

Text Tertiary
→ lighter neutral

Brand/Selected
→ Normal SWIMNOTE Mint 또는 X Steel Blue

Success
→ Green

Warning/Pending
→ Muted Amber

Error/Danger
→ Red

강조를 위해
매번 colored box를 추가하지 않는다.

우선순위:

font weight
font size
text color

로 해결.

21. AI BLUE CORRECTION
==================================================

Audit report의:

"AI 모듈 파란색 #3B82F6 유지 확정"

은 수정한다.

AI라는 이유만으로
별도 Blue Brand System을 유지하지 않는다.

각 AI blue usage를 다시 분류:

A. 실제 INFORMATION semantic
→ 유지 가능

B. AI branding/decorative
→ 해당 mode의 brand color로 교체

Normal에서 유지되는 AI UI:
Normal design system 적용.

X 전용 AI:
Steel Blue system 적용.

A2에서 Normal AI visibility를 별도로 정리하므로
이번에 AI 기능 삭제/권한 변경은 금지.
