GLOBAL RULES
==================================================

1. 한 번에 현재 WP 하나만 수행.

2. 각 WP 종료 시:
PASS / BLOCKED
먼저 보고.

3. PASS 전 다음 WP 시작 금지.

4. Production write가 필요한 작업은
명시적 승인 없이 실행 금지.

5. destructive DB operation 금지.

6. force push / rebase / reset 금지.

7. 이미 검증된 영역 반복 감사 금지.

8. AI Prompt / Knowledge / 판단 로직은
Analytics 작업 때문에 변경 금지.

9. 일반 SWIMNOTE AI 제외는
AI 기능 삭제가 아니라 visibility/access policy 변경.

10. iOS build 246에서 가능한 JS/UI 수정은
runtime 1.6.3 OTA를 우선 사용.

11. native dependency/config 변경 시
새 build 필요 여부를 먼저 보고.

12. TestFlight 검증이 끝나기 전
App Store 정식 release 금지.

13. Android 검증 전
Google Play 정식 release 금지.

14. OpenAI Partner용 숫자는
실제 telemetry/DB 근거 없이 생성 금지.
