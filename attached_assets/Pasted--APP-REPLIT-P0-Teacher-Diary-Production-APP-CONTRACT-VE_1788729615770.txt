2. Production-safe 진단 로그
━━━━━━━━━━━━━━━━━━━━━━

Teacher Diary generate 요청 직전과 성공 응답 직후에
다음 비민감 정보만 구조화 로그로 남긴다.

REQUEST:

- request_id
- endpoint host/path
- contract_version
- pool_id exact match boolean
  (실제 pool_id 문자열 자체는 로그하지 않아도 됨)
- class_id_present
- lesson_date_present
- student_count
- text_length

Toykids exact 비교 기준:

pool_1780849364252_l9k44rbk3

로그 예:

teacher_diary_request_trace {
  request_id,
  contract_version,
  endpoint,
  is_toykids_pool,
  class_id_present,
  lesson_date_present,
  student_count,
  text_length
}

RESPONSE:

- request_id
- HTTP status
- pipeline_mode
- generation_mode
- template_ids_count
- knowledge_ids_count
- grounding_validation status/score
- fallback_used
- common_length
- student_result_count
- total_student_content_length

로그 예:

teacher_diary_response_trace {
  request_id,
  status,
  pipeline_mode,
  generation_mode,
  template_ids_count,
  knowledge_ids_count,
  grounding_status,
  grounding_score,
  fallback_used,
  common_length,
  student_result_count,
  total_student_content_length
}
