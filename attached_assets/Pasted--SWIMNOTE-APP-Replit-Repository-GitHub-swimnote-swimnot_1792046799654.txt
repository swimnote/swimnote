B. AI 중심 업무모드

AI 작업창이 중앙 메인 UI.

사용자가 자연어 업무를 입력하면
관련 기존 업무 화면을 오른쪽 Side Workspace에 자동으로 엽니다.

예:

"김똘똘 보여줘"
→ 회원 상세

"11월 수강료 보여줘"
→ 청구 화면

"오늘 3호차 보여줘"
→ 배차 화면

"최근 학부모 메시지 보여줘"
→ 운영 메시지

즉 AI가 답변만 하는 것이 아니라
필요한 실제 메뉴/업무화면을 자동으로 열어야 합니다.

두 모드는 같은 Action/API를 사용해야 합니다.
