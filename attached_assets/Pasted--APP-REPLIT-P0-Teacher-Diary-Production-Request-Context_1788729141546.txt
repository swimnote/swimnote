3. 특히 pool_id 검증
━━━━━━━━━━━━━━━━━━━━━━

현재 로그인한 토이키즈스윔클럽 계정에서
실제 AI 요청에 들어가는 pool_id가 정확히 무엇인지 확인.

정상 Production Toykids pool:

pool_1780849364252_l9k44rbk3

확인:

- 요청 pool_id가 exact 일치하는가
- null/undefined/다른 tenant id가 들어가지 않는가
- class 객체의 pool id로 잘못 덮어쓰는가
- 사용자/선생님/session에서 오래된 pool id를 사용하는가

pool_id가 잘못되면 center-specific Template 검색이 0건이 될 수 있으므로 최우선 확인.
