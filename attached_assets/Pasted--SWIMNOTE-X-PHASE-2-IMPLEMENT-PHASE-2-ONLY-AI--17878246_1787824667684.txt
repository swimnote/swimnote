2. KPI 상태 매핑
━━━━━━━━━━━━━━━━━━━━━━

V1 KPI는 정확히 4개.

`product_status = 'PUBLISHED'`

2. 검토 대기
`product_status = 'REVIEW_REQUIRED'`

OPEN
PREANALYZING
QUESTION_AVAILABLE
READY_FOR_ANALYSIS

`product_status = 'FAILED'`

NOT_OPEN은 KPI에서 제외.

APPROVED/PARTIAL은
목록 status chip에는 표시할 수 있으나
새 KPI 추가 금지.

화면에 "미시작" 문구 사용 금지.
