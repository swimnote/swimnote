# WP16 — PARENT FEED DIARY CARD VISUAL CLEANUP
# 범위: 학부모 Feed의 일반 Diary 카드 UI만
# Growth Report 카드/내용/기능 변경 금지
# Parent Feed 데이터/API/정렬 로직 변경 금지
# Teacher Diary/AI/Notification/Server 변경 금지
# 수정 완료 시 release/v2.0.0 반영 + iOS production-v2 OTA까지 자동 완료

사용자 첨부 스크린샷 기준으로
Parent Feed의 일반 Diary 카드 디자인이
Growth Report 카드와 시각적으로 불일치합니다.

Growth Report는 현재 정상 디자인이며
이번 작업의 visual reference로 사용합니다.

일반 Diary Feed 카드만 정리하십시오.

━━━━━━━━━━━━━━━━━━━━━━
1. 현재 문제
━━━━━━━━━━━━━━━━━━━━━━

현재 일반 Diary 카드:

- 큰 원형 teacher initial avatar 존재
- 원 안에 성 한 글자만 표시
- teacher 이름 옆에 class
- 아래에 날짜 + "수정됨"
- content
- 하단 좋아요 / 댓글
- 우측 Instagram AI 아이콘

문제:

1.
성 한 글자 원형 avatar가
현재 SWIMNOTE Feed 디자인과 어울리지 않음.

2.
"수정됨" 텍스트가 불필요하고
정보 밀도를 높여 화면이 지저분해 보임.

3.
Diary 카드와 Growth Report의
하단 action 위치/높이/spacing이 서로 다름.

4.
Diary와 Growth Report 사이 간격이 너무 좁아
한 Feed block처럼 붙어 보임.

5.
일반 Diary는 Instagram-like feed 느낌이 필요한데
현재 metadata 비중이 너무 큼.

━━━━━━━━━━━━━━━━━━━━━━
2. Growth Report는 기준 UI
━━━━━━━━━━━━━━━━━━━━━━

현재 Growth Report 카드의:

- 좌우 padding
- content width
- section spacing
- 하단 action row
- divider/spacing
- card-to-card vertical gap

을 visual reference로 사용.

Growth Report 코드 자체는 수정하지 마십시오.

일반 Diary가
같은 Feed system 안에 자연스럽게 보이도록 맞춤.

━━━━━━━━━━━━━━━━━━━━━━
3. Teacher avatar 제거
━━━━━━━━━━━━━━━━━━━━━━

일반 Diary 카드의:

보라색 원형
성 한 글자 avatar

제거.

예:

[서]
서경민 선생님 · 목 19:00반

형태 금지.

대신 간결하게:

서경민 선생님 · 목 19:00반

또는 현재 typography 체계에 맞는
한 줄 metadata 형태 사용.

새 avatar/icon 추가 금지.

━━━━━━━━━━━━━━━━━━━━━━
4. 수정됨 텍스트 제거
━━━━━━━━━━━━━━━━━━━━━━

현재:

9월 3일 목요일 · 수정됨

에서

"수정됨" 제거.

날짜만 표시:

9월 3일 목요일

또는 현재 Feed date style에 맞춰 유지.

updated 상태를 사용자에게 별도 강조하지 않음.

DB/API의 updated_at 변경 금지.
UI text만 제거.

━━━━━━━━━━━━━━━━━━━━━━
5. Metadata 단순화
━━━━━━━━━━━━━━━━━━━━━━

일반 Diary header는 최대한 간결하게.

권장 구조:

서경민 선생님 · 목 19:00반
9월 3일 목요일

또는 기존 typography에 맞는 2줄.

Teacher metadata가
본문보다 시각적으로 강하면 안 됨.

본문이 가장 중요한 요소.

━━━━━━━━━━━━━━━━━━━━━━
6. Diary content 중심
━━━━━━━━━━━━━━━━━━━━━━

일반 Diary:

common content
student-specific content

가 있으면
본문 hierarchy를 명확하게 유지.

현재처럼:

공통 내용

학생별 내용

을 자연스럽게 이어서 표시하되
불필요한 header chrome 최소화.

새 카드 내부 section box를 많이 만들지 말 것.

Instagram-like simple feed 느낌 유지.

━━━━━━━━━━━━━━━━━━━━━━
7. 하단 3개 action 위치 통일
━━━━━━━━━━━━━━━━━━━━━━

사용자 요구:

일반 Diary와 Growth Report의
하단 action 위치 3개를 통일.

현재 Growth Report 하단 구조를 기준으로:

LEFT:
좋아요

CENTER:
댓글

RIGHT:
공유/PDF/Instagram AI 등
해당 item의 기존 third action

일반 Diary도 동일한:

- row height
- horizontal alignment
- bottom padding
- left/center/right positioning
- icon baseline

사용.

Diary의 기존 기능 자체는 유지.

Instagram AI action이 현재 Diary의 third action이면
그 기능은 유지하되 위치만 Growth Report의
right action 위치와 맞춤.

Growth Report의 PDF 공유 기능 변경 금지.

━━━━━━━━━━━━━━━━━━━━━━
8. Feed item 간 vertical gap
━━━━━━━━━━━━━━━━━━━━━━

현재 Diary 바로 아래 Growth Report가
너무 붙어 있음.

Feed item 사이에
명확한 vertical separation 추가.

목표:

Diary block
↓ 충분한 여백
Growth Report block

각 item이 독립된 Feed post처럼 보여야 함.

단 excessive gap 금지.

현재 앱의 spacing scale 안에서
medium-large vertical gap 사용.

예:
기존 4~8px 수준이면
16~24px 범위 검토.

정확한 값은 현재 design token 사용.

━━━━━━━━━━━━━━━━━━━━━━
9. Diary card bottom spacing
━━━━━━━━━━━━━━━━━━━━━━

Diary content 끝
→ action row
→ card bottom
→ 다음 Feed item

spacing을 일관되게 정리.

본문과 좋아요/댓글 row가
너무 붙지 않도록 함.

Growth Report와 visual rhythm 맞춤.

━━━━━━━━━━━━━━━━━━━━━━
10. Card/background 정리
━━━━━━━━━━━━━━━━━━━━━━

현재 Feed background/card style 유지.

이번 작업에서:

- shadow 새로 추가 금지
- gradient 금지
- 새로운 card language 금지
- Growth Report redesign 금지

목표는 기존 SWIMNOTE Feed 안에서
Diary 카드만 정돈.

━━━━━━━━━━━━━━━━━━━━━━
11. 짧은 Diary / 긴 Diary 둘 다 검증
━━━━━━━━━━━━━━━━━━━━━━

짧은 Diary:

공통 1줄
학생별 1줄

에서도 card가 휑하거나 이상하지 않아야 함.

긴 Diary:

여러 줄 content

에서도 action row가 안정적으로 하단에 위치.

text length에 따라
icon/action이 떠다니면 FAIL.

━━━━━━━━━━━━━━━━━━━━━━
12. Media 있는 Diary regression
━━━━━━━━━━━━━━━━━━━━━━

사진/영상이 있는 Diary도
이번 layout 변경으로 깨지지 않아야 함.

확인:

photo
video
no media

모두 header/body/action spacing 정상.

Media 관련 upload/view logic 변경 금지.
