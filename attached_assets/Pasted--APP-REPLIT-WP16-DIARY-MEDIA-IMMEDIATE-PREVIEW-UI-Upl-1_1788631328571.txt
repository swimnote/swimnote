선생님이 일지 작성 중
사진 또는 영상을 선택하면

목표:

사진/영상 선택 직후
업로드 완료를 기다리지 않고
선택한 local asset을 작성 화면에 즉시 표시.

1. 현재 Media Flow 확인
━━━━━━━━━━━━━━━━━━━━━━

현재 코드에서 다음만 확인:

Diary 작성 화면
→ Photo picker
→ Video picker
→ selected local asset state
→ upload state
→ uploaded media state
→ 현재 preview rendering

실제 파일/컴포넌트 기준으로
미리보기가 왜 업로드 전 표시되지 않는지 확인.

전체 repo audit 금지.

2. 사진 즉시 Preview
━━━━━━━━━━━━━━━━━━━━━━

사진 선택 직후:

local URI를 사용해
작성 화면에 즉시 thumbnail 표시.

흐름:

사진 선택
→ local preview 즉시 표시
→ background/current upload 진행
→ 성공 시 server/R2 asset으로 상태 전환

업로드 완료 전까지 빈 화면으로 두지 마십시오.

업로드 실패 시:
해당 미디어에 실패 상태를 표시하고
기존 오류 처리 정책 유지.

━━━━━━━━━━━━━━━━━━━━━━
3. 영상 즉시 Preview
━━━━━━━━━━━━━━━━━━━━━━

영상 선택 직후에도
작성 화면에 즉시 시각적 preview가 보여야 함.

우선순위:

1. 현재 프로젝트에 이미 존재하는 video thumbnail/preview 기능 재사용
2. 기존 video component로 local URI preview 가능하면 재사용
3. 기존 기능으로 thumbnail 생성이 불가능하면
   local video preview card + play indicator 형태 사용

중요:

새 native dependency 추가 금지.
expo-video-thumbnails 등 신규 native package를
이번 작업 때문에 설치하지 마십시오.

현재 dependency 안에서 가장 작은 구현 사용.

사용자가 영상을 선택했다는 사실을
즉시 시각적으로 알 수 있어야 합니다.

━━━━━━━━━━━━━━━━━━━━━━
