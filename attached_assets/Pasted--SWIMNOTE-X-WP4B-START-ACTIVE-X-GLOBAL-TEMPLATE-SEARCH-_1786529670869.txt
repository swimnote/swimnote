8. FALLBACK 정책
━━━━━━━━━━━━━━━━━━━━

매우 중요.

X mode인데 ACTIVE set이 없거나,
ACTIVE set에 적합한 template이 없으면
일반 global template으로 몰래 fallback하지 말 것.

왜냐하면 X mode 교육 시스템과
일반 SWIMNOTE 템플릿이 섞이면 안 됨.

정책:

CASE A
X mode + ACTIVE set 없음
→ X_TEMPLATE_NOT_CONFIGURED

CASE B
X mode + ACTIVE set 존재
+ matching x_global template 없음
→ X_TEMPLATE_NO_MATCH

CASE C
Non-X
→ 기존 template search

단 실제 WP3 config/status contract와
충돌하면 기존 설계 우선.

자동으로 일반 global template을
X mode에 섞는 fallback 금지.
