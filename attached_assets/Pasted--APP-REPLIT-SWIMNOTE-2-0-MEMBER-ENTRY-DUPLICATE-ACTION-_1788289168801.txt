13. FORCE DELETE P1 SAFETY
==================================================

기존 감사에서:

DELETE /admin/students/:id/force-delete

가 active 회원도 HARD DELETE 가능하다는
P1 위험이 확인되어 있음.

이번 중복정리 단계에서
UI가 force-delete를 쉽게 노출하지 않는지 최종 확인.

원칙:

active 일반회원 관리 flow에서
force-delete 노출 금지.

Danger Zone 밖:
NO

만약 현재 active 회원에서
force-delete가 실제로 실행 가능한 UI가 남아있다면
기존 계획대로 최소 guard 필요 여부를 보고.

단:

delete endpoint semantics를
임의 통합하거나 새 delete system 만들지 말 것.

필요한 server guard가 명확하면
현재 WP 완료보고에서 BLOCKER로 보고하고
멋대로 확장하지 마십시오.
