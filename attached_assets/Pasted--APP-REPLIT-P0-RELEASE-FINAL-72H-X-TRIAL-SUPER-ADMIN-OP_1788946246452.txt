2. 무료체험은 PAID ENTITLEMENT가 아님
━━━━━━━━━━━━━━━━━━━━━━

절대:

trial = x_paid_entitlement

로 저장하거나 해석하지 말 것.

상태를 분리.

예:

x_trial_active
trial_started_at
trial_ends_at

또는 현재 이미 존재하는 canonical trial 필드가 있으면

x_paid_entitlement

수동:

x_manual_entitlement

HQ:

x_management_override

무료체험:

trial active

각 의미를 섞지 않는다.

A.
로그인하지 않은 동안 발생
→ DB에 알림 누적

B.
Super Admin 로그인
→ unread notification 조회

C.
알림 badge/count 표시

D.
알림 목록 확인

E.
읽음 처리

browser push까지 연결.

출시 P0 최소 기준은:

"로그인 즉시 unread 알림이 앱/웹 Super Admin 화면에 확실히 표시"

이다.
