==================================================
5. 30-MINUTE BACKGROUND APPLY
==================================================

AppState 사용.

앱이 active → inactive/background로 전환되는 시점에:

backgroundStartedAtRef.current = Date.now()

다시 active가 될 때:

elapsed =
Date.now() - backgroundStartedAtRef.current

조건:

elapsed >= 30 * 60 * 1000

AND

새 OTA download 완료 상태

일 때만:

Updates.reloadAsync()

30분 미만이면:
reload 하지 않는다.

==================================================
6. IMPORTANT — NO RELOAD ON SHORT SWITCH
==================================================

예:

사용자가 카카오톡/전화/사진 확인 등으로
1~10분 정도 앱을 벗어났다가 복귀

→ 절대 reload 금지.

29분 59초:
reload 0

30분 이상 + pending OTA:
reload 1회
