# SWIMNOTE 2.0 — M랩 메신저 전체 UX 정상화
# ADMIN + TEACHER
#
# 목적:
# 현재 관리자 모드 / 선생님 모드의 M랩 메신저가
# 실제 메신저로 쓰기 불편하고,
# 날짜/표시/말풍선/상태 문구 등 UI 오류가 존재하므로
# 기존 기능 범위 안에서 전체 사용성을 정상화한다.
#
# 방향:
# 카카오톡처럼 사용자가 별도 설명 없이 바로 이해할 수 있는
# 일반적이고 익숙한 메신저 UX로 정리한다.
#
# 중요:
# "카카오톡 기능 복제"가 목적이 아니다.
# 이미 SWIMNOTE에 존재하는 기능만 사용하여
# 화면 구조 / 표시 규칙 / 터치 / 스크롤 / 입력 경험을
# 일반적인 메신저 수준으로 정상화한다.
#
# 현재 없는 메신저 기능은 새로 만들지 않는다.
# ============================================================

4. "나에게만 표시" 제거
============================================================

현재 메신저에서 보이는:

"나에게만 표시"

또는 이와 유사한
본인 메시지 관련 잘못된 상태 문구를 전부 추적.

사용자 요구:

이 문구는 메신저에서 제거.

일반적인 메신저처럼:

내 메시지:
오른쪽 말풍선

상대방 메시지:
왼쪽 말풍선

으로 구분하면 충분.

"나에게만 표시"
"본인에게만"
등 불필요한 메타 문구:
화면에서 제거.

단,
실제 privacy 기능이 존재한다면
데이터 기능 자체를 삭제하지 말고
현재 메시지 UI에서 잘못 노출되는 표현만 제거.

============================================================
5. 날짜 표시 오류 전면 수정
============================================================

현재 날짜/시간 표시 관련 오류를 전부 확인.

검사:

- Invalid Date
- undefined
- null
- NaN
- ISO 문자열 그대로 노출
- UTC/KST 잘못 표시
- 같은 날짜 반복
- 날짜 separator 위치 오류
- 메시지 순서와 날짜 순서 불일치
- timestamp 없는 메시지
- created_at / sent_at 혼용
- 서버 timestamp parsing 차이

표시 규칙:

메시지 시간:
오전/오후 + 시:분
또는 앱 기존 locale formatter 사용

예:
오후 3:24

날짜 separator:
날짜가 바뀔 때만 1회 표시

예:
2026년 9월 2일 화요일

오늘/어제 식의 상대 날짜 표현은
현재 앱에 이미 formatter가 있을 때만 사용.

새 날짜 라이브러리 추가 금지 unless absolutely necessary.

Invalid Date는 절대 사용자 화면에 노출 금지.

timestamp가 없거나 잘못된 데이터:
UI crash 없이 안전 fallback.

============================================================
6. 메시지 정렬 규칙
============================================================

메시지는 실제 시간 기준:

과거
↓
최신

순서로 표시.

중복 sort가 여러 곳에서 일어나면
한 곳으로 정리.

같은 timestamp가 있을 경우
기존 stable ordering/id를 사용.

화면 진입 시:
최신 메시지 위치로 이동.

사용자가 과거 메시지를 보고 있는 동안
무조건 아래로 튀는 동작은 최소화.

현재 기능 범위 안에서만 처리.

============================================================
7. 일반적인 메신저 화면 구조로 정리
============================================================

대화 상세 화면은
익숙한 messenger 구조로 정리.

상단:
- 뒤로가기
- 상대방/대상 이름
- 필요한 기존 정보만

중앙:
- 메시지 영역
- 내 메시지 오른쪽
- 상대 메시지 왼쪽
- 날짜 separator
- 시간 표시

하단:
- 입력창
- 보내기 버튼

불필요한 설명문/개발용 상태값/내부 ID:
제거.

기능 설명보다
메시지 자체가 중심이 되어야 함.

============================================================
8. 말풍선 UX
============================================================

내 메시지와 상대 메시지가
한눈에 구분되어야 한다.

원칙:

내 메시지:
오른쪽 정렬

상대 메시지:
왼쪽 정렬

상대 이름:
그룹/여러 상대 구조가 실제 존재할 경우 필요한 범위만 표시.

1:1 구조라면
매 메시지마다 상대 이름 반복 표시할 필요 없음.

말풍선 너비:
화면 전체를 꽉 채우지 말고
일반적인 messenger max width 적용.

긴 문장:
자연스럽게 wrap.

짧은 문장:
불필요하게 넓은 bubble 금지.

개행:
보존.

텍스트가 bubble 밖으로 넘치지 않게 처리.

============================================================
9. 시간 표시 위치
============================================================

시간은 메시지 내용보다 시각적 우선순위를 낮게.

말풍선 옆/아래 등
일반적인 messenger 형태로 정리.

내 메시지:
시간이 말풍선과 자연스럽게 붙음.

상대 메시지:
동일.

시간 때문에 말풍선 alignment가 깨지지 않게 할 것.

같은 메시지에 날짜/시간 중복 표기 금지.

입력창 비우기.

실패:
사용자가 입력한 메시지 임의 삭제 금지.

============================================================
11. 키보드 UX
============================================================

iOS/Android 모두 확인.

입력창이 keyboard에 가려지지 않게.

채팅 영역과 입력창이
키보드 등장 시 자연스럽게 resize/avoid.

메시지 입력 중:
send 버튼 첫 탭에 바로 전송.

keyboardDismissMode만 믿지 말고
실제 터치 동작 확인.

대화 배경을 탭했을 때
키보드를 닫는 동작이 필요하다면
child interaction을 삼키지 않는 안전한 방식 사용.

버튼/메시지를 첫 탭에 정상 선택 가능해야 함.

제거.

============================================================
