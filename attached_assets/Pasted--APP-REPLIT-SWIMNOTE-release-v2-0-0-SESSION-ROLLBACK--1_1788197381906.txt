3. 실행 방식
━━━━━━━━━━━━━━━━━━━━━━

반드시 최신 commit부터 역순으로 revert:

`a227926a`
↓
`29774e53`
↓
`de115377`

각 commit은 개별 revert commit으로 남기십시오.

권장:

`git revert a227926a`

`git revert 29774e53`

`git revert de115377`

충돌이 발생하면 임의 해결하지 말고:

* 충돌 파일
* 충돌 위치
* 왜 충돌했는지
* 어떤 이후 commit과 겹치는지

보고 후 최소 범위로 처리하십시오.
