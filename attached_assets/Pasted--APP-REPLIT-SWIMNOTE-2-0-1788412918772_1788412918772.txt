============================================================
1. 실제 문제
============================================================

첨부 스크린샷의
보강관리 화면 최상단 가로 탭/필터 영역에서

다음 텍스트가 좌우로 잘려 보인다.

1) "결석자 리스트"
2) "담당 보강"

현재 화면에서는:

- 왼쪽 첫 번째 "결석자 리스트" 탭이
  화면 왼쪽 경계에 걸려 앞부분이 잘림

- "담당 보강" 탭 역시
  탭 폭/레이아웃 문제로 글자가 온전히 보이지 않음

첨부사진을 정확한 visual reference로 사용할 것.

============================================================
2. 기대 결과
============================================================

상단 탭 전체:

- 결석자 리스트
- 담당 보강
- 다른선생님
- 완료 기른
- 만료

각 텍스트가

- 좌우 잘림 없이
- 전체 글자 표시
- 세로 잘림 없이
- 버튼 안에서 정상 정렬

되어야 한다.

특히:

"결석자 리스트"
→ 첫 글자부터 마지막 글자까지 전부 보여야 함.

"담당 보강"
→ 전체 글자 전부 보여야 함.

============================================================
3. 수정 범위
============================================================

해당 보강관리 화면의
상단 horizontal tab/filter component만 확인.

다음 가능 원인을 실제 source 기준으로 조사:

- tab width
- minWidth
- paddingHorizontal
- marginHorizontal
- ScrollView contentContainerStyle
- horizontal inset
- gap
- flexShrink
- text numberOfLines
- font size / lineHeight
- screen edge clipping

추측하지 말고
현재 실제 component/style을 보고 최소 수정.

============================================================
4. 중요한 요구사항
============================================================

왼쪽 첫 탭이
화면 밖으로 밀려나가 잘리는 문제를
단순히 글씨 크기만 줄여서 숨기지 말 것.

필요하면 horizontal ScrollView의
좌우 content inset/padding을 정상화해서

첫 번째 탭과 마지막 탭 모두
화면 가장자리에서 잘리지 않게 할 것.

============================================================
6. NORMAL/X 공통 여부
============================================================

이 보강관리 화면이
Normal SWIMNOTE와 X mode에서
같은 shared component를 사용한다면

공통 component 한 번만 수정해서
둘 다 동일하게 반영.

별도 duplicate 구현 금지.

실제 source 기준으로 shared 여부 확인 후 보고.
