4. 기존 KAKAO TEACHER 상태 기준
============================================================

migration 대상 old Kakao teacher가
기존에 실제 승인/활성 teacher였는지 확인.

예:

oldTeacher.is_activated === true
또는 현재 시스템의 승인 완료 상태

이면:

newTeacher에 동일 승인 상태 승계.

old teacher가 승인대기/비활성 상태였다면
임의로 활성화하지 말고
기존 상태 semantics 유지.

핵심:
기존 승인된 teacher만 approval bypass.
