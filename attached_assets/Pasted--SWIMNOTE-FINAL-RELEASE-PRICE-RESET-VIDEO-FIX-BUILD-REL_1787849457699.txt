4. VIDEO BUG FIX #1 — expired row quota
==================================================

현재 문제:

video_assets_meta의 expired row가 quota 사용량 SUM에 계속 포함되어
R2 binary는 이미 삭제되었는데도
사용가능 저장용량이 복구되지 않을 수 있음.

수정 목표:

quota 계산에서는
실제로 현재 storage를 점유하는 active video만 포함.

expired / deleted 상태 object는 quota에서 제외.

중요:
- 기존 active row 계산 훼손 금지
- pool isolation 유지
- storage quota 10/20/50GB 유지
- 사용자 직접 삭제 시 즉시 quota 복구 유지

테스트:
1. active video upload → quota 증가
2. expire 처리 → quota 감소
3. user hard delete → quota 감소
4. expired row DB에 존재해도 quota 미포함
5. 다른 pool row 영향 없음

==================================================
5. VIDEO BUG FIX #2 — thumbnail orphan
==================================================

현재 문제:

사용자가 직접 DELETE /api/videos/:videoId 실행 시
video binary는 R2에서 삭제되지만
thumbnail object가 남을 수 있음.

수정 목표:

사용자 직접 삭제에서도
video binary + thumbnail을 모두 R2에서 삭제.

중요:
- thumbnail 없는 기존 영상도 delete 성공
- R2 delete 일부 실패 시 처리방식 기존 error policy와 일관성 유지
- DB hard delete 타이밍 검토
- 다른 pool object 삭제 불가

테스트:
1. video + thumbnail 삭제
2. thumbnail 없는 video 삭제
3. 잘못된 pool 접근 차단
4. 이미 object 없는 경우 안전 처리
5. DB row 처리 정상
