1. 중요 — 이전 SQL 사용 금지
━━━━━━━━━━━━━━━━━━━━

→ 금지

그런데 제안 SQL:
DEFAULT ''
→ 금지

payment_logs.swimming_pool_id
Production DEFAULT = NONE

그런데 제안 SQL:
DEFAULT ''
→ 금지

원칙:

BACKUP의 신규 컬럼 정의는
Production catalog와 정확히 동일해야 한다.

nullable/default/type까지 임의 보정 금지.

Stub는 row=0이므로
NOT NULL 컬럼도 DEFAULT 없이 ADD 가능하다.
