4. OTA 후 실기기 테스트
━━━━━━━━━━━━━━━━━━━━━━

가장 중요:

현재 문제를 일으켰던
동일한 10장 사진으로 다시 테스트.

CASE 1 — 기존 4장

확인:
- 기존 V3 2×2 그대로
- 사진 크기/구도 회귀 없음
- 한줄평/branding 정상

CASE 2 — 문제됐던 10장

확인:
- 10장 모두 실제 표시
- +N 없음
- 기존 5×2 세로 띠 현상 없음
- 가로사진이 넓은 셀에 자연스럽게 표시
- 세로사진이 과도하게 잘리지 않음
- 각 사진이 무엇인지 식별 가능
- 전체 콜라주가 정돈되어 보임

CASE 3 — 혼합 비율

가로/세로/정사각 혼합 사진에서:

- template 자동 선택 정상
- 사진 누락 없음
- 중복 없음
- 순서 유지
- 과도한 crop 없음

CASE 4 — getSize 실패

한 장의 size 조회가 실패해도:
- 전체 Story 생성
- fallback AR=1 적용
- 앱 crash 없음

CASE 5 — Instagram 공유

- Story 생성
- Instagram Composer 정상 진입
- 공유 로직 회귀 없음

━━━━━━━━━━━━━━━━━━━━━━
5. 디자인 성공 기준
━━━━━━━━━━━━━━━━━━━━━━

이번 수정의 성공 기준은
"10장을 다 넣었다"가 아니다.

다음이 핵심:

- 사진 하나하나가 알아볼 수 있어야 함
- 가로사진이 세로 띠처럼 잘리지 않아야 함
- 세로사진이 납작하게 잘리지 않아야 함
- 전체가 하나의 세련된 photo collage처럼 보여야 함
- 초등학생 사진 모음판처럼 보이면 실패

비대칭 크기는 허용.
사진 크기가 서로 달라도 정상.

원본 비율 보존이 우선.
