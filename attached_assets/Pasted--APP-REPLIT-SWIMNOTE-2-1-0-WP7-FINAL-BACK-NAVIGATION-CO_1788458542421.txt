# SWIMNOTE 2.1.0 — WP7 FINAL BACK NAVIGATION CORRECTION + IOS OTA

대상:
설정 → SWIMNOTE X 관련 하위 화면 전체

WP7 기존 문제:
설정/X모드 하위 화면에서 뒤로가기를 누르면
논리적 상위 화면이 아니라 홈 또는 잘못된 화면으로 이동하는 문제.

기존 수정에서 explicit backTo 전달은 추가했으나
일부 handler가:

1. canGoBack()
2. backTo
3. fallback

순서로 처리되어
명시적 logical parent보다 navigation stack이 우선되는 문제가 남아 있음.

============================================================
최종 원칙
============================================================

설정 계층에서 뒤로가기는 반드시:

1. explicit backTo 존재
   → backTo로 이동

2. backTo 없음 + canGoBack() true
   → router.back()

3. 둘 다 불가
   → settings fallback

순서.

즉:

backTo > navigation stack > fallback

반드시 이 우선순위로 고정.

============================================================
적용 대상
============================================================

기존 WP7에서 수정한 X 설정 계열:

- x-mode-hub
- x-subscription
- x-setup
- XInfoDetailPage
- 기타 해당 설정 descendant

실제 현재 파일/route 명을 다시 확인하고
이미 backTo 전달이 구현된 구조는 그대로 유지.

============================================================
예시
============================================================

잘못된 방식:

if (router.canGoBack()) {
  router.back();
  return;
}

if (backTo) {
  router.replace(backTo);
  return;
}

금지.

올바른 우선순위:

if (backTo) {
  router.replace(backTo);
  return;
}

if (router.canGoBack()) {
  router.back();
  return;
}

router.replace("/(admin)/settings");

실제 route 문자열은 현재 코드 기준 사용.
