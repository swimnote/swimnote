1. 먼저 토이키즈 현재 subscription 상태 확인
============================================================

코드와 현재 사용 가능한 데이터 경로 기준으로
토이키즈가 현재 어떤 상태로 해석되는지 확인.

반드시 확인:

- pool/center identifier
- current tier
- current effective plan
- legacy tier 여부
- legacy product ID 여부
- subscription status
- x_mode
- x_pending
- trial 여부
- member_limit
- storage quota
- RevenueCat-related stored values
- pending_plan
- plan_effective_at
- cancellation state
- expiration state

실제 값을 확인하지 않고
X1000을 덮어쓰지 말 것.

2. 충돌 가능성 검사
============================================================

토이키즈를 X1000으로 설정할 때
다음이 충돌하는지 확인:

- legacy center tier
- old X 119/189/349 tier
- active RevenueCat legacy product
- pending downgrade/upgrade
- expiration
- cancellation
- x_trial
- manual entitlement
- duplicate base plan
- member limit
- storage quota
- X mode flags

legacy subscription이 active로 남아
resolver가 다시 legacy로 덮는" 상황이 없는지 확인.
