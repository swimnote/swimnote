[P0 UI FIX — PARENT AI 커리큘럼 검색 아이콘 의미 맞게 교체]

현재 학부모 모드:

AI 커리큘럼 검색

화면에서
헤더/본문에 느낌표(!) 형태의 아이콘이 사용되고 있음.

이 아이콘은 오류/경고 의미로 보여
AI 커리큘럼 검색 기능의 성격과 맞지 않는다.

이번 작업은 아이콘 의미 정리만 한다.
새 기능 추가 금지.
API/서버 변경 금지.

1. 메인 기능 아이콘 교체
━━━━━━━━━━━━━━━━━━━━━━

현재 본문 중앙의 큰 느낌표 아이콘 제거.

AI 커리큘럼 검색의 성격이 바로 보이도록:

우선순위:

1순위:
book-open / book 계열

2순위:
search + book 의미가 결합된 기존 지원 아이콘

3순위:
graduation-cap / library 계열

중 하나를
현재 프로젝트에서 이미 사용하는 icon library 안에서 선택.

외부 신규 icon package 설치 금지.

권장 의미:

"교육과정 / 커리큘럼"

을 메인으로 보여주고,
검색 기능은 입력창의 search icon으로 표현.

━━━━━━━━━━━━━━━━━━━━━━
2. 헤더 우측 느낌표 아이콘 2개 제거
━━━━━━━━━━━━━━━━━━━━━━

현재 헤더 우측 Home 버튼 왼쪽에
느낌표 계열 아이콘 2개가 있음.

실제 명확한 기능이 없는 장식/placeholder라면
둘 다 제거.

기능이 실제 존재하면:
각 버튼의 onPress와 기능을 확인해서
의미에 맞는 아이콘으로 변경.

예:
정보 → info-circle
검색 기록 → history
도움말 → help-circle

경고/오류가 아닌 기능에
exclamation 아이콘 사용 금지.

기능 없는 버튼을 아이콘만 바꿔서 남기는 것도 금지.

- 메인 일러스트/아이콘:
