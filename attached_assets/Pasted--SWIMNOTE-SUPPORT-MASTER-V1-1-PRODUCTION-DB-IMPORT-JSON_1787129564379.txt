[SWIMNOTE SUPPORT MASTER V1.1 — PRODUCTION DB IMPORT 실행]

사전검증 결과 확인:
- JSON parse 정상
- records 1,051
- Production support_knowledge_items schema와 일치
- 전체 status=pending
- answer_mode 정상
- 아직 DB import는 실행하지 않은 상태

이제 사전검증에서 멈추지 말고 실제 DB import를 진행한다.

목표:
첨부된 v1.1 Master의 1,051개 Canonical Knowledge를
현재 Production support_knowledge_items에 안전하게 적재한다.

중요:
이번 작업은 DB 적재만 한다.
고객지원 구조 수정, resolver 수정, AI 로직 수정, UI 수정은 하지 않는다.

1. Import 전 기존 DB 비교

첨부 Master의 모든 intent_id와
현재 Production support_knowledge_items의 intent_id를 비교한다.

각 항목을 다음 3개로 분류한다.

A. NEW
- Production에 같은 intent_id 없음
→ INSERT

B. SAME
- 같은 intent_id 존재
- 실제 내용도 동일
→ SKIP

C. CONFLICT
- 같은 intent_id 존재
- answer/question/answer_mode 등 내용이 다름
→ 임의 overwrite 금지
→ 별도 conflict 목록으로 보고

ACTIVE row가 이미 존재하는 경우
절대로 자동 overwrite하거나 pending으로 되돌리지 않는다.

2. 실제 적재

transaction 사용.

BEGIN

→ 기존 intent_id 조회
→ NEW / SAME / CONFLICT 분리
→ NEW만 support_knowledge_items에 INSERT
→ INSERT되는 모든 신규 row는 status=pending 유지
→ ACTIVE 자동전환 금지

COMMIT

중간 오류 발생 시 전체 ROLLBACK.
