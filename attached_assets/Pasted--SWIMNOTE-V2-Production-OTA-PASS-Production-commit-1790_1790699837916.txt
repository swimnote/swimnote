A.
이미지가 포함된 슈퍼관리자 공지
→ 앱 실행
→ popup 자동 표시
→ 16:9 대표 이미지 실제 표시

B.
SWIMNOTE 로고 표시

C.
제목/본문 정상 표시

D.
X 버튼으로 닫기
→ popup 사라짐
→ 즉시 underlying 화면 터치 가능

E.
별도 신규 공지에서 하단 "닫기"
→ popup 사라짐
→ 즉시 underlying 화면 터치 가능

F.
앱 재실행
→ 이미 본 동일 공지는 다시 popup되지 않음

G.
공지함에는 공지가 계속 존재

H.
teacher 공지함
→ 슈퍼관리자가 첨부한 대표 이미지 표시

가능하면 parent 공지함 이미지도
안전한 테스트 환경에서 확인한다.

공지 V2 최종 CLOSED 여부를 판단한다.
