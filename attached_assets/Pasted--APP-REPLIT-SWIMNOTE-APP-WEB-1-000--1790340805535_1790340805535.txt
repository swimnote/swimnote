3. 빈 행과 실무 Excel normalization
━━━━━━━━━━━━━━━━━━━━━━

1,000명짜리 실제 파일을 기준으로
불필요한 오류를 만들지 마십시오.

다음은 자동 정리:

- 완전 빈 행 → skip
- 이름 앞뒤 공백 → trim
- 전화번호 앞뒤 공백 → trim
- 하이픈 → 제거
- 공백 → 제거
- 숫자 cell → 문자열 변환
- 문자열 cell → 정상 처리

보호자 전화번호:

010-1234-5678
01012345678
010 1234 5678

은 동일하게:

01012345678

로 저장 가능하게 normalize.

가능하면:

+82 10-1234-5678
821012345678

도:

01012345678

로 normalize하여
현재 parent auto-approval과 매칭되게 하십시오.

전화번호 formatting 차이 때문에
등록 자체가 막히지 않게 하십시오.

4. BLOCKING ERROR는 최소화
━━━━━━━━━━━━━━━━━━━━━━

회원 등록을 실제로 막는 오류는

BLOCKING:

A.
이름이 없음

B.
보호자 연락처가 없음

C.
파일 자체를 읽을 수 없음

D.
필수 header 의미를 찾을 수 없음

E.
1,000명 최대치를 초과

F.
서버/DB 시스템 장애

그 외 가능한 항목은
최대한 WARNING으로 처리합니다.

“전화번호 오류”

금지.

6. DUPLICATE는 ERROR가 아니라 WARNING
━━━━━━━━━━━━━━━━━━━━━━

다음은 절대 registration blocking error로 사용하지 마십시오.

- 동일 이름
- 동일 전화번호
- 동일 보호자 전화번호
- 이름 + 보호자 전화번호 동일
- 동일 파일 내 유사 row
- 기존 DB와 유사 row

필요하면:

DUPLICATE_SUSPECTED

warning으로 표시하십시오.

예:

42행 김민수
기존 회원과 이름/연락처가 동일합니다.
등록은 가능합니다.

WARNING은 commit을 막지 않습니다.

사용자가 파일을 수정하지 않고
그대로 등록할 수 있어야 합니다.

7. 반 이름은 등록 차단 금지
━━━━━━━━━━━━━━━━━━━━━━

반 이름은 완전 optional입니다.

CASE A:

반 이름 공란

→ 회원 정상 등록
→ class_group_id = null

CASE B:

반 이름이 실제 반과 정확히 일치

→ 회원 정상 등록
→ 기존 기능처럼 해당 반 자동배정 가능

CASE C:

반 이름이 입력됐지만 존재하지 않음

→ 회원 정상 등록
→ class_group_id = null
→ CLASS_NOT_FOUND warning

예:

57행 이서준
반 이름 “돌고래A”를 찾지 못했습니다.
회원은 미배정 상태로 등록됩니다.

반 이름 오타 때문에
1,000명 전체 등록을 막지 마십시오.

17. REQUEST BODY LIMIT
━━━━━━━━━━━━━━━━━━━━━━

현재 기본 Express 100KB 때문에
1,000명 payload가 413이 될 수 있습니다.

bulk member endpoint가
1,000명 payload를 안정적으로 받을 수 있게 수정하십시오.

가능하면:

/admin/members/bulk/*

범위에만 route-scoped body limit을 적용.

예:

2MB 또는 실제 최대 payload를 충분히 수용하는 값.

기존 전체 API의 body limit을
불필요하게 5MB 이상으로 넓히지 마십시오.

현재 Express middleware 순서를 확인하여
route-specific limit이 실제로 적용되게 하십시오.

route-scoped 적용이 구조상 불가능하면
최소 안전 범위로 global limit을 조정하고
그 이유를 보고하십시오.

━━━━━━━━━━━━━━━━━━━━━━

Promise.all(rows.map(...))
