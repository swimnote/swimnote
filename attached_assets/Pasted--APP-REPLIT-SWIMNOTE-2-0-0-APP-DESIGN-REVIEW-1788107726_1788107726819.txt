0. 목적
━━━━━━━━━━━━━━━━━━━━

AI ENGINE 쪽에서
Canonical Terminology DB / Search / Inline Link / API를 담당한다.

APP에는 전체 용어 DB를 넣지 않는다.

APP 역할은:

- APP API Gateway
- 인증/권한
- 검색 UI
- 검색 결과
- 상세 UI
- Inline link renderer
- Navigation stack
- Parent 진입
- Teacher 진입
- 작은 iPhone responsive
- loading/error/cache presentation

이번 단계에서는 구현하지 않는다.

현재 release/v2.0.0 repository를 조사해서
이 설계를 실제 앱 구조에 맞게 검수한다.

9. Inline Link Renderer
━━━━━━━━━━━━━━━━━━━━

APP은 본문에서
용어를 직접 탐지하지 않는다.

ENGINE/API가 제공하는 link metadata를 사용.

예:

{
  "text": "...",
  "links": [
    {
      "term_id": "TERM-000014",
      "label": "글라이드",
      "start": 10,
      "end": 15
    }
  ]
}

APP은 해당 range만
클릭 가능한 Text span으로 렌더링.

검토할 것:

- UTF-16/Unicode offset 문제
- 한글
- emoji
- punctuation
- newline
- multiple links
- overlapping links
- long text

offset 방식보다
segment array가 더 안전하면
AI ENGINE과 맞춰 contract 수정안을 제안 가능.

단 제품 의미는 변경 금지.
