TEACHER DIARY HUB UX CLEANUP
SEPARATE "NEW DIARY" FROM "PAST DIARIES"

목표:
현재 수업 일지 화면에서
"새 일지 작성"과 "지난 일지 조회" 기능이 섞여 있는 구조를 정돈한다.

현재 문제:
- 상단 일지 작성 버튼
- 검색
- 필터
- 지난 일지 목록
- 공유
가 한 화면에 동시에 노출되어
진입 목적이 불명확함.

새 구조는:

1. 새 일지 작성
2. 지난 일지

두 역할을 명확히 분리.

==================================================
1. TOP AREA — NEW DIARY
==================================================

현재 상단 큰 "일지 작성" 카드/버튼은 유지하되
역할을 명확히 한다.

표시:

일지 작성
"아직 작성하지 않은 수업을 선택해 일지를 작성합니다."

탭:
→ 이전에 설계한
"미작성 수업 선택"
selector/modal/bottom sheet 오픈.

즉 바로 diary.tsx로 진입 금지.

==================================================
2. PAST DIARY SECTION
==================================================

새 일지 작성 영역 아래에
명확한 section header 추가:

"지난 일지"

보조:
"작성한 수업 일지를 확인하고 수정할 수 있습니다."

그 아래에만:

- 학생 검색
- 요일 필터
- 시간 필터
- 기존 일지 목록

배치.

즉 검색/필터는
새 일지 작성용이 아니라
지난 일지 조회용이라는 구조가 되게 한다.

==================================================
3. REMOVE VISUAL CONFUSION
==================================================

현재 화면에서:

큰 일지작성 카드
바로 아래 검색창
바로 아래 필터
바로 아래 기존 일지

가 붙어 있는 구조를 분리.

권장:

[일지 작성 카드]

여백

지난 일지
보조 설명

[검색]
[요일] [시간]      N건

[기존 일지 목록]

==================================================
4. EXISTING DIARY CARD
==================================================

기존 카드 구조는 최대한 유지.

각 카드:

날짜
반
시간
반 공통 / 학생 추가
내용 preview
공유

유지.

단,
카드 전체 tap:
→ 기존 일지 상세/수정 경로

우측 공유:
→ 기존 공유 동작

역할 충돌 금지.

==================================================
5. DATE LABEL
==================================================

날짜 표시는 실제 lesson_date 기준.

현재처럼:

8월 14일 금요일
8월 7일 금요일
8월 6일 목요일

형태 유지 가능.

단,
일지 생성일(created_at)이 아니라
lesson_date를 표시하는지 확인.

==================================================
6. DUPLICATE SAME-DAY DISPLAY
==================================================

스크린샷처럼 같은 날짜에:

8월 6일 목요일
- 반 공통
- 서태웅 추가

두 카드가 존재할 수 있음.

이건 정상.

단,
같은 수업 회차의
반 공통 일지 + 학생 추가 일지라는 관계가
사용자에게 더 명확하게 보이도록 유지.

예:
반 공통
학생 추가 · 서태웅

현재 badge 구조 최대한 재사용.

==================================================
7. QUICK WRITE ENTRY
==================================================

"일지 작성" 탭 시:

작성할 수업 선택

미작성 session list만 표시.

선택 후:
→ 정확한 lessonDate
→ classGroupId
→ schedule/slot
전달

기존 화면에서 임의 날짜 fallback 금지.

==================================================
8. FILTER BEHAVIOR
==================================================

요일 / 시간 필터는
지난 일지 목록에만 적용.

새 일지 작성 selector에는
별도 필터를 억지로 재사용하지 않는다.

Quick Write selector는
미작성 수업 중심으로 단순하게.

==================================================
9. EMPTY STATES
==================================================

지난 일지 0건:

"작성된 수업 일지가 없습니다."

미작성 수업 0건:

"작성할 수업 일지가 없습니다."

두 상태를 구분.
