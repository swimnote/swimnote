B. 기존 일반 Diary 좋아요가 Teacher 쪽 숫자에 반영되지 않는 문제
━━━━━━━━━━━━━━━━━━━━━━

실기기 증상:

학부모 일반 일지피드에서 좋아요를 누름
→ 학부모 UI에서는 좋아요가 눌린 상태로 보임
→ 그런데 Teacher 쪽의 좋아요 숫자가 올라오지 않음

기존 Diary 좋아요 전체 경로를 다시 실제 코드 기준으로 추적하십시오.

Parent:

DiaryFeedItem heart
→ POST /parent/diary/:diaryId/reactions
→ diary_reactions INSERT/DELETE

Teacher:

class_diaries / teacher diary list
→ like_count 계산
→ Teacher UI 표시

확인할 것:

1. 학부모 like POST 성공 시
실제 diary_reactions row가 생성되는지

2. 생성된다면:
- diary_id
- parent_id
- student_id
- reaction_type='like'

가 올바른지

3. Teacher like_count SQL이
정확히 같은 diary_id를 조회하는지

4. Teacher 화면이
like_count를 어느 API response에서 받는지

5. Teacher 화면이 stale cache / local state / pagination 때문에
새 count를 갱신하지 못하는지

6. Teacher 화면 진입/재진입/refresh 시
API를 다시 호출하는지

7. reaction INSERT는 정상인데
Teacher list query의 WHERE / JOIN / filter 때문에 count가 빠지는지

8. teacher diary-reactions 화면에서는
누른 parent 이름이 보이는지
또는 count만 안 보이는지
