다음 작업은 AI 일지의 텍스트 입력 생성 과정에서 발생하는 깜빡임 수정입니다.

운영 서버와 Android 로그인은 현재 정상 복구됐으므로, 이번 작업에서는 아래 범위 외에는 절대 수정하지 마십시오.

작업 대상

- 선생님이 텍스트를 입력하고 AI 생성을 실행할 때
- 생성 중간에 ERROR 또는 PERMISSION 상태 UI가 순간적으로 나타나는 현상
- 생성 완료 후 이전 오류 UI나 버튼이 잔상처럼 남는 현상
- DiaryAIActionBar 또는 관련 AI 생성 상태 UI의 이중 렌더링

- loading / isLoading / isPending
- error / isError
- permission / isPermissionError
- generationStatus
- requestStatus
- local UI state
- React Query mutation state
- 컴포넌트 mount/unmount
- 화면 focus 시 상태 초기화
- 이전 요청의 오류 상태가 다음 요청까지 남는지
- 동일 기능을 렌더링하는 컴포넌트가 두 군데 존재하는지
- 조건문 사이에 한 프레임 동안 ERROR/PERMISSION이 기본값으로 평가되는지

특히 아래 가능성을 확인하십시오.

1. 요청 시작 직후 mutation.reset() 또는 오류 상태 초기화가 늦게 실행됨
2. 이전 요청의 isError/error 상태가 새 요청 시작 순간까지 남아 있음
3. 권한 확인 결과가 아직 로딩 중인데 false로 간주되어 PERMISSION UI 표시
4. query/mutation 상태와 별도 local state가 충돌
5. DiaryAIActionBar가 부모와 자식에서 동시에 렌더링
6. 생성 완료 후 이전 상태 컴포넌트가 key 또는 조건 문제로 남음
7. useEffect 실행 전 첫 렌더에서 오류 UI가 노출
8. 성공 응답 반영 전에 loading=false가 먼저 되어 중간 상태가 노출
9. API의 실제 오류가 아닌 취소·화면 전환·stale response를 ERROR로 처리
10. React Strict Mode 또는 focus 재렌더로 상태 전이가 두 번 발생

UI 우선순위도 명확히 하십시오.

1. 요청 진행 중이면 GENERATING만 표시
2. 권한 판정 로딩 중에는 PERMISSION 오류 표시 금지
3. ERROR는 현재 요청이 실제 실패한 경우에만 표시
4. SUCCESS가 확정되면 이전 ERROR/PERMISSION 상태 즉시 제거
5. 한 시점에 상태 UI는 하나만 렌더링
6. 새 생성 시작 전에 이전 요청 상태를 동기적으로 초기화
