1. 배포 전 마지막 P0 — PC Dashboard Login
━━━━━━━━━━━━━━━━━━━━━━

대표가 최종 확정한 정책:

공개 홈페이지의
[PC 대시보드]
→ /login

은 오직 "각 수영장 관리자 전용"입니다.

최종 UI:

아이디
비밀번호
PIN 번호

3개 입력.

PIN은 SWIMNOTE 앱에서 설정하는
기존 Web Dashboard PIN을 그대로 사용.

성공:

pool_admin
+ 올바른 ID/PW/PIN
→ 해당 swimming_pool_id scope
→ /admin

절대 금지:

super_admin
→ /login
→ /super

공개 PC 대시보드에서
super_admin 로그인은 반드시 차단되어야 합니다.

Super Admin은 별도:

/super-login

→ 기존 super_admin 인증/TOTP
→ /super

경로만 사용합니다.

홈페이지 Header/Footer/⋯ 메뉴에는
/super-login 링크를 노출하지 않습니다.

중요:
새 Auth API를 만들지 말고
기존 인증/PIN/JWT 로직을 재사용하십시오.

이미 이 구조가 구현되어 있다면
코드 수정 없이 검증만 하십시오.

미구현이면 이 P0만 최소 수정한 후 진행하십시오.

P0 검증 실패 시 Production 배포 금지.
