[SWIMNOTE Instagram Story V1 — Meta App ID 적용 후 Native Test Build 진행]

Gate 결과 확인 완료.

선택:
B안으로 진행한다.

플레이스홀더:
appId: "swimnote"

상태로 Native Build하지 않는다.

react-native-share 공식 Instagram Stories contract에 맞는
실제 Meta/Facebook App ID를 사용한다.

1. Meta App ID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

실제 Meta Developer App ID 확보 전까지
TestFlight / Android Native Build 시작 금지.

App ID 확보 후:

- source code 하드코딩 금지
- git commit에 App ID 직접 노출하지 않는 방식을 우선
- 현재 EAS 환경변수/Secret 구조를 확인하여 사용
- iOS/Android 동일 App ID 사용

예:

EXPO_PUBLIC_META_APP_ID

또는 현재 프로젝트의 기존 env naming convention 사용.

단 실제 client bundle에 들어가야 하는 공개 App ID이므로
비밀번호/secret처럼 취급할 필요는 없지만
플레이스홀더와 실제 값을 명확히 분리한다.

현재:

appId: "swimnote"

제거.

실제 환경변수/config에서 읽는다.

값이 없으면 Instagram Story 공유를 실행하지 않는다.

예:

if (!META_APP_ID) {
  Alert.alert(
    "Instagram 공유 준비 중",
    "Instagram Story 공유 설정이 완료되지 않았습니다."
  );
  return;
}
