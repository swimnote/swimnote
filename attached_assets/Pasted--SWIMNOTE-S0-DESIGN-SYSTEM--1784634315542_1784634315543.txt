# 현재 진행할 작업

## S0 — 디자인 시스템 기반 구축

이번 단계에서는 **디자인 시스템의 기반만 구축**합니다.

앱의 화면이나 기능은 절대 변경하지 않습니다.

## 작업 내용

### 1. Theme 시스템 생성

다음 구조를 생성합니다.

theme/

- colors.ts
- spacing.ts
- radius.ts
- typography.ts
- shadows.ts
- index.ts

---

### 2. 기존 colors.ts 유지

기존

constants/colors.ts

는 삭제하지 않습니다.

기존 import가 모두 정상 동작하도록

re-export 구조로 유지합니다.

기존 코드 수정 없이 그대로 동작해야 합니다.

---

### 3. DESIGN_SYSTEM.md 생성

DESIGN_SYSTEM.md를 프로젝트 최상단에 생성합니다.

문서에는 반드시 아래 내용을 포함합니다.

- 아이콘 규칙
- Component Naming Rules
- Colors
- Typography
- Spacing
- Radius
- Shadow
- 카드 규칙
- 버튼 규칙
- 배너 규칙
- 사진 카드 규칙
- 수업일지 카드 규칙
- Animation Rule
- Theme 구조
- 금지사항

Animation Rule에는

- 100ms
- 150ms
- 200ms
- 250ms

Fade

Scale

Spring

기준을 포함합니다.

Theme 구조에는

- Light
- Dark (Reserved)
- System (Reserved)

을 포함합니다.

# 이번 단계에서 절대 하면 안 되는 작업

이번 단계에서는 아래 작업을 하지 않습니다.

- 화면 UI 변경
- 카드 스타일 변경

- 아이콘 교체
- 배너 변경
- 학부모 홈 수정
- FlatList 변경
- Soft Snap 구현
