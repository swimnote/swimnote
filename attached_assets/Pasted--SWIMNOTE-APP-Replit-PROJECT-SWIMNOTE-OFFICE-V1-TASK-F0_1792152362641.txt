- 로그인 유지 선택·저장 성공/실패.

- 로그아웃.

token·PIN·비밀번호·불필요한 개인정보 표시 금지.

완료했다고 표시하지 않는다.
조회 대상이 없으면 그 사실을 구분한다.

4. Windows 패키징
- unsigned Windows x64 unpacked 검증본 1회 제작 승인.
- F02 ZIP과 구분되는 이름으로 저장하고 기존 파일 보존.
- 원본 ZIP 크기·SHA-256·포함 source 식별값 제공.
- exe 형식·필수 파일·asar 포함 확인.
- 실제 Windows 실행 전 실기기 PASS 선언 금지.
- signed installer·자동업데이트·Windows 자동 실행 제외.

전달 편의:
- 가능하면 원본 ZIP 하나로 전달.
- 첨부 제한으로 분할이 필요하면 같은 폴더에 풀고
  더블클릭하면 결합·해시 검증까지 하는 명령 파일 제공.
- 명령 파일은 상대 경로만 사용하고 관리자 권한·
  PowerShell 실행 정책 변경·추가 다운로드를 요구하지 않는다.
- 결합/해시 검증 실패 시 실행 단계로 넘어가지 않는다.
- 해당 전달 스크립트도 검증한다.
- 사용자가 경로 입력·수동 copy 명령을 반복하지 않게 한다.

5. 사용자 검증 안내
기존 F02 창 동작 검증은 반복하지 않는다.

최소 순서:
① toykids 계정으로 기존 로그인/PIN/TOTP 절차 진행.
② 실제 응답 기준 Pool·역할·X 접근 확인.
③ 로그인 유지 OFF → 종료/재실행 시 로그인 화면 확인.
④ ON으로 로그인 → 종료/재실행 시 서버 재검증 후 진입 확인.
⑤ 네트워크 끊김/복구 시 SSE 상태 변화 확인.
   업무 조회가 없다면 재동기화 완료 검증과 구분.
⑥ 로그아웃 → 재실행 시 자동 진입하지 않는지 확인.
⑦ 보조 swimnote 계정은 일반 모드의 기존 접근 정책 확인만.

실제 자격증명은 사용자 PC에서만 입력.
운영 PIN·TOTP·권한·회원정보 변경 실험 금지.
보안 경고·입력 오류가 발생하면 해당 화면만 수집.
보안 기능 해제·관리자 실행 요구 금지.

Windows DPAPI 저장/삭제는 안전한 상태 표시와
제한 진단 근거를 사용하고, 암호문 파일 자체 제출은 요구하지 않는다.
