[WP-X03 — X MODE POOL SETUP / DOCUMENT SUBMISSION / SUPER ADMIN SOURCE PACKAGE]

목적:

SWIMNOTE X 가입 수영장이
복잡한 앱 입력폼이 아니라
SWIMNOTE가 제공하는 표준 문서 양식을 다운로드하고,
작성한 파일과 브랜드 자료를 다시 업로드하여
X모드 세팅에 필요한 원본자료를 제출할 수 있게 한다.

동시에 Super Admin에서는
각 수영장별 제출자료/원본파일/처리상태를
한 곳에서 정확하게 확인하고 관리할 수 있게 한다.

이번 WP는 향후:

- 수영장별 X 커리큘럼 구축
- 수영장별 AI 설정
- 홈페이지 제작
- 고객센터 AI Knowledge
- Super Admin 운영

의 입력 source를 만드는 기반 작업이다.

==================================================
1. CORE PRODUCT POLICY
==================================================

X모드 수영장 세팅자료는
앱 안에서 긴 모달/폼을 작성시키지 않는다.

원칙:

SWIMNOTE 제공 DOCX 다운로드
→ 수영장이 PC 등에서 작성
→ 파일 업로드
→ 원본 그대로 보관
→ Super Admin에서 확인
→ 이후 SWIMNOTE가 구조화/가공

수영장이 제출하는 기본 자료:

1. 커리큘럼 작성양식 DOCX
2. 홈페이지 제작자료 DOCX
3. 로고 파일 (선택)
4. 홍보용 사진 최대 10장

중요:

원본파일은 절대 구조화 데이터로 대체하지 않는다.

ORIGINAL과 STRUCTURED를 분리한다.

5. CURRICULUM TEMPLATE
==================================================

SWIMNOTE가 제공할 공식 DOCX:

예:
SWIMNOTE_X_커리큘럼_작성양식.docx

중요:

이번 WP에서는 실제 DOCX template file을
repository/asset/download 구조에 포함할 수 있는지 확인하고,
가능하면 공식 파일 배포 경로까지 구현.

양식 내용의 핵심 가이드:

--------------------------------
커리큘럼 작성 안내

현재 체계적인 커리큘럼이 없어도 괜찮습니다.

현재 수영장에서 실제로 가르치는 순서와
각 단계에서 배우는 내용을 기준으로 작성해주세요.

최대 10단계까지 작성할 수 있습니다.

10단계를 반드시 모두 채울 필요는 없습니다.

현재 교육과정이 7단계라면
1단계부터 7단계까지만 작성하면 됩니다.

정확한 문장이나 전문적인 표현으로
작성할 필요는 없습니다.

현재 실제 수업에서
"이 단계에서는 무엇을 가르치는지"
중심으로 작성해주세요.

작성 내용이 구체적이고 상세할수록
SWIMNOTE가 해당 수영장의 실제 교육방식을
더 체계적으로 정리할 수 있습니다.
--------------------------------

24. ORIGINAL FILE STORAGE — CRITICAL
==================================================

원본파일을 반드시 그대로 보관.

Concept:

X_SETUP_SUBMISSION
│
├── ORIGINAL
│   ├── curriculum.docx
│   ├── website_profile.docx
│   ├── logo
│   └── photos[]
│
└── STRUCTURED
    └── future processing

이번 WP에서 STRUCTURED AI parsing을
과도하게 구현하지 않는다.

우선 원본 제출/보관/관리 source of truth 완성.

- 커리큘럼 내용을 더 자세히 작성해주세요.
- 대표사진을 고화질 가로사진으로 다시 올려주세요.
- 운영철학 설명을 추가해주세요.

필요 데이터:

requested_at
requested_by
message
resolved_at/status

수영장 pool_admin이
X Setup 화면에서 수정요청을 확인 가능.

기존 notification 시스템과 안전하게 연결 가능하면 재사용.

대규모 notification 변경은 금지.
