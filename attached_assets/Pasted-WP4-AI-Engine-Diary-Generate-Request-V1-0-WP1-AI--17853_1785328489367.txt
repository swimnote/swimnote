WP4 — AI Engine Diary Generate Request 구현 및 검증

설계도 V1.0을 기준으로 작업한다.

현재 상태

- WP1 완료 (AI 모달)
- WP2 코드 완료 (Voice Recorder)
- WP3 조건부 완료 (Whisper STT)
- Transcript는 입력창까지 정상 연결되는 구조 확인 완료

이번 WP에서는

Transcript를 AI Engine으로 전달하여
Diary Generate 요청을 생성하고
응답을 수신하는 단계까지만 구현·검증한다.

이번 WP에서는

- Draft Insert
- Save
- Student Diary 화면 반영

은 절대 수정하지 않는다.
