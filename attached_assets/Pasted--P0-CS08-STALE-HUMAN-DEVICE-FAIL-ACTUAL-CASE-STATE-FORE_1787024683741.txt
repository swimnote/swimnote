[P0-CS08-STALE-HUMAN-DEVICE-FAIL — ACTUAL CASE STATE FORENSIC]

실제 production iPhone에서 stale human UI defect 재현됨.

실제 화면 확인:

1. "스윔노트 x에 대해 알려줘"
   → 정상 답변 표시

2. "커리큘럼 검색에대해 알려줘"
   → 정상 답변 표시

하지만 현재 화면에는 계속:

- header: "상담사 연결 대기"
- legacy ack:
  "문의가 접수되었습니다. 운영팀이 확인 후 답변드립니다."
- human card:
  "상담사에게 문의하기"
  "상담사가 확인 중입니다. 잠시 기다려주세요."

가 표시됨.

따라서:

==================================================

→ answer
→ AI_RESPONDED
