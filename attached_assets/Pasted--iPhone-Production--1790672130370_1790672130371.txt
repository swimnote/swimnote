[추가 버그 — 공지 등록 대표 이미지 첨부 불가]

현재 실제 iPhone Production 화면에서
슈퍼관리자 > 공지 관리 > 공지 등록의

"대표 이미지 (선택, 16:9)"
→ "이미지 선택 (16:9 크롭 조절 가능)"

영역을 눌러도 사진 첨부가 정상적으로 동작하지 않는다.

이 문제를 기존 공지 등록 수정 작업에 포함해서 원인부터 추적하고 수정해라.

중요:
단순히 버튼 onPress를 다시 연결하는 식으로 추정 수정하지 말고
현재 실제 코드 흐름을 끝까지 확인한다.

1. 이미지 선택 버튼 onPress
2. 실제 호출되는 함수
3. expo-image-picker 또는 현재 사용 중인 이미지 선택 모듈
4. iOS 사진 권한 요청
5. launchImageLibraryAsync 호출 여부
6. picker 결과 처리
7. canceled/assets 처리
8. 선택한 asset URI 저장
9. crop/edit 단계 진입
10. 최종 local image URI가 공지 form state에 반영되는지
11. 미리보기에서 해당 이미지가 표시되는지
12. 최종 등록 시에만 R2 업로드되는지

특히 현재 UI에는
"16:9 크롭 조절 가능"
이라고 표시되어 있으므로,

실제로 크롭 기능이 구현되어 있지 않은 상태에서
UI 문구만 먼저 들어간 것인지도 확인한다.

━━━━━━━━━━━━━━━━━━━━
필수 확인
━━━━━━━━━━━━━━━━━━━━

A. 버튼 터치 자체가 안 먹는지
B. onPress는 실행되지만 picker가 호출되지 않는지
C. iOS 사진 권한에서 막히는지
D. picker는 열리지만 결과가 state에 저장되지 않는지
E. crop 로직 진입 과정에서 막히는지
F. 새 native dependency가 필요한 구현을 OTA 코드에 넣어둔 것은 아닌지

정확한 root cause를 보고할 것.

━━━━━━━━━━━━━━━━━━━━
수정 목표
━━━━━━━━━━━━━━━━━━━━

정상 동작은 다음과 같아야 한다.

이미지 선택
→ iPhone 사진 보관함 열림
→ 사진 선택
→ 16:9 영역 조절
→ 적용
→ 공지 등록 화면에서 선택 이미지 확인
→ 미리보기
→ 실제 공지 팝업과 동일한 16:9 이미지 표시
→ 최종 공지 등록 시에만 R2 업로드

이미지를 다시 누르면
사진 변경 또는 크롭 위치 재조정이 가능해야 한다.

취소하면 기존 입력 내용이 사라지면 안 된다.

━━━━━━━━━━━━━━━━━━━━
Native dependency gate
━━━━━━━━━━━━━━━━━━━━

현재 설치되어 있는 패키지만으로 안정적으로 구현 가능한지 먼저 확인한다.

새 native dependency가 필요한 경우:

- 임의 설치 금지
- Expo Go/현재 production binary에서 동작한다고 가정 금지
- OTA 배포 금지
- 필요한 패키지명
- 필요한 이유
- native build가 필요한 이유
- 현재 설치 패키지만으로 가능한 대안

을 보고하고 HOLD한다.

단, 새 native dependency 없이 현재 설치된 image-picker/image manipulation 기능으로
정상적인 16:9 선택/크롭이 가능하면 그대로 구현한다.
