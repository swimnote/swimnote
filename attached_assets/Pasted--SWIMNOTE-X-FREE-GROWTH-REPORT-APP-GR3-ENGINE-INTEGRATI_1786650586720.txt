5. TWO-PASS PRODUCT FLOW
==================================================

정상 시나리오:

PASS 1 — PREANALYSIS / INITIAL REPORT ANALYSIS

25일 이후:

APP snapshot 생성
parent_answers 없음 또는 현재 답변만 포함
→ ENGINE 호출

ENGINE:
questions[] + report result 반환

APP:
questions 저장
report analysis result 저장

질문이 있고 입력창 열림:
product_status = QUESTION_AVAILABLE

질문이 없으면:
READY_FOR_ANALYSIS 또는 REVIEW_REQUIRED로 이어질 수 있는
명확한 policy 사용.

PASS 2 — AFTER PARENT INPUT CLOSE / ANSWER

5일 이후 또는 Parent answer를 반영한 재분석:

새 request_id
새 immutable snapshot
parent_answers 포함
→ ENGINE 다시 호출

ENGINE:
parent evidence 포함 재분석
→ final structured result

APP:
기존 Product Report row에
최신 Engine Result 업데이트
→ REVIEW_REQUIRED

중요:

같은 request_id 재사용 금지.

새 분석 Snapshot은 새 request_id.
