SWIMNOTE Teacher Diary AI
FINAL RELEASE — 통합 감사·배포·운영 검증

목적

WP10~WP12까지 구현된 Teacher Diary AI를
실제 Production 환경에 안전하게 배포하고,
앱에서 실제 사용 가능한 상태인지 최종 검증한다.

→ AI 화면 진입
→ 텍스트 또는 음성 입력
→ AI 일지 생성
→ 학생별 결과 확인
→ 일지에 삽입
→ 최종 저장
→ 저장 결과 재조회

단순 코드 존재만으로 완료 처리하지 않는다.

7. Render 배포 확인
================================

Render가 해당 브랜치를 자동 배포하는 구조인지 먼저 확인한다.

자동 배포라면:

- 새 배포 시작 여부
- 배포 대상 commit SHA
- Build 성공 여부
- Start command 성공 여부
- 서버 정상 기동 여부
- Health check 성공 여부
- 반복 재시작 여부

수동 배포가 필요한 구조라면
기존 프로젝트 배포 방식만 사용한다.

배포 로그에서 다음을 확인한다.

- dependency install 오류
- TypeScript/build 오류
- DB migration 오류
- missing environment variable
- port binding 오류
- process crash
- route registration 실패

배포 대상 SHA가 로컬 HEAD와 정확히 같은지 확인한다.

배포가 완료되기 전 API 테스트를 PASS 처리하지 않는다.

완료 판정:

- PASS
- FAIL
