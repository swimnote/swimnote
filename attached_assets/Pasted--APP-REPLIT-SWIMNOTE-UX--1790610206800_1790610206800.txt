[SWIMNOTE — 홈 화면 '학부모 미연결' 진입 경로 수정]

현재 실기기에서 확인된 UX 문제입니다.

현재 관리자 홈 화면에 '학부모 미연결' 진입점이 2곳 있습니다.

1. 홈 통계 영역의
   '학부모미연결 XX명'

2. '처리 필요' 영역의
   '학부모 미연결 XX명 / QR 초대로 연결하기'

현재 이 중 학부모 미연결을 누르면
'QR 초대 > 학부모용' 화면으로 이동하는 경로가 있습니다.

하지만 현재 QR 초대 화면은 실제 학부모 연결 workflow와 네트워크 연결이 완성되어 있지 않으며,
사용자가 원하는 동작도 아닙니다.

이미 회원 관리 화면에는
'학부모미연결' 필터가 존재하고,
미연결 회원 목록을 정상적으로 표시할 수 있습니다.

목표:

관리자 홈에 존재하는 두 개의 '학부모 미연결' 진입점을 모두

회원 관리
→ 학부모미연결 필터가 선택된 상태

로 직접 이동하도록 통일하십시오.

예상 사용자 흐름:

홈
→ 학부모 미연결 XX명
→ 회원 관리
→ '학부모미연결' 필터 활성화
→ 미연결 회원 목록 표시
→ 회원 선택
→ 기존 회원 상세/학부모 연결 업무

두 번째 진입점도 동일합니다.

홈
→ 처리 필요
→ 학부모 미연결 XX명
→ 동일한 회원 관리 학부모미연결 목록
