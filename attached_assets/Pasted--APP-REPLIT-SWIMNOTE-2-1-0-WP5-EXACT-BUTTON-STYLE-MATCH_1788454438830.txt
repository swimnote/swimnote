# SWIMNOTE 2.1.0 — WP5 EXACT BUTTON STYLE MATCH

대상:
관리자 → 선생님 관리 → 선생님 선택 → 운영현황

첨부한 두 화면을 기준으로 작업.

기준 화면:
관리자 → 선생님관리 목록 화면

기준 버튼:
- 전체
- 승인됨
- 미승인
- 관리자

요구:
운영현황 화면의
- 담당 회원
- 출결
- 수업일지
- 보강

4개 버튼 디자인을
위 `선생님관리` 화면 버튼과 완전히 동일한 디자인으로 맞춘다.

============================================================
중요
============================================================

새 디자인 만들지 말 것.

새 chip style 만들지 말 것.

임의 수치 추측 금지.

"비슷하게" 만들지 말 것.

반드시 선생님관리 화면의 기존 버튼 구현을 직접 찾아서
같은 style/component/token을 그대로 재사용한다.

============================================================
1. 기준 UI 찾기
============================================================

선생님관리 화면에서 실제로 렌더링되는:

전체 / 승인됨 / 미승인 / 관리자

버튼의 JSX와 style/component를 찾는다.

확인:
- height
- paddingHorizontal
- paddingVertical
- borderRadius
- borderWidth
- backgroundColor
- borderColor
- text color
- fontSize
- fontWeight
- lineHeight
- gap
- selected/unselected 처리

가능하면 같은 컴포넌트 자체를 재사용.

컴포넌트 재사용이 어렵다면
동일 style object/token을 그대로 사용.

============================================================
2. 운영현황 4개 탭에 그대로 적용
============================================================

적용 대상:
- 담당 회원
- 출결
- 수업일지
- 보강

디자인은 선생님관리의:
- 전체
- 승인됨
- 미승인
- 관리자

와 동일해야 한다.

즉:
- 선택 버튼 색상 동일
- 비선택 버튼 테두리/배경 동일
- 높이 동일
- radius 동일
- 글자 크기 동일
- 좌우 여백 동일
- 버튼 간격 동일

텍스트 길이만 다르므로
버튼 폭은 내용에 따라 자연스럽게 달라도 됨.

============================================================
3. 기존 WP5 clipping 회귀 금지
============================================================

현재 운영현황에서 텍스트가 정상적으로 전부 보이는 상태는 유지.

다시 발생하면 안 되는 것:
- 글자 위아래 잘림
- 1px처럼 눌림
- ScrollView cross-axis collapse
- selected/unselected 높이 차이

선생님관리 버튼 style을 가져오되
운영현황의 현재 정상 렌더 구조를 깨지 말 것.

즉:
가능하면 visual style만 재사용하고
문제 없던 layout 구조는 유지.

============================================================
5. PASS 기준
============================================================

실기기에서 운영현황 버튼이
선생님관리 화면 버튼과 같은 디자인으로 보여야 함.

비교 기준:

선생님관리:
[전체] [승인됨] [미승인] [관리자]

운영현황:
[담당 회원] [출결] [수업일지] [보강]

두 화면의:
- 버튼 높이
- radius
- 테두리
- 선택색
- 비선택색
- 글자 스타일
- 내부 여백
- 버튼 간격

동일.
