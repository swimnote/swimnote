Scenario A:

"수업 일지는 앱의 홈 화면 하단 [일지 작성] 버튼을 눌러 작성할 수 있습니다..."

검증 대상:

* 홈 화면 하단에 실제 "일지 작성" 버튼이 존재하는가
* teacher role에서 실제 접근 가능한가
* 실제 일지 작성 경로와 일치하는가

Scenario C:

"...SwimNote의 공식 지원팀에 문의하시거나 앱 내 도움말을 확인해 보시기 바랍니다."

검증 대상:

* 실제 앱에 "도움말" 기능/메뉴/화면이 존재하는가
* 존재하지 않는다면 HALLUCINATED_UI_PATH로 판정

Scenario D:

"앱이 작동하지 않는 경우, 앱을 재시작해 보시거나 고객센터에 문의해 주세요."

검증 대상:

* 앱 재시작 안내가 현재 Support 정책상 허용되는 safe action인지
* 데이터 손실/설정 초기화 등을 암시하지 않는지
* 고객센터 escalation이 실제 지원 경로와 일치하는지

Scenario E:

"...앱 내 [고객센터] 버튼을 이용해 주세요."

검증 대상:

* 실제 앱에 "[고객센터]"라는 버튼/메뉴/화면이 존재하는가
* 해당 role에서 접근 가능한가
* 실제 표시 명칭과 일치하는가
