[SWIMNOTE 2.0.0 — CRITICAL PARENT SIGNUP WRONG POOL BUG]

실기기에서 Pool-First 가입 오류 재현됨.

재현:

1. 관리자 측에서 신규 수영장 "스윔노트3" 생성
2. 학부모 신규가입
3. 가입 화면에서 "스윔노트3" 선택
4. 가입 완료
5. 실제 학부모 계정은 계속 "스윔노트" 수영장으로 귀속됨

과거에도:
스윔노트2 / 스윔노트3처럼
기존 "스윔노트" 이름 뒤에 숫자를 붙여 가입 테스트했는데
학부모 계정이 계속 기본 "스윔노트"로 연결되는 현상 발생.

현재 2.0.0 Pool-First Architecture의 핵심 오류다.

이번 작업은 release/v2.0.0에서만 진행.

→ 그대로 INSERT

금지:

→ pool_name으로 다시 찾기

금지:

pool_name prefix 검색
→ 첫 row 선택

금지:

금지:

default pool fallback

6. 서버 Fallback 제거
==================================================

2.0.0 parent-register에서
pool_id가 없거나 invalid이면:

400

으로 실패해야 한다.

다음 fallback 금지:

- 첫 번째 pool
- 이름 비슷한 pool
- 기존 account pool
- legacy swimming_pool_id
- phone으로 찾은 기존 account pool
- default "스윔노트"

2.0.0 신규가입에서는
정확한 pool_id 없이는 account 생성 금지.

1.6.3 backward compatibility가 필요한 legacy endpoint는
별도로 유지 가능하지만
2.0.0 신규가입 route에는 적용하지 않는다.
