[앱] Growth Report 좋아요·댓글 기능 — 조사 및 구현계획서 작성 ONLY

이번 단계에서는 코드 수정/DB 변경/배포를 절대 하지 마십시오.

목적:
현재 일반 수업일지 피드에는 학부모의 좋아요·댓글 기능이 실제로 존재합니다.

반면 AI 성장 리포트 하단의
- 좋아요
- 댓글

은 현재 UI만 있고 실제 기능이 연결되어 있지 않습니다.

최종 목표는 향후:

1. 성장리포트 하단 좋아요/댓글 디자인을 기존 수업일지와 동일하게 통일
2. 기존 일지 좋아요와 동일한 실제 기능 연결
3. 기존 일지 댓글과 동일한 실제 기능 연결
4. 학부모가 성장리포트에 좋아요/댓글을 남기면
   해당 학생/반의 선생님이 기존 Teacher Mode 흐름에서 확인 가능
5. 가능하면 기존 일지 기능을 재사용하고 별도 중복 시스템을 만들지 않음

하지만 지금은 구현 금지.
먼저 실제 구조 조사 + 구현계획서만 제출하십시오.

5. 재사용 가능성 설계

A안
기존 diary likes/comments 시스템을 그대로 확장하여
target_type 또는 ref_type으로 Growth Report 지원

기존 interaction table/API 구조를 유지하면서
