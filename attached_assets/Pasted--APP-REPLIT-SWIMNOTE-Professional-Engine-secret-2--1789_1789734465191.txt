[SWIMNOTE — 훈련용어 검색 Professional Engine secret 불일치 수정]

2차 조사 결과 승인합니다.

확정 원인:

swimnote-api의

PROFESSIONAL_ENGINE_API_SECRET

값과

swimnote-professional-engine의

PROFESSIONAL_ENGINE_API_SECRET

값이 서로 달라서

API server → Professional Engine 호출이
항상 401 UNAUTHORIZED로 실패하고 있습니다.

이번 작업은 이 secret 불일치 1건만 수정하십시오.

swimnote-api

PROFESSIONAL_ENGINE_API_SECRET

PROFESSIONAL_ENGINE_API_SECRET

“APP authenticated smoke 확인하지 못함”
