3. HUB 메뉴 구성
==================================================

아래 기능 카드를 순서대로 배치.

① 우리아이 분석정보 보충하기

설명:
"아이를 더 정확하게 이해할 수 있도록
평소 모습과 최근 변화에 대한 정보를 추가할 수 있어요."

향후:
- 질문 목록
- 부모 자유 음성답변
- STT
- parent-reported evidence
로 연결 예정.

현재:
더미 상세 화면 또는 준비중 화면.

--------------------------------------------------

② 학생 기본정보 입력

설명:
"성장 분석에 참고할 기본 정보를 입력할 수 있어요."

입력 항목:

- 키 (cm)
- 몸무게 (kg)
- 나이

가능하면 기존 학생 schema에 생년월일이 존재하는지 먼저 확인.

생년월일이 이미 있으면:
→ 생년월일 기준 만 나이 자동 계산
→ 화면에 나이 표시
→ 별도 age 중복 저장하지 말 것.

생년월일이 없고
height / weight / age 저장 필드도 없다면
임의 DB schema 변경하지 말고
현재 저장 가능 구조가 있는지 먼저 확인.

DB migration이 반드시 필요하면
해당 부분만 STOP 후 정확한 최소 schema를 보고.

UI 입력 형식:

키:
숫자, cm

몸무게:
숫자/소수 허용, kg

나이:
정수 또는 생년월일 기반 자동 계산

validation:
음수 / 비정상 값 저장 금지.
