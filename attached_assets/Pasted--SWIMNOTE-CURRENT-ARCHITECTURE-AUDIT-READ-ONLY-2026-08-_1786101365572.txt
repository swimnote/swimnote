[REQ-1] 지난 보강 이월

지난달 미처리 보강은 다음 달로 넘어가도 삭제/숨김 처리하지 않습니다.

예:

7월 미처리
→ 8월에도 보강 대기 목록 유지

기간이 지난 경우:

“기간 지난 보강”

으로 표시.

일반 보강과 구분.

[REQ-2] 보강 가능 날짜

KST 오늘 기준:

오늘 -14일
~
오늘 +28일

경계 포함.

즉:

-14일 선택 가능
오늘 선택 가능
+28일 선택 가능

-15일 불가
+29일 불가

[REQ-3] 선보강

결석 예정일보다 먼저 보강 가능.

예:

결석 예정:
8월 20일

보강:
8월 17일

→ 가능해야 함.

다음 제한이 있으면 요구사항 위반 후보:

occurrence_date >= absence_date
makeup_date >= absence_date
결석일 이후만 표시

[REQ-4] 정원 초과 보강

보강은 선택한 반의 정원이 이미 가득 차 있어도
추가 배정할 수 있어야 합니다.

예:

정원 5명
현재 5명

→ 보강 학생 추가 가능
→ 6명 가능

정원 5명
현재 이미 6명

→ 보강 학생 추가 가능.

정원 정보 자체는 표시 가능.

예:

5/5
정원 마감
정원 초과

하지만 보강을 차단하는 조건으로 사용하지 않습니다.

정원 초과 때문에:

eligible class 제외
eligible occurrence 제외
날짜 선택 차단
배정 버튼 disabled
assign API 거절
DB update 거절

하면 안 됩니다.

이번 조사에서 현재 코드가 이 요구사항과
어디서 충돌하는지 반드시 찾습니다.
