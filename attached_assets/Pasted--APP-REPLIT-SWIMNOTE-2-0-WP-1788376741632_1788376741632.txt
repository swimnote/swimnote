============================================================
2. 목표 동작
============================================================

학생에게 보호자 전화번호가 존재하고,

same swimming_pool_id
+
same normalized guardian phone

의 기존 parent account가 있으면:

→ 해당 parent와 student를 자동 연결.

사용자가 별도의 승인 요청을 다시 하지 않아도
기존 parent account에서 해당 학생이 연결되어야 함.

단:

다른 pool parent:
연결 금지

전화번호 불일치:
연결 금지

전화번호 없음:
아무 작업 없음

이미 연결됨:
중복 row 생성 금지

중요:

NO

student creation 전체를 실패시켜야 하는지 여부는
현재 helper/기존 정책을 확인하고 동일하게 유지.

임의 정책 변경 금지.
