1. 저장소 전체 서버 후보 경로 조사
================================

저장소 전체에서 서버 프로젝트 후보를 찾는다.

반드시 조사:

- package.json이 있는 모든 서버 후보 디렉터리
- src/server.ts
- src/index.ts
- server.ts
- app.ts
- routes/index.ts
- Express 초기화 코드
- /api/health 등록 코드
- /api/auth/login 등록 코드
- /api/auth/me 등록 코드
- /api/diaries 등록 코드
- build script
- start script

다음 명령 또는 동등한 방식으로 조사한다.

find . -name package.json
find . -path "*/src/server.ts"
find . -path "*/src/index.ts"
find . -path "*/routes/index.ts"
grep -R '"/api/health"' .
grep -R '"/api/auth/login"' .
grep -R '"/api/auth/me"' .
grep -R 'router.use' .
grep -R 'app.use("/api"' .

결과를 서버 후보별로 표로 작성한다.

열:

- 경로
- package name
- build command
- start command
- API route 존재
- DB 연결 존재
- auth 존재
- production 가능성

2. 실제 Production entrypoint 확정
================================

현재 swimnote.kr에서 실행되는 API 서버의 entrypoint를 확정한다.

반드시 확인:

- Render Root Directory
- Render Build Command
- Render Start Command
- Render 연결 branch
- Render service name
- 실행 중인 Node entry file
- 현재 배포된 commit SHA
- 현재 health route를 제공하는 파일
- 현재 version v2.4-2026-07-20 문자열이 정의된 파일

코드에서 다음 문자열 위치를 찾는다.

v2.4-2026-07-20

이 문자열을 반환하는 파일이
현재 Production health endpoint의 실제 코드인지 확인한다.

반드시 기록:

- 실제 파일 경로
- 해당 파일을 실행하는 start command
- 해당 파일이 속한 package.json 경로

이 세 가지가 연결돼야 Production 서버로 인정한다.

================================
9. 절대 수정 금지 상태에서 통합 방식만 설계
================================

현재 단계에서는 파일을 옮기지 않는다.

대신 아래 두 경우로 나눠 통합 계획을 작성한다.

CASE A
artifacts/api-server가 실제 Production 서버인 경우

- 필요한 dependency
- 필요한 env
- route mount
- build/start
- 배포 순서

CASE B
artifacts/api-server가 Preview/복제 서버인 경우

- 실제 Production 서버 경로
- 옮겨야 할 backend 파일
- 옮기면 안 되는 test/audit 파일
- 기존 auth middleware에 연결할 위치
- 기존 DB client를 재사용할 위치
- 기존 error handler에 연결할 위치
- 기존 route index에 등록할 위치
- package.json 변경 위치
- lockfile 변경 위치
- Render Root Directory 유지 여부

중요:

“폴더 전체 복사” 금지.
필요 파일 단위로만 제안한다.

10. 현재 openai 오류의 진짜 의미 판정
================================

현재 오류:

src/routes/ai.ts:18:19
Could not resolve "openai"

다음 중 무엇인지 판정한다.

A. 실제 Production 서버에 openai dependency만 빠짐
B. Preview 서버를 잘못 Production 빌드 중
C. Production 서버 복제본의 package.json이 불완전
D. workspace dependency 선언이 잘못됨
E. 복합 원인

openai 패키지 설치를 해결책으로 제시하기 전에
서버 경로 판정을 먼저 완료한다.

각 항목을 HIGH / MEDIUM / LOW로 판정한다.

================================
12. 최종 판정
================================

다음 중 하나만 선택한다.

1. ARTIFACTS/API-SERVER IS VERIFIED PRODUCTION SERVER

의미:
artifacts/api-server가 실제 운영 서버이며,
현재 Render 경로가 맞다.

다음 단계:
dependency 수정 → build → push → Render 재배포

2. PRODUCTION SERVER MIGRATION REQUIRED

의미:
Teacher Diary AI backend가 Preview/복제 경로에 저장되어 있으며,
실제 운영 서버에 정식 이전해야 한다.

다음 단계:
운영 서버 경로 기준 파일 단위 이전 계획 수립 후 구현

3. RENDER PATH MISCONFIGURED

의미:
코드는 운영 서버에 있지만 Render Root/Build/Start 설정이 잘못됐다.

다음 단계:
Render 설정 수정 후 재배포

4. EVIDENCE INSUFFICIENT

의미:
Render 설정 또는 entrypoint 증거 부족

다음 단계:
필요한 화면과 설정값을 정확히 요청
