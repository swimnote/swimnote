[학부모 모드 AI 기능 안내 모달 제작 — 설계 및 구현 지시]

현재 학부모 홈에 아래 버튼 2개가 이미 만들어져 있습니다.

1. AI 커리큘럼
2. AI 성장 리포트

이번 작업은 실제 AI 기능 연결이 아니라,
각 버튼을 눌렀을 때 출시 예정 내용을 안내하는 모달을 표시하는 작업입니다.

0. 작업 원칙
━━━━━━━━━━━━━━━━━━━━━━

- 기존 버튼 위치, 크기, 색상, 아이콘을 변경하지 마십시오.
- 기존 학부모 홈 레이아웃을 이동하거나 재배치하지 마십시오.
- 선생님 모드와 운영자 모드는 수정하지 마십시오.
- API 연결 금지
- AI 연결 금지
- DB 변경 금지
- 결제 기능 연결 금지
- 현재는 안내 모달 UI만 구현합니다.
- 승인 없이 commit, push, OTA 배포하지 마십시오.

1. 버튼별 동작
━━━━━━━━━━━━━━━━━━━━━━

AI 커리큘럼 버튼 탭

두 버튼은 각각 독립된 내용을 표시해야 합니다.

동일한 모달 컴포넌트를 재사용하되,
title, icon, content를 props로 전달하는 방식도 가능합니다.

2. 공통 모달 구조
━━━━━━━━━━━━━━━━━━━━━━

모달은 화면 중앙의 작은 Alert 형태가 아니라,
내용을 충분히 읽을 수 있는 큰 안내 모달로 제작하십시오.

권장 구조:

Modal / Bottom Sheet
└─ backdrop
└─ modalContainer
├─ fixedHeader
│ ├─ 기능 아이콘
│ ├─ 제목
│ └─ 닫기 X 버튼
├─ ScrollView
│ └─ 안내 내용
└─ fixedFooter
└─ 확인 버튼

필수 조건:

- 모달 최대 높이: 화면 높이의 약 80~85%
- 모달 최소 높이 고정 금지
- 짧은 내용이면 콘텐츠 높이에 맞춤
- 긴 내용이면 본문 영역만 스크롤
- 헤더와 확인 버튼은 스크롤되지 않고 고정
- 본문 ScrollView는 충분한 스크롤 공간 확보
- ScrollView에 flex: 1 또는 명확한 높이 경계 적용
- contentContainerStyle의 하단 padding은 최소 32~40
- iOS에서 위아래 스크롤 정상
- Android에서도 위아래 스크롤 정상
- nestedScrollEnabled 적용 검토
- 텍스트 마지막 문장이 확인 버튼에 가려지지 않도록 여유 확보
- Safe Area 대응
- 키보드는 사용하지 않으므로 입력창 없음
- 배경 터치로 닫기 여부는 기존 앱 모달 정책에 맞춤
- X 버튼과 확인 버튼 모두 모달을 닫을 수 있어야 함

중요:

이전에 발생했던 것처럼 modalContainer에 position:absolute를 사용해
ScrollView 높이 계산이 깨지지 않게 하십시오.

backdrop에 justifyContent:"center" 또는 "flex-end"를 적용하고,
modalContainer는 flex 레이아웃 안에서 명확한 maxHeight를 가져야 합니다.

4. AI 성장 리포트 모달
━━━━━━━━━━━━━━━━━━━━━━

제목:

AI 성장 리포트

본문:

세계 최초 수영 전문 AI 엔진 SWIMNOTE AI와 OpenAI GPT가 결합된 차세대 AI 성장 분석 서비스입니다.

수영 학습 데이터를 분석하여 130개의 평가 데이터로 구성된 종합 성장 리포트를 제공합니다.

수영 과정에서 축적된 다양한 학습 데이터를 바탕으로 운동 능력뿐 아니라 일반학습과 관련된 집중력, 논리적 사고, 문제 해결 과정 등 학습에도 도움이 될 수 있는 성장 지표를 함께 분석하여 아이의 강점과 성장 방향을 확인할 수 있습니다.

SWIMNOTE AI의 수영 전문 분석 기술과 OpenAI GPT  빅데이터 분석 결합을 통해 부모님이 이해하기 쉬운 최종 분석 보고서를 제공합니다.

성장평가분석 리포트 라이센스 최종 체결 후 서비스가 제공됩니다.

현재 토이키즈스윔클럽에서 swimnote AI와 oepnAI gpt독점 시범 서비스를 준비 중이며, 정식 출시 후 순차적으로 확대될 예정입니다.

5. 디자인
━━━━━━━━━━━━━━━━━━━━━━

- 기존 학부모 모드 디자인 토큰 우선 사용
- 모달 배경: 흰색
- 모서리 radius: 기존 앱 모달과 통일
- 제목: 19~22px, Bold
- 본문: 14~16px
- 줄 간격: 22~26px 수준으로 충분히 확보
- 문단 간격: 최소 16px
- 좌우 padding: 최소 22~24px
- 본문 정렬: 왼쪽 정렬
- 버튼/아이콘/하단 Powered 문구 색상은 현재 학부모 화면에 적용된 동일한 AI 색상 사용

- 현재 제작된 각 기능 아이콘이 있다면 헤더에 작은 크기로 재사용 가능
- 아이콘 원본 비율 유지
- 아이콘이 제목보다 과도하게 커지지 않게 조절
- 확인 버튼은 기존 앱 primary 버튼 스타일 우선

━━━━━━━━━━━━━━━━━━━━━━
6. 접근성 및 동작
━━━━━━━━━━━━━━━━━━━━━━

- 모달이 열리면 배경 화면 터치 차단
- 닫힌 뒤 버튼 focus/state 정상 복구
- 빠르게 연속 탭해도 모달 중복 생성 금지
- A 모달을 닫고 B 모달을 열 때 이전 내용 잔존 금지
- 스크롤 위치는 모달을 새로 열 때 최상단으로 초기화
- 작은 화면에서도 제목·본문·확인 버튼이 잘리지 않아야 함
- Dynamic Type가 큰 경우에도 최소한 스크롤로 전체 내용 확인 가능
- iPhone SE급 작은 화면 확인
- 일반 iPhone 확인
- Android 소형 화면 확인
- 가로모드는 현재 앱 지원 정책에 따름
