직전 READ ONLY forensic 결과를 승인합니다.

ROOT CAUSE는 확정되었습니다.

문제:
artifacts/api-server/src/lib/class-membership.ts
classAccessPredicate()

현재 관리자 우회 조건이
JWT의 현재 effective role이 아니라
DB users.role을 기준으로 동작함.

따라서 DB 기본 role=pool_admin,
roles=[pool_admin, teacher]인 겸임 계정이
teacher JWT로 호출해도 관리자 전체반 접근이 허용됨.

목표 계약:

- effective JWT role=teacher
  → 주담당 teacher_user_id 또는 co_teacher_ids에 포함된 반만
- effective JWT role=pool_admin
  → 자기 swimming_pool_id 전체 반
- super_admin
  → 기존 계약 유지
- DB 기본 role이 pool_admin이어도
  teacher JWT에서는 관리자 우회 금지
