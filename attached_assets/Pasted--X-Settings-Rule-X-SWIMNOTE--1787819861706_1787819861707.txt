[앱] X모드 선생님 설정 — 공통 Settings Rule 적용

현재 X모드 선생님 설정 화면을
이미 확정한 SWIMNOTE 공통 설정 원칙에 맞게 재정리합니다.

이번 작업은 UI/IA 정리 ONLY.

기능 삭제/통합 금지.
API/DB 수정 금지.
기존 route/toggle/storage 로직 유지.

━━━━━━━━━━━━━━━━━━━━━━
1. 공통 Settings Rule
━━━━━━━━━━━━━━━━━━━━━━

앞으로 모든 모드/자격 설정 화면 공통 기준:

- 최상단 프로필/역할 요약
- 해당 역할에서 정말 자주 쓰는 핵심 기능만 첫 화면 직접 노출
- 나머지는 4개 안팎의 분류로 수납
- 첫 화면과 분류 내부 동일 기능 중복 최소화
- 쿠팡식 익숙한 list UI
- section container + hairline divider
- White / Navy / Neutral
- 큰 rounded card 반복 금지
- shadow 최소화
- 기능은 먼저 보존, 통합/삭제는 별도 단계

이번 X모드 선생님 설정도 이 기준에 맞춤.

━━━━━━━━━━━━━━━━━━━━━━
2. 최상단 선생님 요약
━━━━━━━━━━━━━━━━━━━━━━

현재 선생님 이름/수영장/역할 정보가 있으면
compact profile summary row로 정리.

예:

서경민 선생님
토이키즈스윔클럽

우측:
필요 시 역할전환 또는 기존 동작 유지

큰 프로필 Hero 카드 금지.

━━━━━━━━━━━━━━━━━━━━━━
3. 첫 화면 직접 노출 핵심 기능
━━━━━━━━━━━━━━━━━━━━━━

사진 기준으로 선생님이 실제 자주 쓰는 핵심 기능은
첫 화면에 직접 남깁니다.

직접 노출 권장:

1. 공지함
subtitle:
수영장 공지 확인

2. 선생님 설정
subtitle:
담당 수업 · 기본 설정

3. 일지 템플릿
subtitle:
수업 일지 작성 템플릿 관리

4. 알림함
subtitle:
좋아요 · 댓글 · 요청 · 소식 확인

5. 사진·영상 업로드/앨범
subtitle:
수업 사진과 영상 관리

중요:
현재 기능 route가 실제로 존재하는 항목만 사용.
새 기능 만들지 말 것.

이 5개는 첫 화면에서 바로 찾을 수 있게 유지.

━━━━━━━━━━━━━━━━━━━━━━
4. 설정 toggle류는 분류 안으로
━━━━━━━━━━━━━━━━━━━━━━

현재 화면에 길게 나열된 toggle:

- 납부 체크 기능 사용
- 쪽지·메시지 알림
- 보강 신청 알림
- 일지 리마인더
- 소식
- 좋아요
- 일지 댓글

등은 첫 화면에 전부 펼쳐두지 말고
"알림 및 개인 설정" 분류 안으로 수납.

첫 화면에서 토글을 여러 개 직접 노출하지 말 것.

━━━━━━━━━━━━━━━━━━━━━━
5. 나머지 설정 분류 4개
━━━━━━━━━━━━━━━━━━━━━━

추천 분류:

A. 알림 및 개인 설정
subtitle:
메시지 · 보강 · 일지 · 좋아요 · 댓글

내부:
- 쪽지·메시지 알림
- 보강 신청 알림
- 일지 리마인더
- 소식 알림
- 좋아요 알림
- 일지 댓글 알림
- 기타 현재 존재하는 개인 알림 toggle

B. 수업 및 운영
subtitle:
납부 체크 · 수업 운영 · 보강

내부:
- 납부 체크 기능 사용
- 수업 관련 기존 설정
- 보강 관련 기존 설정
- 선생님 설정에서 직접 노출되지 않은 운영 보조 설정

C. 저장공간 및 데이터
subtitle:
사진 · 영상 · 일지 · 저장용량

내부:
- 저장공간 현황
- 사진 용량
- 영상 용량
- 메시지 데이터
- 수영일지 데이터
- 공지 데이터
- 시스템 데이터

중요:
현재 저장공간 상세 정보는 기능은 유지하되
첫 화면에 전체 펼침 금지.
분류 내부에서 확인.

D. 도움말 및 계정
subtitle:
약관 · 정책 · AI · 문의 · 업데이트

내부:
- 이용약관
- 개인정보처리방침
- 환불 및 결제 정책
- AI 문의
- 문의하기(기존)
- 업데이트 확인
- 회원 탈퇴
- 현재 존재하는 계정/지원 메뉴

회원 탈퇴는 항상 이 분류 최하단 위험 영역.

━━━━━━━━━━━━━━━━━━━━━━
6. 문의 관련
━━━━━━━━━━━━━━━━━━━━━━

이번 선생님 설정에서는
관리자처럼 "문의함" 운영 기능이 아니라
선생님 개인 문의 기능 기준으로 처리.

현재 존재하는:

- AI 문의
- 문의하기(기존)

는 이번 단계에서 기능 통합하지 말 것.

둘 다
"도움말 및 계정" 내부에 수납.

향후 중복 문의 통합은 별도 단계.

━━━━━━━━━━━━━━━━━━━━━━
