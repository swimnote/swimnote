SWIMNOTE 보강 날짜 범위 수정 — 최종 검수 및 누락 보완 지시

현재 구현 방향은 승인한다.

다만 Commit·Push·배포 전 아래 2개를 마무리해야 한다.

1. 관리자 네트워크 오류 안내 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

파일:

artifacts/swim-app/app/(admin)/makeups.tsx

현재 제출 내용에는 HTTP 오류 Alert만 있고 네트워크 오류 처리 변경이 확인되지 않는다.

현재 catch가 아래처럼 목록만 다시 불러오는 구조라면:

.catch(() => load());

다음 동작으로 변경한다.

- 네트워크 오류 Alert 표시
- 그 뒤 load()로 optimistic 제거 상태 복원
- 기존 409 conflict 처리는 그대로 유지
- 성공 처리 변경 금지

기대 동작:

Alert 제목:
배정 실패

메시지:
네트워크 오류로 보강을 배정하지 못했습니다. 잠시 후 다시 시도해주세요.

수정 후 handleAssign의 전체 Promise 처리 구간을 제출한다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

97개 테스트 통과 숫자만 제출하지 말고 아래 결과를 각각 명시한다.

### 보강 상태

- waiting + 범위 내 + 기존 expire_at 이후
  기대: 허용

  기대: 409 MAKEUP_EXPIRED_CONFIRM_REQUIRED

- expired + allow_expired=true + 범위 내
  기대: 허용

- expired + allow_expired=true + 범위 밖
  기대: 400 MAKEUP_DATE_OUT_OF_RANGE

- completed

- cancelled
  기대: 차단

  기대: 차단

  기대: 기존 COMPLETE_DIRECT_REQUIRES_TODAY_OR_PAST 유지
