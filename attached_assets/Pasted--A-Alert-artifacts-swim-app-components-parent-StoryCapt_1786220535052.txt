B. Alert 발생 조건

if (!META_APP_ID)   // META_APP_ID가 "" (빈 문자열) 또는 undefined 이면 true
조건 true = Alert 발생 + cleanup + onDone() 즉시 종료

C. 실제 실패한 조건값

항목	값
process.env.EXPO_PUBLIC_META_APP_ID	undefined (OTA 번들 빌드 시점에 미주입)
META_APP_ID	"" (nullish coalescing fallback)
!META_APP_ID	true → Alert 발생
D. META_APP_ID 실제 runtime 값

EXPO_PUBLIC_* 변수는 Metro bundler 빌드 시점에 소스코드에 literal로 inline 됩니다.

// eas update 실행 시 로컬 Replit 환경에서 Metro bundle 생성
printenv EXPO_PUBLIC_META_APP_ID → (아무 값도 없음, exit code 1)
// 결과: bundle 안의 코드
const META_APP_ID = undefined ?? "";  // = ""
