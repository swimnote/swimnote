============================================================
B. WP7 — x-setup dynamic previous-page fallback 수정
============================================================

현재 fda30b5c 문제:

x-setup.tsx 진입 가능 경로가 최소:

1. Settings → X Setup
2. X Mode Hub → X Setup
3. X Mode Hub → Subscription → X Setup

인데 stack이 없을 때 fallback을
무조건 Settings로 보내고 있음.

이것은:

BACK = 바로 직전 단계

정책을 완전히 보장하지 못함.

최종 정책:

x-setup 진입 시
호출하는 parent가 명시적으로 backTo를 전달.

예:

Settings → X Setup
backTo=settings

X Mode Hub → X Setup
backTo=x-mode-hub

Subscription → X Setup
backTo=x-subscription

x-setup Back:

1. 정상 stack이 있고 그것이 신뢰 가능한 경우
   → previous screen

2. stack이 없거나 불안정
   → 전달받은 backTo logical parent

3. backTo도 없을 경우에만
   → settings 최후 fallback

중요:
하위 페이지 자체가 parent를 추측하지 말고
진입 route에서 backTo를 정확히 전달하는 방식을 우선 사용.

동일 원칙으로
x-subscription / XInfoDetailPage도
진입 parent와 fallback이 정확히 일치하는지 재확인.

테스트:

W7C-01 Settings → X Setup → Back = Settings

W7C-02
Settings → X Mode → X Setup
→ Back = X Mode

W7C-03
Settings → X Mode → Subscription → X Setup
→ Back = Subscription

W7C-04
위 W7C-03에서 다시 Back
→ X Mode

W7C-05
X Info pages → Back = X Mode

W7C-06
stack unavailable 상태에서도 동일 logical parent

W7C-07
Back → Admin Home 발생 0

W7C-08
Home icon → Admin Home 유지
