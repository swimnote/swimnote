최소 실제 샘플:

CASE A
Teacher A 현재 담당반 학생
→ A visibility = true

CASE B
Teacher B의 학생
→ A visibility = false

CASE C
학생이 A반에서 B반으로 이동했고
과거 보강이 남아 있는 경우
→ 현재 B = true
→ 과거 A = false

CASE D
expired 보강
→ 현재 담당 teacher에게 true

CASE E
현재 co_teacher
→ true

CASE F
handed_to_teacher_id = Teacher C
→ C = true

CASE G
handoff가 있어도 현재 담당 teacher
→ 기본 current-class 조건으로 true인지 확인

실제 데이터가 없는 CASE는
임의 데이터를 만들지 말고 NOT_TESTABLE로 표시.
