2. 이미 변경한 내용이 있다면
==================================================

먼저 현재 작업상태를 조사한다.

아직 commit되지 않은 가격/구독 관련 변경:
→ 전부 원복

이미 commit했지만 production deploy 전:
→ 해당 변경을 production에 배포하지 말고
   가격 변경 전 stable commit 기준으로 되돌린다.

이미 production DB를 수정했다면:
→ 즉시 보고하고 임의 복구 금지.
→ 어떤 table/row/column이 변경되었는지 정확히 보고.
→ 데이터 손실 없이 rollback 계획부터 작성.

이미 RevenueCat / Apple / Google Play Console을 변경했다면:
→ 어떤 product/price/offering이 변경됐는지 정확히 보고.
→ 추가 변경 금지.
