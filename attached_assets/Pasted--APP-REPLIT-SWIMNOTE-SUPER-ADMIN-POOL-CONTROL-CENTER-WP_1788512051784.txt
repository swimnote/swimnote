────────────────────
C. HEALTH ISSUE → DETAIL TAB DRILL-DOWN
────────────────────

가장 중요한 WP1 작업.

Health issue 클릭 시 해당 문제와 연관된 Control Center 탭으로 이동시킨다.

기본 매핑 예:

- FREQUENT_ERRORS
  → Errors 탭

- GR_FAILURES
  → Growth Reports 탭

- STORAGE_QUOTA
  → Storage 탭

- entitlement / paid + force-disabled conflict
  → Access / Plan 탭

- AI 관련 failure
  → AI 탭

- Notification / Push 관련 문제
  → Notifications 탭

- Curriculum processing 문제
  → Curriculum 탭

실제 존재하는 issue code 목록을 코드에서 먼저 확인하고
그 목록을 기준으로 deterministic mapping을 작성할 것.

절대 문자열 감으로 임의 추론하지 말 것.

매핑되지 않은 issue는:
- Overview에 표시하되
- 잘못된 탭으로 이동시키지 말 것.

탭 이동 방식:
- 기존 SuperPoolControlCenter의 active tab state / routing 구조 재사용.
- 새 페이지 push를 남발하지 말 것.
- 같은 Control Center 내부에서 탭 전환.
- 가능하면 URL/query/hash 등의 기존 상태 구조가 있으면 그것을 유지.
- 브라우저 뒤로가기 동작을 망가뜨리지 말 것.

D. RECENT SUPPORT CASE
────────────────────

우선순위:

- state
- created_at / updated_at
- category/title 등이 실제 DB source에 있을 때만 표시

없는 title/category를 가짜로 만들지 말 것.

클릭 시:
→ Support 탭 이동.

support case가 없으면:
→ “최근 지원 요청 없음” 정도로 표시.
