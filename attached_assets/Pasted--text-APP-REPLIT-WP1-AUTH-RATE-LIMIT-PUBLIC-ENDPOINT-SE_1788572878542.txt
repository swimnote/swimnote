A. Auth-sensitive rate limit

최소 대상:

- login
- signup
- password reset/request/verify 계열
- 현재 실제 repository에 존재하는 기타 credential/auth-sensitive public endpoint

- 정상 사용자를 과도하게 차단하지 않음

- rate-limit 응답은 식별 가능한 HTTP status/error로 반환

구체 limit 값은 현재 route 특성과 기존 convention을 확인해 합리적인 최소값으로 설정하고 보고하십시오.
