4. LIFECYCLE 규칙
━━━━━━━━━━━━━━━━━━━━

global_template_sets.status:

DRAFT
ACTIVE
ARCHIVED

규칙:

- 신규 set은 DRAFT
- ACTIVE는 전체 시스템에서 최대 1개
- DRAFT → ACTIVE 가능
- ACTIVE → ARCHIVED 가능
- ARCHIVED를 임의 수정/재활성화할지는
  기존 설계/코드 확인 후 보수적으로 처리
- 동시에 ACTIVE 2개가 생기면 안 됨

activate는 반드시 transaction 처리.

새 set을 ACTIVE로 만들 때:

기존 ACTIVE 존재 시
정확한 기존 설계에 따라
기존 ACTIVE를 ARCHIVED 처리하고
새 set을 ACTIVE로 전환.

중간 상태에서 ACTIVE 2개가
존재하지 않도록 보장.
