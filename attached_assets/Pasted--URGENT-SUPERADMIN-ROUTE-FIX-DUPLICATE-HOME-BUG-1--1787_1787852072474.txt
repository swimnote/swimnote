[URGENT SUPERADMIN ROUTE FIX — DUPLICATE HOME BUG]

현재 슈퍼관리자 네비게이션 버그가 확인됐다.

증상:

1. 정상 슈퍼관리자 홈은
   SWIMNOTE 헤더가 있는 대시보드 화면이다.
   - 전체 수영장
   - 활성 수영장
   - 승인 대기
   - X MODE
   - 수영장 현황
   - Action Center
   - 운영 건강
   등이 표시되는 화면

2. 그런데 슈퍼관리자에서
   X모드 관리 등 하위 화면에 진입한 뒤
   "홈" 버튼을 누르면

   상단에 "더보기"라고 표시되는
   별도의 화면으로 이동한다.

3. 결과적으로 슈퍼관리자 홈이 2개처럼 동작하며
   잘못된 "더보기" 화면에서는
   정상 홈에 있어야 할 로그아웃 접근도 사라진다.

==================================================
1. ROOT CAUSE 조사
==================================================

슈퍼관리자 관련 모든 home/navigation route를 조사한다.

반드시 확인:

- superadmin root route
- superadmin home route
- more route
- tabs/layout route
- X mode 관리 화면의 home navigation target
- header home button target
- bottom/tab home target
- router.replace / router.push 대상
- redirect logic
- initialRouteName
- index.tsx
- _layout.tsx

현재 어떤 경로 때문에
"더보기" 화면이 superadmin home처럼 열리는지
정확한 ROOT CAUSE를 확인한다.

추측 금지.

==================================================
2. FINAL ROUTE POLICY
==================================================

슈퍼관리자 홈은 반드시 1개만 존재해야 한다.

FINAL SUPERADMIN HOME:

현재 SWIMNOTE 헤더가 있고
대시보드 카드가 표시되는 화면.

즉:

- 전체 수영장
- 활성 수영장
- 승인 대기
- X MODE
- 수영장 현황
- Action Center
- 운영 건강

이 화면을 유일한 superadmin home으로 사용한다.

==================================================
3. "더보기" 화면 처리
==================================================

현재 상단에 "더보기"라고 표시되는
기존 화면이 superadmin home 역할을 하면 안 된다.

다음 중 repo 구조에 가장 안전한 방식으로 처리:

A. 사용하지 않는 legacy route면
   navigation target에서 완전히 제거

또는

B. route 자체를 유지해야 하면
   접근 시 FINAL SUPERADMIN HOME으로 redirect

중요:
기존 다른 역할의 화면까지 삭제하지 말고
superadmin home 중복 문제만 해결한다.

==================================================
4. 모든 HOME ACTION 수정
==================================================

슈퍼관리자 상태에서 아래 모든 동작은
FINAL SUPERADMIN HOME으로 이동해야 한다.

- X모드 관리 → 홈
- 구독 관리 → 홈
- 운영 관리 → 홈
- 데이터 관리 → 홈
- 보안/통제 → 홈
- 기타 superadmin 하위화면 → 홈
- header home
- tab home
- hardware back 후 home 진입
- deep link 후 home 복귀

어떤 경로에서도
"더보기" 화면을 superadmin home으로 열면 안 된다.

==================================================
5. LOGOUT
==================================================

FINAL SUPERADMIN HOME에는
현재 정상 로그아웃 버튼이 반드시 유지되어야 한다.

잘못된 legacy "더보기" 화면에
로그아웃 버튼을 따로 추가해서 문제를 덮지 말 것.

원인은 duplicate home routing이므로
routing을 수정한다.
