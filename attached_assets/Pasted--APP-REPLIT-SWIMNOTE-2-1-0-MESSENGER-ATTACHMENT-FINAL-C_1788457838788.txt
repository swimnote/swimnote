============================================================

없다면 APP/서버에서 DB migration 없이
기존 extra/metadata JSON 또는 현재 사용 가능한 필드를 통해
batch id를 저장할 수 있는지 확인.

DB schema 변경 금지.

임의 변경하지 말고 보고 후 중단.

============================================================
1-2. GROUPING 요구
============================================================

한 번에 선택한 사진:
photo A
photo B
photo C

→ 업로드는 개별 request여도 됨.

하지만 최종 메시지 렌더는:

GalleryGroup
  photo A
  photo B
  photo C

형태로 묶어서 표시.

중요:
시간이 비슷하다는 이유만으로 임의 grouping 금지.

반드시 같은 selection/upload batch인지
명시적으로 판별할 수 있어야 함.
