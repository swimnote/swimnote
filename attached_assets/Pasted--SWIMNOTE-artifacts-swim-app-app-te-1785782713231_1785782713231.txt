[SWIMNOTE 긴급 수정 — 일지 작성 하단 ‘나가기’ 버튼 구현 승인]

원인조사 결과를 승인한다.

확정 원인:

artifacts/swim-app/app/(teacher)/diary.tsx에서

onBack={params.backTo ? undefined : () => setSelectedGroup(null)}

를 DiaryWriteView에 전달하고 있어,
params.backTo가 존재하는 모든 진입 경로에서 하단 나가기 버튼의
Pressable.onPress가 undefined가 된다.

이번 수정은 일지 화면의 상단 뒤로가기와 하단 나가기가
동일한 종료 함수를 사용하도록 통합한다.

1. 수정 대상
━━━━━━━━━━━━━━━━━━━━━━

파일:

artifacts/swim-app/app/(teacher)/diary.tsx

원칙적으로 이 파일 1개만 수정한다.

DiaryWriteView.tsx의 버튼 UI·스타일·저장 로직은 변경하지 않는다.

━━━━━━━━━━━━━━━━━━━━━━
2. 공통 종료 함수 구현
━━━━━━━━━━━━━━━━━━━━━━

diary.tsx에 handleExitDiary를 추가한다.

중요:

단순히 다음 두 경로만 하드코딩하고
나머지를 router.back()으로 처리하지 않는다.

- my-schedule
- today-schedule

기존 SubScreenHeader가 사용하던 params.backTo 처리 규칙을
그대로 보존해야 한다.

현재 화면은 teacher route이므로,
params.backTo가 있으면 기존 상단 헤더와 동일한 최종 경로로 이동한다.

권장 구조:

const handleExitDiary = useCallback(() => {
  if (params.backTo) {
    router.replace(
      (`/(teacher)/${params.backTo}`) as any
    );
    return;
  }

  setSelectedGroup(null);
}, [params.backTo, router]);

단, params.backTo 값에 이미 경로 prefix 또는 query가 포함될 가능성이 있다면
Repository의 실제 전달값 전체를 먼저 확인하고 기존 SubScreenHeader의
경로 조합 방식을 정확히 복사한다.

확인 대상:

- today-schedule
- my-schedule
- diary-unwritten
- diary-index

임의로 경로 이름을 변경하지 않는다.

━━━━━━━━━━━━━━━━━━━━━━
3. 두 버튼에 동일 함수 연결
━━━━━━━━━━━━━━━━━━━━━━

상단 SubScreenHeader:

변경 전:

onBack={params.backTo ? undefined : () => {
  setSelectedGroup(null);
}}

변경 후:

onBack={handleExitDiary}

하단 DiaryWriteView:

변경 전:

onBack={params.backTo ? undefined : () => {
  setSelectedGroup(null);
}}

변경 후:

onBack={handleExitDiary}

상단과 하단이 반드시 같은 함수 참조를 사용해야 한다.

━━━━━━━━━━━━━━━━━━━━━━
4. 동작 정책
━━━━━━━━━━━━━━━━━━━━━━

params.backTo 있음:

- 해당 teacher 화면으로 router.replace
- 예:
  - today-schedule → /(teacher)/today-schedule
  - my-schedule → /(teacher)/my-schedule
  - diary-unwritten → 실제 기존 경로
  - diary-index → 실제 기존 경로

params.backTo 없음:

- diary 내부에서 선택된 반 화면만 닫음
- setSelectedGroup(null)
- diary 메인 화면으로 복귀
- router.back()을 호출하지 않음

━━━━━━━━━━━━━━━━━━━━━━
