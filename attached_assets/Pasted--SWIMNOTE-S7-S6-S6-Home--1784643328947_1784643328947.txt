# SWIMNOTE 디자인 시스템 리뉴얼 — S7 작업 지시

S6 완료 보고서를 검토했습니다.

S6는 승인합니다.

학부모 Home 구조 변경이 계획대로 완료되었으며, API·Context·Navigation을 변경하지 않은 점을 확인했습니다.

이제 S7만 진행하세요.

======================================
S7 — Soft Snap 구현
======================================

이번 단계의 목표는 스크롤 경험을 개선하는 것입니다.

기존 UI와 기능은 절대 변경하지 않습니다.

======================================
작업 시작 전
======================================

현재 상태의 Checkpoint를 먼저 생성하세요.

보고 항목

- Checkpoint 생성 여부
- Rollback 가능 여부

Checkpoint 생성 후 작업을 시작하세요.

======================================
구현 목표
======================================

학부모 Home FlatList에 Soft Snap을 적용합니다.

강제 페이지 이동이 아닌 자연스러운 보정만 수행합니다.

======================================
구현 규칙
======================================

허용

- onLayout 기반 위치 측정
- onMomentumScrollEnd
- SNAP_THRESHOLD
- MAX_SNAP_DISTANCE
- VELOCITY_CUTOFF

금지

- pagingEnabled
- snapToInterval
- snapToOffsets
- 강제 페이지 이동
- 고정 높이 계산

======================================
동작 조건
======================================

스크롤이 멈춘 후

경계 근처에 있는 경우에만

가장 가까운 섹션 시작 위치로

부드럽게 보정합니다.

빠르게 넘기는 경우에는

절대 보정하지 않습니다.

======================================
적용 범위
======================================

학부모 Home FlatList만 적용합니다.

다른 화면에는 적용하지 않습니다.
