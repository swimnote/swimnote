PASSNOTE 정책 최종 검증 요청 (Security & Operation Review v2)

아래는 PASSNOTE의 최신 설계안입니다.

서비스 철학은

"온라인 등기우편"

입니다.

이번 검토는

사업성보다

운영 안정성

법적 리스크

보안

UX

실제 서비스 운영 가능성

위주로 검토해 주세요.

==================================================
1. 서비스 철학
==================================================

PASSNOTE는

파일 공유 서비스가 아닙니다.

PASSNOTE는

지정된 수신자에게

파일을 안전하게 전달하는

"온라인 등기우편"

서비스입니다.

철학

- 지정된 수신자 1명 전달
- 전달 완료 확인
- 원본 장기 보관 없음
- 전달 완료 후 서버 원본 삭제
- 파일 저장 서비스가 아닌 전달 서비스

4. 수신자 UX
==================================================

다운로드 완료되었습니다.

파일이 정상적으로 열리는지 확인해 주세요.

PASSNOTE는

원본 파일의 장기 보관으로 인한

유출 위험을 줄이기 위해

수령 완료 후

서버의 원본 파일을 즉시 삭제합니다.

파일이 정상이라면

[수령 완료]

를 눌러주세요.

다른 기기에서도 받아야 한다면

수령 완료 전에

추가 다운로드를 진행하세요.

==================================================
푸시 알림
==================================================

수령 완료를 눌러야

발신자가

전달 완료를 확인할 수 있으며

PASSNOTE는

원본 파일을 안전하게 삭제할 수 있습니다.

[수령 완료]

↓

해당 전송 화면 즉시 이동

↓

남은 보관시간 표시

6. 원본 파일 정책
==================================================

PASSNOTE는

원본 파일의

장기 보관으로 인한

유출 위험을 줄이기 위해

수령 완료 후

즉시 서버 원본을 삭제합니다.

수령 완료가 없는 경우

24시간 추가 보관 후

자동 삭제합니다.

삭제 완료 후에는

복구가 불가능합니다.

8. Zero Tolerance 정책
==================================================

PASSNOTE는

불법 콘텐츠에 대해

Zero Tolerance 정책을 운영합니다.

업로드 전

이용자는

다음 내용에 동의합니다.

□ 본 파일은

관련 법령 및

저작권을 침해하지 않습니다.

□ 불법 콘텐츠 업로드 시

서비스 이용이 제한될 수 있습니다.

PASSNOTE는

불법 콘텐츠가

확인되거나

적법한 신고가 접수되는 경우

다음 조치를 진행할 수 있습니다.

- 계정 이용 제한

- 계정 영구 이용 제한

- 필요한 기록 보존

- 적법한 절차에 따른
  관계 기관 협조

10. 개인정보 보호
==================================================

PASSNOTE는

파일 전송에 필요한

최소한의 개인정보만 수집합니다.

전화번호는

로그인 및

수신자 확인에만 사용됩니다.

내부 시스템은

전화번호 대신

UUID 기반으로 동작합니다.

전화번호는

암호화 저장되며

관리자도

기본적으로

원문을 조회할 수 없습니다.

적용 예정

- 전화번호 암호화 저장

- UUID 기반 내부 처리

- 관리자 마스킹

- 접근 권한 최소화

- 관리자 조회 로그 기록

- 암호화 키 분리 관리

==================================================
11. 추가 운영 정책
==================================================

다운로드 전까지

발신자는

전송을 취소할 수 있습니다.

전송 취소 시

즉시 서버 원본 삭제

다운로드 후에는

취소할 수 없습니다.

==================================================
12. 서비스 목표
==================================================

PASSNOTE는

파일을 저장하는 서비스가 아니라

안전하게 전달하고

확인하고

삭제하는

온라인 등기우편 서비스를 목표로 합니다.

==================================================
검토 요청
==================================================

1.

온라인 등기우편이라는 서비스 철학과

현재 전달 구조가 일관되는지

2.

다운로드 완료

↓

수령 완료

↓

전달 완료

↓

삭제

흐름이 UX와 사업성 측면에서 적절한지

3.

24시간 추가 보관 정책이

원가·보안·사용자 경험 측면에서 적절한지

4.

같은 기기 재확인

다른 기기 추가 다운로드(최대 3기기)

정책이 적절한지

5.

전화번호 보호 정책

(UUID 기반 처리, 암호화 저장 등)

설계가 적절한지

6.

업로드 자동 보안 검사와

Zero Tolerance 정책이

현실적인 운영 정책인지

7.

현재 구조에서

법적 리스크를 줄이기 위해

추가해야 할 보안 정책,

운영 정책,

개인정보 보호 정책이 있는지

8.

서비스 출시 전에

반드시 추가해야 하는 기능이나

보안 요소가 있는지

객관적으로 검토해 주세요.
