==================================================
1. 핵심 확인사항 — PAID X MODE
==================================================

WP2B 완료보고에는 서로 다른 두 설명이 있습니다.

A. TRIAL ACTIVE LOGIC

x_paid_entitlement = true
→ "x"

B. MODE MODEL

paid 또는 manual
+ xmode_config_status != READY
→ "x_pending"

paid 또는 manual
+ xmode_config_status = READY
→ "x"

LOCKED MASTER DESIGN 기준은 B입니다.

정식 X 결제 직후
센터별 X 설정이 완료되지 않았다면:

x_paid_entitlement = true
xmode_config_status = NOT_CONFIGURED
→ mode = "x_pending"

이어야 합니다.

센터 설정 완료 후:

x_paid_entitlement = true
xmode_config_status = READY
→ mode = "x"

이어야 합니다.

==================================================

  return "x"

paid/manual entitlement 존재
→ xmode_config_status 확인
→ READY이면 x
→ READY가 아니면 x_pending

으로 처리하십시오.

Trial branch는
paid/manual entitlement 처리 이후에 유지.

5. 1.6.3 MODE COMPATIBILITY 재확인
==================================================

WP2B 보고서에는:

1.6.3이 `x_trial`을 모름

그리고

mode === "x" → false
mode === "x_pending" → false
mode === "normal" → false

라고 되어 있습니다.

그런데 결과 설명에는
"trial 센터 = normal 화면 표시"
라고 되어 있어 논리상 설명이 불충분합니다.

실제 1.6.3 렌더링 코드를 확인하여:

mode = "x_trial"

이 들어왔을 때 실제 UI가:

A. normal 화면
B. fallback 화면
C. blank
D. error
E. 기타

중 무엇인지 정확히 확인하십시오.

추측 금지.

반드시 실제 component/path/branch 근거 제출.
