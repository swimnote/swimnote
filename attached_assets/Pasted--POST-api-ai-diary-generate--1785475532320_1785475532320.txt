교사 입력
→ 입력 의미 분석
→ 공통 내용과 학생별 내용 분리
→ 학생·반·수업 컨텍스트 확인
→ 커리큘럼 또는 템플릿 조회
→ SWIMNOTE 지식 DB 검색
→ 검색 결과 보충
→ GPT 문장화
→ 공통 일지 생성
→ 학생별 일지 생성

파이프라인을 모두 거치는지는 아직 증명되지 않았습니다.
