6. wp2a-plans-and-storage.ts 감사
==================================================

이 migration이:

- production에서 이미 실행된 migration인지
- 아직 production 미실행 future migration인지
- release/v2.0.0 배포 때 실행 예정인지

HAS THIS MIGRATION EVER RUN IN PRODUCTION:
YES / NO / UNKNOWN

명시.

2.0 migration은 production 미실행이었지만
추측하지 말고 실제 repository/deploy history 기준으로 확인.

만약 아직 실행되지 않은 future migration이면
신규 X 가격을 최신값으로 수정:

x300 = 129000
x500 = 199000
x1000 = 359000

미래 migration이 구가격을 넣고
다음 migration이 다시 신가격으로 고치는
불필요한 구조를 만들지 마십시오.

이미 production 실행 완료된 immutable migration이라면
기존 파일 변경 대신 안전한 후속 migration 전략 유지.
