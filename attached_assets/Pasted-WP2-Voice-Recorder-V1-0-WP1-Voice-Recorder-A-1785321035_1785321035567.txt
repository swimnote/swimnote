WP2 — Voice Recorder 구현 및 검증

설계도 V1.0을 기준으로 작업을 진행한다.

WP1은 완료되었으며, 다음 단계인 Voice Recorder만 수행한다.

AI Engine, Whisper, Draft, Insert, Save는 이번 WP에서 수정하지 않는다.

──────────────────────────────────
1. 작업 원칙
──────────────────────────────────

이번 WP에서는 Voice Recorder 기능만 검증한다.

다른 기능은 절대 수정하지 않는다.

이미 정상 구현된 코드는 다시 작성하지 않는다.

설계와 코드와 실제 동작을 비교하여 문제가 있는 부분만 최소 범위로 수정한다.

관련 없는 리팩터링을 하지 않는다.

──────────────────────────────────
4. 검증 항목
──────────────────────────────────

① 권한

- 최초 실행 시 마이크 권한 요청
- 권한 허용
- 권한 거부
- 권한 거부 후 재시도

② 녹음

- 녹음 시작
- 녹음 중 상태 표시
- 녹음 종료
- 녹음 시간 정상 증가
- Recording 객체 정상 생성

③ 파일

- uri 정상 생성
- 파일 존재 확인
- 빈 파일 생성 안됨
- 0 byte 파일 방지

④ 반복 녹음

- 여러 번 연속 녹음 가능
- 첫 녹음 종료 후 두 번째 정상 시작
- Recording 객체 누수 없음

⑤ 취소

- 녹음 중 취소
- 모달 종료 시 Recording 정리
- 메모리 누수 없음

⑥ 예외

- 권한 거부
- 녹음 실패
- 예외 발생
- Timeout
- 앱 백그라운드 전환
- 앱 복귀

⑦ 안전성

- 중복 탭 방지
- 이미 녹음 중인데 startRecording 재호출 방지
- stopRecording 중복 호출 방지
- unmount 이후 setState 없음

⑧ 기존 기능 회귀

- AI 모달 정상
- 닫기 정상
- 재진입 정상
- 기존 일지 작성 영향 없음

──────────────────────────────────
5. 수정 원칙
──────────────────────────────────

문제가 없으면 수정하지 않는다.

문제가 있으면 Voice Recorder 관련 파일만 수정한다.

Whisper API 호출은 수정하지 않는다.

AI Engine 요청은 수정하지 않는다.

Draft는 수정하지 않는다.

Insert는 수정하지 않는다.

Save는 수정하지 않는다.
