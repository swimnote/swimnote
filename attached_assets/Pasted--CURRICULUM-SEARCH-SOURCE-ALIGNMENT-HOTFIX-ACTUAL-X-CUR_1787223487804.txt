4. ELIGIBILITY
==================================================

X 검색 가능 조건:

실제 의미 있는 searchable curriculum_items >= 300

300 기준은 절대 완화하지 않는다.

금지:

- level count로 대체
- weighted count
- comma split
- 문장 임의 분할
- x entitlement만으로 허용
- xmode_config_status만으로 허용
- global_template_set 존재만으로 허용

결과:

count >= 300
→ eligible=true

count < 300
→ eligible=false
→ reason=CURRICULUM_NOT_READY

5. SEARCH SCOPE
==================================================

실제 검색은 다른 source를 보는 구조 금지.

eligibility와 실제 curriculum search scope 모두
동일한 pool-specific curriculum_items를 사용.

즉:

eligibility authority
=
search authority

이어야 한다.
