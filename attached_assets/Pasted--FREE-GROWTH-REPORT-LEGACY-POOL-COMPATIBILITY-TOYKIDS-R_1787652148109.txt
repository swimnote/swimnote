A. X CONFIG READY

신규 가맹점의 정식 X Setup 완료 여부.

현재 validateXModeReadiness() 유지:

- entitlement
- force disabled
- approval
- setup submission
- curriculum file
- 기타 실제 필수조건

이것은 신규 X onboarding용.

TOYKIDS 때문에 이 validator를 약화시키지 말 것.


B. FREE GROWTH REPORT ELIGIBILITY

무료 월간 성장리포트를 생성할 수 있는가.

이것은 X CONFIG READY와 별도 판단.

최소 base 조건:

- x_paid_entitlement OR x_manual_entitlement
- NOT x_force_disabled
- pool approval 정상
- active student
- report generation에 사용할 실제 데이터 source가 존재

중요:

xmode_config_status='READY'
또는 최신 curriculum DOCX는
FREE Report의 절대 blocker가 아님.


C. FUTURE PAID REPORT ELIGIBILITY

향후 유료 상품은 별도 extension point 유지.

이번 Step에서 paid product 구현 금지.

예:

isPaidGrowthReportEligible(...)
→ base commercial eligibility
→ paid product/order/license
→ 필요 시 stricter config requirement

FREE와 PAID를 하나의 gate로 묶지 말 것.
