추가 재현 결과가 확인되었습니다.

텍스트 입력뿐 아니라 음성 입력 후 AI 생성 과정에서도 동일하게 화면이 깜빡입니다.

따라서 이번 문제를 “텍스트 입력 전용 문제”로 한정하지 말고,
텍스트와 음성이 공통으로 사용하는 AI 생성 상태·결과 렌더링 문제로 범위를 수정하십시오.

확인된 재현 경로

1. 텍스트 직접 입력
→ AI 생성
→ 화면 깜빡임 발생

2. 음성 입력/STT
→ AI 생성
→ 화면 깜빡임 발생

이 결과로 입력 방식 자체보다 아래 공통 구간을 우선 조사해야 합니다.

- 텍스트와 음성이 합쳐지는 공통 생성 함수
- 공통 React Query mutation
- 공통 generationStatus
- DiaryAIActionBar
- ERROR / PERMISSION / GENERATING / SUCCESS 렌더링 조건
- AI 응답을 일지 입력란에 반영하는 시점
- 화면 focus 및 컴포넌트 mount/unmount
- 요청 완료 직전과 직후의 상태 변경 순서

이번 단계에서는 아직 코드를 수정하지 말고 원인 분석만 제출하십시오.

이전 요청 상태와 현재 요청 상태가 섞이는지 확인하십시오.

우선 확인할 원인 후보

1. 생성 시작 전에 이전 error 상태가 초기화되지 않음
2. mutation.reset()이 첫 렌더 이후 useEffect에서 실행됨
3. 권한 조회 loading 상태를 permission=false로 처리함
4. loading=false가 결과 반영보다 먼저 실행됨
5. 텍스트·음성 각각의 local state와 공통 mutation state가 충돌함
6. DiaryAIActionBar가 두 위치에서 동시에 렌더링됨
7. 동일 request가 음성 경로에서 두 번 호출됨
8. STT 완료와 AI 생성 시작 사이에 IDLE/ERROR UI가 한 프레임 노출됨
9. 성공 후 이전 ERROR/PERMISSION 컴포넌트가 unmount되지 않음
10. requestId 없는 비동기 응답이 최신 상태를 덮어씀

정상 상태 전이

텍스트:
IDLE → GENERATING → SUCCESS

음성:
RECORDING → TRANSCRIBING → GENERATING → SUCCESS

실패 시에만:
GENERATING → ERROR

발생하면 안 되는 전이

TRANSCRIBING → PERMISSION → GENERATING
GENERATING → ERROR → SUCCESS
GENERATING → IDLE → SUCCESS
SUCCESS 상태에서 이전 ERROR UI 잔존
동일 requestId에서 GENERATING 두 번 시작
DiaryAIActionBar 동시 2개 mount
