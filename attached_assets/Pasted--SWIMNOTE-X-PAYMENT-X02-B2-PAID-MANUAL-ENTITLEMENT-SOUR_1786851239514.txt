[SWIMNOTE X PAYMENT]
[X02-B2 — PAID / MANUAL ENTITLEMENT SOURCE SEPARATION]

목적:

현재 단일 컬럼:

swimming_pools.xmode_entitlement

을 RevenueCat paid entitlement와
Super Admin manual entitlement가 함께 수정하는 충돌을 제거한다.

이미 X02-B1에서 생성된:

x_paid_entitlement
x_manual_entitlement
x_force_disabled

를 실제 source of truth 구조에 연결한다.

이번 WP에서는:

- RevenueCat purchase UI 구현 금지
- slot reserve API 구현 금지
- sync-x-subscription 구현 금지
- restore 구현 금지

entitlement source separation만 한다.

==================================================
0. CURRENT DB CONTRACT
==================================================

현재 DB:

x_paid_entitlement
BOOLEAN DEFAULT FALSE

x_manual_entitlement
BOOLEAN DEFAULT FALSE

x_force_disabled
BOOLEAN DEFAULT FALSE

legacy:

xmode_entitlement

존재.

X02-B1 backfill 정책:

x_paid_entitlement = FALSE

x_manual_entitlement =
legacy xmode_entitlement

따라서 기존 manual X 상태는
x_manual_entitlement에 보존되어 있다.

==================================================
1. FINAL EFFECTIVE ENTITLEMENT
==================================================

최종 effective entitlement:

effective_x_entitlement =

(x_paid_entitlement OR x_manual_entitlement)
AND NOT x_force_disabled

이 규칙을 단일 source of truth로 만든다.

==================================================
2. MODE CONTRACT
==================================================

mode resolver:

effective = false
→ normal

effective = true
AND xmode_config_status = READY
→ x

effective = true
AND xmode_config_status != READY
→ x_pending

중요:

approval_status는 mode 계산에 포함하지 않는다.

config_status를 결제 로직이 수정하면 안 된다.

==================================================
3. REVENUECAT PAID SOURCE
==================================================

RevenueCat webhook X product 처리에서는
더 이상:

xmode_entitlement

를 직접 true/false 하지 않는다.

대신:

INITIAL_PURCHASE
RENEWAL
UNCANCELLATION
→ x_paid_entitlement = true

CANCELLATION
→ paid 기간 종료 전이므로 true 유지

EXPIRATION
REFUND
→ x_paid_entitlement = false

x_manual_entitlement 수정 금지.

x_force_disabled 수정 금지.

==================================================
4. SUPER ADMIN MANUAL SOURCE
==================================================

Super Admin manual X entitlement endpoint:

PATCH /super/operators/:id/xmode

현재 xmode_entitlement를 직접 수정하고 있다면
다음으로 변경:

manual ON
→ x_manual_entitlement = true

manual OFF
→ x_manual_entitlement = false

x_paid_entitlement 수정 금지.

RevenueCat subscription 상태 수정 금지.

==================================================
5. FORCE DISABLE
==================================================

이번 WP에서
Super Admin 기존 UI/API에
force disable 기능이 이미 없다면
새 UI 추가 금지.

단 effective resolver는
x_force_disabled 값을 반영해야 한다.

현재 default false이므로
기존 동작에는 영향 없어야 한다.

향후 별도 Super Admin control에서 사용 가능.

==================================================
6. LEGACY xmode_entitlement
==================================================

기존 xmode_entitlement 컬럼은
이번 WP에서 DROP 금지.

하위 호환성 때문에 유지.

하지만 mode resolver와
신규 RevenueCat/manual write path에서는
legacy 컬럼을 source of truth로 사용하지 않는다.

필요하면 read compatibility만 유지.

이번 WP 완료 후 신규 source:

paid
manual
force_disabled

3개.

==================================================
7. EFFECTIVE HELPER
==================================================

가능하면 entitlement 계산을
여러 route에 복제하지 않는다.

예:

resolveEffectiveXEntitlement(pool)

또는 기존 xmode helper에 통합.

반드시 한 곳에서:

(paid OR manual) AND NOT force_disabled

계산.

중복 로직 금지.
