# 관리자 권한 부여·회수 성공 모달 멈춤 현상 수정

현재 원장 계정에서 다른 선생님의 관리자 권한을 회수하면
서버 처리는 정상 성공하지만, 성공 결과 모달에서 화면이 멈춥니다.

첨부 화면을 보면 결과 모달에

- 완료 아이콘
- 완료 제목
- 관리자 권한이 회수되었습니다.

만 표시되고 확인 버튼이나 닫기 동작이 없습니다.

이 문제는 ROLE_REVOKED 자동복귀 문제가 아닙니다.
테스트 계정은 원장 계정이며, 다른 선생님의 권한을 회수한 상황입니다.

따라서 admin-grant.tsx의 결과 모달 상태 및 닫기 동작을 수정하세요.

==================================================
1. 결과 모달에 확인 버튼 추가
==================================================

성공 및 실패 결과 모달 하단에 반드시 확인 버튼을 추가하세요.

예:

[ 확인 ]

확인 버튼을 누르면 다음 상태를 모두 초기화하세요.

setResultMsg(null);
setConfirmTarget(null);
setProcessing(false);

결과 모달 표시 여부를 별도 state로 관리한다면 해당 state도 false로 변경하세요.

==================================================
2. 배경 터치로도 닫을 수 있게 처리
==================================================

결과 모달 바깥의 반투명 배경을 누르면 모달이 닫히도록 처리하세요.

단, 모달 내부를 누른 경우에는 닫히지 않도록 이벤트 전파를 막으세요.

Android 뒤로가기 요청도 onRequestClose에서 동일한 닫기 함수를 실행하세요.

공통 함수 예:

function closeResultModal() {
  setResultMsg(null);
  setConfirmTarget(null);
  setProcessing(false);
}

Modal:

onRequestClose={closeResultModal}

배경 Pressable:

onPress={closeResultModal}

==================================================
3. 성공 직후 상태 흐름 분리
==================================================

handleGrant 성공 후에는 다음 순서로 처리하세요.

1. 서버 응답 확인
2. 서버 roles 기준으로 목록 상태 갱신
3. 확인용 다이얼로그 상태 종료
4. processing 해제
5. 결과 메시지 모달 표시
6. 목록 전체 재조회는 백그라운드로 실행

목록 재조회 완료를 기다린 뒤 결과 모달을 닫는 구조로 만들지 마세요.

예:

setConfirmTarget(null);
setProcessing(false);
setResultMsg(successMessage);

void refreshTeacherList();

==================================================
4. finally에서 결과 모달 상태를 지우지 않도록 확인
==================================================

finally에서는 반드시 다음만 처리하세요.

setProcessing(false);
setConfirmTarget(null);

성공 메시지인 resultMsg를 finally에서 null로 만들면 안 됩니다.

반대로 결과 모달을 닫는 동작은 사용자의 확인 버튼,
배경 터치 또는 onRequestClose에서만 실행하세요.

==================================================
5. 중복 Modal 구조 점검
==================================================

현재 화면에

- 권한 부여·회수 확인 모달
- 처리 결과 모달

두 개가 존재한다면 동시에 visible=true가 되지 않도록 하세요.

결과 모달을 열기 전에 확인 모달 상태를 먼저 닫으세요.

visible 조건 예:

확인 모달:
confirmTarget !== null && resultMsg === null

결과 모달:
resultMsg !== null

==================================================
6. 수정 후 테스트
==================================================

아래 항목을 실제 기기에서 확인하세요.

1. 관리자 권한 부여 성공
   - 성공 모달 표시
   - 확인 버튼으로 정상 닫힘
   - 배경 터치로 정상 닫힘

2. 관리자 권한 회수 성공
   - 성공 모달 표시
   - 확인 버튼으로 정상 닫힘
   - 목록에서 관리자 표시와 버튼이 즉시 변경됨

3. API 실패
   - 오류 모달 표시
   - 확인 버튼으로 정상 닫힘
   - 목록 상태는 변경되지 않음

4. 네트워크 실패
   - 네트워크 오류 메시지 표시
   - 모달 정상 닫힘
   - 다시 부여·회수 버튼을 누를 수 있음

5. 모달 닫은 뒤 화면 스크롤 및 다른 버튼 터치 정상 작동

이번에는 원인 분석 보고만 하지 말고,
admin-grant.tsx의 결과 모달에 명시적인 닫기 동작을 구현하고
실제 기기 테스트 결과까지 보고하세요.
