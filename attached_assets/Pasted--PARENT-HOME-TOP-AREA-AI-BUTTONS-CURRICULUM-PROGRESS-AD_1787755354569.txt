3. 교육과정 진행도 — 실제 % 게이지 추가
==================================================

현재 "교육과정 진행도" 안내만 있고
실제 몇 % 진행됐는지 시각적으로 보이는 게이지가 없음.

여기에 실제 progress UI 추가.

구조 예:

교육과정 진행도                         48.7%
[██████████████░░░░░░░░]

필수:
- 현재 curriculum progress 데이터 사용
- percentage 표시
- progress bar 표시
- 숫자와 bar가 동일 데이터 기준
- 하드코딩 금지

데이터가 없거나 표시 조건 미충족이면
거짓 0%를 보여주지 말 것.

현재 기존 정책에 따라
progress 표시 불가 상태라면
깔끔한 fallback 상태 사용.

예:
"진행 정보가 쌓이는 중입니다"

단,
실제 값이 존재하면 반드시 %와 gauge 표시.

디자인:
- X_NAVY 중심
- progress fill에 X_MINT 제한적 사용 가능
- 큰 mint background 금지
- 성적표보다는 교육과정 진행 상태처럼 표현

4. "스윔노트와 우리아이 수영 성장을 기록해보세요" 영역 → 광고 슬롯으로 변경

현재 해당 박스는 일반 안내 박스로 보이지만,
앞으로 사용자가 직접 광고/프로모션 콘텐츠를 넣는 영역으로 사용한다.

"스윔노트와 우리아이 수영 성장을 기록해보세요"

구조 자체는 향후 광고 콘텐츠를 넣기 쉽게 만든다.

--------------------------------------------------
5-C. MONTHLY badge 색상
--------------------------------------------------

현재 mint 위주의 badge는 변경.

MONTHLY는 리포트 cadence/분류 표시이므로
강한 mint 강조가 필요 없음.

X mode 분위기에 맞게:

권장:
- background: X_NAVY 또는 navy-tinted neutral
- text: white
또는
- very light neutral/navy tint bg
- navy text

중 하나.

중요:
mint background + mint border 조합 금지.

MONTHLY badge는
작고 차분한 product tag처럼 보여야 함.

--------------------------------------------------
5-D. Growth Report 전체 mint 사용 절제
--------------------------------------------------

현재 X mode에서 mint가 과다 사용된 느낌을 줄인다.

색 역할 재정리:

X_NAVY
= title / structure / badge / strong information

WHITE
= base

NEUTRAL
= border / divider / metadata

X_MINT
= progress / accent line / selected or active state 등
정말 필요한 곳만

모든 박스 테두리를 mint로 만드는 방식 금지.
