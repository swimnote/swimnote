[앱]

MONTHLY GROWTH REPORT FEED — INSTAGRAM-INSPIRED FULL REPORT UI

목표:
MONTHLY 성장 리포트를 일반 카드처럼 중간에서 잘라 보여주지 말고,
피드 안에서 전체 내용이 아래로 자연스럽게 이어지도록 한다.

단순히 긴 텍스트를 한 덩어리로 늘이는 것이 아니라,
각 항목이 명확히 구분되고 정돈된 “리포트형 피드”로 보여야 한다.

전체 UX는 Instagram feed를 오마주한다.

중요:
Instagram을 그대로 복제하지 말 것.
구조/리듬/정보 배치만 참고해서
SWIMNOTE 브랜드에 맞는 전문적인 리포트 피드로 구현한다.

==================================================
1. FEED 전체 방향
==================================================

성장리포트 피드는:

- 모바일 세로 스크롤 중심
- 카드 전체가 내용 길이만큼 아래로 확장
- 본문 truncation 없음
- line clamp 없음
- max-height 없음
- overflow hidden 없음
- “더보기”를 눌러야 본문을 읽는 구조 금지

부모가 피드에서 바로
리포트 마지막 항목까지 읽을 수 있어야 한다.

==================================================
2. INSTAGRAM-INSPIRED STRUCTURE
==================================================

Instagram feed의 다음 UX를 오마주:

- 상단 identity/header 영역은 얇고 간결
- 내용이 본문의 중심
- 스크롤 리듬이 자연스러움
- 섹션 사이 구분은 명확하지만 과한 카드 남발 없음
- 하단 action 영역은 단순하고 직관적
- 모바일에서 한 손 스크롤로 읽기 편해야 함

Instagram을 시각적으로 복제하지 말 것.
SWIMNOTE navy/aqua 브랜드 톤 유지.

==================================================
3. COMPACT HEADER
==================================================

현재 navy header block이 너무 큼.

상단을 훨씬 작고 Instagram feed header처럼 간결하게 구성.

권장:

ROW 1:
[실제 SwimNote AI REPORT 가로형 로고]
월간 리포트

ROW 2:
2026년 8월 · 서태웅 · 토이키즈스윔클럽 · 진도 48.7%

모바일 폭이 좁으면
ROW 2는 자연스럽게 2줄까지 허용.

중요:
- 사용자가 제공한 실제 로고 사용
- 새 로고 생성 금지
- 로고 비율 유지
- 로고가 너무 크지 않게
- header 높이를 현재보다 확실히 축소
- 학생명이나 월이 지나치게 큰 타이포가 되지 않게

==================================================
4. TYPOGRAPHY SYSTEM 통일
==================================================

현재 가장 중요한 요구사항:

글자 크기가 항목마다 들쭉날쭉해서
산만하게 보이면 안 된다.

성장리포트 feed 전용 typography system을 명확하게 정의하고
모든 section에 동일하게 적용한다.

권장 4단계 이내:

A. Report metadata / header
B. Section title
C. Body text
D. Small metadata/action text

불필요하게 5~6개 이상의 font size 사용 금지.

예시:

- section title: 15~16
- body: 14~15
- metadata: 12~13
- action/footer: 12~13

실제 프로젝트 단위 기준에 맞게 조절 가능하지만
section마다 제각각인 font size 사용 금지.

==================================================
5. SECTION TITLE 통일
==================================================

모든 항목 제목은 동일 규칙:

예:
- 이번 달 한눈에 보기
- 핵심 성장
- 수영 교육과정 진행
- 행동 강점
- 이전 기간 비교
- 성공 조건
- 교사 관찰 메모
- 다음 수업 방향
- 가정에서 함께해요

모두 동일한:
- font size
- font weight
- color
- accent rule
- padding
- spacing

사용.

어떤 제목만 특별히 크게 만드는 것 금지.

단,
“가정에서 함께해요”는 배경 강조는 가능하지만
제목 font size 자체는 다른 section과 통일.

==================================================
6. BODY TEXT 통일
==================================================

모든 본문은:

- 동일 font size
- 동일 line height
- 동일 text color
- 동일 paragraph spacing

을 사용.

특정 section만
본문 글자가 갑자기 커지거나 작아지면 안 됨.

읽는 사람이 스크롤할 때
한 문서처럼 느껴져야 한다.

==================================================
7. SECTION 구분 방식
==================================================

긴 피드 안에서도
각 항목이 어디서 시작하고 끝나는지 명확해야 한다.

권장 구조:

[section title]
본문

얇은 divider 또는 spacing

[다음 section title]
본문

과한 카드 박스를 모든 section에 적용하지 말 것.

Instagram처럼
여백 + 얇은 divider + 타이포 위계 중심으로 정리.

SWIMNOTE accent cyan line은
section title 왼쪽에 작게 사용하는 방식 가능.

단 모든 section 동일 규칙.

==================================================
8. “이번 달 한눈에 보기”
==================================================

첫 번째 핵심 section.

다른 section과 완전히 다른 font size를 사용하지 말 것.

대신:
- 약간 넓은 padding
- 아주 연한 background
- section 상단 강조

정도로만 중요도를 표현.

읽기 시작점이 명확하면 충분.

==================================================
9. BULLET 사용 규칙
==================================================

성장 포인트나 짧은 핵심 요약은
bullet을 사용할 수 있음.

단:
- bullet font 크기도 body와 동일
- bullet 간격 일정
- 한 section에 bullet 남발 금지
- 긴 문장은 paragraph 우선

Instagram caption처럼
짧고 자연스럽게 읽히는 리듬 유지.

==================================================
10. EMPTY SECTION
==================================================

아래 경우 section 전체 숨김:

- null
- empty
- whitespace
- "(이번 기간 해당 내용 없음)"
- 동일 의미 placeholder

숨길 때:
- 제목 제거
- divider 제거
- padding 제거
- 빈 공간 제거

11. FULL CONTENT
==================================================

실제 존재하는 모든 parent-facing section을
feed에서 끝까지 표시.

중간 truncation 절대 금지.

마지막
“가정에서 함께해요”
까지 피드 자체에서 읽을 수 있어야 한다.

==================================================
12. “가정에서 함께해요”
==================================================

최종 section은
부모가 실제 행동을 이해하는 영역.

Instagram feed에서 마지막 caption/action area처럼
자연스럽게 마무리되게 한다.

가능:
- 아주 연한 aqua background
- subtle border
- accent line

금지:
- 큰 CTA 버튼 같은 느낌
- 광고 카드 같은 느낌
- 다른 본문보다 과하게 큰 font

==================================================
13. BOTTOM ACTION BAR
==================================================

리포트 전체 내용 아래에
Instagram-inspired action row 배치.

현재 정책에 맞는 항목만:

- 좋아요
- 댓글
- PDF 다운로드/공유
- 필요 시 상세 보기

중요:
리포트 본문을 읽기 위한
“전체 보기” 버튼은 필요하지 않다.

내용은 이미 feed에서 전체 노출.

상세 페이지는
별도 기능 진입용으로만 유지 가능.
