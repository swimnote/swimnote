매우 중요.

새 native build와 동일한 FINAL HEAD에서:

production-v2

channel에

runtimeVersion:
2.2.0

Production OTA를 새로 publish한다.

목적:

Store native binary와
Production OTA baseline을
처음부터 동일 source로 맞추기 위함.

즉:

2.2.0 native bundled source
=
2.2.0 Production OTA baseline source

가 되어야 한다.

이 OTA가 없으면 native 앱이 불완전한 것은 아니다.

Native binary 자체가 이미 최신 완성본이어야 한다.

OTA는 앞으로 2.2.0 운영의 기준점이다.

iOS/Android 모두
runtime 2.2.0 compatible update 확인.

기존 runtime 2.1.0 OTA를
2.2.0용으로 재사용/복사한 것으로 간주하지 말 것.

반드시 FINAL HEAD에서 fresh publish.

23. FINAL PASS 조건
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS는 아래를 전부 만족해야 한다.

- 공식 배포버전 2.2.0
- runtimeVersion 2.2.0
- iOS buildNumber >= 300
- Android versionCode >= 300
- 최신 origin HEAD 사용
- 모든 최신 P0 source 포함
- 기존 OTA에만 남은 수정 0
- fresh native bundle
- iOS Production build SUCCESS
- Android Production AAB SUCCESS
- runtime 2.2.0 Production OTA fresh publish SUCCESS
- native와 OTA source HEAD 동일
- iOS App Store Connect binary upload SUCCESS
- Android Production rollout은 아직 시작하지 않음
- 신규 설치만으로 최신 기능 완전 동작
- blocker 0

PASS 후:

새 기능 추가 금지.
대규모 refactor 금지.
과거 runtime으로 회귀 금지.

2.2.0 / runtime 2.2.0 / build 300계열

로 확정하고 STOP.
