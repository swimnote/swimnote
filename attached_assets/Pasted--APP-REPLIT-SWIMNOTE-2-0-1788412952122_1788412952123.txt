============================================================
1. 실제 문제
============================================================

첨부사진의:

"김동호 운영현황"

화면에서
상단 통계 카드 바로 아래에 있는
가로 메뉴 탭들의 텍스트가 심하게 잘려 있음.

현재는 각 탭이:

- 글자 상단/하단 일부만 보임
- 무슨 메뉴인지 식별이 어려움
- 버튼 외곽선/선택상태만 보이고
  label이 거의 읽히지 않음

실기기 기준으로 명백한 UI clipping 상태.

============================================================
2. 기대 결과
============================================================

상단 메뉴 탭의 모든 label이:

- 전체 글자 표시
- 세로 잘림 0
- 좌우 잘림 0
- 버튼 중앙 정렬
- 선택 탭/비선택 탭 모두 가독성 정상

이어야 함.

사용자가 탭 이름을
실기기에서 즉시 읽을 수 있어야 한다.

3. 실제 SOURCE 확인
============================================================

추측 금지.

이 화면의 실제 route/component를 찾아서
상단 menu/tab component와 style 확인.

가능 원인:

- height 부족
- minHeight 부족
- lineHeight 문제
- paddingVertical 문제
- overflow: hidden
- alignItems / justifyContent
- text container height
- transform/offset
- absolute positioning
- font scaling
- horizontal ScrollView clipping

실제 source 기준으로 정확히 원인 확인.

4. 수정 원칙
============================================================

텍스트를 억지로 작게 줄여서
버튼 안에 집어넣지 말 것.

우선:

- 충분한 tab height
- 정상 lineHeight
- 정상 vertical padding
- 정상 text container
- overflow 문제 제거

기준으로 수정.

기존 디자인 비율 최대한 유지.
