[WP-N1 — NORMAL SWIMNOTE SAGE/OCEAN DESIGN TOKEN FOUNDATION]

목적:

Normal SWIMNOTE의 기존 개발단계 민트 테마를
차분하고 고급스러운 Sage/Ocean Wave 기반 디자인 시스템으로
점진적으로 전환하기 위한 "토큰 기반"을 먼저 구축한다.

이번 WP에서는 전체 화면을 대량 변경하지 않는다.

핵심:

1. Normal SWIMNOTE 공식 Sage/Ocean palette를 theme/colors.ts에 정의
2. text hierarchy를 3단계 이상으로 정상화
3. background/surface 계층을 정리
4. legacy mint alias를 즉시 삭제하지 않고 호환 유지
5. 다음 WP-N2/N3에서 안전하게 화면별 적용할 기반 확보

==================================================
7. PRIMARY ACTION FUTURE POLICY
==================================================

중요:

현재 감사에서 기존 design standard는:

C.primaryAction = #0F2742 navy

였지만
이것은 과거 기준이다.

앞으로 Normal SWIMNOTE의 최종 방향은
Sage/Ocean theme다.

따라서 최종적으로:

Normal Primary Action
→ Sage Strong #4F6F67
또는 해당 공식 primary-action token

Normal Active/Selected
→ Sage Primary #6F9187

로 전환한다.

하지만 이번 WP에서는
기존 화면 100개에 바로 영향을 줄 수 있으므로
C.primaryAction 값을 무조건 즉시 바꾸지 않는다.

먼저 repository dependency를 확인한다.

==================================================
8. PRIMARY ACTION IMPACT AUDIT BEFORE CHANGE
==================================================

C.primaryAction을 현재
어떤 화면/컴포넌트가 사용하는지 확인.

보고:

PRIMARY_ACTION_USAGE_COUNT =
PRIMARY_ACTION_COMMON_COMPONENTS =
PRIMARY_ACTION_HIGH_RISK_SCREENS =

다음과 같은 경우:

C.primaryAction 변경만으로
Normal 전체 주요 CTA가 안전하게 Sage Strong으로 전환되며
semantic/feature-fixed 영역을 침범하지 않는 것이 명확하면
이번 WP에서 token value 변경 가능.

반대로 영향범위가 불명확하면:

새 token만 추가하고
C.primaryAction 기존 값은 유지.

WP-N3에서 역할별 버튼 normalization과 함께 전환.

추측 금지.

9. LEGACY MINT COMPATIBILITY
==================================================

현재:

C.tint / C.primary = #2EC4B6

#2EC4B6 하드코딩 511회 수준.

이번 WP에서
전부 제거하려 하지 않는다.

legacy alias는 당장 삭제 금지.

예:

C.tint
C.primary
C.tintLight

등을 사용하는 기존 코드가 깨지지 않게 유지.

단 신규 공식 Sage token을 추가하고
향후 WP에서 점진적으로 migration.
