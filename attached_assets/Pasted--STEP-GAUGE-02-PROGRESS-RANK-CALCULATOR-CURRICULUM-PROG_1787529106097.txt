3. Rank 계산 규칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

절대 raw sort_order / total_count 계산 금지.

반드시 active items만 대상으로
실제 curriculum 순서를 1-based rank로 계산.

개념:

WITH ranked AS (
  SELECT
    ci.id,
    ROW_NUMBER() OVER (
      ORDER BY ci.sort_order ASC, ci.id ASC
    ) AS progress_rank,
    COUNT(*) OVER () AS total_count
  FROM curriculum_items ci
  WHERE ci.curriculum_version_id = $versionId
    AND ci.is_active = true
)
SELECT
  progress_rank,
  total_count
FROM ranked
WHERE id = $itemId

progressPct =
ROUND(progress_rank / total_count * 100, 1)

중요:
- sort_order=0 시작 가능
- gap 가능
- 비연속 가능
- inactive item 제외
- 마지막 active item은 반드시 100.0%
- deterministic tie-breaker 유지
  (현재 UNIQUE sort_order가 있어도 id ASC 보조 정렬 가능)
