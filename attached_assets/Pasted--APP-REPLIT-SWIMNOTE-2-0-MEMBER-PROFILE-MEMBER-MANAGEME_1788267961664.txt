회원 상세 화면을 다시 설계해야 하는 문제가 있습니다.

→

이번 단계에서는
절대 구현하지 말고

A.

B.
별도 child table

예:
student_links

구조 예:

id
pool_id
student_id
type
title
url
is_parent_visible
sort_order
created_by
created_at
updated_at

향후 확장성을 고려할 때
