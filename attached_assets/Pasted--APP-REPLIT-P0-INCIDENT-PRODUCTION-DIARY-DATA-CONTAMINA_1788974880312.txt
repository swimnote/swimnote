[P0 INCIDENT — PRODUCTION DIARY DATA CONTAMINATION / FORENSIC + FIX]

실제 Production에서 심각한 일지 오염 의심 발생.

현상:

한 선생님의 어제 수업 일지에
본인이 작성한 적 없는 문장이
서로 다른 시간/학생에게 반복 생성되어 있음.

실제 사용자 제보:

- 본인이 쓴 적 없는 내용
- 여러 다른 수업 학생들에게 동일/유사 문장 반복
- 평소 학생 이름에 성을 붙이지 않는데 전체 이름으로 작성됨
- "발목 힘이 많이 좋아졌습니다" 같은 본인이 다룬 적 없는 내용
- 자동 템플릿에도 없는 문장

예시 패턴:

"{학생명}도 자유형 발차기 연습을 열심히 했습니다.
발목 힘이 많이 좋아졌습니다."

서로 다른 학생/수업/시간에 반복.

이것은 P0 DATA INTEGRITY INCIDENT로 취급.
