[배포 종료 후 운영 원칙 위반 정리 지시]

이번 배포는 종료한다.
추가 Push / Render / OTA / DB 작업을 금지한다.

확인된 지시 위반:

1. Preview 배포 금지 원칙이 있었으나 preview OTA를 배포함
2. 배포 중 승인 범위 밖 package.json dev 스크립트를 임시 변경함
3. working tree에 mockup 자동생성 파일 수정이 남아 있음

앞으로 다음을 절대 준수한다.

배포 도구 실행을 위해 dev 스크립트를 임시 교체하는 방식도 앞으로 금지한다.
기존 명령 또는 별도 일회성 명령으로 실행한다.

4. working tree 정리
━━━━━━━━━━━━━━━━━━━━━━

현재 남은 파일:

artifacts/mockup-sandbox/src/.generated/mockup-components.ts

이 파일을 자동 커밋하지 않는다.

원본 기준으로 안전하게 복원 가능한 자동생성 파일인지 확인만 하고,
사용자 승인 없이 commit하지 않는다.

attached_assets, mockup, generated 파일은 모든 배포 커밋에서 제외한다.
