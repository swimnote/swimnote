[P0 FINAL UI BLOCKER — X TRIAL SUCCESS BUT BUTTON STUCK IN INFINITE LOADING]

실기기 iOS 최신 OTA에서 재현:

1. 신규 trial 미사용 pool
2. "무료체험 시작하기" 클릭
3. 서버에서는 trial activation 성공
4. 실패 메시지는 더 이상 안 뜸
5. 그러나 버튼 spinner가 계속 돌아가며 무한 loading
6. 앱 완전 종료 후 재실행하면 X Trial이 정상 활성화되어 있음

따라서 현재 확정:

- POST activation 성공
- DB exact 72h 저장 성공
- mode=x_trial 성공
- trial feature access 성공
- false failure 문제는 개선됨

남은 유일한 문제:

"성공 후 현재 화면의 loading state가 해제되지 않고,
subscription UI가 즉시 trial-active 상태로 전환되지 않음"

서버/DB/resolver 다시 수정하지 말 것.
CLIENT UI state lifecycle만 최소 수정.
