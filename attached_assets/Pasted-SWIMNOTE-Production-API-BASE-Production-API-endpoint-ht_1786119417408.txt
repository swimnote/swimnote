SWIMNOTE 긴급 복구 — Production API_BASE 정상화 승인

원인 확정.

Production 앱의 의도된 API endpoint:

https://swimnote-api.onrender.com/api

현재 장애 원인:

EAS production server env의

EXPO_PUBLIC_API_URL=https://swimnote.kr/api

가 eas.json의 정상값

https://swimnote-api.onrender.com/api

를 override하여,
Production OTA가 별도 GCP 서버를 호출하고 있었음.

코드 수정은 하지 않는다.
Render 재배포도 하지 않는다.
DB 변경도 하지 않는다.

EXPO_PUBLIC_API_URL

https://swimnote-api.onrender.com/api

실제 값이 위 URL인지 증거 제출.
