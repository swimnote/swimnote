WP-DIARY-0 Architecture Audit 결과 기준으로
WP-DIARY-1 구현을 시작한다.

이번 작업 범위는
"개별일지 내용이 2~3줄에서 잘리는 UI 문제"
하나뿐이다.

원인 이미 확정:

1. DiaryWriteView.tsx 개별일지 TextInput
   numberOfLines={3}

2. 학생 카드 미리보기
   numberOfLines={2}

3. 개별일지 입력창에
   onContentSizeChange 기반 동적 높이 또는
   scrollEnabled={false} 기반 자연 확장 구조가 없음

AI Engine / API / state에서는
학생별 content truncation이 발견되지 않았다.

따라서 서버/AI 수정 금지.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 최종 목표 UX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

전체일지와 개별일지 모두
내용 전체를 한 번에 확인할 수 있어야 한다.

개별일지:

- multiline 유지
- 내용 길이에 따라 TextInput 높이 자동 증가
- TextInput 내부 작은 스크롤 사용하지 않음
- 학생 카드 자체가 내용 길이만큼 아래로 늘어남
- 학생별 내용 전체 표시
- 학생별 개별 수정 가능
- 학생 A 수정이 학생 B에 영향 없음
- 학생 20명이어도 각 학생 카드가 순서대로 아래로 이어짐
- 화면 전체 바깥 ScrollView를 내려
  마지막 학생까지 전부 확인/수정 가능

즉:

학생1
[전체 개별일지 내용]

학생2
[전체 개별일지 내용]

학생3
[전체 개별일지 내용]

...

학생20
[전체 개별일지 내용]

형태가 되어야 한다.

학생마다 2~3줄짜리 작은 내부 스크롤창을 만들지 않는다.

3. DiaryWriteView 수정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A. 개별일지 TextInput

현재:

multiline
numberOfLines={3}

구조 확인.

변경 목표:

- numberOfLines={3} 제거
- multiline 유지
- scrollEnabled={false} 적용
- textAlignVertical="top" 유지
- maxHeight 강제 제한 금지
- 고정 height 금지
- 내용에 따라 자연스럽게 높이가 늘어나도록 구성

현재 style에 minHeight가 있다면
초기 입력 편의용 최소 높이만 유지.

내용이 길어질수록
TextInput 자체 높이가 증가해야 한다.

B. 학생 카드 미리보기

현재:

<Text numberOfLines={2}>...</Text>

→ numberOfLines={2} 제거.

AI 개별일지 전체 내용이 카드에서도 잘리지 않고 보여야 한다.

단 UI가 완전히 무너지지 않도록
기존 padding / border / card 구분은 유지.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. DiaryEditView도 동일 정책
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기존 일지 수정 화면에서도
개별일지 장문이 똑같이 잘리면 안 된다.

DiaryEditView의:

- student note preview

구조를 확인해서
DiaryWriteView와 동일 정책 적용.

두 화면의 동작 원칙을 동일하게 맞춘다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 전체일지 영역은 건드리지 않는다
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

전체일지는 현재 실기기에서
내용이 길어지면 정상적으로 늘어난다고 확인됐다.

따라서 전체일지 TextInput 구조를
불필요하게 리팩터링하지 않는다.

개별일지 쪽만 전체일지와 같은 사용자 경험을 만든다.
