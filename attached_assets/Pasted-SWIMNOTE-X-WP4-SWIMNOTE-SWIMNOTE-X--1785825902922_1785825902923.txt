현재까지 확정된 흐름과 마지막 감사 결과를 기준으로 이어서 진행합니다.

- 학부모 AI 검색
- 성장리포트
- 결제

8. 상태별 UI 원칙
━━━━━━━━━━━━━━━━━━━━━━

normal

- 기존 SWIMNOTE 외형 그대로
- 기존 메뉴 그대로
- X 표시 없음
- X 전용 메뉴 비노출
- X 전용 Route 접근 차단
- 일반기능 변화 없음

x_pending

- 일반 SWIMNOTE 기능 유지
- X 준비 중 상태 표시
- X 기능이 활성화된 것처럼 보여서는 안 됨
- X 메뉴 또는 진입 시 준비 중 안내
- 실제 기능 연결 금지

x

- SWIMNOTE X 명칭 또는 로고 표시
- 확정된 네이비·민트 디자인 규칙 적용
- 역할별 X 전용 메뉴 노출
- 아직 구현되지 않은 기능은 준비 중 또는 출시 예정 처리
- 실제 Backend 연결 금지

loading / error / null

- 이전 X 상태 재사용 금지
- X 메뉴 비노출
- 일반 앱 구조를 깨지 않음
- 오류를 X 활성 상태로 처리 금지
