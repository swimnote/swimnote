S1 완료 보고서를 검토했습니다.

배너 제목 제한, 줄바꿈 제한, POST·PUT 검증, 관리자 입력 화면 검증이 계획대로 적용된 것으로 판단합니다.

이제 S2만 진행하세요.

======================================
S2 — 서버 기본 이모지 제거
======================================

## 목표

서버에서 자동 생성하거나 기본값으로 제공하는 문구에 포함된 Unicode 이모지를 제거합니다.

사용자가 직접 작성하거나 저장한 콘텐츠의 이모지는 변경하거나 차단하지 않습니다.

이번 단계는 서버 기본 텍스트와 기본 템플릿 정리만 진행합니다.

======================================
작업 범위
======================================

서버 전체에서 다음 항목을 조사하세요.

1. 푸시 알림 기본 제목 및 본문
2. 알림 기본 템플릿
3. 자동 생성 메시지
4. 공지 기본 문구
5. 출결·일지·앨범 관련 자동 알림
6. 초대·가입·승인·거절 관련 자동 알림
7. 결제·구독 관련 자동 알림
8. 관리자 및 슈퍼관리자 시스템 메시지
9. 테스트용 기본 데이터 및 seed 문구
10. 서버에 하드코딩된 상태 표시용 이모지

다음과 같은 Unicode 이모지를 기본 문구에서 제거합니다.

- 🔔
- 📢
- 🎉
- ✅
- ❌
- ⚠️
- 📸
- 🏊
- 📝
- 📅
- 💬
- ⭐
- 🎁
- 기타 UI 또는 알림 의미로 사용된 모든 이모지

이모지를 제거한 뒤에도 문장의 의미가 자연스럽게 유지되도록 텍스트를 정리하세요.

예시:

변경 전:
🔔 새로운 알림이 있습니다

변경 후:
새로운 알림이 있습니다

변경 전:
🎉 레벨업을 축하합니다!

변경 후:
레벨업을 축하합니다!

======================================
유지해야 하는 항목
======================================

다음 항목은 삭제하거나 수정하지 않습니다.

1. 사용자가 직접 입력한 문구
2. 기존 DB에 저장된 사용자 콘텐츠
3. 사용자 게시물
4. 사용자 작성 수업일지
5. 사용자 작성 공지
6. 사용자 작성 배너
7. 사용자 작성 메시지
8. 사용자 이름이나 수영장 이름에 포함된 이모지
9. 기존 logo_emoji 데이터
10. 클라이언트 앱 UI 코드

이번 단계에서는 입력 단계에서 이모지를 차단하는 검증도 추가하지 않습니다.

======================================
검색 방법
======================================

서버 코드 전체를 검색하여 이모지가 포함된 위치를 먼저 목록화하세요.

대상 경로 예시:

- artifacts/api-server/src
- 서버 seed 및 template 파일
- 서버 notification 관련 파일
- 서버 push 관련 파일
- 서버 message 관련 파일

검색 결과를 확인한 뒤 서버 기본 문구에 해당하는 것만 수정하세요.

문서, 주석, 테스트 설명에 포함된 이모지는 실제 사용자에게 노출되는 값이 아니라면 불필요하게 수정하지 마세요.
