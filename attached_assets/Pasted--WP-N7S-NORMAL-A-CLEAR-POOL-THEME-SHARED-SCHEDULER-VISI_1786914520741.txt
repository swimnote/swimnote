[WP-N7S — NORMAL A CLEAR POOL THEME + SHARED SCHEDULER VISIBILITY RECOVERY]

목적:

1. Normal SWIMNOTE의 Sage/회녹색 테마를 폐기하고
   최종 확정한 A안 "Clear Pool" 테마로 변경한다.

2. X모드의 기존 Nautic/Yacht
   배경 / 프레임 / 헤더 / 테두리 / 탭바는 그대로 유지한다.

3. 단, 스케줄러는 Normal/X에서 공통으로 사용하는 업무 화면이므로
   스케줄러 내부의 GENERAL CONTROL 색상은
   양 모드에서 동일한 Clear Pool 규칙을 사용한다.

4. 스케줄러의 사용자 지정 반 색상(classColor),
   요일 구분색,
   출결/보강 등 semantic 색상은
   테마 색상과 완전히 분리하여 보호한다.

- classColor가 backgroundSoft로 대체됨

수정 목표:

한눈에 식별될 만큼 선명해야 한다.

단:

원본 classColor 값 자체를 변조하지 않는다.

필요 시:

- solid dot
- stronger left bar
- readable chip
- controlled light tint + solid indicator

등 기존 UI 구조 안에서
최소한의 visual correction 가능.

13. SELECTED DATE VS CLASS COLOR
==================================================

오늘 / 선택 날짜는 Clear Pool.

반 색은 classColor.

둘이 겹칠 때
무엇이 선택 날짜이고 무엇이 수업인지
구분 가능해야 한다.

예:

오늘:
Clear Pool circle/ring

수업:
classColor dot/bar/block

같은 pixel 역할을
두 의미가 경쟁하지 않게 한다.
