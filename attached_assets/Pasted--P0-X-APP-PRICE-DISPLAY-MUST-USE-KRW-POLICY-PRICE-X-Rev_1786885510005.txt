[P0 — X APP PRICE DISPLAY MUST USE KRW POLICY PRICE]

현재 X 정기결제 화면에서:

RevenueCat:
pkg.product.priceString

을 그대로 표시하기 때문에
TestFlight Apple ID storefront가 US인 경우

앱 내부에도:
US$49.99

가 표시되고 있다.

실제 Apple Purchase Sheet에도
US$49.99가 다시 표시되어
가격이 두 번 보이고,

SWIMNOTE 앱 내부의 X 상품 가격 안내까지
미국 storefront 가격으로 바뀌는 문제가 있다.

==================================================
1. FINAL DISPLAY POLICY
==================================================

SWIMNOTE 앱 내부의 X 가격 안내는
한국 서비스 정책 가격을 원화로 표시한다.

앱 내부 표시:

tier1 / 50%
→ ₩75,000 / 월

tier2 / 30%
→ ₩105,000 / 월

tier3 / 10%
→ ₩135,000 / 월

standard
→ ₩150,000 / 월

Apple Purchase Sheet는 건드리지 않는다.

Apple 결제창 가격은
StoreKit / RevenueCat이 반환하는
실제 storefront 가격을 그대로 사용한다.

==================================================
2. IMPORTANT SEPARATION
==================================================

APP DISPLAY PRICE
≠
STORE TRANSACTION PRICE SOURCE

앱 화면:

SWIMNOTE X 한국 정책 가격 안내

Apple 결제창:

실제 App Store transaction price

purchasePackage()에 전달하는 package는
기존 RevenueCat package 그대로 유지.

결제 금액 조작 금지.

==================================================
3. SERVER TIER IS SOURCE
==================================================

앱이 가격 tier를 임의 선택하면 안 된다.

기존:

POST /billing/x-reserve-slot

서버 응답의:

tierKey
discountPercent
storeProductId

를 기준으로
앱 표시용 KRW 가격을 결정한다.

mapping:

tier1
→ 75000

tier2
→ 105000

tier3
→ 135000

standard
→ 150000

가능하면 한 helper/source에서만 관리.

여러 화면에 숫자 중복 hardcode 금지.

==================================================

한국어 화면:

₩135,000 / 월
₩150,000 / 월
