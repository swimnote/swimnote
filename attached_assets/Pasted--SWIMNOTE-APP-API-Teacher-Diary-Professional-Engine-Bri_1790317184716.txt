9. 실제 Engine E2E
━━━━━━━━━━━━━━━━━━━━━━

코드 구현 후
Production env를 변경하지 않은 상태에서
개발/테스트 실행에서만 professional branch를 강제로 사용하여
실제 Professional Engine을 1회 호출하십시오.

입력:

자유형 호흡할 때 고개 많이 듦

학생 없는 기존 검증 방식 사용 가능:

student_refs: []
students: []

확인:

- auth success 여부
- HTTP status
- generation_mode
- knowledge_ids
- template_ids
- result.common
- sentence count

성공 기준:

result.common이 단순 원문 1문장이 아니라

Teacher Fact 자연화
+
Knowledge 기반 기술 설명

형태로 2문장 이상 출력.

없는 향상/성공/과거 훈련 사실 생성 금지.

실제 GPT 호출은 최대 1회.
