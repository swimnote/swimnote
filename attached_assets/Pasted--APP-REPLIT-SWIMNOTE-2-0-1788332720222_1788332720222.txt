# SWIMNOTE 2.0 KAKAO SIGN-UP POLICY CHANGE
#
# 목표:
# 1.6.3 카카오 로그인/가입은 그대로 유지한다.
#
# 2.0.0부터 카카오 가입/계정연결은
# "학부모 전용"으로 제한한다.
#
# 관리자/선생님은 카카오 가입 불가.
# 관리자/선생님은 앱 내 일반 가입/로그인만 사용한다.

# 기존의 "관리자 / 선생님 / 학부모 역할 선택 화면"을 제거하고,
# 카카오 인증 후 바로 학부모 회원정보 입력/연결 화면으로 이동시킨다.

2. 로그인 첫 화면 카카오 버튼
============================================================

카카오 로그인 버튼을 눌렀을 때

문구:

"카카오 회원가입은 학부모만 가능합니다.
관리자와 선생님은 앱 내 가입을 이용해 주세요."

버튼:

[확인]
[취소]

또는 현재 앱의 표준 confirm UI에 맞는 형태 사용.

확인:
→ 카카오 인증 진행

취소:
→ 현재 로그인 화면 유지

중요:
새로운 복잡한 온보딩 화면 만들지 말 것.
짧은 안내 modal/alert 형태로 처리.

  기존대로 로그인

- 기존 관리자/선생님 legacy 카카오 계정:
  기존 정상 로그인 경로가 있다면
  이번 작업에서 깨뜨리지 말 것.

"신규 가입 제한"과
"기존 로그인 호환성"을 분리한다.

기존 관리자/선생님 카카오 로그인 제거:
이번 작업 범위 아님.

4. kakao_no_account 신규 가입 흐름 변경
============================================================

현재 2.0에서:

카카오 인증
→ kakao_no_account
→ 역할 선택
→ 관리자 / 선생님 / 학부모
→ 역할별 연결

구조가 있다면 변경.

신규 2.0 구조:

카카오 인증
→ kakao_no_account
→ 역할 선택 화면 SKIP
→ 바로 학부모 회원정보 입력/연결 화면

즉:

관리자 선택:
삭제

선생님 선택:
삭제

학부모 선택:
삭제

역할은 자동으로:

parent

로 고정.

5. 카카오 회원정보 입력 화면
============================================================

카카오 신규 사용자가
바로 들어가는 학부모 연결 화면에서

현재 필요한 기존 필드를 그대로 사용.

예:

- 학부모 이름
- 전화번호
- 필요한 계정 연결 정보
- 자녀/수영장 연결에 필요한 기존 정보

정확한 필드는
현재 kakao-link parent flow를 재사용.

새 필드를 임의 추가하지 말 것.

기존 parent 연결 API/contract를 그대로 사용.
