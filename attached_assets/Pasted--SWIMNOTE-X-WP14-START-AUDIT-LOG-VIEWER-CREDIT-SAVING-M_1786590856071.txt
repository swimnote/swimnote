7. 민감정보
━━━━━━━━━━━━━━━━━━━━

Audit Viewer라고 해서
raw 개인정보를 과도하게 노출하면 안 됨.

가능하면 표시:

- actor 내부 ID
- actor role
- pool id/name
- event/action
- target type/id
- timestamp
- old/new status
- 안전한 metadata

다음 raw 값은 그대로 노출하지 말 것:

- password/hash
- access token
- refresh token
- API key
- 전화번호
- 일지 본문 전체
- AI prompt/response 전체

기존 audit log에 민감 field가 들어가 있다면
response serialization 단계에서 masking.
