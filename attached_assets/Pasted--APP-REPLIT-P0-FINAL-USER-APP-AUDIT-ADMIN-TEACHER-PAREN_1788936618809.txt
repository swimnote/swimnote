중요:

Super Admin은 이번 작업에서 완전히 제외한다.

이번 작업은 코드 수정 작업이 아니다.

금지:
- 코드 수정
- route 수정
- API 수정
- DB migration
- UI redesign
- OTA
- Render deploy
- Android 작업
- 새 build

목표:

Super Admin을 제외한 실제 사용자 앱 전체를

1. 일반 관리자 (Pool Admin)
2. 선생님 (Teacher)
3. 학부모 (Parent)

각 역할별로

A. 일반 SWIMNOTE(BASE)
B. SWIMNOTE X

두 상태를 모두 전수검사한다.

이번 결과를 사용자에게 먼저 보고하고
검사 승인 후 실제 수정 작업을 별도로 진행한다.

1. MODE SEMANTICS — 절대 변경 금지
━━━━━━━━━━━━━━━━━━━━━━

다시 확인:

mode === 'x'
= paid X

가 아니다.

현재 canonical 의미 유지.

feature mode:
canonical mode resolver

paid:
x_paid_entitlement

manual:
x_manual_entitlement

HQ:
x_management_override

forced disabled:
x_force_disabled

config:
xmode_config_status

가능한 mode 예:
- base
- x_pending
- x
- 기타 실제 resolver 반환값

모든 화면에서
각자 임의로 mode를 계산하는 코드가 있는지도 찾는다.

가능하면 canonical resolver와 비교.

이번에는 수정하지 말고
불일치만 보고.
