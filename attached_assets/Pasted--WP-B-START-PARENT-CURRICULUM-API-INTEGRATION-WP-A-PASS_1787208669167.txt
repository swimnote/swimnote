==================================================
3. NORMAL SWIMNOTE 차단
==================================================

정책 유지:

Normal SWIMNOTE 학부모는
커리큘럼 AI 검색을 실제 실행하지 않는다.

버튼 노출은 WP-C에서 처리.

서버에서는 Normal 요청이 들어와도
AI Engine/GPT 전에 차단 가능해야 한다.

안내 reason:

CURRICULUM_NOT_AVAILABLE

또는 기존 error contract에 맞는 안전한 code.

사용자 메시지:

"현재 수영장에 AI 검색용 커리큘럼이 등록되어 있지 않아
커리큘럼 AI 검색을 이용할 수 없습니다."

이 경우:

AI Engine 호출 0
quota 차감 0

==================================================
4. X / 허용 센터 eligibility
==================================================

검색 허용 조건:

- 서비스 허용 상태
- 검색 가능한 curriculum_items >= 300

현재 X ingestion이 아직 실제 Production에서 실행되지 않아
curriculum_items가 0일 수 있음.

그 경우 정상적으로 NOT_AVAILABLE 처리.

300개를 우회하지 않는다.

금지:

- active X profile만으로 허용
- level count 기준 허용
- 임의 가중치 허용

==================================================
8. DIRECT_DB
==================================================

DIRECT_DB는 AI Engine/GPT 호출하지 않는다.

가능한 예:

- 현재 level
- 명확한 최근 수업일
- DB에서 확정 가능한 사실

DIRECT_DB:

AI call = 0
quota charge = 0

답변은 deterministic formatter 사용.

단,
자연어 품질을 위해 GPT를 몰래 호출하지 않는다.

9. HUMAN_ONLY
==================================================

고정 안전 안내.

예:

"진급 시점이나 다음 단계 전환 여부는
실제 수업 수행 상태와 담당 선생님의 판단이 필요합니다."

필요 시 기존 문의 연결 구조와의 연결은
이번 WP-B에서 새로 만들지 않는다.

13. ENGINE FAILURE
==================================================

Engine timeout / 5xx / validation failure:

- quota rollback
- completed_count 증가 금지
- 사용자 안전 오류
- raw engine error 노출 금지

사용자:

"커리큘럼 정보를 불러오지 못했습니다.
잠시 후 다시 시도해주세요."

DIRECT_DB 경로는
Engine 장애와 무관하게 동작 가능.

==================================================
15. QUOTA RESERVATION 위치
==================================================

가능하면 비용이 실제 발생할 가능성이 있는
GROUNDED_GPT 경로에서만 reservation.

하지만 현재 기존 route 구조상
초기에 reserve하도록 되어 있다면:

DIRECT_DB/HUMAN_ONLY 결정 후
즉시 rollback하는 구조보다

answer_mode 결정 후 reserve하는 구조가
더 안전한지 검토.

기존 concurrency/idempotency 보호를 깨면 안 됨.

최소 변경으로 구현.

19. CURRENT CURRICULUM ABSENCE
==================================================

==================================================
20. NO OVERCLAIM
==================================================

AI Engine에 전달하기 전에 이미
Progress Resolver 결과를 확정.

Engine이:

NOT_CONFIRMED
→ COMPLETED

로 승격하지 못하도록 prompt/validation에 명시.

Engine output이 APP progress_state와 충돌하면
validation failure 또는 APP state 우선.

APP deterministic progress가 authority.
