정원이 정확히 찬 반을 찾는다.

예:

현재 인원 = 5

확인:

- 해당 반/회차가 목록에 보임
- 정원마감 또는 정원초과 표시가 유지됨
- 회차 자체가 disabled 되어 있지 않음
- 탭 가능

PASS 조건:
5/5 반이 경고 표시를 유지하면서 선택 가능.

- 배정 가능

- MAKEUP_DATE_OUT_OF_RANGE 오류 없음
- 앱 crash 없음

6. 이월 보강 검증
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

전월 이월 보강이 실제로 존재하면 확인.

중요 검증:

- 이월 표시 정상
- 결석일을 기준으로 후보 날짜가 잘리지 않음
- 오늘 기준 -14일 ~ +28일 범위의 회차가 표시됨
- 8월 회차 선택 가능
- 정원 마감 반도 선택 가능
- expired 확인이 필요한 경우 기존 확인창 유지
- 정상 배정 가능

이 항목은 기존 이월 보강 문제까지 함께 확인하는 핵심 실기기 검증이다.

7. 선보강 검증
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

결석 예정일보다 앞선 날짜로 보강 가능한 데이터가 있으면 확인.

예:

보강일 8/17

기대:

- 8/17 회차 표시
- 선택 가능
- 미래 날짜이므로 assign 정상
- DATE_BEFORE_OR_ON_ABSENCE 같은 과거 정책 오류 없음

데이터가 없으면 NOT_TESTABLE.

8. 기존 보호장치 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

실기기에서 자연스럽게 확인 가능한 범위만 확인.

- expired 보강 확인창 유지
- 정원마감 뱃지 유지
- 중복 터치 방지/isSaving 정상
- 기존 보강 대기 목록 정상
- 기존 배정 완료 처리 정상
- 앱 crash 없음
- 로그인 정상
- 오늘 스케줄 정상
- 일지 기능에 이상 없음

테스트를 위해 운영 데이터를 임의 생성하거나 변경하지 않는다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

하나라도 실패하면 즉시 코드 수정하지 않는다.

먼저 다음을 수집한다.

- 어떤 화면
- 학생/반 식별에 필요한 최소 정보
- 선택한 날짜
- 정원 표시
- 오류 메시지
- HTTP status가 기존 진단 수단으로 확인되면 status
- 재현 순서
- 스크린샷

그 후 원인 분석 보고서만 제출한다.

승인 없이 수정 금지.
