[WP-N5 — NORMAL SWIMNOTE ICON / EMOJI VISUAL NORMALIZATION]

목적:

Normal SWIMNOTE 전반의 일반 기능 아이콘과 장식용 이모지를
완성형 앱 수준의 일관된 visual language로 정리한다.

이번 WP는:

- icon color
- decorative emoji → vector icon
- active/inactive icon hierarchy

만 정리한다.

기능, 위치, 버튼 동작, route, API는 변경 금지.

==================================================
0. FINAL NORMAL ICON POLICY
==================================================

Normal SWIMNOTE 일반 기능 아이콘:

DEFAULT / NORMAL
→ C.textPrimary 또는 C.textStrong 계열

ACTIVE / SELECTED
→ C.brandStrong 또는 C.brandPrimary

SECONDARY / LOW PRIORITY
→ C.textSecondary

MUTED / META
→ C.textMuted
단 중요한 조작 아이콘에는 사용 금지.

아이콘을 예쁘게 보이게 하려고
blue / purple / orange / mint를 임의 사용하지 않는다.

==================================================
1. CORE PRINCIPLE
==================================================

색은 장식이 아니라 의미와 상태를 표현한다.

→ Sage

→ semantic 고유색

==================================================
4. DO NOT USE PURE BLACK
==================================================

일반 icon을 #000000으로 통일하지 않는다.

Normal 공식 텍스트 계열을 사용:

C.textStrong
C.textPrimary
C.textSecondary

목표:

선명하지만 너무 쨍하지 않음.

==================================================
5. LEGACY 3-COLOR ICON SYSTEM AUDIT
==================================================

현재 감사 결과:

iconBlue   #007AFF
iconGreen  #00704A
iconOrange #FF6F0F

사용 중.

각 사용처 의미를 다시 분류.

iconBlue가 단순 navigation/general function이면:
→ Normal neutral/Sage system으로 migration 후보.

iconGreen이 실제 success/complete 의미면:
→ semantic 유지.

iconOrange가 실제 warning/alert 의미면:
→ semantic 유지.

단순 decoration 목적으로 색을 나눈 경우:
→ 제거.

18. ACCESSIBILITY
==================================================

일반 actionable icon은
배경과 충분한 대비 확보.

C.textMuted는
중요 버튼/icon에 사용하지 않는다.

작은 active icon은
C.brandPrimary보다
C.brandStrong이 더 적절하면 Strong 사용.

19. VISUAL TARGET
==================================================

- 알록달록한 기능 아이콘 감소

- warning/error/success만 의미색
