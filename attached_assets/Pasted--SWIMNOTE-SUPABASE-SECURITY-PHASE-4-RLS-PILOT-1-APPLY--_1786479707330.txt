SWIMNOTE SUPABASE SECURITY — PHASE 4
RLS PILOT 1 APPLY + RUNTIME VERIFY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

승인된 작업:
Production SUPABASE의 저위험 5개 테이블에만
RLS를 실제 적용한다.

대상:

1. global_template_sets
2. curriculum_requests
3. curriculum_versions
4. curriculum_items
5. feature_flags

중요:
POOL_DB에는 이번 단계에서 RLS 적용하지 않는다.
Production SUPABASE만 먼저 적용한다.

DB SOURCE:
SUPABASE_DATABASE_URL

executeSql production 사용 금지.

━━━━━━━━━━━━━━━━━━━━
1. 적용 전 증거 저장
━━━━━━━━━━━━━━━━━━━━

READ ONLY:

각 테이블에 대해 제출:

- relrowsecurity
- relforcerowsecurity
- row count
- existing policy count
- owner
- anon SELECT/INSERT/UPDATE/DELETE privileges
- authenticated SELECT/INSERT/UPDATE/DELETE privileges

기존 policy가 하나라도 있으면
임의 변경하지 말고 STOP.

━━━━━━━━━━━━━━━━━━━━
2. 연결 role 재확인
━━━━━━━━━━━━━━━━━━━━

같은 DB session에서:

SELECT current_user;

그리고:

rolsuper
rolbypassrls

확인.

기대:

current_user = postgres
rolbypassrls = true

다르면 STOP.

━━━━━━━━━━━━━━━━━━━━
3. RLS Pilot 적용
━━━━━━━━━━━━━━━━━━━━

대상 5개에만:

ALTER TABLE global_template_sets ENABLE ROW LEVEL SECURITY;
ALTER TABLE curriculum_requests ENABLE ROW LEVEL SECURITY;
ALTER TABLE curriculum_versions ENABLE ROW LEVEL SECURITY;
ALTER TABLE curriculum_items ENABLE ROW LEVEL SECURITY;
ALTER TABLE feature_flags ENABLE ROW LEVEL SECURITY;

정책 생성하지 않는다.

현재 목적:
anon/authenticated Data API deny-by-default.

FORCE ROW LEVEL SECURITY 사용 금지.

다른 테이블 변경 금지.

━━━━━━━━━━━━━━━━━━━━
4. 즉시 DB READ-BACK
━━━━━━━━━━━━━━━━━━━━

적용 직후 실제 Production Supabase에서:

각 테이블:

relrowsecurity = true

인지 다시 조회.

policy count도 제출.

정확한 결과:

RLS=true
policy=0

인지 확인.

━━━━━━━━━━━━━━━━━━━━
5. direct postgres 회귀 검증
━━━━━━━━━━━━━━━━━━━━

SUPABASE_DATABASE_URL direct postgres로:

global_template_sets COUNT
curriculum_requests COUNT
curriculum_versions COUNT
curriculum_items COUNT
feature_flags COUNT

전부 정상 조회되어야 함.

기대:
postgres rolbypassrls=true이므로 기존과 동일.

━━━━━━━━━━━━━━━━━━━━
6. Render Runtime 회귀 검증
━━━━━━━━━━━━━━━━━━━━

Render 재배포는 하지 않는다.

현재 Live 서버에서:

GET /api/health → 200

기존 READ ONLY API 최소 smoke.

Render 로그에서:

permission denied
row-level security
policy violation
relation access denied

신규 오류가 발생하는지 확인.
