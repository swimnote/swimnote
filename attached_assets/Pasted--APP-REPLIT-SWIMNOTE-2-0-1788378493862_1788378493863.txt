2. A — NORMAL + X 구분
============================================================

관리자 dashboard가 Normal/X에서 동일 component라면
한 파일 안에서 현재 mode/entitlement에 따라
기존 분기만 유지.

공통 요소:

- 현황
- 인원관리
- 공통 admin home structure

는 Normal/X 양쪽에서 일관되게 반영.

X 전용 요소:

- X 카드
- X 관련 AI entry

는 X mode에서만 표시되는 기존 정책 유지.

Normal SWIMNOTE에
X 전용 카드/CTA가 새로 노출되면 FAIL.
