1. MATCHING RULE
============================================================

기존 Kakao Parent ↔ 새 General Parent 매칭 기준:

- normalized phone 동일
- 동일 pool 관계 또는 기존 parent/student relation으로 확인
- old account는 kakao_id IS NOT NULL
- new account는 general auth account
- 동일 사용자임이 명확할 때만 migration

이름만으로 매칭:
NO

전화번호 normalization:
현재 공통 함수 재사용

7. ALREADY MIGRATED / BROKEN ACCOUNT RECOVERY
============================================================

이미:

Kakao Parent
→ General account 생성
→ 로그인 가능
→ 그런데 기존 자녀/정보가 안 넘어간 상태

라면
동일 migration endpoint 재호출로 강제 복구 가능해야 한다.

처리:

1. archived old Kakao Parent 탐색
2. new General Parent 탐색
3. old ACTIVE refs 전수 확인
4. 누락된 refs만 old → new
5. duplicate는 skip
6. new account active 유지
7. old account active refs = 0

manual DB edit 없이 recovery 가능하게.
