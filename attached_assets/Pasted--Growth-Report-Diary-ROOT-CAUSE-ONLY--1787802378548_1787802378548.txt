POST /parent/diary/:diaryId/reactions

diary_reactions
UNIQUE(diary_id, parent_id, reaction_type)

Teacher count:
SELECT COUNT(*)
FROM diary_reactions dr
WHERE dr.diary_id = cd.id
AND dr.reaction_type = 'like'

GET /diaries
→ diaries state
→ DiaryHistoryList
→ item.like_count

- pull-to-refresh → fetch
- useFocusEffect 복귀 → diaries refetch 없음

따라서 현재 유력 ROOT CAUSE:
