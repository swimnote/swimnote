3. TERMINOLOGY 수정 방식
==================================================

단순:

if (router.canGoBack()) router.back()

만으로 해결하지 마십시오.

감사 결과 실제 TestFlight에서
router.back() stack이 신뢰되지 않는 상황이 확인됐습니다.

따라서 검색 → 상세 진입 시
명시적인 return context를 전달합니다.

예:

router.push({
  pathname: detailPath,
  params: {
    termId,
    backTo: "terminology-search"
  }
})

그리고 상세 Back은
기존 SubScreenHeader의 backTo 처리 규칙을 사용하여:

Teacher:
→ /(teacher)/terminology-search

Parent:
→ /(parent)/terminology-search

로 복귀.

==================================================
11. IMPORTANT — BUTTON TAP에서 강제 dismiss 금지
==================================================

사용자 요구:

키보드가 올라와 있어도
Button / Pressable / Result Card를 누르면

버튼 action이 정상 실행되어야 함.

버튼 tap 자체를
전역 Keyboard.dismiss handler로 가로채지 마십시오.

즉:

Button tap
→ Action

Empty background tap
→ Keyboard.dismiss()

두 동작을 분리.

==================================================
12. EMPTY BACKGROUND DISMISS 구현 원칙
==================================================

금지:

화면 전체를
TouchableWithoutFeedback 하나로 감싸서

내부 버튼 interaction까지
부모 dismiss handler가 먹는 구조.

권장:

기존 검증된
feedback-custom.tsx 패턴 참고.

Modal:

<View overlay>
  <Pressable
    style={StyleSheet.absoluteFill}
    onPress={Keyboard.dismiss}
  />

  <ActualModalContent>
    ...
  </ActualModalContent>
</View>

배경 Pressable은
실제 interactive content 뒤에 위치.

중 안전한 방식 선택.
