7. GENERAL ACCOUNT가 이미 생성된 경우
============================================================

현재 실제 사용자 중:

Kakao account 존재
→ General account 이미 생성
→ 승인/활성까지 됨
→ 그런데 기존 정보가 안 넘어간 상태

가 있을 수 있음.

이 경우 migration endpoint 재호출 또는
idempotent recovery path로 복구 가능해야 한다.

Teacher recovery:
1. archived old Kakao teacher 찾기
2. new General teacher 찾기
3. old ACTIVE refs 전수 확인
4. 누락된 ref만 old → new
5. duplicate 없이 skip
6. new teacher active 유지

Parent recovery:
1. archived old Kakao parent 찾기
2. new General parent 찾기
3. old ACTIVE refs 전수 확인
4. child/pool/request/settings 등 누락 ref만 old → new
5. duplicate 없이 skip
6. new parent active 유지

manual DB edit 없이 recovery 가능하게.
