11. DOCX Parser 수정 방향
==================================================

현재 정보 손실 지점:

docxParser.ts
extractCellText()

<w:t> text run들을
.join("")

으로 병합하면서:

- paragraph boundary
- line break
- list boundary
- item boundary

가 소실된다.

PRE-WP-X에서는
먼저 이 경계를 보존한다.

우선 검토:

- <w:p> paragraph 단위
- <w:br> line break
- list paragraph
- table cell 내부 item boundary

단순 comma split만으로 item을 생성하지 않는다.

원본 DOCX 구조를 최대한 보존한다.
