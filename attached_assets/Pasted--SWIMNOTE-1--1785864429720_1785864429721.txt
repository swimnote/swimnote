6. 삭제 학생 필터 여부
━━━━━━━━━━━━━━━━━━━━━━

GET /teacher/makeups와 GET /admin/makeups에서
students 테이블을 JOIN하는지 확인한다.

최종 SQL이 아래처럼 makeup_sessions 단독 조회라면:

SELECT ms.*
FROM makeup_sessions ms
WHERE ...

삭제 학생 필터가 전혀 없는 것이다.

필요한 확인 대상:

LEFT JOIN students s ON s.id = ms.student_id

그리고 다음 조건 존재 여부:

s.id IS NOT NULL
s.deleted_at IS NULL
s.status NOT IN ('withdrawn', 'archived')

현재 어떤 조건도 없다면 명확히 보고한다.

7. 문제 학생 DB 조회
━━━━━━━━━━━━━━━━━━━━━━

사용자가 제보한 삭제 학생을 이름 일부 마스킹하여 조회한다.

학생 테이블:

SELECT
  id,
  name,
  status,
  deleted_at,
  withdrawn_at,
  archived_reason,
  swimming_pool_id,
  class_group_id,
  assigned_class_ids
FROM students
WHERE name ILIKE '%서동%'
ORDER BY updated_at DESC;

보강 테이블:

SELECT
  id,
  student_id,
  student_name,
  swimming_pool_id,
  status,
  absence_date,
  expire_at,
  assigned_date,
  completed_at,
  cancelled_at,
  cancelled_reason,
  handed_to_teacher_id,
  created_at,
  updated_at
FROM makeup_sessions
WHERE student_name ILIKE '%서동%'
   OR student_id IN (
     SELECT id FROM students WHERE name ILIKE '%서동%'
   )
ORDER BY created_at DESC;

attendance:

SELECT
  id,
  student_id,
  date,
  status,
  session_type,
  class_group_id,
  created_at,
  updated_at
FROM attendance
WHERE student_id IN (
  SELECT id FROM students WHERE name ILIKE '%서동%'
)
ORDER BY date DESC;

보고서에서 이름은 마스킹한다.
운영 DB 조회만 허용하며 수정 금지.
