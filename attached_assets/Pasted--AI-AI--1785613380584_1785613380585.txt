[긴급 수정 — AI 안내 모달 본문 미표시 문제]

현재 배포된 AI 안내 모달은 헤더와 확인 버튼만 보이고, 가장 중요한 본문이 전혀 표시되지 않습니다.

이번 작업은 디자인 변경이 아니라 본문 렌더링 구조를 바로잡는 수정입니다.

━━━━━━━━━━━━━━━━━━━━━━
1. 현재 문제
━━━━━━━━━━━━━━━━━━━━━━

실기기 확인 결과:

- 모달 제목 정상
- 아이콘 정상
- X 버튼 정상
- 확인 버튼 정상
- 본문 전체 미표시
- 모달 높이가 지나치게 낮음
- ScrollView가 화면 높이를 배정받지 못했거나 높이 0으로 축소된 것으로 추정

본문 데이터가 실제로 props에 전달되는지부터 확인하고,
본문이 렌더 트리에 존재하는지 확인하십시오.

스타일만 임의로 수정하지 말고 아래 순서로 원인을 증명하십시오.

1. 모달에 전달되는 title
2. 모달에 전달되는 content 또는 sections
3. 본문 렌더 함수가 실제 호출되는지
4. ScrollView의 실제 layout height
5. modalContainer의 실제 layout height
6. header/footer 높이
7. 본문이 조건부 렌더링에서 제외되는지
8. 본문 글자색과 배경색이 동일한지
9. zIndex 또는 overflow:hidden에 가려지는지

개발 로그 또는 onLayout 수치로 확인하고 수정하십시오.

━━━━━━━━━━━━━━━━━━━━━━
2. 모달 크기
━━━━━━━━━━━━━━━━━━━━━━

안내 모달은 작은 Alert가 아닙니다.

모달을 화면의 대부분을 사용하는 큰 안내창으로 변경하십시오.

필수 기준:

- width: 화면 너비의 약 92%
- height: 화면 높이의 약 78~85%
- maxHeight만 두고 내용에 맡기지 말고, 실제 height 또는 flex 기반 높이를 명확히 배정
- 화면 세로 중앙 배치
- 상단과 하단 Safe Area를 침범하지 않음
- 작은 화면에서도 최소 높이 확보
- 기존처럼 본문이 없을 때 모달이 300px 수준으로 축소되는 구조 금지

권장 예시:

modalContainer:
- width: "92%"
- height: Dimensions.get("window").height * 0.82
- maxHeight: Dimensions.get("window").height * 0.85
- minHeight: Dimensions.get("window").height * 0.68
- backgroundColor: "#FFFFFF"
- borderRadius: 기존 모달 기준
- overflow: "hidden"

단, Repository의 기존 반응형 유틸이 있다면 그 방식을 우선 사용하십시오.

━━━━━━━━━━━━━━━━━━━━━━
3. 레이아웃 구조
━━━━━━━━━━━━━━━━━━━━━━

다음 구조로 고정하십시오.

Modal
└─ Backdrop: flex: 1
└─ ModalContainer: 명확한 height
├─ Header: 고정 높이
├─ BodyWrapper: flex: 1
│ └─ ScrollView: flex: 1
│ └─ 본문 전체
└─ Footer: 고정 높이

필수 스타일:

ModalContainer
- display: flex
- flexDirection: "column"

Header
- flexShrink: 0

BodyWrapper
- flex: 1
- minHeight: 0

ScrollView
- flex: 1

Footer
- flexShrink: 0

중요:

- ScrollView에 flexGrow: 0만 넣지 마십시오.
- BodyWrapper에 height가 없는 상태에서 ScrollView만 flex:1로 두지 마십시오.
- 모달을 content 높이에만 맡기지 마십시오.
- 본문 영역에 position:"absolute" 사용 금지
- Footer를 absolute로 겹쳐 놓지 마십시오.
- 본문 부모에 overflow:"hidden"을 잘못 적용해 내용을 잘라내지 마십시오.
- 본문을 헤더와 푸터 사이의 정상 flex 영역에 배치하십시오.

━━━━━━━━━━━━━━━━━━━━━━
4. 본문은 첫 화면부터 보여야 함
━━━━━━━━━━━━━━━━━━━━━━

모달이 열리자마자 다음이 보여야 합니다.

- 헤더
- 본문 첫 문단 최소 2~3줄
- 필요할 경우 아래 내용이 더 있다는 것을 알 수 있는 자연스러운 스크롤 영역
- 하단 확인 버튼

확인 버튼 바로 위가 텅 빈 상태는 실패입니다.

본문이 길더라도 첫 화면에서 충분한 양이 보여야 하며,
사용자가 위아래로 부드럽게 스크롤할 수 있어야 합니다.

ScrollView 설정:

- showsVerticalScrollIndicator: true
- bounces: true
- alwaysBounceVertical: false
- nestedScrollEnabled: true
- keyboardShouldPersistTaps: "handled"
- contentContainerStyle:
- paddingHorizontal: 24
- paddingTop: 24
- paddingBottom: 48
- flexGrow: 0

본문 마지막 문장과 Powered 문구 아래에도 최소 24~32px 여백을 확보하십시오.

7. 본문 가독성
━━━━━━━━━━━━━━━━━━━━━━

본문이 이 모달의 핵심입니다.

제목보다 본문 가독성을 우선하십시오.

기준:

- 본문 글자 크기: 16px 전후
- lineHeight: 25~27px
- 기본 글자색: 기존 앱의 진한 본문색
- 문단 간 marginBottom: 20~24px
- 첫 소개 문단: fontWeight 700
- 나머지 문단: fontWeight 400~500
- 왼쪽 정렬
- 텍스트 중앙 정렬 금지
- 한 문단을 한 줄로 압축 금지
- 글자색을 너무 연하게 설정 금지

강조 가능 항목:

커리큘럼:
- SWIMNOTE AI
- OpenAI GPT
- 수영 전문 데이터베이스
- 독점 시범 서비스

성장 리포트:
- SWIMNOTE AI
- OpenAI GPT
- 130개의 평가 데이터
- 집중력
- 논리적 사고
- 문제 해결 과정
- 학습에도 도움이 될 수 있는 성장 지표
- 독점 시범 서비스

강조 색상은 현재 AI 버튼 글자색과 동일하게 사용하되,
강조가 너무 많아 본문 전체가 청록색으로 보이지 않도록 하십시오.

━━━━━━━━━━━━━━━━━━━━━━
8. 헤더와 확인 버튼 크기 조정
━━━━━━━━━━━━━━━━━━━━━━

현재 헤더와 확인 버튼이 본문보다 지나치게 많은 공간을 차지합니다.

수정 기준:

헤더:
- 높이 약 72~84px
- 아이콘 32~40px
- 제목 22~26px
- X 터치 영역 44px 이상

Footer:
- 높이 약 88~104px
- 확인 버튼 높이 약 52~58px
- 좌우 여백 24px
- 확인 버튼이 모달 본문의 절반 가까이를 차지하지 않도록 제한

헤더와 Footer를 줄여 본문 가용 면적을 최대한 확보하십시오.

━━━━━━━━━━━━━━━━━━━━━━
9. 확인해야 할 실패 원인
━━━━━━━━━━━━━━━━━━━━━━

다음 중 실제 원인이 무엇인지 코드 기준으로 보고하십시오.

- 본문 문자열이 빈 값으로 전달됨
- `content` 대신 다른 prop 이름을 읽음
- sections 배열이 비어 있음
- 조건부 렌더가 false
- BodyWrapper에 flex 없음
- ScrollView height 0
- modalContainer가 content 높이로 축소
- Footer가 본문 위를 덮음
- 글자색이 흰색 또는 투명
- 부모 overflow로 잘림
- 잘못된 absolute positioning
- zIndex 문제

원인을 확인하지 않고 모달 높이만 키우는 임시 수정은 금지합니다.

━━━━━━━━━━━━━━━━━━━━━━

- Powered 문구 확인 가능
- 마지막 문장이 확인 버튼에 가려지지 않음
