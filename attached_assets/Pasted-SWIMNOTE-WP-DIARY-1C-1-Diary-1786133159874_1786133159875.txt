SWIMNOTE — WP-DIARY-1C 실제 문제 화면 수정 승인

이번 조사 결과 기준으로 구현 승인한다.

확정된 사실:

1. 실제 문제 화면은
   DiaryWriteView / DiaryEditView가 아니라

   artifacts/swim-app/.../DiaryAIModalV2.tsx

   의 "AI 일지 작성" 모달이다.

2. 실제 학생별 개별일지는
   StudentNoteCard 안의 TextInput이다.

3. 같은 모달의 전체일지(COMMON)는:

   - 명시적 height 없음
   - minHeight 사용
   - onContentSizeChange 없음

   구조이고 실기기에서 긴 내용이 정상 표시된다.

4. 학생별 일지(STUDENT)는:

   - height: Math.max(60, inputHeight)
   - onContentSizeChange로 inputHeight 갱신

   구조다.

5. 명시적 height 구조가 정확한 장애 원인이라는 실측 확정은 아직 없지만,
   동일 모달에서 이미 정상 작동하는 COMMON 방식으로 STUDENT를 통일하는
   최소 변경은 승인한다.

1. 실제 수정
━━━━━━━━━━━━━━━━━━━━

파일:

DiaryAIModalV2.tsx

StudentNoteCard에서 제거:

const [inputHeight, setInputHeight] = useState(...)

style={[
  cardStyles.noteInput,
  { height: Math.max(STUDENT_NOTE_MIN_H, inputHeight) }
]}

onContentSizeChange={...}

변경:

style={cardStyles.noteInput}

그리고 noteInput style에:

minHeight: STUDENT_NOTE_MIN_H

적용.

유지:

multiline
scrollEnabled={false}
textAlignVertical="top"

목표:

학생별 일지도 같은 AI 결과 모달의 전체일지와 동일하게
내용 길이에 따라 카드가 자연스럽게 늘어나도록 한다.
