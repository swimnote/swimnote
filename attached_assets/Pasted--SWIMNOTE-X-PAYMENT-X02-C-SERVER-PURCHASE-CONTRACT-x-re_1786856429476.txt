5. EXISTING SLOT CHECK
==================================================

새 slot 생성 전 현재 pool의 slot 상태 확인.

우선순위:

A.
이미 PURCHASED active slot 존재
→ 신규 예약 금지
→ ALREADY_SUBSCRIBED 또는 equivalent 409

B.
아직 유효한 RESERVED slot 존재
→ 새 번호 발급 금지
→ 기존 reservation 반환

즉 버튼 재탭/네트워크 retry로
번호 여러 개 소비하지 않게 한다.

C.
RESERVED지만 deadline 초과
→ transaction 안에서 RELEASED 처리 후 신규 예약 가능
