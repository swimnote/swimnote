문제:
현재 Parent 일반 SWIMNOTE 모드에서는
"AI 인사이트 전략 리포트" 버튼이 비활성/클릭 불가.

X모드 Parent에서는 클릭 가능.

사용자 확정 정책:

AI 인사이트 전략 리포트 버튼은
X 기능 접근 버튼이라기보다
상품 소개/홍보 진입 버튼에 가깝다.

따라서:

BASE Parent
X Trial Parent
X Paid Parent

모두 동일하게 버튼을 눌러
AI 인사이트 전략 리포트 소개/정보 화면까지
진입 가능해야 한다.
