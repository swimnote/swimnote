1. 교육과정 진행도
   ==================================================

현재 문제:

데이터 부족 상태에서
"수업 기록이 쌓이면..." 안내문만 보이고
gauge UI 자체가 없음.

수정:

기본 구조는 항상 유지.

교육과정 진행도            XX.X% 또는 fallback 상태
[ progress gauge ]

A. 유효 데이터 있음

* 기존 progress source 그대로 사용
* % 표시
* gauge fill 표시
* 숫자와 bar 동일 데이터 기준
* 하드코딩 금지
* 기존 계산식 변경 금지

B. 데이터 부족

* 가짜 0% 금지
* gauge track은 표시
* active fill은 표시하지 않거나 neutral 상태
* fallback 문구 표시

권장 문구:
"진행 정보가 쌓이는 중입니다"

색상:

* title / % = navy
* track = neutral
* 실제 progress fill만 mint 사용 가능

6. OTA / ROLLBACK
=================

JS/TS/TSX only이고
native/runtimeVersion 변경 없으면
iOS production OTA 즉시 배포.

OTA 전에 반드시 실제 현재 상태에서 기록:

PREVIOUS STABLE

* update group ID
* update ID
* runtimeVersion
* channel
* git SHA

추측 금지.

현재 이전 보고상 최신 OTA:

* group: ef3d16a0-1b6c-4f06-9344-d2ea67464ae3
* update: 01a03e8b-7de3-7de1-87fa-a3124790444d

단 실제 EAS 현재 상태를 확인해서
이번 작업의 rollback target으로 확정할 것.

그 후:

수정
→ 최소 테스트
→ commit
→ iOS production OTA

Android OTA 금지.

문제 발생 시
기록한 PREVIOUS STABLE로 즉시 rollback 가능 상태 유지.
