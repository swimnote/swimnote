5. SWIMNOTE CTA 상태
============================================================

외부 App Store/RC 제품이 아직 실제 생성되지 않은 상태에서는
앱이 crash하면 안 된다.

정책:

외부 product/package 없음:
→ "구독 신청 준비 중"
→ safe disabled

외부 product/package 정상 수신:
→ "구독 시작"
→ purchase 가능

즉 외부 설정 전/후를
동일 build가 안전하게 처리해야 함.

hardcoded 강제 활성화 금지.

6. APP STORE SUBSCRIPTION GROUP 최종 확정
============================================================

동시에 BASE plan 하나만 존재:

SWIMNOTE
X300
X500
X1000

X includes SWIMNOTE.

X → SWIMNOTE:
다음 결제일부터 변경

X300 ↔ X500 ↔ X1000:
upgrade/downgrade 가능

따라서 App Store Connect에서
가장 안전한 subscription group 구조를
코드/정책 기준으로 하나로 확정한다.

후보:

OPTION A
SWIMNOTE + X300 + X500 + X1000
모두 동일 subscription group

OPTION B
SWIMNOTE 별도 group
X300/X500/X1000 동일 group

반드시 하나 선택.

판단 기준:

- base 중복구독 방지
- X → SWIMNOTE next billing
- SWIMNOTE → X upgrade
- X tier 변경
- Apple subscription group semantics
- RevenueCat current product replacement
- 이중결제 위험

추측 금지.

현재 코드와 Apple/RC 구조상
확정할 수 없는 항목은
EXTERNAL CONSOLE VERIFICATION REQUIRED로 표시.
