[긴급 재감리 — META_APP_ID 빈값 진단 검증 / 수정 금지]

직전 감리에서:

".env에 EXPO_PUBLIC_META_APP_ID가 없으므로
OTA bundle의 META_APP_ID가 빈 문자열이다"

라고 원인을 확정했으나,
현재 프로젝트는 Expo SDK 55이고 이전 작업에서 이미
EAS preview environment에 다음 값이 등록되어 있다.

EXPO_PUBLIC_META_APP_ID=2093655621362240

또한 기존 정상 OTA는:

eas update
--environment preview

방식으로 배포했다.

Expo SDK 55+에서는 --environment를 사용한 EAS Update가
로컬 .env가 아니라 EAS 서버 environment 값을 사용한다.

따라서 .env 부재만으로 META_APP_ID=""를 확정하지 않는다.

코드 수정 금지.
.env 수정 금지.
OTA 금지.
Build 금지.
Render 변경 금지.

1. 최신 instagram-test OTA 정확히 확인
━━━━━━━━━━━━━━━━━━━━━━

현재 TestFlight 1.6.2가 실제 수신 중인
instagram-test 최신 OTA를 확인한다.

보고:

- OTA Group ID
- iOS Update ID
- commit SHA
- message
- runtimeVersion
- branch
- channel
- publishedAt

특히 보고서에 언급된:

a23799a4

가 실제 현재 iOS 최신 OTA인지 확정한다.

2. 해당 OTA 배포 명령 확인
━━━━━━━━━━━━━━━━━━━━━━

a23799a4 또는 현재 최신 OTA가
실제로 어떤 명령으로 배포됐는지 확인한다.

반드시 확인:

--environment preview

가 있었는가 YES/NO.

YES라면:
로컬 .env 부재는 META_APP_ID 빈값의 근거가 될 수 없다.

NO라면:
어떤 environment source로 bundle이 생성됐는지 확인한다.

추측 금지.

━━━━━━━━━━━━━━━━━━━━━━
3. EAS preview environment 재확인
━━━━━━━━━━━━━━━━━━━━━━

실행:

eas env:list --environment preview

다음 실제 존재 여부 확인:

EXPO_PUBLIC_META_APP_ID

값:

2093655621362240

인지 확인한다.

값 자체가 삭제/변경되었는지도 확인.

4. OTA bundle 실제 값 검증
━━━━━━━━━━━━━━━━━━━━━━

가장 중요.

현재 최신 OTA bundle 안에서:

process.env.EXPO_PUBLIC_META_APP_ID

가 최종적으로 어떤 literal로 inline됐는지 확인한다.

가능한 안전한 방법을 사용:

- EAS Update artifact/bundle 확인
- 동일 environment로 expo export 후 bundle 검사
- 또는 instagram-test와 동일 조건의 local export

반드시:

--environment preview와 동일한 EAS env를 사용한다.

확인 결과는 아래 셋 중 하나로 확정:

A.
"2093655621362240"

B.
""

C.
undefined

추정값 금지.

━━━━━━━━━━━━━━━━━━━━━━
5. 현재 코드의 META_APP_ID 표현식 확인
━━━━━━━━━━━━━━━━━━━━━━

StoryCapturePipeline.tsx 실제 코드 확인:

const META_APP_ID =
  process.env.EXPO_PUBLIC_META_APP_ID ?? "";

정확히 dot notation인지 확인.

다른 파일에서 재정의하거나 shadowing하는지 검색:

EXPO_PUBLIC_META_APP_ID
META_APP_ID

전체 repository 검색.

보고:

- 정의 위치
- 사용 위치
- 중복 정의 여부
- runtime override 여부

6. 현재 실패 Alert 경로 확정
━━━━━━━━━━━━━━━━━━━━━━

현재 실기기 증상:

"이미지 생성 중..."
→ 모달 종료
→ Instagram 미실행

이것이 실제로:

if (!META_APP_ID)

분기를 탔다는 증거를 확보한다.

추론만으로 확정하지 않는다.

진단 코드가 이미 a23799a4에 있다면
그 값을 사용한다.

없다면 코드 변경하지 말고
현재 로그/기존 Alert 경로에서 확인 가능한 범위를 보고한다.

특히 현재 화면에서 실제:

"Instagram Story 공유 설정이 완료되지 않았습니다."

Alert가 표시됐는지,
아니면 Modal만 사라졌는지 구분한다.

8. 부가 문제는 분리
━━━━━━━━━━━━━━━━━━━━━━
