목적:
Parent Curriculum AI가 학생의 실제 현재 교육과정 진행 위치를
optional context로 받을 수 있도록
student_curriculum_progress(SCP)를
기존 Parent Curriculum scope에 연결한다.

핵심 원칙:
- Gauge 값은 설명용 context다.
- Gauge가 Parent Curriculum 검색 결과를 강제로 바꾸는 authority가 아니다.
- Professional V2 / GPT는 gauge를 수정할 수 없다.
- Gauge source는 오직 SCP read-only.
- 기존 Parent Curriculum pipeline/grounding/quota 동작을 깨뜨리지 않는다.

1. buildStudentProgress() 구현

3. 기존 engine request contract 최소 확장
4. 테스트
5. production DB write 금지

구현:

buildStudentProgress(db, studentId, poolId)

조회:

SELECT
  display_confirmed_pct,
  active_confirmed_pct,
  active_confirmed_rank,
  active_confirmed_total,
  active_curriculum_version_id,
  observation_session_count,
  confirmed_at
FROM student_curriculum_progress
WHERE student_id = $studentId
  AND swimming_pool_id = $poolId
LIMIT 1

return 예:

{
  confirmed_progress_pct,
  active_progress_pct,
  active_confirmed_rank,
  active_total_count,
  active_version_id,
  observation_session_count,
  confirmed_at
}

명칭은 기존 request contract에 맞게 최소 조정 가능.

AI context에서 핵심 current progress는:

confirmed_progress_pct
= SCP.display_confirmed_pct

두 값을 혼동 금지.
