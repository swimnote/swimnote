# SWIMNOTE 디자인 시스템 리뉴얼 — S3 작업 지시

S2 완료 보고서를 검토했습니다.

S2는 승인합니다.

사용자에게 노출되는 서버 기본 문구의 이모지 제거가 계획대로 완료되었습니다.

이제 S3만 진행하세요.

======================================
S3 — 앱 아이콘 시스템 통일
======================================

## 목표

앱 전체에서 아이콘 시스템을 LucideIcon으로 통일합니다.

UI에서 사용하는 Unicode 이모지를 제거하고 디자인 시스템 규칙을 적용합니다.

이번 단계는 **앱 UI만 수정**합니다.

서버는 수정하지 않습니다.

======================================
변경 규칙
======================================

모든 UI 아이콘은

LucideIcon

래퍼 컴포넌트만 사용합니다.

직접

import { Bell }

또는

@expo/vector-icons

사용을 금지합니다.

필요한 아이콘은

LucideIcon.tsx의 ICON_MAP에 먼저 등록한 뒤 사용하세요.

- ❌

- 🏊
