사용자가 문제라고 한 화면:
"AI 일지 작성"
하단:
"수정하기"
"다시 생성"
"일지에 삽입"

여기에서 학생별 AI 일지가 길어질 때

"반 공통 일지"

"템플릿선택"

이 있는 일반 일지 작성 화면이다.

즉 현재 진단 위치가 잘못됐다.

- 문제 화면과 진단 화면이 서로 다름
- 진단 화면에서 S.layout / S.content / S.parent = undefined
- 따라서 현재 진단값은 실제 장애 분석에 사용할 수 없음

4. 현재 실기기 증상 기준
━━━━━━━━━━━━━━━━━━━━

확인된 실제 증상:

- 학생별 일지에 타이핑은 계속 입력됨
- 뒷부분 텍스트는 화면에 안 보임
- 커서도 아래로 사라짐
- 카드 높이는 늘어나지 않음
- 전체일지는 긴 내용이 화면에 보임

따라서 실제 문제 모달 안에서:

A. TextInput content는 늘어나는데 layout 고정인지
B. TextInput은 늘어나지만 parent가 자르는지
C. 내부 scroll만 되고 cursor follow가 안 되는지

코드로 확인.

━━━━━━━━━━━━━━━━━━━━
5. 진단도 실제 문제 모달에만 붙일 것

- student parent height

6. 목표 동작

AI 일지 작성 결과 모달에서:

전체일지
[전체 내용 전부 표시]

학생1
[개별 내용 전부 표시/수정]

학생2
[개별 내용 전부 표시/수정]

...
학생20
[개별 내용 전부 표시/수정]

학생별 카드가 내용 길이만큼 늘어나고,
모달 전체를 아래로 스크롤해서 마지막 학생까지 접근 가능.

수정 중 커서가 항상 현재 입력 위치에 보여야 한다.

작은 고정 높이 TextInput 내부에서
텍스트/커서가 사라지는 구조 금지.
