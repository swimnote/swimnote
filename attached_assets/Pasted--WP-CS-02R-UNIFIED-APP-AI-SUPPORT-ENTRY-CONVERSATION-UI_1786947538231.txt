X

이번 WP의 목표는:

즉 GPT/OpenAI 자동답변은 추가하지 않는다.

==================================================
5. FIRST MESSAGE FLOW
==================================================

사용자가 첫 메시지 입력:

1. context 수집
2. POST /support/cases
3. case_id 확보
4. POST /support/cases/:id/messages
5. 사용자 메시지 저장
6. 화면에 표시

이번 단계에서는
AI 자동답변을 생성하지 않는다.

대신 시스템 상태:

문의가 접수되었습니다.

정도의 deterministic/system message가 필요하면
서버/앱 고정 문구로 처리 가능.

OpenAI 호출 금지.

실제 repository 구조 기준 최소 구현.
