[SWIMNOTE 학부모 빨간점 미표시 — Teacher 업무대화 → Parent unread 경로 즉시 복구]

현재 실기기 CONFIRMED:

- Teacher → Parent 업무대화 메시지 전송 정상
- Parent 업무대화 Modal을 다시 열면 메시지 확인 가능
- Parent notifications polling은 30초로 구현됐다고 보고됨
- 그러나 Teacher가 메시지를 보낸 뒤 3분 이상 기다려도
  학부모 화면의 빨간점/unread 표시가 나타나지 않음

따라서 이번 문제는 polling 간격 문제가 아니다.

이번 작업 목표:

Teacher 업무대화 메시지
→ Parent notification 저장
→ unread_count 증가
→ 학부모 앱 state 갱신
→ 실제 빨간점 render

전체 체인에서 최초 실패 지점을 찾아 즉시 복구한다.

조사만 하고 멈추지 말고
원인 확인 → 수정 → Production 배포까지 완료한다.
