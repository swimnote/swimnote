[WP-N6 — PARENT NORMAL/X THEME FRAME FINALIZATION]

목적:

학부모 앱에서도
Normal SWIMNOTE와 SWIMNOTE X가
테마 수준에서 명확히 구분되도록 정리한다.

단,
기능 고유색 / semantic color / 콘텐츠 색상은 보호한다.

이번 WP의 핵심:

Normal Parent
→ Sage/Ocean theme frame

X Parent
→ Nautic/Yacht theme frame

하지만:

AI 리포트
AI 커리큘럼
Feed
Reaction
Attendance
Level
Photo/content

등 기능/의미 색상은 모드가 바뀌어도 유지한다.

==================================================
0. CORE PRINCIPLE
==================================================

Normal/X 테마는:

"앱의 프레임과 조작 UI"

를 구분한다.

기능의 의미를 전달하는 색상은
모드와 관계없이 유지한다.

즉:

THEME_MUTABLE
→ mode에 따라 변경

FEATURE_FIXED
→ 고유색 유지

SEMANTIC_PROTECTED
→ 의미색 유지
