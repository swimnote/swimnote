[앱] FREE GROWTH REPORT — PRODUCTION GENERATION PIPELINE P0

실기기에서 확인된 현재 상태:

- Parent Curriculum quota 3/4 정상
- Growth Report entry는 NEW status screen으로 정상 진입
- 하지만 현재 학생에게 report가 생성되어 있지 않아 NOT_AVAILABLE 표시
- "수업 기록 보기" 버튼은 존재하지 않는 route로 이동하여
  Expo Router:
  "This screen doesn't exist."
  오류 발생

현재 핵심 문제:

FREE Growth Report의 월간 생성 파이프라인이
Production에서 실제 report를 생성하고 있는지 불명확함.

오늘은 2026-08-25 KST이며,
기존 설계상 월간 Growth Report 생성 cycle이 있는 상태.

이번 Step에서는 UI 디자인 작업 금지.

목적:

1. 왜 현재 학생의 report가 NOT_AVAILABLE인지 정확히 확인
2. 월간 report generation pipeline을 Production에서 정상 작동 상태로 만듦
3. "수업 기록 보기" 404 route 수정
4. 실제 report가 만들어진 뒤 PUBLISHED 이전까지 정상 lifecycle 확인

2. GENERATION PIPELINE 확인

각 단계의 실제 파일/함수/trigger를 확인.

repo-wide audit 금지.
Growth Report generation 관련 파일만.

3. SCHEDULER 실제 상태 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기존 설계에서 report 생성 cycle이
25th KST 기준이라면 실제 구현을 확인.

반드시 보고:

- scheduler file/function
- 실행 cadence
- timezone
- next/last run
- Production에서 scheduler가 실제 실행되고 있는지
- worker/service가 살아 있는지
- scheduler가 API server process 내부인지
- external cron인지
- Render cron인지
- 현재 disabled 상태인지

"코드가 있다"가 아니라
Production에서 실제 실행 여부 확인.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. ELIGIBILITY GATE 확인
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 학생이 왜 generation 대상이 아닌지 확인.

가능 후보:

- X mode gate
- pool eligibility
- monthly period condition
- minimum diary/evidence
- attendance/session threshold
- duplicate prevention
- report already exists
- scheduler date mismatch
- timezone mismatch
- student role/status
- teacher diary not counted
- required snapshot missing

실제 조건을 하나씩 확인해서
정확한 root cause를 확정.

추측 금지.
