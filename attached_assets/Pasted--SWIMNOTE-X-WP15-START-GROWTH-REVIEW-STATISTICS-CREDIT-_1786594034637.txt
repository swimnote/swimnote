5. 필수 집계
━━━━━━━━━━━━━━━━━━━━

최소 다음 값을 반환:

total_valid_events
pending_review
teacher_accepted
teacher_rejected
auto_accepted
discarded

추가 계산:

reviewed_total =
teacher_accepted + teacher_rejected

review_rate =
reviewed_total /
(pending_review + teacher_accepted + teacher_rejected)

accepted_rate =
teacher_accepted / reviewed_total

rejected_rate =
teacher_rejected / reviewed_total

단:

분모 = 0이면 반드시 0 반환.

NaN
Infinity

절대 금지.

AUTO_ACCEPTED는 teacher review rate의
분모에 임의 포함하지 말 것.
