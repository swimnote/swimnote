[WP-N4 — NORMAL SWIMNOTE SCHEDULER CONTROL UI NORMALIZATION]

목적:

Normal SWIMNOTE의 Scheduler / Calendar / Schedule 관련 화면에서
정보 식별을 위해 사용되는 기존 색상은 100% 보존하고,

사용자가 조작하는 CONTROL UI만
Normal Sage/Ocean 디자인 시스템으로 정리한다.

이번 WP의 핵심 원칙:

"정보를 구분하는 색은 유지한다.
조작을 위한 색만 테마에 맞춘다."

==================================================
5. TODAY / DATE SELECTION
==================================================

Normal mode의:

today highlight
selected date
selected day
active calendar day

같은 theme-controlled selection은
Sage system 사용.

권장:

background:
C.brandSoft

border / text / icon:
C.brandStrong
또는 C.brandPrimary

작은 텍스트 가독성이 부족하면
C.brandStrong 사용.

기존 mint #2EC4B6 직접 사용 제거.

단 classColor dot는 그대로.

==================================================
6. WEEK DOT / MONTH DOT RULE
==================================================

중요.

"오늘임을 나타내는 theme dot"
와
"반/일정을 나타내는 classColor dot"
를 구분한다.

THEME DOT
→ Sage/Ocean 변경 가능

CLASSIFICATION DOT
→ 절대 변경 금지

같은 component 안에 두 종류가 존재하면
의미를 확인해서 각각 다르게 처리.

==================================================
7. PROGRESS BAR
==================================================

Scheduler 내부 일반 progress가
themeColor / mint를 단순 브랜드 강조로 사용하면:

Normal:
→ C.brandPrimary 또는 C.brandStrong

배경 track:
→ C.brandSoft / C.backgroundSoft

하지만 progress bar 색 자체가
상태/출결/위험도를 나타내면 semantic 보호.

8. FILTER / CHIP
==================================================

일반 scheduler filter / chip:

X:

반 이름 chip 자체가 classColor를 사용하는 경우:
변경 금지.

==================================================

Normal → Sage

16. COLOR OVERUSE 금지
==================================================

이번 WP의 목적은
scheduler를 초록색으로 만드는 것이 아니다.

Sage는:

- active control
- selected state
- primary interaction
- neutral accent

에만 사용.

classColor 8색이 이미 강한 시각정보를 제공하므로
주변 UI는 오히려 차분하게 정리한다.
