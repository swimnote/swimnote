==================================================
0. 현재 AI ENGINE 운영 상태
==================================================

AI ENGINE은 다음 작업이 완료된 상태입니다.

- GLOBAL DB: kf.*
- SWIMNOTE Diary DB: diary_kf.*
- 업로드 경로 분리 완료
- GLOBAL TEST FIXTURE cleanup 완료
- Diary Cutover/Rollback 준비 완료

현재 AI ENGINE 운영값:

DIARY_PIPELINE_MODE = unset
→ legacy

DIARY_KNOWLEDGE_SOURCE = GLOBAL
→ 기존 kf.* 검색

중요:

현재 Production SWIMNOTE 앱에 대해서는
grounded_v1 + DIARY Cutover를 아직 하지 않았습니다.

따라서 앱 입장에서는 기존 AI Diary API Contract가
그대로 유지되어야 합니다.
