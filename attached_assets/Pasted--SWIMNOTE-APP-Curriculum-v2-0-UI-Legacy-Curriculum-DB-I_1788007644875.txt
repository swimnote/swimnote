==================================================
1. 현재 실기기에서 확인된 오류
==================================================

오류 A.

새 [교육과정] 화면의 Curriculum Node 카드 본문에

{"canonical_key": "...", "source_key": "...", ...}

형태의 내부 JSON/metadata가 그대로 노출되고 있다.

사용자 화면에 canonical_key/source_key/raw JSON을 표시하면 안 된다.

오류 B.

관리자 모드 > 일지 템플릿 화면이 아직 legacy global diary_templates 화면을 사용한다.

실기기에서 다음 구버전 UI가 보임:

- "내 항목"
- "흰색: 물적응·호흡" category dropdown
- 1,2,3... 번호의 기존 완성형 일지문장
- 활성/비활성 switch
- 수정 버튼

이 화면은 기존 global diary_templates 350개 기반 legacy editor다.

현재 Canonical Curriculum v2.0에서는
관리자도 이 legacy global350을 교육과정 정본으로 사용하면 안 된다.

8. Raw JSON 원인 확인
==================================================

현재 API가 goal/source_text/metadata 중
어느 필드에 JSON string을 반환하는지 확인.

가능한 원인:

- description fallback이 metadata JSON 사용
- source_text를 카드 subtitle로 잘못 사용
- DTO serialization 결과를 String()으로 렌더링
- importer raw metadata field를 UI description에 연결

원인을 코드 기준으로 확인하고
UI DTO mapping을 정상 필드로 고친다.

DB 데이터를 수정해서 숨기지 않는다.
