[ACTIVE]

정상 수강 상태.

[연기 / suspended]

- 시간표 제외
- 출석 대상 제외
- 현재 반 배정 종료
- student_id 유지

즉:

연기 = 수강 일시중지

이며 데이터 삭제가 아닙니다.

[1개월 이상 장기연기]

원본 데이터는 삭제하지 않습니다.

그러나 1개월 이상 연기 후 재등록하는 경우:

- 이전 교육구간 종료
- 현재 수업기록 연속성 초기화
- 누적 피드백 연속 기준 초기화
- 성장 분석의 현재 기준 초기화
- 재등록일부터 새로운 교육구간 시작

과거 데이터는 내부 history/archive로 보존합니다.

[퇴원 / withdrawn]

자동 퇴원 금지.

반드시 선생님 또는 관리자가
명시적으로 “퇴원 처리”를 눌렀을 때만 실행.

퇴원은 연기와 달리
회원의 교육/서비스 데이터를 제거하는 종료 행위입니다.

1. 1개월 기준을 명확하게 정의
━━━━━━━━━━━━━━━━━━━━━━

“1개월 이상”은
임의의 30일 숫자로 구현하지 말고

연기 시작일 + calendar 1 month

기준으로 판정하십시오.

KST 기준 날짜 의미를 사용하십시오.

예:

2026-01-15 연기
→ 2026-02-15부터 장기연기

2026-01-31 연기처럼
월말 날짜의 경우 PostgreSQL calendar interval 동작을
테스트하여 예측 가능한 결과를 사용하십시오.

2. suspended_at 추가
━━━━━━━━━━━━━━━━━━━━━━

현재 DB에는
정확한 연기 시작시각 전용 field가 없습니다.

students에 nullable field 추가:

suspended_at timestamptz NULL

연기 즉시 처리:

status = 'suspended'
suspended_at = 현재 시각

다음달 예약 연기의 경우:

실제 suspended 상태가 적용되는 시점에
suspended_at을 기록하십시오.

예약을 건 시점에 미리 기록 금지.

연기 취소 또는 active 복귀 시
판정이 끝난 뒤 suspended_at을 clear.

“1개월 이상 연기 시 기존 수업기록과 누적 피드백이 초기화됩니다.

“실제 데이터는 내부에서 보존됩니다”

1개월 이상 장기연기

→ 새 교육구간 시작

입니다.

그리고 실제 코드도
education_started_at을 통해
이 의미와 일치하게 구현하십시오.

suspended_at을 추측해서 backfill 금지.
