# 학생-학부모 자동 연결 정책 최종 수정 (보호자 2 자동 승인 포함)

이번 작업은 SWIMNOTE의 학생-학부모 연결 정책을 최종 확정하는 작업입니다.

이번 작업에서는
기능 추가보다

"잘못 연결되는 일 없이
가능한 많은 경우 자동 승인"

을 목표로 수정하세요.

==================================================
현재 발견된 문제
==================================================

1.

보호자2 가입 시

학생 연결 요청 화면에

학생 이름이 비어있는 경우가 있습니다.

학생 이름이 정상 전달되지 않는 원인을 찾으세요.

학생 이름이

- 화면 state
- API request
- 서버
- DB

어느 단계에서 사라지는지 확인하세요.

단순히 UI만 수정하지 말고

데이터 흐름 전체를 확인하세요.

==================================================
2.

보호자2 자동승인 정책 확정
==================================================

다음 정책으로 변경합니다.

보호자2 가입

↓

전화번호 인증 완료

↓

학생 연결 요청

↓

학생 이름 입력

↓

서버에서 자동 판별

=====================

자동 승인 조건

=====================

다음 두 조건이 모두 일치하면

자동 승인합니다.

①

학생 이름

완전 일치

AND

②

학생에 등록된 보호자2 전화번호

=

현재 로그인한 학부모의 인증된 전화번호

완전 일치

↓

즉시 승인

↓

student-parent 생성

↓

연결됨 표시

↓

학부모 앱에서 즉시 학생 조회 가능

관리자 승인 필요 없음

==================================================
3.

승인 대기 조건
==================================================

다음 경우는

자동 승인하지 않습니다.

학생 이름 불일치

또는

등록된 보호자2 번호와

로그인한 학부모 번호 불일치

↓

승인대기

↓

관리자 확인

↓

승인

==================================================
4.

학생 이름 전달 문제 수정
==================================================

현재

학생 이름이

연결 요청에서

비어있는 경우가 있습니다.

확인하세요.

- 학생 검색 결과
- 선택 이벤트
- navigation parameter
- request body
- API
- DB

학생 이름이

어느 단계에서 누락되는지

정확히 수정하세요.

==================================================
5.

학생 검색 방식
==================================================

학생 이름 입력 시

현재 센터(student tenant)

안에서만 검색합니다.

다른 센터 학생은

절대 검색하면 안 됩니다.

==================================================
6.

==================================================

전화번호 인증 완료

↓

학생 이름 입력

↓

센터 내 학생 검색

↓

동명이인 존재 여부 확인

↓

등록된 보호자2 전화번호 비교

↓

일치

↓

↓

parent_students 생성

↓

학생 상세 연결됨

↓

학부모 앱 즉시 조회 가능

==================================================
7.

동명이인 처리
==================================================

같은 이름 학생이

여러 명 존재하면

전화번호 비교가 가장 우선입니다.

예)

김민준 3명

↓

각 학생의 보호자2 전화번호 비교

↓

전화번호 일치

↓

그 학생만 자동 연결

전화번호가

일치하지 않으면

자동 승인하지 않습니다.

==================================================
8.

중복 연결 방지
==================================================

이미 연결되어 있으면

새 row 생성 금지

중복 승인 금지

중복 parent_students 생성 금지
