4. DB 연결 증거
━━━━━━━━━━━━━━━━━━━━━━

실행 전에 다음을 다시 출력하십시오.

비밀번호와 전체 URL은 마스킹합니다.

environment variable
database name
masked host
port
current_user
current_schema

SQL:

SELECT
  current_database() AS current_database,
  current_user AS current_user,
  inet_server_addr()::text AS server_addr,
  inet_server_port() AS server_port,
  current_schema() AS current_schema;

운영 DB가 아니면 즉시 중단하십시오.

5. 모든 수영장 X 상태 기준선
━━━━━━━━━━━━━━━━━━━━━━

실행:

SELECT
  id,
  name,
  xmode_entitlement,
  xmode_config_status,
  xmode_purchased_at,
  xmode_subscription_end_at,
  xmode_payment_failed_at,
  created_at
FROM swimming_pools
ORDER BY created_at, id;

제출:

* 전체 수영장 수
* xmode_entitlement=true 수
* xmode_config_status<>'NOT_CONFIGURED' 수
* 각 수영장의 X 상태

전화번호·주소·대표자 정보는 출력하지 마십시오.

기대 기준:

xmode_entitlement=true: 0
READY: 0
CURRICULUM_PENDING: 0

다르면 변경하지 말고 즉시 보고하십시오.

FROM users

8. X Audit 기준선
━━━━━━━━━━━━━━━━━━━━━━

실행:

SELECT COUNT(*) AS cnt
FROM audit_logs
WHERE entity_type = 'swimming_pool_xmode';

POOL_B 기준:

SELECT
  COUNT(*) AS cnt,
  COALESCE(MAX(entity_version), 0) AS max_version
FROM audit_logs
WHERE entity_type = 'swimming_pool_xmode'
  AND entity_id = 'pool_1784310621737_qryl1x79s';

기대:

전체 X Audit: 0
POOL_B X Audit: 0

다르면 변경하지 말고 원인을 보고하십시오.

개별 Audit 내용은 현재 0건이 아닐 경우에만 다음 컬럼으로 제출하십시오.

id
entity_type
entity_id
entity_version
action
actor_type
pool_id
reason
created_at

before_data, after_data, actor_id는 개인정보 가능성이 있으므로 원문 출력하지 마십시오.

11. 체크섬 형태 기준선

row_count
max(updated_at)

대상:

swimming_pools
audit_logs
growth_events
global_template_sets
curriculum_versions
curriculum_items
student_curriculum_assignments

컬럼이 없으면 억지로 실행하지 말고 COLUMN_NOT_FOUND로 보고하십시오.

12. 실패 중단 조건
━━━━━━━━━━━━━━━━━━━━━━

다음 중 하나라도 발생하면 이후 조회를 중단하십시오.

운영 DB가 아닌 DB에 연결
SELECT가 아닌 SQL 실행 발견
POOL_B 상태가 기존 보고와 다름
xmode_entitlement=true인 수영장 존재
READY 또는 CURRICULUM_PENDING 수영장 존재
POOL_B에 실제 학생·결제·일지 데이터 존재
예상하지 않은 X Audit 존재
growth_events에 데이터 존재
x_global 템플릿 존재
DB 권한 오류
테이블 구조가 Repository와 다름

임의 수정하지 말고 증거만 제출하십시오.
