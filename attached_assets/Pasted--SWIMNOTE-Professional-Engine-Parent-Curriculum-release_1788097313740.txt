[SWIMNOTE — Professional Engine Parent Curriculum 포맷 개선 경로 조사]

목적:
현재 release/v2.0.0 commit 87371f4c에서
앱 renderer 안정화는 완료되었다.

그러나 실제 Professional Engine이 한 문단 answer를 반환하면
앱에서는 의미 있는 문단 구조를 새로 만들지 않는다.

따라서 다음 단계는
앱/공용 API를 더 수정하는 것이 아니라
실제 Professional Engine의 Parent Curriculum prompt를
안전하게 수정할 수 있는 repository / deployment source를 찾는 것이다.

이번 단계:
조사만 한다.
코드 수정 금지.
배포 금지.
