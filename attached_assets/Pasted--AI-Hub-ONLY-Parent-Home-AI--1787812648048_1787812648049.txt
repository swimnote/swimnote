1.
아이 기본정보

- 키
- 몸무게

불필요한 개인정보 수집 금지.

2.
학부모 관찰정보

목적:
수영장 수업 데이터만으로 관찰할 수 없는
아이의 평소 모습/변화/반응을
학부모가 보충.

입력 방식 후보:

- 질문형 항목
- 선택형
- 짧은 텍스트
- 자유 음성 → STT

현재 app의 STT 또는 음성 입력 구조가 재사용 가능한지 조사.

Parent 입력은 반드시:
PARENT_REPORTED

등 별도 evidence/source로 분리될 수 있어야 함.

교사의 직접 관찰과 동일한 사실로 취급 금지.

3.
기존 분석정보 수정·보충

기존 입력값을 다시 확인하고 수정 가능.

"정보 관리" 안에서 자연스럽게 묶는 방향 검토.
