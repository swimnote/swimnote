# SWIMNOTE 2.1.0 — WP5 REGRESSION RECOVERY

첨부한 최신 실기기 사진 기준.

현재 상태:
직전에는 4개 탭의 글자가 정상적으로 전부 보였음.
그 상태에서 "기존 SWIMNOTE 소형 chip 디자인 적용" 작업을 한 뒤
과거 WP5 버그가 다시 발생함.

최신 실기기 증상:
- 담당 회원 글자 세로 잘림
- 출결 글자 세로 잘림
- 수업일지 글자 세로 잘림
- 보강 글자 세로 잘림
- 탭 텍스트가 가운데 일부만 보임

즉 이번 normalization 작업이
이전에 해결한 text clipping / cross-axis collapse를 재발시켰다.

4. 디자인 목표
============================================================

직전 정상 상태보다 버튼을 조금 더 컴팩트하게만 한다.

예상 형태:

[ 담당 회원 ] [ 출결 ] [ 수업일지 ] [ 보강 ]

요구사항:

- 글자 전부 완전히 표시
- 좌우 여백은 직전 정상 상태보다 감소
- 현재 깨진 상태처럼 지나치게 작게 만들지 않음
- 버튼 높이는 터치 가능성을 해치지 않는 범위에서만 소폭 축소
- selected/unselected 크기 동일
- 탭 간 gap 일정

가장 중요:
"작게 만드는 것"보다
"절대 다시 잘리지 않는 것"이 우선.

============================================================
5. 실기기 회귀 방지 기준
============================================================

코드상 정상이라고 판단하지 말 것.

레이아웃 수치상 다음 조건을 확인:

Text lineHeight <= chip usable inner height

즉:
chip height
- top/bottom border
- vertical padding

을 제외한 실제 text 영역이
lineHeight보다 작아지면 FAIL.

Text 부모 중 어느 단계에서도
텍스트 높이보다 작은 fixed height가 있으면 FAIL.
