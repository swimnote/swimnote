6. 관련 DB 조회
━━━━━━━━━━━━━━━━━━━━━━

운영 DB는 SELECT만 허용한다.

문제가 발생한 보강 세션:

SELECT
  id,
  swimming_pool_id,
  student_id,
  student_name,
  status,
  absence_date,
  expire_at,
  original_class_group_id,
  assigned_class_group_id,
  handed_to_teacher_id,
  handed_to_teacher_name,
  cancelled_at,
  completed_at
FROM makeup_sessions
WHERE id = :makeupId;

선택한 반:

SELECT
  id,
  swimming_pool_id,
  name,
  schedule_days,
  schedule_time,
  capacity,
  is_deleted,
  is_one_time,
  teacher_user_id
FROM class_groups
WHERE id = :classGroupId;

로그인 교사:

SELECT
  id,
  role,
  swimming_pool_id,
  email
FROM users
WHERE id = :userId;

학생 정원 계산에 포함되는 학생:

SELECT
  id,
  status,
  class_group_id,
  assigned_class_ids,
  deleted_at
FROM students
WHERE class_group_id = :classGroupId
   OR assigned_class_ids @> to_jsonb(:classGroupId::text);

보고서에서 이름·이메일은 마스킹한다.

7. 조건별 판정표
━━━━━━━━━━━━━━━━━━━━━━

실제 코드와 DB 결과를 기준으로 아래를 판정한다.

A. API_BASE가 롤백 과정에서 잘못된 서버를 가리킴
B. 서버 live SHA에 eligible-occurrences 라우트가 없음
C. makeupId가 undefined 또는 잘못됨
D. class_group_id가 undefined 또는 잘못됨
E. 로그인 교사 pool_id가 null
F. makeup_sessions.pool_id와 사용자 pool_id 불일치
G. class_groups.pool_id 불일치
H. class_groups.is_deleted=true
I. schedule_days 파싱 실패
J. absence_date/expire_at 날짜 변환 예외
K. pool_holidays 쿼리 예외
L. DB connection 오류
M. apiRequest가 응답 본문을 소비하거나 변형
N. 롤백된 앱과 현재 서버 Contract 불일치

각 항목을 다음 중 하나로 표시한다.

- 확정 원인
- 정상
- 확인 불가
