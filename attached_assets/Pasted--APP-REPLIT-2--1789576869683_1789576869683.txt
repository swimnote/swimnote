SAFE_URL_RE = /^https?:\/\//i

https://

2. INTERNAL LINK — 죽은 옵션 제거
━━━━━━━━━━━━━━━━━━━━━━

현재 Super Admin에서는:

link_type = internal

선택이 가능한데

ParentPromoStrip에서는
internal을 완전히 no-op 처리하고 있습니다.

이 상태는 금지합니다.

사용자가 선택 가능한 기능은
실제로 동작해야 합니다.

우선 현재 APP에 이미 존재하는
공식 deep-link / route registry / 허용 navigation mapping이 있는지
해당 배너 연결에 필요한 범위만 확인하십시오.

A.
기존 안전한 내부 route registry가 이미 있다면:

→ 그것만 재사용하여 internal 링크를 실제 연결하십시오.
→ 허용 route whitelist만 사용.
→ DB 임의 route를 router.push하지 마십시오.

B.
재사용할 안전한 내부 route 구조가 없다면:

→ 이번 버전에서는 Super Admin 배너 폼에서
  “내부 링크” 선택 옵션을 제거하십시오.
→ link_type은 none / external 두 개만 노출.
→ DB 컬럼과 기존 값은 삭제하지 마십시오.
→ 향후 internal deep-link 체계가 정리되면 다시 활성화할 수 있게 둡니다.

새 navigation system을 만들지 마십시오.

가장 작은 수정으로 처리하십시오.
