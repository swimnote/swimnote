1. 기능의 제품 정의
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기능 공식명:

"수영·훈련용어 검색"

이 기능은 단순한 한 줄짜리 용어사전이 아니다.

SWIMNOTE 내부에서
수영기술, 훈련, 경기, 코칭 등 수영 관련 용어를 검색하고
상세 설명을 읽으며,
그 설명에 등장하는 다른 수영용어를 눌러
계속 다음 용어로 이동할 수 있는
"연결형 수영 전자사전"으로 만든다.

사용 경험의 기준은:

과거 전자사전
+
위키식 연결 탐색

이다.

예:

스트림라인 검색

→ 스트림라인 상세설명

설명 중
"글라이드"
"브레이크아웃"
"돌핀킥"

등 SWIMNOTE DB에 존재하는 용어가 등장

→ 해당 용어를 탭

→ 브레이크아웃 상세설명

→ 그 설명에서 돌핀킥 탭

→ 돌핀킥 상세설명

→ 뒤로가기

→ 브레이크아웃 상세로 정확히 복귀

→ 다시 뒤로가기

→ 스트림라인 상세로 정확히 복귀

즉 용어를 하나씩 읽다가
연관 개념을 계속 공부할 수 있어야 한다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 이번 기능의 핵심 철학
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 검색 중심이다.

카테고리 탐색 UI를 만들지 않는다.

사용자가
영법/훈련/경기/생리학 등의 카테고리를 먼저 이해해야 하는 구조 금지.

검색창을 중심으로 한다.


② AI 실시간 생성 기능이 아니다.

GPT에 매 검색마다 질문해서 설명을 생성하지 않는다.

SWIMNOTE가 사전에 검수한
Canonical Terminology DB의 내용을 그대로 제공한다.


③ 학부모와 선생님이 같은 지식체계를 사용한다.

별도의:

Parent Terminology DB
Teacher Terminology DB

를 만들지 않는다.

하나의:

SWIMNOTE Swimming & Training Terminology Master

를 공동 사용한다.


④ 단순 검색에서 끝나지 않는다.

용어 하나를 읽으면
다른 관련 용어로 자연스럽게 이동하는
학습형 탐색 경험을 만든다.


⑤ 데이터 자체가 장기 자산이다.

이번 DB는 임시 학부모 콘텐츠가 아니다.

향후:

- SWIMNOTE APP
- SWIMNOTE X
- AI ENGINE
- AI 검색
- AI 리포트
- 코치 교육
- 수영 콘텐츠

등에서 재사용 가능한
Canonical Terminology Master로 만든다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7. 검색 UX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

검색은 가능한 한 즉각적으로 반응해야 한다.

사용자가 입력하는 동안:

"스트"
→ 스트림라인 등 관련 결과

처럼 검색 가능.

검색어 정규화 검토:

- trim
- 영어 대소문자 무시
- 한글/영문 case-insensitive
- 중복 공백 정리
- 특수문자 처리
- 약어 검색
- aliases 매칭

다만 fuzzy search를 지나치게 공격적으로 사용해서
엉뚱한 용어가 많이 나오는 것은 금지.

검색 정확도 우선순위 권장:

1. canonical_name_ko 정확 일치
2. canonical_name_en 정확 일치
3. alias 정확 일치
4. search keyword 정확 일치
5. prefix match
6. 부분 match

현재 DB/search stack을 조사한 뒤
Postgres 검색,
서버 search,
클라이언트 index,
기타 방식 중
가장 안정적인 방식을 제안한다.

1,000~수천 개 수준의 용어를 기준으로
과도한 검색 인프라를 도입하지 않는다.

Elasticsearch 같은 별도 대형 검색시스템 도입 금지.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

10. 용어 유형별 설명 차이
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

11. 설명 본문 내부 용어 링크 — 핵심 기능

상세 설명을 렌더링할 때
본문에 SWIMNOTE Terminology DB에 존재하는

DB에:

글라이드
브레이크아웃

이 존재하면
해당 두 표현은 탭 가능.

탭:

브레이크아웃
→ 브레이크아웃 상세페이지

여기에서 다시 다른 용어를 탭할 수 있다.
