==================================================
5. BEFORE / AFTER 코드 비교
==================================================

수정 후 반드시 git diff를 확인한다.

허용되는 diff:

- JSX block 위치 이동

허용되지 않는 diff:

- handler 내용 변경
- router.push 문자열 변경
- 조건 변경
- state 변경
- import 변경
  (순서 이동 때문에 formatter가 import order만 바꾼 경우도 가능하면 되돌릴 것)
- style object 변경
- component props 변경
- text 변경

diff가 순수 reorder가 아니면 원인을 확인하고
불필요 변경을 되돌린다.

- 통합 사용량

X:

- 퀵액션이 X보다 먼저 표시
- X 섹션 정상 표시
- X 카드 4개 모두 기존 route 유지

모드 전환 후 stale UI가 없는지 확인.
