5. "카카오 로그인 제거 시 잠기는 계정" 찾기
============================================================

이번 감사의 핵심.

카카오 로그인 버튼을 2.0에서 제거할 경우
기존 사용자가 일반 로그인으로 들어갈 수 있는지 확인.

각 Kakao 연결 계정에 대해:

A.
일반 login identifier 존재?

B.
password credential 존재?

C.
phone 기반 일반 로그인 가능한가?

D.
password reset/recovery 가능한가?

이를 기준으로 다음 분류:

SAFE
= Kakao 없어도 일반 로그인 가능

RECOVERY_REQUIRED
= 계정은 있으나 password reset 등 한번의 복구 절차 필요

LOCKOUT_RISK
= Kakao 버튼 제거 시 일반 로그인 진입 방법이 현재 없음

반드시 parent / teacher / admin 각각 집계.
