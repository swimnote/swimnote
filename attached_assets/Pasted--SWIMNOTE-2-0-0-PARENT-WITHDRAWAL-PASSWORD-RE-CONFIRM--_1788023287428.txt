[SWIMNOTE 2.0.0 — PARENT WITHDRAWAL PASSWORD RE-CONFIRM]

목표:

학부모 회원탈퇴가 현재 즉시 실행되므로
실수 방지를 위해 최종 탈퇴 전에
비밀번호 재입력 단계를 추가한다.

1.6.3 수정 금지.
2.0.0 only.

==================================================
1. UX FLOW
==================================================

현재:

회원 탈퇴
→ 탈퇴 확인
→ 즉시 API 호출

변경:

회원 탈퇴
→ 1차 경고
→ [계속]
→ 비밀번호 재입력 화면/모달
→ [최종 탈퇴]
→ 서버 비밀번호 재검증
→ 일치 시 탈퇴 실행

==================================================
2. 비밀번호 검증은 SERVER에서
==================================================

클라이언트에서만 비교 금지.

현재 로그인 account의:

account_id
+
입력 password

를 서버에서 검증.

비밀번호 일치:
→ 탈퇴 진행

불일치:
→ 401/400
→ "비밀번호가 올바르지 않습니다."

==================================================
3. Pool-First 안전성
==================================================

현재 선택된 account만 탈퇴.

같은 전화번호의 다른 pool account 영향 0.

전화번호로 account 검색 후 삭제 금지.

삭제 대상은 현재 인증된 account_id 기준.

==================================================
4. 비밀번호 입력 UX
==================================================

- secureTextEntry
- 자동완성/키보드 적절히 설정
- 입력 전 최종탈퇴 버튼 disabled 가능
- 버튼 연타 방지
- loading 상태
- 오류 시 비밀번호 입력값 유지 또는 정책에 맞게 clear

7. FREE / PAID 공통
==================================================

무료 플랜:

즉 모든 회원탈퇴는
비밀번호 재확인 없이 실행 불가.
