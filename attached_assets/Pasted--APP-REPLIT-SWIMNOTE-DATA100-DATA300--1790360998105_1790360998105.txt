[SWIMNOTE — DATA100 / DATA300 실제 결제 연결 전 최종 구조 조사]

중요:

이번 단계에서는 조사만 합니다.

코드 수정 금지.
DB migration 금지.
RevenueCat 설정 변경 금지.

DATA100 / DATA300을 실제 판매 가능한
추가 저장공간 구독으로 활성화할 예정입니다.

두 상품은 App Store에서
기본 SWIMNOTE/X 구독과 별도 Subscription Group입니다.

따라서 기본 구독과 DATA add-on을
동시에 유지할 수 있다는 전제로 조사하되,
실제 현재 코드/RevenueCat 구조를 확인하십시오.

1. 만료 정책 — 고정
━━━━━━━━━━━━━━━━━━━━━━

[CANCELLATION]

사용자가 자동갱신을 취소해도
이미 결제한 이용기간 종료 전까지:

- 추가용량 유지
- 업로드 가능
- 기존 데이터 유지

삭제 금지.

[EXPIRATION]

실제 DATA 구독 기간이 끝나는 순간:

1. DATA 추가용량 제거
2. 현재 플랜의 기본 저장용량으로 즉시 복귀
3. 현재 사용량이 새 허용량을 초과하면
4. 오래된 사진/영상부터 즉시 삭제
5. 허용용량 이하가 되는 순간 삭제 중단

유예기간 없음.

예:

기본 10GB
+
DATA100 100GB
=
총 110GB

실제 사용 78GB

DATA100 EXPIRATION

→ 허용량 즉시 10GB
→ 오래된 미디어부터 삭제
→ 사용량 <= 10GB가 되면 중단

19. 즉시 삭제 WORKER 위치
━━━━━━━━━━━━━━━━━━━━━━

EXPIRATION webhook 요청 안에서
100GB 단위의 R2 삭제를 동기적으로 전부 실행하면
timeout 위험이 있을 수 있습니다.

현재 worker/job infrastructure를 확인하십시오.

목표:

EXPIRATION 발생

→ add-on 상태 만료 확정
→ 새 effective quota 계산
→ 초과 시 purge job 생성
→ worker가 오래된 media부터 삭제
→ quota 이하에서 종료

또는 현재 시스템에 더 단순하고 안전한
검증된 background 처리 방식이 있다면 재사용.

“즉시 삭제” 정책은
사용자 정책상 유예기간이 없다는 의미이며,

반드시 webhook HTTP request 안에서
수십/수백 GB를 동기 삭제하라는 뜻은 아닙니다.

실행은 즉시 queue/start되고
백그라운드에서 안전하게 완료되는 구조를 검토.

━━━━━━━━━━━━━━━━━━━━━━
20. PURGE 재시도 / IDEMPOTENCY
━━━━━━━━━━━━━━━━━━━━━━

대량 삭제 중:

- worker 재시작
- R2 delete 일부 실패
- DB delete 일부 실패
- webhook duplicate

가 발생해도 안전해야 합니다.

확인:

- 같은 media 두 번 삭제해도 안전한지
- 이미 삭제된 object 처리
- purge job 중복 생성 방지
- RevenueCat duplicate event idempotency와 연결 가능 여부

대규모 새 framework 제안 전에
기존 worker/job 구조 재사용 가능성부터 확인.

━━━━━━━━━━━━━━━━━━━━━━
21. 삭제 대상 SIZE 계산
━━━━━━━━━━━━━━━━━━━━━━

예:

현재 사용 78GB
허용량 10GB

라고 해서 정확히 68GB만 삭제한다고
단순 계산하기 어렵습니다.

파일 단위로 삭제하므로:

오래된 순으로 삭제
→ 누적 remaining usage <= effective limit

이 되는 순간 종료해야 합니다.

예:

10.2GB 남은 상태에서
마지막 500MB 파일 삭제

→ 9.7GB

처럼 허용.

파일을 부분 삭제하는 구조 금지.

━━━━━━━━━━━━━━━━━━━━━━
22. 사용자 안내 문구 위치 조사
━━━━━━━━━━━━━━━━━━━━━━

DATA 구매 CTA를 활성화할 때
반드시 다음 정책을 명확히 보여줘야 합니다.

핵심 의미:

“추가 데이터 구독이 종료되면
저장 한도가 즉시 기본 제공 용량으로 변경됩니다.

종료 시 허용 용량을 초과한 사진·영상은
오래된 자료부터 자동 삭제되며
삭제된 자료는 복구할 수 없습니다.”

현재:

- DATA100/300 카드
- 구매 confirmation
- 구독 상세
- 관리 화면

중 어디에 이 문구를 넣는 것이 적절한지 조사.

아직 문구 수정 금지.

━━━━━━━━━━━━━━━━━━━━━━
