SWIMNOTE Teacher Diary AI 설계도 V1.0을 최종 고정한다.

WP0 구조 검증은 완료되었다.

현재 모달, 버튼, 음성녹음, Whisper, Request/Response Contract, 공통 Draft, 학생별 Draft, Teacher Review, Insert, 기존 Save 연결 코드가 존재하는 것으로 확인됐다.

그러나 코드가 존재한다는 사실만으로 기능 완료로 판정하지 않는다.

이제부터 설계도 V1.0의 순서대로 기능을 하나씩 실제 검증하고, 미구현·오작동·설계 불일치가 발견될 경우에만 최소 범위로 수정한다.

최종 목표는 SWIMNOTE 앱이 담당하기로 한 Teacher Diary AI 기능이 실제 앱에서 처음부터 끝까지 정상 작동하도록 완성하는 것이다.

AI Engine은 별도 프로젝트이며 이번 작업에서 수정하지 않는다.

2. 앱에서 절대 하면 안 되는 작업
──────────────────────────────────

앱에서 다음 작업을 수행하지 않는다.

- 학생 이름의 성 제거
- 학생 이름의 조사 제거
- 학생 이름 유사도 분석
- Teacher Input에서 학생별 문장 분리
- Teacher Input의 수영 기술 의미 해석
- 수영 지식 생성
- 커리큘럼 범위 판단
- 템플릿 검색
- Knowledge 검색
- GPT Prompt 생성
- AI 결과 내용 생성
- AI 결과의 수영 기술 정확성 판단
- AI Engine 응답을 앱에서 임의 재작성

앱은 사용자가 선택한 수업 사실과 학생 정보를 전달하고, AI Engine 결과를 표시·수정·삽입·저장하는 역할만 한다.

──────────────────────────────────
3. 작업 진행 원칙
──────────────────────────────────

각 기능은 아래 순서로 진행한다.

1. 설계도 요구사항 확인
2. 현재 코드 확인
3. 실제 동작 검증
4. 설계와 코드와 실제 동작 비교
5. 이상이 없으면 수정 없이 통과
6. 미구현·오작동·설계 불일치가 있으면 최소 범위 수정
7. 수정 후 다시 실제 동작 검증
8. 회귀 테스트
9. Git 상태와 증거 보고
10. 사용자 승인 후 다음 단계 진행

이미 구현된 코드를 다시 작성하지 않는다.

기존 구현이 정상이라면 수정하지 않는다.

관련 없는 리팩터링을 하지 않는다.

설계도에 없는 기능을 추가하지 않는다.

사용자 승인 없이 다음 단계로 넘어가지 않는다.

──────────────────────────────────
4. Git 및 작업 안전 원칙
──────────────────────────────────

Production에서 직접 작업하지 않는다.

현재 개발 브랜치에서만 작업한다.

작업 시작 전 반드시 아래를 출력한다.

- git status
- git rev-parse HEAD
- git branch --show-current
- git branch -vv

작업 완료 후 반드시 아래를 출력한다.

- git status
- git diff
- 변경 파일 목록
- 테스트 결과
- git rev-parse HEAD
- git show --stat --oneline HEAD
- git branch -vv

작업 결과는 반드시 commit하고 push한 뒤 보고한다.

Commit과 push가 완료되지 않은 작업은 완료로 인정하지 않는다.

사용자 승인 없이 staging 또는 production에 반영하지 않는다.

──────────────────────────────────
5. WP1 — Teacher Diary AI 모달 기본 동작
──────────────────────────────────

이번에는 WP1만 수행한다.

다음 단계로 넘어가지 않는다.

목표

Teacher Diary 화면에서 AI 버튼을 눌렀을 때 모달이 설계대로 정상 열리고 닫히는지 실제로 검증한다.

검증 항목

- Teacher Diary 작성 화면이 정상 진입되는가
- DiaryAIButton이 정상 표시되는가
- 버튼을 한 번 눌렀을 때 BaseAIModal이 한 번만 열리는가
- 모달 안에 DiaryAIContent가 정상 표시되는가
- 모달이 전체 화면을 깨뜨리지 않는가
- 모달 닫기 버튼이 정상 작동하는가
- Android 뒤로가기 또는 현재 지원하는 닫기 동작이 정상 작동하는가
- 모달을 닫은 뒤 다시 열 수 있는가
- 여러 번 열고 닫아도 상태 충돌이 없는가
- 모달을 닫아도 기존 일지 작성 내용이 사라지지 않는가
- AI 모달을 열고 닫는 것만으로 기존 일지 데이터가 변경되지 않는가
- 중복 탭으로 모달이 중복 생성되지 않는가
- 오류 또는 경고가 콘솔에 발생하지 않는가
- 개인정보가 로그에 출력되지 않는가

코드 검증 대상

- components/ai/features/diary/DiaryAIButton.tsx
- components/ai/features/diary/DiaryAIContent.tsx
- BaseAIModal 관련 파일
- components/teacher/diary/DiaryWriteView.tsx
- app/(teacher)/diary.tsx

수정 원칙

모달 기본 동작에 문제가 없다면 코드 수정 없이 통과한다.

문제가 있으면 해당 문제를 해결하는 최소 파일만 수정한다.

UI 디자인을 재설계하지 않는다.

모달의 색상, 구조, 문구를 임의로 변경하지 않는다.

AI 요청, Whisper, Draft, Insert, Save 기능은 이번 WP에서 수정하지 않는다.

WP1 완료 조건

- AI 버튼 정상 표시
- 모달 정상 열림
- 모달 정상 닫힘
- 재진입 정상
- 중복 모달 없음
- 기존 일지 내용 보존
