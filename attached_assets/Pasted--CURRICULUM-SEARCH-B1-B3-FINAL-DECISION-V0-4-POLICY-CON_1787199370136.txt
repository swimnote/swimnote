B1. X CURRICULUM 300-ITEM RULE — 확정
==================================================

x_curriculum_levels의 row count 또는
level count × 임의 가중치로 300개를 계산하지 않는다.

AI 커리큘럼 검색 활성 조건:

1. 해당 센터가 AI 커리큘럼 검색 사용 가능 상태
2. 실제 검색 가능한 curriculum item >= 300

둘 다 만족해야 한다.

Normal SWIMNOTE:
→ AI 검색 항상 차단
→ 버튼 탭 시 커리큘럼 등록 필요 안내
→ GPT/AI 호출 0

X/허용 센터:
→ 실제 searchable curriculum >= 300인 경우만 검색 허용

중요:

"300개"의 단위는
실제 검색 엔진이 독립적으로 검색할 수 있는
최소 curriculum item 단위다.

x_curriculum_levels는 level 단위이므로
row count를 그대로 사용하지 않는다.

확인할 것:

- X curriculum이 실제 검색 시 어떤 최소 단위로 분해되는지
- skills
- detailed_skills
- learning_contents
- 기타 실제 검색 단위

이들을 어떤 방식으로 canonical searchable item으로
정규화할 수 있는지 READ-ONLY 확인.

이미 AI Engine/별도 DB에
X 커리큘럼이 item 단위로 저장되어 있다면
그 source를 우선 사용한다.

임의 추정 count 금지.
