1. 확인된 실제 버그
============================================================

Production DB user_role enum:

super_admin
pool_admin
parent
teacher

확인된 문제 쿼리:

role IN ('teacher', 'pool_admin', 'sub_admin')

실제 테스트 결과:

invalid input value for enum user_role: "sub_admin"

따라서 해당 Kakao auth 쿼리는
실행 시 500 오류를 만들 수 있다.

이번 작업에서는 이 버그만 최소 수정한다.

============================================================
2. Kakao auth 내 sub_admin 전수 검색
============================================================

다음 영역에서:

sub_admin

검색.

특히:

POST /auth/kakao-social-login

- Step 3 kakao_id lookup
- Step 4 phone lookup

POST /auth/kakao-link-teacher

확인.

Kakao auth query 안에서
존재하지 않는 'sub_admin'을 사용하는 위치를
전부 찾아라.
