[WP-SA0-A — SUPER ADMIN SHELL / URL ROUTING / EXISTING FUNCTION REORGANIZATION]

목적:

기존 SuperAdmin의 8개 탭 구조를
운영용 사이드바 + URL 기반 라우팅 구조로 전환한다.

이번 단계의 핵심은:

"기존 기능을 잃지 않고 새 정보구조 안으로 안전하게 재배치"

이다.

신규 운영 기능을 대량 구현하는 단계가 아니다.
