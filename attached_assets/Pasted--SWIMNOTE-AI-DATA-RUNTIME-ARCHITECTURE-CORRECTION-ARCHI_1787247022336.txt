==================================================

Production retrieval:

ACTIVE only.

ACTIVE + DIRECT_DB
→ DB_DIRECT 가능

→ GROUNDED_AI 가능

→ HUMAN_REQUIRED

6. AI GATEWAY
==================================================

AiGateway는 공통 transport/execution layer.

공통화:

- OpenAI client
- timeout
- transient retry
- structured output
- token accounting
- request_id
- error classification
- saveAiTrace

domain prompt / evidence policy는 Gateway 밖에 유지.

Retry는:

- timeout
- 429
- retryable 5xx

등 transient failure에만 적용.

validation failure나 business error를
무조건 재호출하지 않는다.

retry_count 의미도:
"추가 재시도 횟수"
인지
"총 attempt"
인지 명확히 정의.
