[WP-CS-03R — SUPER ADMIN SUPPORT INBOX / HUMAN MESSAGE E2E]

목적:

현재 앱의 공통 AI 문의 UI에서 생성되는

support_case
support_ticket
support_ticket_replies

를 Super Admin에서 실제 운영자가
한 화면에서 확인하고 답변할 수 있도록 한다.

이번 WP가 끝나면:

사용자 앱 문의
→ Super Admin 확인
→ 상담사 메시지 답변
→ 사용자 앱에서 답변 확인

Human Support E2E가 완성된다.

아직 Support AI 자동답변은 구현하지 않는다.

9. 상담사 요청
==================================================

Inbox 상단 우선순위에서 쉽게 확인.

AGENT_REQUESTED 상태가 눈에 띄어야 한다.

==================================================

→ RESOLVED

==================================================
11. 전화 필요
==================================================

[전화 필요]

는 별도 명시 action.

무조건 모든 escalation을 전화로 만들지 않는다.

PHONE_REQUIRED는 기존 master rule 준수.

reason 필수 가능하면:

billing
refund
privacy/safety
complex case
other

12. 재오픈
==================================================

Inbox에 다시 나타남.

기존 history 유지.
