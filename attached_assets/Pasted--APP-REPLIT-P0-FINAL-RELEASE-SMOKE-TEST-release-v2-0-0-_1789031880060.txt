15. RELEASE BLOCKER 판정
━━━━━━━━━━━━━━━━━━━━━━

P0로 처리할 것:

- 가입 불가
- 로그인 불가
- 정책 gate 우회/무한루프
- 실제 결제 불가
- 표시가격 ≠ Store 가격
- 무료체험 실패/무한로딩
- X 적용 실패
- 데이터 손실
- PAYMENT_SUSPENDED 우회
- 서버 5xx 반복
- 핵심 운영 기능 사용 불가

P0가 아닌 것:

- 사소한 간격
- 문구 취향
- 아이콘 위치
- 미세 UI polish
- 출시 후 개선 가능한 UX

P0 아닌 것은 수정하지 말고 기록도 최소화.

1. branch
2. HEAD
3. origin exact / clean
4. CASE A~L PASS/FAIL
5. 기본 운영 smoke 결과
6. 발견된 P0 목록

8. 최종 main HEAD
9. Render LIVE SHA
10. iOS OTA
11. Android OTA
12. 최종 Android native build 필요 여부
13. blocker
14. 최종 PASS/HOLD/FAIL

PASS 조건:

- CASE A~L 전부 PASS
- 핵심 운영 smoke PASS
- P0 blocker 0
- 데이터 손실 0
- 결제/무료체험/정책 정상

PASS이면:
추가 기능 개발/리팩터링 금지.
출시용 최종 native build 지시를 기다리고 STOP.
