[P0 — X MODE PERSISTENCE / NORMAL FALLBACK ROOT-CAUSE FIX]

목적:

유료 X모드 수영장이 사용 중 또는 앱 재실행 과정에서
의도치 않게 Normal SWIMNOTE로 풀리는 문제를 근본 해결한다.

이 문제는 UI 문제가 아니라
"entitlement trust / mode persistence" P0 문제다.

중요:

이번 작업은 먼저 전체 trace로 원인을 확정한 뒤
최소 범위만 수정한다.

추측성 수정 금지.
fallback을 무조건 X로 바꾸는 식의 임시방편 금지.
서버 truth와 entitlement policy를 유지한다.

==================================================
6. CORE TRUST RULE
==================================================

이 원칙으로 수정한다.

A. SERVER CONFIRMED NORMAL
→ normal 전환 가능

B. SERVER CONFIRMED X
→ x 유지

C. SERVER CONFIRMED X_PENDING
→ x_pending

D. TRANSIENT FAILURE
(network / timeout / temporary 5xx / fetch error)
→ 마지막 server-confirmed mode 유지
→ retry

즉:

UNKNOWN != NORMAL

이다.

일시적인 조회 실패를
Normal entitlement 판정으로 취급하지 않는다.

==================================================

lastConfirmedMode
lastConfirmedPoolId
lastConfirmedAt

정도.

단:

client cache는 서버 entitlement를 새로 만들어내는 source가 아니다.

용도는 오직:

"서버 재확인 전 transient failure 동안
마지막으로 서버가 확인한 UI 상태를 보존"

이다.

다른 pool의 cached X가
새 pool에 적용되지 않게 poolId key 필수.
