[P0 — 수업 스케줄러 월간 화면 레이아웃 붕괴 수정]

첨부된 실제 iPhone 스크린샷 기준으로 수정한다.

이번 작업 목표는
"월간 스케줄러를 깔끔하게 읽을 수 있게 만드는 것".

기능 로직은 건드리지 말고
레이아웃/표현만 수정.

현재 문제:

1. 날짜 숫자와 시간 텍스트가 서로 겹침
2. 취소선 일정이 날짜 영역을 침범함
3. 한 날짜에 일정이 많을 때 줄 간격이 무너짐
4. 휴무일 배경 박스가 날짜 셀 위로 올라와 날짜/일정을 가림
5. +9, +10 같은 추가 일정 개수가 날짜 숫자 근처에 겹침
6. 셀별 세로 높이가 제각각이라 전체 달력이 지저분함
7. 과거 일정/취소 일정/현재 일정 표현이 한 셀에서 뒤섞임
8. 작은 iPhone 화면에서 특히 레이아웃이 붕괴함

━━━━━━━━━━━━━━━━━━━━━━
1. 월간 셀 구조 고정
━━━━━━━━━━━━━━━━━━━━━━

각 날짜 셀 내부 구조를 반드시 아래 순서로 고정:

[날짜 숫자]
[대표 일정 1]
[대표 일정 2]
[추가 건수 +N]

날짜 숫자는 항상 셀 맨 위.

일정 텍스트가 날짜 숫자 영역을 침범하지 못하게
dateHeader 영역과 scheduleContent 영역을 분리.

예:

8
16시
18시
+7

날짜 숫자와 시간 텍스트 overlap 0건.

━━━━━━━━━━━━━━━━━━━━━━
2. 일정 표시 개수 제한
━━━━━━━━━━━━━━━━━━━━━━

한 날짜에 일정이 많아도
월간 화면에서 전부 렌더하지 말 것.

최대 2개까지만 대표 일정 표시.

그 이상은:

+7
+10

처럼 한 줄로 표시.

현재처럼
16시
16시
16시
16시
...
전부 렌더해서 셀 붕괴시키지 말 것.

━━━━━━━━━━━━━━━━━━━━━━
3. 셀 높이 통일
━━━━━━━━━━━━━━━━━━━━━━

한 주(row)의 날짜 셀 높이는 모두 동일하게 유지.

일정이 많은 날 때문에
해당 셀만 길어지지 않게.

월간 달력은 grid 형태 유지.

필요하면:

minHeight / fixedHeight
overflow hidden

적용.

단 실제 정보는 +N으로 요약.

━━━━━━━━━━━━━━━━━━━━━━
4. 휴무일 표현 수정
━━━━━━━━━━━━━━━━━━━━━━

현재 휴무일 background가
여러 날짜 셀 위를 덮으면서 날짜를 가림.

이 방식 금지.

휴무일은 각 날짜 셀 단위로 표시.

예:

22
휴무일

23
휴무일

24
휴무일

25
휴무일

26
휴무일

또는 연속 휴무 시
row 배경을 사용하더라도
dateHeader보다 뒤에 깔리게 zIndex 조정.

절대 날짜 숫자/일정 영역을 덮지 말 것.

휴무일 배경:
cell 내부 background 처리.

날짜 숫자는 항상 최상단 visibility 유지.

━━━━━━━━━━━━━━━━━━━━━━
5. 취소 일정
━━━━━━━━━━━━━━━━━━━━━━

취소된 일정은
대표 일정 slot 안에서만 표현.

예:
16시 취소선

취소선이 셀 전체를 가로질러
다른 날짜나 날짜 숫자를 침범하지 말 것.

현재처럼 긴 horizontal line처럼 보이면 안 됨.

Text decoration:
해당 시간 텍스트 자체에만 적용.

━━━━━━━━━━━━━━━━━━━━━━
6. 추가 건수 위치 고정
━━━━━━━━━━━━━━━━━━━━━━

+N은 항상 셀 맨 아래.

날짜 숫자 옆이나
다음 날짜 숫자와 겹치지 않게.

예:

15시
16시
+10

+N 전용 lineHeight 확보.

━━━━━━━━━━━━━━━━━━━━━━
7. 폰트/간격
━━━━━━━━━━━━━━━━━━━━━━

작은 iPhone 기준으로도 읽혀야 함.

날짜:
기존보다 너무 작아지지 말 것.

시간:
최소 legible font 유지.

각 line 사이:
충분한 lineHeight.

예시 방향:

date lineHeight >= 18
schedule lineHeight >= 16
+N lineHeight >= 16

실제 값은 현재 디자인 시스템에 맞게 조정.

text scaling 때문에 겹치지 않도록
numberOfLines / flexShrink / minHeight 확인.

━━━━━━━━━━━━━━━━━━━━━━
8. 월요일~일요일 grid 정렬
━━━━━━━━━━━━━━━━━━━━━━

7열 grid 기준
모든 날짜 셀 width 동일.

margin/padding 때문에
열이 좌우로 밀리지 않게.

특히:
일요일/토요일 색상 유지.

오늘 선택 표시도
날짜 숫자 영역 안에서만.

선택 원형 badge가 일정 영역까지 침범하지 않게.

━━━━━━━━━━━━━━━━━━━━━━
9. 현재 날짜 선택
━━━━━━━━━━━━━━━━━━━━━━

현재 8일 선택 원형 배경은 유지 가능.

단:

- 원형 안 날짜 숫자 centered
- 아래 일정은 원형 아래부터 시작
- 원형과 일정 겹침 금지

━━━━━━━━━━━━━━━━━━━━━━
10. 렌더링 우선순위
━━━━━━━━━━━━━━━━━━━━━━

월간 화면에서는 정보 우선순위를:

1. 날짜
2. 휴무 여부
3. 대표 시간 1~2개
4. 추가 일정 +N

으로 한다.

세부 수업 목록은
날짜 선택 후 상세 화면에서 확인.

월간 화면에 모든 수업을 다 보여주려고 하지 말 것.

━━━━━━━━━━━━━━━━━━━━━━
11. 스크롤/클리핑
━━━━━━━━━━━━━━━━━━━━━━

월간 calendar 전체에서
각 셀의 schedule content는
해당 셀 boundary 밖으로 나가지 못하게.

overflow hidden 또는 equivalent 적용.

다른 날짜 셀 침범 금지.

단 날짜 선택 touch 영역은 정상 유지.

━━━━━━━━━━━━━━━━━━━━━━
