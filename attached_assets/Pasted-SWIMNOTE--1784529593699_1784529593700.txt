SWIMNOTE 날짜 시스템 통합 작업 범위 확인

이번 답변은 코드 수정이나 구현 계획을 작성하는 단계가 아닙니다.

먼저 이번 작업에서 수정할 범위와 수정하지 않을 범위를 서로 동일하게 이해하기 위한 확인 단계입니다.

현재 앱은 날짜 기준이 기능마다 다르게 적용되어 다음과 같은 문제가 발생하고 있습니다.

- 회원 등록일 이전 스케줄에도 회원이 표시됨
- 관리자 / 선생님 / 학부모 화면마다 날짜 기준이 다름
- 출결 대상 회원과 실제 스케줄 회원이 다름
- 날짜가 다른 일지의 상태가 서로 영향을 줌
- 이전 수업 사진이나 데이터가 다음 수업으로 따라오는 경우가 있음
- 반 이동, 미배정, 퇴원 등의 날짜 적용 기준이 화면마다 다름

이번 작업의 목적은 위 문제를 개별적으로 수정하는 것이 아니라,

SWIMNOTE 전체가 하나의 날짜 기준을 사용하도록 통일하는 것입니다.

==================================================

이번 작업 범위

1.
회원의 반 참여 날짜 기준 통일

회원은 등록한 날이 아니라
실제 첫 수업일부터 반에 참여한 것으로 처리합니다.

예)

7/18 등록
7/20 첫 수업

→ 스케줄, 출결, 일지는 모두 7/20부터 적용

등록일과 첫 수업일은 서로 다른 개념으로 유지합니다.

==================================================

2.
회원 상태 적용 날짜 통일

다음 상태는 모두 적용 시작일을 기준으로 처리합니다.

- 반 등록
- 반 이동
- 미배정
- 퇴원
- 연기
- 복귀

예)

8/1부터 미배정

→ 7월 마지막 수업까지는 기존 반 표시

→ 8/1부터 기존 반 미표시

과거 기록은 변경하지 않습니다.

==================================================

3.
일간 / 주간 / 월간 스케줄 날짜 기준 통일

세 화면은 서로 다른 날짜 계산을 하지 않습니다.

모두 동일한 날짜 기준과 동일한 회원 조회 로직을 사용합니다.

==================================================

4.
출결 대상 회원 통일

출결 대상 회원은

해당 수업 날짜에 실제 반에 등록되어 있는 회원만 포함합니다.

==================================================

5.
일지 대상 회원 통일

일지도 동일한 날짜 기준을 사용합니다.

7/20 수업이면

7/20 당시 반에 등록되어 있던 회원만 일지 대상입니다.

==================================================

6.
수업 날짜별 일지 독립

같은 반이라도

7/20 수업

7/27 수업

은 서로 완전히 다른 수업입니다.

다음 항목은 날짜별로 독립되어야 합니다.

- 일지
- 완료 상태
- 출결
- 개인 메모
- 사진
- 영상
- 학부모 전송

다른 날짜 데이터가 자동으로 따라오면 안 됩니다.

==================================================

7.
사진 및 첨부파일 날짜 기준 통일

사진과 영상은

해당 날짜 수업의 일지에만 연결됩니다.

이전 수업 사진이 다음 수업에 자동으로 표시되면 안 됩니다.

==================================================

8.
관리자 / 선생님 / 학부모 날짜 기준 통일

세 모드 모두

같은 날짜

같은 반

같은 수업

을 조회하면

동일한 결과를 보여야 합니다.

권한 차이만 존재하고

날짜 기준은 동일해야 합니다.

==================================================

9.
보강 규칙 유지

보강은 현재 구조를 유지합니다.

보강 회원은

해당 보강 수업 날짜에만 표시합니다.

정규 반 이력은 변경하지 않습니다.

==================================================

10.
연기 규칙

연기 기간에는

정규 스케줄

출결

일지 대상

모두 제외합니다.

연기가 끝난 복귀일부터 다시 정상 표시합니다.

과거 기록은 유지합니다.

==================================================

11.
반 이동 규칙

예)

A반 마지막 수업

7/27

B반 첫 수업

8/3

→ 7/27까지 A반

→ 8/3부터 B반

→ 중간 공백 기간은 어느 반에도 표시하지 않습니다.

==================================================

이번 작업에서 변경하지 않는 기능

- 디자인
- 로그인
- 회원가입
- 결제
- 구독
- 교재
- 레벨
- 알림
- 저장공간 정책
- 기타 날짜 시스템과 관계없는 기능

==================================================

위 내용을 기준으로

1.
현재 프로젝트에서 어떤 파일을 수정해야 하는지

2.
현재 구조에서 부족한 부분은 무엇인지

3.
위 범위를 모두 충족하기 위해 필요한 수정 사항은 무엇인지

4.
추가로 반드시 확인해야 할 위험 요소가 있는지

정리해서 먼저 보고해 주세요.
