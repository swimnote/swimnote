============================================================
0. 가장 중요한 제품 방향 변경
============================================================

기존 계획:

X모드 사용 수영장마다
SWIMNOTE가 개별 홈페이지를 제작

→ 완전히 폐기.

더 이상 X모드 서비스에
수영장별 홈페이지 제작을 포함하지 않는다.

대신:

X모드 사용자에게
PC용 SWIMNOTE 관리자 대시보드를 제공한다.

기존 PC Dashboard 기능은 이미 구현되어 있으므로
이를 재사용/업데이트한다.

SWIMNOTE Office 개발 전까지
기존 PC Dashboard가 X모드의 PC 관리자 기능 역할을 한다.

============================================================
1. 새 PC 이용 구조
============================================================

기존 구조:

수영장별 내부 도메인 생성
→ 각 수영장 도메인 접속
→ 로그인
→ PC Dashboard

이 구조는 폐기 예정.

새 구조:

SWIMNOTE 공식 홈페이지
→ "PC모드 로그인" 탭/버튼
→ 관리자 계정 로그인
→ X모드 PIN 인증
→ 해당 관리자 swimming_pool_id context 확정
→ PC Dashboard 바로 진입

즉:

SWIMNOTE WEBSITE
        ↓
PC모드 로그인
        ↓
관리자 계정 로그인
        ↓
X모드 PIN
        ↓
POOL / ADMIN CONTEXT
        ↓
PC DASHBOARD

수영장별 별도 도메인을 사용자가 찾아 들어가는 구조가 아니라
SWIMNOTE 홈페이지 하나에서 접속하는 구조로 변경.

============================================================
2. 로그인 후 바로가기 구조
============================================================

PC모드 사용성을 매우 간단하게 만든다.

최초:

SWIMNOTE 홈페이지
→ PC모드 로그인
→ 관리자 로그인
→ PIN
→ Dashboard

이후에는 가능한 범위에서
인증 세션이 유효하면
PC모드 바로가기 URL을 통해
곧바로 Dashboard에 접근할 수 있는 구조를 설계.

중요:

PIN 자체를 URL에 넣는 방식 금지.

password/PIN/token을 query string에 노출 금지.

안전한 session / cookie / JWT 구조를 사용.

자동로그인 또는 세션 유지가 가능하다면
기존 인증 구조를 재사용.

로그아웃 / 세션 만료 시
다시 로그인 화면으로 이동.

새 entitlement 체계를 임의로 만들지 말 것.
