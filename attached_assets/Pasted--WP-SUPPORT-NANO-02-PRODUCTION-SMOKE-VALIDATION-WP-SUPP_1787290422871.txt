# 1. 조사 금지

전체 repo 조사 금지.

다음 실제 경로만 검증:

`Support request → retrieval → candidate → nanoResolve → validator → response → usage trace`

---

# 2. Smoke Case A — Grounded Match

실제 Support DB에 근거가 존재하는 안전한 테스트 질문 1건 사용.

확인:

* HTTP 정상 응답
* candidate KI 존재
* LLM call 정확히 1회
* selected_knowledge_ids 존재
* selected IDs가 candidate 안에 존재
* insufficient_knowledge=false
* 답변이 선택된 KI 근거 범위 안에 있음

---

# 3. Smoke Case B — No Evidence

Support DB에 명확한 근거가 없는 테스트 질문 1건.

확인:

* evidence/candidate 0
* nanoResolve 호출 0회
* `NO_EVIDENCE`
* `ai_no_match`
* generic GPT answer 생성 없음

---

# 4. Follow-up Case

문맥이 필요한 2턴 질문 1세트.

예시는 실제 Support DB에 존재하는 안전한 주제를 선택.

확인:

* 최근 context 전달
* 두 번째 질문이 첫 질문 문맥과 연결됨
* AI call은 두 번째 logical request에서도 1회 이하

---

# 5. Usage Trace

실제 `event_logs` read-back으로 최소 확인:

* feature = SUPPORT_AI
* trigger_type = USER_ACTION
* provider
* service
* model
* request_id
* latency_ms
* logical_request_count
* actual_call_count
* retry_count
* estimated_cost_usd / cost_source

실제 저장값을 보고한다.

추측 금지.

# 6. 모델 확인

운영 trace에서 실제 사용 모델을 보고한다.

현재 예상:

`AI_MODEL.SUPPORT = gpt-4o-mini`

그러나 코드 추정으로 보고하지 말고 실제 trace/model 값을 확인한다.
