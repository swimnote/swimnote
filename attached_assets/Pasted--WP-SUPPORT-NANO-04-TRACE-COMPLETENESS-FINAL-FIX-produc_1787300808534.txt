3. Deterministic / no-evidence

OpenAI 호출이 없는 경로는 provider=null/service=internal 유지.

가능하면 의미를 명확히 하기 위해:

logical_request_count = 0
actual_call_count = 0
retry_count = 0

을 명시적으로 저장한다.

단 기존 contract상 logical_request_count가
'provider logical request'만 의미하도록 설계돼 있다면
그 의미를 깨지 말고 현재 0 처리 방식을 유지한다.
