==================================================
0. GLOBAL COMMON-FIX RULE
==================================================

본 작업은 특별히 X 전용으로 지정된 부분 외에는
Normal SWIMNOTE와 SWIMNOTE X 공통 구조를 우선한다.

먼저 동일 source/component/route를 공유하는지 확인한다.

공통 구조라면 source of truth 한 곳만 수정하고
Normal/X 양쪽을 검증한다.

분기 구현이면 양쪽에서 동일 문제가 존재하는지 확인하고
필요한 범위만 각각 수정한다.

불필요한 중복 구현 금지.

==================================================
4. X MODE DESCRIPTION
==================================================

"X모드 설명"에서는 다음을 명확하게 설명한다.

일반 SWIMNOTE는:

- 회원 관리
- 학생/반 관리
- 수업
- 출결
- 일정
- 일지
- 사진/앨범
- 공지
- 알림
- 메시지
- 기타 운영 기능

등을 제공하며,

일반 SWIMNOTE만으로도
수영장 운영에 필요한 기본 기능을 충분히 사용할 수 있다.

SWIMNOTE X는
일반 SWIMNOTE 위에 추가되는 별도 서비스다.

추가 요소:

- SWIMNOTE AI ENGINE 사용
- 수영장별 커리큘럼 제작 및 연결
- AI 기반 일지 작성 지원
- 학부모 AI 기능
- 성장/리포트 관련 X 기능
- 기타 실제 구현된 X 전용 기능

==================================================
5. WHY X IS SEPARATE
==================================================

중요한 설명.

X모드를 단순히
"돈을 더 내야 쓰는 기능"
처럼 설명하지 않는다.

핵심:

일반 SWIMNOTE 플랜은
앱 이용과 데이터 운영을 위한 서비스다.

X모드는 추가로:

- SWIMNOTE AI ENGINE을 사용하고
- AI 처리 비용이 지속적으로 발생하며
- 수영장별 커리큘럼을 별도로 제작/연결해야 하고
- 해당 커리큘럼을 기반으로 AI 기능을 제공하기 때문에

별도의 가맹/정기결제가 필요한 서비스다.

사용자용 설명 예:

"일반 SWIMNOTE는 앱 운영과 데이터 관리만으로 충분히 사용할 수 있습니다.

SWIMNOTE X는 여기에 SWIMNOTE AI ENGINE과
수영장별 커리큘럼 제작·연결이 추가되는 별도 서비스입니다.

AI 처리 비용과 수영장별 교육과정 구축이 필요한 서비스이기 때문에
별도 정기결제로 제공됩니다."

내부 기술 용어는 최소화한다.

7. FREE PARENT REPORT DESCRIPTION
==================================================

메뉴:

무료 학부모 리포트 지원

현재 확정된 X 정책 범위 안에서 설명한다.

핵심 방향:

- 학부모에게 아이의 수업/성장 흐름을 보여주는 기능
- X 운영처에서 제공되는 추가 서비스
- 실제 확정된 무료 지원 조건만 표시
- 구현되지 않은 혜택 임의 추가 금지

현재 제품 정책에 있는
재등록 회원 무료 리포트 조건이 실제 UI에 들어갈 수 있는 상태라면
그 범위 내에서만 설명.

불확실하면 문구를 일반 설명 수준으로 제한.

학부모에게 수업 과정을 꾸준히 보여줄 수 있음

과장 표현 금지.
