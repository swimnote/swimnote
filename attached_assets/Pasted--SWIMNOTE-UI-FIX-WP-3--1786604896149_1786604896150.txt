3. 사진 크게보기 swipe crash 수정
━━━━━━━━━━━━━━━━━━━━

파일:

DiaryPhotoStrip.tsx

조사에서 확인된 viewer layout 충돌을
최소 수정합니다.

현재:

viewerPage: {
  width: SCREEN_W,
  flex: 1,
  ...
}

horizontal paging ScrollView 자식의
flex: 1 제거.

페이지는 명시적인 paging width를 유지해야 합니다.

예상 구조:

viewerPage: {
  width: SCREEN_W,
  height: "100%",
  alignItems: "center",
  justifyContent: "center",
}

ScrollView의

contentContainerStyle={{ alignItems: "center" }}

도 horizontal paging 계산에 불필요하면 제거하십시오.

필요한 경우 height만 유지하십시오.

중요:

추측으로 다른 viewer 구조를 새로 만들지 마십시오.

현재:

- Modal
- horizontal swipe
- pagingEnabled
- 사진 저장
- 닫기
- 현재 사진 표시
- 기존 image source

기능을 유지하면서
레이아웃 충돌만 최소 수정합니다.
