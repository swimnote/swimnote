9. 사용자 실기기 최종 체크리스트
==================================================

사용자가 실제 iPhone에서 확인:

[ ] OTA "앱 재실행하기" 모달 정상 표시

[ ] 설정 → SWIMNOTE X모드 → 뒤로가기
    → 설정으로 복귀

[ ] 홈으로 강제 이동하지 않음

[ ] 설정 → 알림 설정 → 뒤로가기
    → 직전 화면 복귀

[ ] X모드 → 구독 및 요금제 → 뒤로가기
    → X모드 복귀

[ ] 설정 → 구독 및 요금제 → 뒤로가기
    → 설정 복귀

[ ] X모드 → 상세 기능 → 뒤로가기
    → X모드 복귀

[ ] 커리큘럼 검색 진입
    → 키보드 자동 표시 안 됨

[ ] 검색창 tap
    → 키보드 표시

[ ] 검색 실행
    → 키보드 내려감

[ ] 검색결과가 많아도 마지막 항목까지 scroll 가능

[ ] 결과 scroll 시작
    → 키보드 자연스럽게 내려감

[ ] 결과 항목 한 번 tap으로 선택 가능

[ ] 결과 하단이 keyboard / Safe Area에 가려지지 않음

[ ] 뒤로가기
    → keyboard dismiss
    → 직전 화면 복귀

[ ] navigation loop 없음

[ ] blank/crash 없음
