# SWIMNOTE 보호자 가입 UX 최종 수정 (미연결 제거 정책)

## 목적

보호자 가입 이후 운영자가 "누구를 연결해야 하는지 모르는 상태"가 발생하면 안 됩니다.

앞으로는 가입한 순간부터 운영자가 반드시 어떤 학생인지 확인할 수 있어야 합니다.

이번 작업은 미연결 보호자 UX를 최종 마무리하는 작업입니다.

──────────────────────────────
1. 현재 미연결 보호자 처리
──────────────────────────────

현재

서정주
문희택

보호자가 미연결 상태입니다.

가입 시 입력한 자녀 이름을 기준으로

기존 학생과 연결 가능한지 확인하고

기존 학생이라면

신규 Student 생성 없이

기존 Student에 보호자만 연결하십시오.

필요하면 기존 승인 보호자의 추가 보호자 번호에도 등록하여
동일 학생을 공유하도록 처리합니다.

처리 후

미연결 상태가 해제되는지 확인하십시오.

──────────────────────────────
2. 앞으로는 미연결이 발생하지 않도록 개선
──────────────────────────────

이번 작업 이후부터는

단순히

"자녀 미연결"

만 표시되는 상태가 존재하면 안 됩니다.

최소한 아래 정보는 항상 보여야 합니다.

- 가입자 이름
- 가입 전화번호
- 가입 시 입력한 자녀 이름
- 가입일
- 현재 상태

예)

자녀 미연결

가입 시 입력한 자녀

문희택

정보가 없으면

"정보 없음"

이라고 표시하십시오.

섹션 자체를 숨기지 마십시오.

──────────────────────────────
3. 자녀 이름 표시 우선순위
──────────────────────────────

가입 시 입력한 자녀 이름은

아래 순서대로 조회합니다.

1.
parent_v2_pending.child_name_raw

2.
student_registration_requests.child_names

3.
reg_request.child_names

첫 번째 값이 있으면 그것을 사용합니다.

없으면 다음 순서로 조회합니다.

세 곳 모두 없을 경우에만

"정보 없음"

표시

절대로 빈 화면을 보여주지 마십시오.

──────────────────────────────
4. 미연결 보호자 목록
──────────────────────────────

목록에서도

이름만 보이지 말고

예)

서정주

가입 자녀
문희택

처럼

학생 이름이 같이 보여야 합니다.

운영자가

누구를 연결해야 하는지

한눈에 알아야 합니다.

──────────────────────────────
5. 기존 학생 자동 추천
──────────────────────────────

가입 시 입력한 자녀 이름이 있으면

관리자 화면에서

기존 학생과 연결

버튼을 눌렀을 때

자동으로

해당 이름으로 검색된 결과가

바로 표시되어야 합니다.

운영자가 검색어를 다시 입력하지 않도록 합니다.

──────────────────────────────
6. 완료 조건
──────────────────────────────

현재 미연결 상태인

서정주

문희택

계정을 실제로 기존 학생에 연결한 뒤

다음을 확인하십시오.

- 기존 Student 사용
- 신규 Student 생성 없음
- 보호자 앱에서 학생 정상 표시
- 관리자 목록에서 미연결 해제

그리고

이번 시각 이후 새로 가입하는 보호자는

"자녀 미연결"

만 표시되는 경우가 발생하지 않는지

실제 가입 테스트를 통해 확인하십시오.

완료 보고에는

1. 서정주 계정 처리 결과
2. 문희택 연결 결과
3. 어떤 Student와 연결했는지
4. 신규 Student 생성 여부
5. 자녀 이름 표시 화면 스크린샷
6. 미연결 목록 스크린샷
7. 실제 신규 가입 테스트 결과

를 포함하여 제출하십시오.
