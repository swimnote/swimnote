SWIMNOTE X — WP5 실행 전 DB 대상 재검증 및 설계 오류 정정 지시

제출한 WP5 설계서는 아직 승인하지 않습니다.

이유:

1. 과거 운영 DB 검증 결과와 이번 “X 스키마 없음” 보고가 충돌함
2. 실제 조회 DB 연결 대상이 증명되지 않음
3. PATCH Contract와 SQL에 설계 오류가 있음
4. 안전한 테스트 수영장 여부가 추정에 머물러 있음

이번 작업에서는 코드·DB를 변경하지 말고 아래 항목만 재검증하십시오.

ENUM:

SELECT t.typname, e.enumsortorder, e.enumlabel
FROM pg_type t
JOIN pg_enum e ON t.oid=e.enumtypid
JOIN pg_namespace n ON n.oid=t.typnamespace
WHERE n.nspname='public'
AND t.typname IN (
  'xmode_config_status_enum',
  'global_template_status_enum',
  'growth_match_status_enum'
)
ORDER BY t.typname, e.enumsortorder;

7. Audit SQL 정정
━━━━━━━━━━━━━━━━━━━━━━

다음 SQL은 잘못됐습니다.

SELECT COUNT(*)
FROM audit_logs
WHERE pool_id='pool_sample_x_2026'
AND action ILIKE '%xmode%';

action은 create, update, delete 값만 가집니다.

X모드 변경 Audit은 다음 기준으로 조회해야 합니다.

SELECT
  id,
  entity_type,
  entity_id,
  entity_version,
  action,
  actor_type,
  actor_id,
  pool_id,
  before_data,
  after_data,
  reason,
  created_at
FROM audit_logs
WHERE entity_type='swimming_pool_xmode'
  AND entity_id='<POOL_ID>'
ORDER BY created_at DESC;

이 SQL을 WP5 설계서에 반영하십시오.

8. diary_templates SQL 정정
━━━━━━━━━━━━━━━━━━━━━━

다음 SQL도 현재 확인된 스키마와 맞지 않습니다.

SELECT COUNT(*)
FROM diary_templates
WHERE template_type='global';

기존 확인된 컬럼은 scope입니다.

다음처럼 수정하십시오.

SELECT scope, COUNT(*)
FROM diary_templates
GROUP BY scope
ORDER BY scope;

X 글로벌 템플릿 확인:

SELECT COUNT(*)
FROM diary_templates
WHERE scope='x_global';

일반 템플릿 확인:

SELECT COUNT(*)
FROM diary_templates
WHERE scope IN ('global','teacher');

실제 DB 스키마에서 scope가 존재하는지도 함께 확인하십시오.
