[WP-SA0-B — SUPER ADMIN LIVE OPERATIONS DATA / INCIDENT / BILLING / POOL SEARCH]

목적:

WP-SA0-A에서 만든 Super Admin 운영 콘솔 구조에
실제 운영 데이터를 연결한다.

이번 WP 핵심:

1. Global Pool Search
2. Pool Operations Detail 실제 데이터
3. Billing / Subscription 운영화면
4. incidents DB + CRUD
5. 서버관리 실제 상태
6. AI Usage / Errors foundation
7. 정확한 UNKNOWN 처리
8. 고객센터/장애 대응용 빠른 drill-down

이번 단계는 "운영 관제 기능" 구현이다.

SuperLayout 상단 또는
항상 접근 가능한 위치에
Global Pool Search 구현.

검색 대상:

- 수영장명

- pool_id

클릭:
→ /super/pools/:poolId
