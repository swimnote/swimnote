3. 실행 가능 여부 분기
============================================================

CASE A:
토이키즈가 readiness 조건을 모두 충족하고
기존 safe admin route만으로 정상화 가능

→ 아래 최소 변경 실행 가능.

CASE B:
readiness 조건 미충족

→ 절대 bypass 하지 말고
어떤 prerequisite가 부족한지만 보고.

CASE C:
safe route가 예상과 다르거나
Production 데이터 정합성 위험 있음

→ 실행 중단하고 BLOCKED 보고.
