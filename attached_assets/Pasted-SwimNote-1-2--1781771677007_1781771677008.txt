SwimNote 앨범 선택 모달 추가 수정 지시문

이번 작업은 두 가지를 동시에 수정합니다.

1. 일지 작성/수정 시 앨범에서 사진뿐 아니라 영상도 선택 가능하게 수정
2. 앨범 선택 모달 상단 헤더가 아이폰 Dynamic Island / 노치에 가려지는 UI 문제 수정

바로 코딩하지 말고 먼저 수정 대상 파일과 영향 범위를 간단히 확인한 뒤 작업해 주세요.

⸻

작업 1. 앨범에서 사진 + 영상 통합 선택

현재 상태:

* 일지 작성/수정 화면에서 “앨범에서 선택”을 누르면 사진만 선택 가능
* 영상은 업로드/썸네일은 가능하지만 일지 첨부 선택 흐름이 없음

목표:

* “앨범에서 선택”을 누르면 사진과 영상을 함께 볼 수 있는 통합 앨범 선택 화면 표시
* 기본값은 전체
* 상단 필터: 전체 / 사진 / 영상
* 사진과 영상 모두 선택 가능
* 영상은 썸네일 위에 재생 아이콘 표시
* 선택 후 일지에 첨부

⸻

선택 화면 UX

상단 필터:

전체 | 사진 | 영상

기본값:

전체

그리드:

* 사진: 일반 썸네일
* 영상: 썸네일 + 재생 아이콘
* 선택된 항목: 체크 표시
* 하단 버튼: 선택한 자료 첨부

⸻

일지 화면 표시

일지 작성/수정 화면에서는 첨부자료를 구분해서 표시합니다.

첨부 사진

* 사진 썸네일 목록

첨부 영상

* 영상 썸네일 목록
* 영상에는 재생 아이콘 표시

영상 재생 기능이 완전하지 않아도 됩니다.
이번 목표는 “영상 첨부 + 영상 썸네일 표시”입니다.

⸻

API 확인 및 구현

사진은 기존 기능 사용:

GET /photos/picker
POST /photos/diary-attach
POST /photos/diary-detach
GET /photos/diary/:diaryId

영상은 현재 API 상태 확인 후 필요한 최소 API를 추가 또는 재사용하세요.

확인할 것:

1. 영상 전체앨범 picker API가 있는지
2. 없다면 GET /videos/picker 추가
3. video_assets_meta에 journal_id가 이미 존재하는지 확인
4. 존재한다면 영상도 journal_id 연결 방식 사용
5. 없다면 이번 작업 전 보고 후 진행

필요 시 추가 API:

GET /videos/picker
POST /videos/diary-attach
POST /videos/diary-detach
GET /videos/diary/:diaryId

주의:

* 영상 업로드 권한은 기존 정책 유지
* 낮은 플랜에서는 영상 업로드는 막히지만, 이미 첨부된 영상 조회/표시는 정책에 맞게 처리
* 이번 작업에서 영상 14일 만료, 200MB 변경, 영상 자동 압축은 하지 않음

⸻

영상 썸네일

이미 영상 썸네일 생성/표시가 성공한 상태라면 그 방식을 재사용합니다.

목표:

* 영상 카드에 회색 박스 대신 실제 썸네일 표시
* R2 presigned URL 또는 현재 성공한 썸네일 URL 방식 사용
* 영상 재생은 이번 작업 필수 아님

⸻

작업 2. 앨범 선택 모달 Safe Area 수정

현재 문제:

* “앨범에서 선택” 모달 상단 헤더가 아이폰 Dynamic Island / 노치 영역에 가려짐
* X 버튼, 제목, 선택 개수 버튼이 너무 위에 붙어 있음
* 실기기에서 제목이 잘려 보임

수정 목표:

* 모달 상단 헤더가 상태바/노치/Dynamic Island와 겹치지 않도록 수정
* Safe Area 적용
* 아이폰 Pro 계열에서도 제목이 완전히 보이도록 수정

⸻

수정 방식

react-native-safe-area-context 사용

예:

const insets = useSafeAreaInsets();

헤더 컨테이너에:

paddingTop: insets.top

또는 SafeAreaView 적용

주의:

* 단순 paddingTop 하드코딩 금지
* 기기별 safe area inset 기준으로 처리
* Android에서도 상단 여백이 과도하지 않도록 확인

완료 기준

1. 일지 작성 화면에서 앨범 선택 시 사진과 영상이 함께 보임
2. 전체 / 사진 / 영상 필터가 동작함
3. 사진 선택 가능
4. 영상 선택 가능
5. 선택한 사진은 첨부 사진 영역에 표시
6. 선택한 영상은 첨부 영상 영역에 표시
7. 영상은 썸네일 + 재생 아이콘으로 표시
8. 저장 후 일지에 첨부자료가 유지됨
9. 수정 화면에서도 사진/영상 추가/제거 가능
10. 아이폰에서 앨범 선택 모달 상단 제목이 노치에 가려지지 않음
11. 기존 사진 선택 기능과 기존 사진 업로드 기능이 깨지지 않음
