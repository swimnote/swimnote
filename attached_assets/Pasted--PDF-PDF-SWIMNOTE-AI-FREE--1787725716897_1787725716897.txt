[작업명]
학부모 성장리포트 PDF 상단 헤더 레이아웃 개편

[목표]
현재 PDF 상단의 기존 텍스트형 헤더(SWIMNOTE / AI 성장 리포트 / FREE)를 제거하고,
사용자가 제공한 로고 이미지를 좌측 상단에 배치한 뒤,
로고 우측에 핵심 리포트 정보를 한눈에 보이도록 깔끔하게 재구성한다.

[핵심 요구사항]
1. 기존 상단 헤더에서 아래 요소는 제거
   - "SWIMNOTE"
   - "AI 성장 리포트"
   - "FREE"
   - 기타 무료/내부용 표기

2. 사용자가 제공한 로고 이미지를 좌측 상단에 배치
   - 가로형 로고 사용
   - 로고 안의 "SwimNote AI REPORT" 텍스트는 이미지 그대로 사용
   - 상단 좌측에 충분한 여백을 두고 배치
   - 너무 크거나 답답하지 않게, 헤더 전체 균형을 해치지 않는 크기로 조정

3. 로고 오른쪽 영역에 아래 정보를 깔끔하게 배치
   표시 항목:
   - 리포트 이름
   - 등록된 수영장명
   - 아이 이름
   - 해당 월
   - 현재 커리큘럼상 진도 완료율

4. 상단 정보는 “예쁘게”가 아니라 “명확하고 고급스럽게” 정리
   - 정보 우선순위가 한눈에 보여야 함
   - 부모가 가장 먼저 봐야 할 정보가 즉시 읽혀야 함
   - 장식보다 가독성 우선
   - 줄간격/여백/정렬을 정교하게 맞출 것

[권장 레이아웃]
- 1행: 리포트 이름 (가장 크게)
- 2행: 수영장명 | 아이 이름 | 해당 월
- 3행: 현재 커리큘럼 진도 완료율
- 완료율은 숫자가 잘 보이도록 강조
- 예시:
  - MONTHLY 성장 리포트
  - 토이키즈스윔클럽 | 김수영 | 2026년 8월
  - 현재 커리큘럼 진도 완료율 48.7%

[스타일 가이드]
- 전체 톤: SWIMNOTE 브랜드와 맞는 깔끔한 전문 문서형
- 좌측 로고, 우측 정보 블록 구조
- 헤더 안에서 텍스트 크기 위계 명확히 구분
  - 리포트 이름: 가장 큼 / 굵게
  - 수영장명·아이이름·해당월: 중간 크기
  - 진도 완료율: 중간 이상, 숫자는 강조
- 색상은 기존 리포트 톤 유지 가능하되 과하지 않게
- 구분선이 필요하면 매우 얇고 정돈되게 사용

[데이터 바인딩]
헤더 우측 정보는 하드코딩 금지. 실제 데이터 바인딩 구조로 반영.
필요 필드 예시:
- reportDisplayName
- poolName
- studentName
- reportMonth
- curriculumProgressPercent

예시 매핑:
- reportDisplayName: "MONTHLY 성장 리포트"
- poolName: 등록된 수영장명
- studentName: 학생 이름
- reportMonth: "2026년 8월"
- curriculumProgressPercent: "48.7%"

[진도 완료율 표시 규칙]
- “현재 커리큘럼상 진도 완료율”이라는 의미가 명확히 보이게 표시
- 숫자 + % 형태 유지
- 소수점 표기는 기존 데이터 기준 유지
- 값이 없으면 빈칸으로 두지 말고 fallback 문구 처리
  - 예: "진도 정보 준비 중"

[빈 값 fallback]
- 수영장명 없으면: "등록 수영장 정보 없음"
- 아이 이름 없으면: "학생 정보 없음"
- 해당 월 없으면: 현재 report_period 기반 기본 표시
- 진도 완료율 없으면: "진도 정보 준비 중"

[레이아웃 주의사항]
- 로고와 텍스트가 겹치면 안 됨
- 헤더 높이가 과도하게 커지면 안 됨
- 본문 시작 위치가 밀려서 전체 페이지 균형이 무너지면 안 됨
- A4 2페이지 구성의 기존 전체 레이아웃 안정성 유지
- 모바일 미리보기/PDF 뷰어에서도 잘 보여야 함

[절대 금지]
- FREE / 무료 표기 노출 금지
- 내부 상태값, 품질판정값, 시스템용 텍스트 노출 금지
- 로고 옆 정보 과밀 배치 금지
- 기존 본문 텍스트/분석 내용 수정 금지
- 리포트 엔진 로직 수정 금지
- 이번 작업은 “상단 헤더 디자인 및 정보 배치 수정”만 수행

[산출물]
1. 수정된 PDF 샘플
2. 변경된 상단 헤더가 보이는 1페이지 스크린샷
3. 사용한 데이터 바인딩 필드명 정리
4. 변경 파일 목록
5. 기존 대비 before/after 차이 요약

[추가]
리포트 이름은 우선 "MONTHLY 성장 리포트"로 적용하되,
상수화해서 이후 "정기 성장 리포트" 등으로 쉽게 교체 가능하게 구현할 것.
