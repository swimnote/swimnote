## 작업 목표

현재:

사진 업로드
→ 일지에 직접 업로드

구조가 섞여 있음

목표:

전체앨범사진
↓
선생님 또는 관리자 업로드
↓
일지 작성 시 선택
↓
journal_id 연결
↓
학부모에게 노출

사진은 한 번만 저장

파일 복제 없음

재업로드 없음

journal_id 연결만 사용

1단계
storage.ts 버그 수정
----------------

현재:

student_photos
student_videos

참조

실제:

photo_assets_meta
video_assets_meta

사용

수정:

student_photos
→ photo_assets_meta

student_videos
→ video_assets_meta

file_size_bytes
→ file_size

목표:

* 관리자 저장공간 정상 표시
* 선생님 저장공간 정상 표시
* 대시보드 저장공간 정상 표시

주의:

업로드 제한 로직은 수정 금지

현재 정상 동작 중

---

2단계
photo_assets_meta journal_id 인덱스 추가
-----------------------------------

확인 결과:

photo_assets_meta

journal_id 컬럼 존재

인덱스 없음

실행:

CREATE INDEX IF NOT EXISTS idx_photo_assets_journal_id
ON photo_assets_meta(journal_id);

---

3단계
전체앨범 → 일지 연결 구조 구현
------------------

핵심 목표:

일지에는 복사 저장 금지

journal_id 연결만 사용
