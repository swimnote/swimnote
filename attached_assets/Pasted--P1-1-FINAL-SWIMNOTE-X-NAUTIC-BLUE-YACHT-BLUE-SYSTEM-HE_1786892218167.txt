==================================================
1. FINAL X COLOR CONCEPT
==================================================

SWIMNOTE X의 최종 color identity는:

NAUTIC BLUE
+
YACHT BLUE

두 계열을 혼합한 X 전용 blue family로 구성한다.

역할은 다음처럼 구분한다.

NAUTIC BLUE
= 깊이
= 묵직함
= 브랜드 중심
= 강한 surface
= header / bottom nav / primary strong emphasis

YACHT BLUE
= 세련됨
= 조금 더 밝은 청색감
= elevated surface
= icon / selected state / secondary accent
= X 기능카드 보조 강조

두 색을 경쟁시키지 말고
하나의 동일한 premium blue family처럼 구성한다.
