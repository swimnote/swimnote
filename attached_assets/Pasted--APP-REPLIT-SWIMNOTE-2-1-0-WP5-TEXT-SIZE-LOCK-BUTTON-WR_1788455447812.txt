# SWIMNOTE 2.1.0 — WP5 TEXT SIZE LOCK + BUTTON WRAP FIX

대상:
관리자 → 선생님 관리 → 선생님 선택 → 운영현황

첨부한 최신 실기기 화면 기준.

현재 상태:
- 글자 크기/가독성은 현재 상태가 맞음
- 하지만 버튼이 세로/가로로 너무 큼
- 버튼 박스가 글자보다 과하게 큼

이번 수정 목표:
"현재 글자 크기는 100% 그대로 유지하고,
버튼 테두리/배경 영역만 글자를 감싸는 크기로 축소"

============================================================
절대 변경 금지
============================================================

아래는 절대 수정하지 말 것:

- fontSize
- lineHeight
- fontWeight
- fontFamily
- letterSpacing
- Text transform
- Text scale
- Text wrapper 구조

즉 현재 보이는
담당 회원 / 출결 / 수업일지 / 보강
글자 크기와 형태는 그대로 고정.

글자 크기를 줄이거나 바꾸면 FAIL.

============================================================
수정 허용 범위
============================================================

ONLY 버튼 컨테이너 크기 조정:

- height 제거 또는 축소
- minHeight 제거 또는 축소
- paddingHorizontal 축소
- paddingVertical 축소
- width 고정값 제거
- flex:1 제거
- 불필요한 minWidth 제거
- margin/gap 최소 조정

목표:
버튼이 글자 크기에 맞춰 자연스럽게 감싸도록 변경.

예상 형태:

[ 담당 회원 ] [ 출결 ] [ 수업일지 ] [ 보강 ]

글자는 현재 크기 그대로,
버튼만 글자 주변에 적당한 여백만 남겨야 함.

============================================================
중요
============================================================

현재처럼:

담당 회원 버튼이 큰 사각형
출결 버튼이 큰 사각형
수업일지 버튼이 큰 사각형
보강 버튼이 큰 사각형

이런 형태는 금지.

버튼 width는 내용 기반 intrinsic width 사용.

즉:
- 담당 회원은 글자 길이만큼
- 출결은 더 짧게
- 수업일지는 글자 길이만큼
- 보강은 더 짧게

각각 자연스럽게 달라져야 함.

============================================================
선택/비선택 디자인
============================================================

현재 색상 체계는 유지:

selected:
- 기존 청록 배경
- 기존 흰색 텍스트

unselected:
- 기존 흰 배경
- 기존 연한 청록 border
- 기존 텍스트색

단,
selected/unselected 모두
글자 크기/높이/폰트는 동일.

selected 상태라고 버튼 크기가 커지면 안 됨.

============================================================
레이아웃
============================================================

4개 버튼은 한 줄 유지.

버튼 간 gap은 작고 일정하게.

상단 통계 카드와 탭 사이 간격:
현재보다 과하게 크지 않게 유지.

탭과 아래 목록 사이 간격:
현재보다 과하게 크지 않게 유지.

============================================================
회귀 금지
============================================================

이전 WP5에서 발생했던 문제 절대 재발 금지:

- 글자 세로 clipping
- 글자 1px처럼 눌림
- ScrollView cross-axis collapse
- selected/unselected 높이 차이

특히:
글자 크기를 줄여서 버튼에 맞추는 방식 금지.

반드시:
버튼이 글자에 맞춰야 함.

Text가 버튼에 맞추는 게 아니라
Button container가 Text에 맞춰야 함.

============================================================
작업 전 비교
============================================================

현재 style에서 다음을 확인:

- width
- minWidth
- height
- minHeight
- flex
- flexGrow
- flexBasis
- paddingHorizontal
- paddingVertical

버튼이 커지는 원인이 무엇인지 먼저 확인.

특히:
fixed height / minHeight / flex:1 / large padding
존재 여부 확인.
