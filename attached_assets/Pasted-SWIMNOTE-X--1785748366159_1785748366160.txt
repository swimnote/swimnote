3. 증거 등급
━━━━━━━━━━━━━━━━━━━━━━

모든 결과에 다음 중 하나를 붙이십시오.

CODE_VERIFIED
현재 작업 트리의 실제 파일 원문으로 확인
GIT_VERIFIED
Commit 객체·diff·branch·remote 상태로 확인
DB_VERIFIED
읽기 전용 SQL 원문과 결과로 확인
RUNTIME_VERIFIED
현재 실행 중인 서버 또는 앱 응답으로 확인
OTA_VERIFIED
Expo/EAS의 실제 Update 조회 결과로 확인
REPORTED_ONLY
이전 보고에만 있고 현재 증거 없음
CONTRADICTED
이전 보고와 현재 증거가 충돌함
NOT_FOUND
현재 코드·Git·DB·배포에서 찾을 수 없음
NOT_TESTED
실제 테스트 증거 없음

완료, 정상, 적용됨이라는 표현은 위 증거가 있을 때만 사용하십시오.

14. 원격 Push 감사
━━━━━━━━━━━━━━━━━━━━━━

각 관련 Commit이 원격에 실제 존재하는지 확인하십시오.

git fetch --all --prune

주의: git fetch는 작업 트리를 변경하지 않는 읽기성 네트워크 조회로 허용합니다.
Pull·merge·checkout은 금지합니다.

그 후:

git branch -r --contains <commit>
git merge-base --is-ancestor <commit> <remote-branch>

각 Commit:

* 로컬만 존재
* 원격 포함
* 현재 배포 브랜치 포함
* 다른 브랜치에만 존재
* 어디에도 없음
