[앱] X모드 학부모 설정 — 첫 화면 구조 재정리

현재 구현은 사용자 의도와 다름.

현재:
- 자주 쓰는 설정 3개
- 아래에 다시 설정 분류 4개

이 구조 폐기.

최종 목표:
설정 첫 화면에는 정말 중요한 항목만 직접 노출하고,
나머지는 전부 분류 내부에 넣는다.

2. 첫 화면 직접 노출 메뉴는 3개만
━━━━━━━━━━━━━━━━━━━━━━

프로필 바로 아래:

1. 공지
subtitle:
수영장 공지 전체 보기

2. 수업변경요청
subtitle:
결석 · 연기 · 퇴원 · 상담 신청

3. 문의하기
subtitle:
수영장 · 고객센터 문의

이 3개만 첫 화면에 직접 노출.

중요:
"자주 쓰는 설정"이라는 섹션명도 제거 가능.
그냥 핵심 기능 3개가 자연스럽게 보이게.

형태는 쿠팡처럼:

       subtitle                  >

한 section container
hairline divider

3. 나머지는 전부 분류 안으로
━━━━━━━━━━━━━━━━━━━━━━

첫 화면 아래에는 세부 메뉴를 직접 나열하지 말고
분류 버튼만 표시.

추천 분류:

A. 계정 및 가족
subtitle:
내 정보 · 보호자 · 자녀 · 로그인/보안

내부:
- 내 정보
- 부모 정보 수정
- 자녀 관리
- 추가 보호자 관리
- 로그아웃
- 회원 탈퇴

B. 알림 및 소식
subtitle:
푸시 알림 · 알림함

내부:
- 푸시 알림 설정
- 알림함
- 필요 시 기타 알림 관련 설정

중요:
공지는 첫 화면에 이미 직접 노출되므로
분류 내부 중복 노출은 피하는 방향.

C. 수업 및 수영장
subtitle:
수업 정보 · 등록 수영장

내부:
- 등록 수영장
- 수업 관련 설정/정보
- 필요한 기존 수업 관련 메뉴

중요:
수업변경요청은 첫 화면에 직접 노출되므로
분류 내부에서 중복 배치하지 않거나
필요 시 상세 기능 진입용으로만 유지.

D. 도움말 및 서비스
subtitle:
AI · 고객센터 · 약관

내부:
- AI 문의
- 고객센터 문의
- 이용약관
- 개인정보처리방침

중요:
문의하기는 첫 화면에 직접 노출.
내부에는 실제 세부 문의 채널만 정리.

━━━━━━━━━━━━━━━━━━━━━━
4. 중복 노출 최소화
━━━━━━━━━━━━━━━━━━━━━━

첫 화면에 직접 노출된:

- 공지
- 수업변경요청
- 문의하기

는 아래 분류에서
같은 이름으로 또 반복 노출하지 않는 방향으로 정리.

필요한 경우 분류 내부에는
세부 기능만 남길 것.

이번 작업에서는 기능 통합/삭제는 하지 말고
UI상 중복 노출만 최소화.
