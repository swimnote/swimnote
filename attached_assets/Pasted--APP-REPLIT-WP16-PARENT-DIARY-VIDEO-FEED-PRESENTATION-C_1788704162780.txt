현재 학부모 수업일지 Feed:

- 사진은 정상 표시

- 영상 다운로드도 정상

  기능 오류처럼 보임
- 사용자 입장에서는 실제 영상 내용이 식별되지 않음

오류처럼 보이지 않는 자연스러운 fallback UI

3.
사진 + 영상 혼합 Feed를 깔끔하게 표현

4.
Instagram Story 공유에서는
영상은 기술적으로 복잡하면 포함하지 않음

5.
Story 공유는 사진만 사용
