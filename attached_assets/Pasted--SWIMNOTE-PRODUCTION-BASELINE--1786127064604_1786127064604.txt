이 상태를 정상 기준으로 고정한다.

A. Teacher visibility

GET /teacher/makeups가 pool 전체를 반환하면 안 된다.

현재 담당 학생 Source of Truth:

student_class_history.left_at IS NULL
→ current active class
→ class_groups.teacher_user_id
   OR co_teacher_ids

handoff 예외:

ms.handed_to_teacher_id = current user

original_teacher_id는 현재 visibility 기준으로 사용 금지.

Admin은 기존처럼 pool 전체.

B. 날짜 정책

현재 성공한 날짜 정책 유지:

KST 오늘 기준
-14일 ~ +28일

MAKEUP_DATE_OUT_OF_RANGE 유지.

eligible-occurrences 정상 유지.

C. assign / complete-direct

미래:
PATCH /teacher/makeups/:id/assign

오늘/과거:
PATCH /teacher/makeups/:id/complete-direct

분기 유지.

D. expired

waiting + expired 조회 유지.

기간 지난 보강 UI 유지.

MAKEUP_EXPIRED_CONFIRM_REQUIRED 유지.

E. FULL CLASS OVERRIDE

매우 중요.

일반 class capacity가 5명이어도
보강은 정원을 초과해서 추가 가능해야 한다.

예:

capacity = 5
current_members = 5
makeup +1
→ 총 6명 허용.

따라서:

- CLASS_FULL로 보강 assign 차단 금지
- eligible-classes에서 FULL 반 제거 금지
- FULL 반 UI disabled 금지
- FULL 반 onPress guard 금지

단:

is_full
available_slots
current_members

등의 정보와
"정원마감/정원초과" 뱃지는 표시용으로 유지 가능.

F. 날짜 다시 선택

현재:

setSelectedDate(null)
setSelectedOccurrence(null)

두 state를 같이 초기화하는 코드 유지.

G. 배정 확정

반드시:

onPress={() => doAssign()}

유지.

다시:

onPress={doAssign}

으로 되돌리는 것 금지.

doAssign의 allowExpired 파라미터에
GestureResponderEvent가 들어가면 안 된다.
