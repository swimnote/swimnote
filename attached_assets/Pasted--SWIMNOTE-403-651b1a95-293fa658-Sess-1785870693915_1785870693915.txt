2. SessionContext 403 오판 수정
━━━━━━━━━━━━━━━━━━━━━━

대상:

artifacts/swim-app/context/SessionContext.tsx

현재 잘못된 코드:

if (res.status === 403 && !data.error_code) {
  throw Object.assign(
    new Error("서비스 이용이 중단되었습니다.\n구독 상태를 확인해주세요."),
    {
      error_code: "pool_deactivated",
      days_until_deletion: 0,
      deletion_scheduled_at: "",
      deactivated_at: new Date().toISOString(),
    }
  );
}

이 로직을 제거한다.

원칙:

구독취소·수영장 비활성 화면은 서버가 명시적으로 아래 코드 중 하나를 반환한 경우에만 표시한다.

허용되는 명시적 코드 예:

- pool_deactivated
- subscription_cancelled
- subscription_expired
- deletion_scheduled

실제 서버에서 사용하는 정확한 코드 목록을 Repository 검색으로 먼저 확인한다.
임의 코드 추가 금지.

수정 정책:

if (
  res.status === 403 &&
  [
    "pool_deactivated",
    "subscription_cancelled",
    "subscription_expired",
    "deletion_scheduled",
  ].includes(data?.error_code)
) {
  // 기존 구독 중단 처리
}

그 외 일반 403:

- pool_deactivated로 변환 금지
- 구독취소 화면 이동 금지
- 원래 error_code/message 유지
- 일반 권한 오류로 처리
- 현재 세션 전체를 파괴하거나 로그아웃시키지 않음

서버의 실제 구독 오류 코드 확인 후 배열을 확정한다.
