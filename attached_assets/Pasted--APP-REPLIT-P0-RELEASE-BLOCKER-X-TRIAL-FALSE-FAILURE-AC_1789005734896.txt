   "X AI 기능 무료체험 중"

   정상 표시

따라서 현재 문제는 2개가 동시에 존재할 가능성이 높음:

A. 서버 trial activation은 실제 성공했는데
   client가 성공 이후 과정의 오류를 activation 실패로 잘못 표시

B. canonical mode=x_trial 상태를
   실제 feature access / admin UI가 완전하게 사용하지 않음

이전 refreshMode lock 수정만 다시 제출하지 말 것.
실제 Production 신규 계정 재현 기준으로 끝까지 추적.

Android 새 native build는 이 P0 해결 전 보류.

1. FALSE FAILURE 정확한 원인 추적
━━━━━━━━━━━━━━━━━━━━━━

무료체험 버튼 handler 전체 실행 순서를 추적:

POST /billing/x-trial-activate
→ response
→ forceRefreshMode
→ subscription refetch
→ query invalidation
→ state update
→ navigation/UI update

각 단계별 성공/실패를 분리.

반드시 확인:

- POST 실제 HTTP status
- response body/error code
- DB UPDATE 성공 여부
- POST 성공 이후 어떤 코드가 throw하는지
- catch 범위가 너무 넓어서 refresh/UI 오류까지
  "체험 시작 실패"로 표시하는지

핵심:

DB trial activation이 성공했다면
그 이후 refresh/UI 오류 때문에
"체험 시작에 실패했습니다"라고 표시하면 안 됨.

━━━━━━━━━━━━━━━━━━━━━━
2. 성공/실패 경계 수정
━━━━━━━━━━━━━━━━━━━━━━

activation 결과와
post-activation refresh 결과를 분리.

예:

ACTIVATION FAILURE
→ 서버 POST 자체가 실패
→ "체험 시작 실패"

ACTIVATION SUCCESS + REFRESH FAILURE
→ trial 자체는 성공
→ 실패 메시지 표시 금지
→ canonical mode 재조회/retry
→ 필요하면
   "무료체험이 시작되었습니다. 화면을 새로고침합니다."
   수준 처리

서버에서 201/2xx + trial timestamps 저장 성공했는데
generic failure banner가 뜨는 상태는 FAIL.

연속 탭으로 두 번째 activate 요청 보내지 않게 유지.
