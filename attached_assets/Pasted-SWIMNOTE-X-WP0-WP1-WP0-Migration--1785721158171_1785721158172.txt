2. WP0 보고서 추가 확인 사항
━━━━━━━━━━━━━━━━━━━━━━

다음 내용은 현재 보고만으로 확정할 수 없으므로 WP1 설계서 제출 전에 추가 조사하십시오.

현재 보고:

* pool-db-init.ts 마지막에서 initXModeSchema() 호출
* index.ts 서버 기동 시 initPoolDb() 실행
* pool-db-x-init.ts 실제 존재
* 그러나 DB에는 X 컬럼·테이블 없음

위 상태가 동시에 발생한 정확한 이유를 실제 코드·환경 기준으로 확인하십시오.

가능성을 추정해서 선택하지 말고 다음을 조사하십시오.

1. 현재 Repository 코드가 실제 실행 환경에 배포된 상태인지
2. 코드 추가 이후 서버가 재시작된 적이 있는지
3. 조사한 DB와 실행 서버가 사용하는 DB가 동일한지
4. DATABASE_URL 또는 DB 연결 분기
5. isDbSeparated 조건
6. getPoolDb(), getBackupDb(), getSuperDb() 실제 연결 대상
7. initXModeSchema()가 환경 조건에 따라 건너뛰어지는지
8. 과거 Migration 실패 로그가 있는지
9. 현재 서버 기동 로그에 initXModeSchema 관련 기록이 있는지
10. 실제 DB에서 아래 컬럼·테이블을 직접 조회했는지

결과는 다음 중 하나로 표시하십시오.

* REPOSITORY_VERIFIED
* ENVIRONMENT_VERIFIED
* NOT_FOUND
* NEEDS_VERIFICATION

운영 DB 조회 권한이 없으면 추정하지 말고 NEEDS_VERIFICATION으로 유지하십시오.
