공지사항 작성 화면에:

- 직접 제목 입력
- 직접 본문 입력
- 기존 AI 텍스트 작성
- 음성 AI 작성

모두 유지.

음성 흐름:

마이크 버튼
→ 녹음 시작

→ 종료
→ STT
→ AI 정리
→ 제목 자동 입력
→ 본문 자동 입력

기존 작성폼에 채워주는 방식.

관리자가 확인/수정 후 직접 등록.

3. AI 작성 정책
━━━━━━━━━━━━━━━━━━━━━━

AI는 사용자가 말한 내용만 정리.

허용:
- 제목 생성
- 문장 정리
- 줄바꿈
- 공지문 어투 정돈

금지:
- 날짜 임의 생성
- 휴강일 임의 생성
- 보강정책 임의 생성
- 가격/시간/장소 창작
- 사용자 입력에 없는 사실 추가

프롬프트에 명시.

━━━━━━━━━━━━━━━━━━━━━━
4. 출력 형식
━━━━━━━━━━━━━━━━━━━━━━

가능하면 기존 AI endpoint 응답을:

{
  title: string,
  content: string
}

형태로 명확히 유지.

STT 원문
→ 공지 AI
→ title/content

사용자 입력이 너무 짧거나 모호하면
사실을 만들지 말고
입력 내용 범위 안에서만 최소 작성.
