5. APP CHANGE REQUIRED?
==================================================

결론:

A.
raw Bearer 방식 정상
→ APP_CHANGE_REQUIRED = NO

B.
JWT 필요
→ APP_CHANGE_REQUIRED = YES

JWT 필요 시
APP Server가 어떤 방식으로 token을 생성해야 하는지
정확한 contract만 제시.

예:

jwt.sign(
  {...required claims...},
  ENGINE_SHARED_SECRET,
  {
    algorithm: "HS256",
    expiresIn: ...
  }
)

단 이번 단계에서 APP 코드 수정은 하지 않는다.
