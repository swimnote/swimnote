==================================================
1. EMPTY SECTION 자동 숨김
==================================================

현재 아래처럼 내용이 없는 섹션이 그대로 노출됨:

"(이번 기간 해당 내용 없음)"

최종 정책:

section text가
- empty
- null
- whitespace
- "(이번 기간 해당 내용 없음)"
- equivalent empty placeholder

이면
해당 section 전체를 PDF에서 렌더하지 말 것.

숨길 대상은 모든 section 공통.

예:
- 핵심 성장
- 행동 강점
- 성공 조건
- 교사 관찰 메모
등.

중요:
빈 section 제목/구분선/여백까지 모두 제거.

==================================================
2. 남은 SECTION 자동 재배치
==================================================

빈 section이 빠진 뒤
고정 좌표 때문에 큰 빈 공간이 남으면 안 됨.

남은 section을 위에서부터 자연스럽게 재배치.

즉:
section Y 위치를 고정값으로 두지 말고
이전 section의 실제 높이 + spacing 기준으로 계산.

목표:
- 빈 공간 최소화
- 과밀하지 않게
- 부모가 읽기 편한 리듬 유지

3. PAGE 1 정보 구조
==================================================

Page 1 우선순위:

1. 이번 달 한눈에 보기
2. 핵심 성장 (있을 때만)
3. 수영 교육과정 진행
4. 행동 강점 (있을 때만)
5. 이전 기간 비교 (있을 때만)

중요:
summary는 Page 1의 가장 중요한 본문 블록.

"이번 달 한눈에 보기"는
다른 section보다 시각적 중요도가 한 단계 높게.

가능:
- 아주 연한 배경
- 여백 조금 더 넓게
- 제목 강조

단:
과한 카드 디자인 금지.

==================================================
4. PAGE 2 정보 구조
==================================================

Page 2 우선순위:

1. 성공 조건 (있을 때만)
2. 교사 관찰 메모 / 지도 방향 (있을 때만)
3. 다음 수업 방향
4. 가정에서 함께해요

"가정에서 함께해요"는
Page 2의 마지막 핵심 강조 블록으로 유지.

부모가 리포트를 다 읽고
실제로 무엇을 하면 되는지
마지막에 바로 보이게 할 것.

==================================================
5. "가정에서 함께해요" 박스 개선
==================================================

현재 강조 박스 구조는 유지 가능.

다만 다음 기준으로 정리:

- 다른 section보다 배경이 조금 더 명확
- 텍스트 대비 충분
- 왼쪽 accent line 유지 가능
- padding 넉넉하게
- 지나치게 큰 박스 금지
- 너무 광고/CTA처럼 보이면 안 됨

이 섹션은
"부모 행동 가이드" 느낌이 나야 함.

6. SECTION TITLE 스타일 통일
==================================================

모든 section title:

본문과 제목 사이 간격은
부모가 한 덩어리로 읽기 좋게 유지.

7. BODY TYPOGRAPHY
==================================================

본문 가독성 개선.

확인:
- font size 너무 작지 않게
- line-height 충분히
- 긴 문장 줄간격 답답하지 않게
- 문단 폭 너무 넓지 않게

한 줄에 너무 많은 글자가 들어가
보고서가 빽빽해 보이면
