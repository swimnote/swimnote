1. 신규 가입 시 자동 환불정책 모달 제거
━━━━━━━━━━━━━━━━━━━━━━

현재 신규 가입/최초 진입 시 자동으로 뜨는
기존 환불정책 관련 모달을 제거한다.

중요:
- 기존 정책 데이터를 삭제하지 말 것
- 기존 동의 이력 DB 삭제 금지
- 정책/환불 관련 서버 구조 대규모 수정 금지
- 단순히 "신규 가입 직후 자동 노출"만 제거

향후 별도 작업에서:
- 환불정책
- 구독정책
- 무료체험 정책
- 자동갱신
- 가격/환불 안내
를 새 canonical 정책으로 다시 작성하고,
구독/무료체험 시작 전에 명시적 동의를 받는 구조로 재구현 예정.

이번 작업에서는 새 정책 모달 만들지 말 것.
