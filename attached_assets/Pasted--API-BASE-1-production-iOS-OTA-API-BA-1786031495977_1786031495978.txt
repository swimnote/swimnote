1. production iOS OTA API_BASE가
   https://swimnote.kr/api
   로 빌드됨

2. 지정 운영 API는
   https://swimnote-api.onrender.com/api
   임

3. Render live SHA 143fd336의 전체 tree에
   이번 보강 수정 범위 밖 WP6·진단·로그인 관련 코드가 포함됨

4. Android production OTA는 이번 배포에 없음

- Preview 배포
- 새 기능 수정
- WP6 작업
- 로그인·인증 수정
