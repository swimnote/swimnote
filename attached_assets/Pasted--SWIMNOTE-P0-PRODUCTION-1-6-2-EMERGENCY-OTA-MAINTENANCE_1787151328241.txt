[SWIMNOTE P0 — PRODUCTION 1.6.2 EMERGENCY OTA MAINTENANCE]

대상:
현재 App Store Production 버전 1.6.2

목표:
1.6.2 사용자가 앱을 실행하면
로그인 화면이나 홈 화면으로 진입하기 전에
전체화면 서버 점검 안내만 표시한다.

이번 작업은 긴급 OTA 배포다.

표시 문구:

서버 점검 중입니다

SWIMNOTE AI 대규모 업데이트로 서버 점검을 실시합니다.

더 안정적이고 향상된 AI 서비스를 제공하기 위해
시스템 업데이트 및 서버 안정화 작업을 진행하고 있습니다.

작업이 완료되는 즉시 정상적으로 이용하실 수 있습니다.
이용에 불편을 드려 죄송합니다.

--------------------------------------------------
구현 요구
--------------------------------------------------

1. 앱 시작 최상단에서 차단

Production 1.6.2 앱 실행 직후
AuthProvider / 로그인 / 자동로그인 / 홈 화면보다 먼저
Maintenance Screen을 렌더링한다.

유지보수 모드에서는 다음 화면 진입 금지:
- 로그인
- 회원가입
- 자동로그인
- 관리자 홈
- 선생님 홈
- 학부모 홈
- 기타 앱 내부 화면

2. 서버 호출 최소화

점검 화면 표시 중에는 가능하면 아래 초기 호출을 실행하지 않는다.

- unified-login
- session restore
- profile
- pool
- student/member list
- attendance
- diary
- RevenueCat
- 기타 앱 초기화 API

현재 서버 장애 때문에 오류 팝업이 추가로 뜨지 않게 한다.

3. 기존 코드 삭제 금지

- 인증 코드 삭제 금지
- API endpoint 변경 금지
- 기존 화면 삭제 금지
- DB 변경 금지
- 서버 변경 금지

Maintenance gate만 최상단에 추가/활성화한다.

4. 사용자 화면

전체화면으로 표시.

디자인:
- 기존 SWIMNOTE 디자인 유지
- 흰색 배경
- SWIMNOTE 로고
- 네이비/민트 톤
- "서버 점검 중입니다" 강조
- 안내문 중앙 정렬
- 버튼 없음

사용자에게 절대 노출하지 말 것:
- HTTP status
- API URL
- rawText
- Cannot POST
- Render
- GitHub
- GitLab
- Cloudflare
- stack trace
- debug 정보

5. 뒤로가기 / 우회 차단

Android hardware back 차단.
iOS gesture/navigation으로 기존 화면 진입 불가.
deep link로 내부 화면 진입 불가.

6. OTA 가능 여부 먼저 확인

현재 App Store 1.6.2의:
- runtimeVersion
- updates configuration
- update channel
- branch
- EAS Update 적용 가능 여부

를 먼저 확인한다.

중요:
1.6.2 binary와 호환되는 runtime/channel에만 OTA를 올린다.

호환되지 않는 runtime에 억지 배포 금지.

7. OTA 배포

1.6.2 Production 사용자가 실제 수신하는
정확한 Production update channel/branch에 배포한다.

배포 전 보고:
- App Store version: 1.6.2
- build number:
- runtimeVersion:
- production update channel:
- OTA compatible: YES/NO

YES인 경우에만 배포.

8. OTA 후 실제 검증

실제 Production 1.6.2 설치 기기 기준:

- 앱 완전 종료
- 재실행
- OTA 수신
- 재실행 필요 시 재실행
- Maintenance Screen 표시
- 로그인 화면 진입 불가
- 홈 화면 진입 불가
- 기존 서버 오류창 미표시

9. 절대 금지

- 새 native build 생성
- App Store binary 변경
- Production server 변경
- Render source 변경
- Git repo/branch 변경
- DB 변경
- auth 수정
- 고객센터 DB 변경
- AI engine 변경

이번 작업은
"Production 1.6.2 긴급 OTA Maintenance 차단"
만 수행한다.
