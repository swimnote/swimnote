# SWIMNOTE 앱 Phase 4 작업 지시

AI Engine Phase 3가 완료되었습니다.

이번 작업은 새로운 기능 개발이 아니라,
기존 SWIMNOTE 앱과 AI Engine을 실제로 연결하는 작업입니다.

SWIMNOTE 앱의 기존 구조와 UX는 유지하며,
AI Engine API와의 연동만 진행합니다.

--------------------------------------------------
AI Engine 완료 사항
--------------------------------------------------

완료된 API

1.
POST /api/ai/diary/generate

2.
POST /api/ai/whisper/transcribe

AI Engine은 다음 기능을 모두 지원합니다.

- Teacher Diary 생성
- Whisper 음성 인식
- Knowledge 기반 생성
- Knowledge 0건 안전 정책
- JSON Response Contract
- Error Contract
- request_id End-to-End
- LLM Usage
- AI Request Log

--------------------------------------------------
Response JSON
--------------------------------------------------

AI Engine은 항상 아래 구조를 반환합니다.

{
  "request_id": "...",
  "schema_version": "1.0",
  "feature": "teacher_diary",
  "result": {
    "common": "...",
    "students": [
      {
        "student_id": "...",
        "content": "..."
      }
    ]
  },
  "usage": {
    "input_tokens": 0,
    "output_tokens": 0,
    "total_tokens": 0
  }
}

--------------------------------------------------
Error Contract
--------------------------------------------------

실패 시 항상 아래 구조를 반환합니다.

{
  "request_id": "...",
  "error": {
    "code": "...",
    "message": "...",
    "retryable": false
  }
}
