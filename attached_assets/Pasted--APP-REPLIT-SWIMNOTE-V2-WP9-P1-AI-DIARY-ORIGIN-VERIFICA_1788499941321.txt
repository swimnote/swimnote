3. 최종 원칙
============================================================

ai_generated는
client field 존재 여부만으로 TRUE가 되면 안 됨.

목표:

client sends ai_request_id
↓
server verifies
"이 request_id가 실제 이 pool의 AI diary generation에서 생성된 것인가?"
↓
verified:
ai_generated = TRUE

unverified:
ai_generated = FALSE
ai_trace_id = NULL

또는 현재 API convention에 맞는
안전한 처리.
