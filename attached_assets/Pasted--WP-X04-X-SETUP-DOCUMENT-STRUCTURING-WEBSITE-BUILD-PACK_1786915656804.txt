[WP-X04 — X SETUP DOCUMENT STRUCTURING / WEBSITE BUILD PACKAGE / CURRICULUM PROCESSING FOUNDATION]

목적:

WP-X03에서 수집한 공식 원본자료:

1. 커리큘럼 DOCX
2. 홈페이지 제작자료 DOCX
3. 로고
4. 사진 최대 10장

- 원본은 그대로 보존하고

- Super Admin에서 검토/수정할 수 있고
- 홈페이지 제작용 패키지를 즉시 생성할 수 있게 한다.

이번 WP는
실제 홈페이지를 자동 제작하는 단계가 아니다.

"원본 → 구조화 → 검토 → 제작패키지"

파이프라인 기반을 완성하는 작업이다.

==================================================
1. CORE DATA PRINCIPLE
==================================================

절대 원칙:

ORIGINAL != STRUCTURED != GENERATED

세 계층을 분리한다.

ORIGINAL
→ 수영장이 실제 제출한 원본자료

STRUCTURED
→ 원본에서 추출/정리한 구조화 데이터

GENERATED
→ 이후 SWIMNOTE가 생성한 커리큘럼/홈페이지 결과물

원본을 덮어쓰거나
구조화 데이터로 대체하지 않는다.

==================================================
2. PROVENANCE
==================================================

구조화되는 모든 주요 필드는
출처 추적이 가능해야 한다.

최소 개념:

source_file_id
source_version
source_section
extraction_method
review_status

향후 GENERATED 결과가 생기더라도
어떤 원본을 기준으로 만들어졌는지 추적 가능해야 한다.

==================================================
3. NO HALLUCINATION RULE
==================================================

AI/parser가
수영장이 제출하지 않은 사실을
그 수영장의 고유 정보로 생성하면 안 된다.

가능:

- 형식 정리
- 문장 분리
- field mapping
- 목록 구조화
- 중복 정리
- 명백한 표 구조 해석

금지:

- 없는 시설 생성
- 없는 철학 생성
- 없는 레벨 생성
- 없는 수강료 생성
- 없는 차별점 생성
- 없는 운영시간 생성

UNKNOWN은 UNKNOWN/EMPTY로 유지.

기준.

자유서술 구조화에만 이후 제한적으로 사용 가능.

이번 WP에서는
가능하면 parser 기반 foundation 우선.
