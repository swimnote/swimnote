[P0 PRE-DESIGN — SUPER ADMIN 전체 기능 스캔 + 운영형 대시보드 재구성 설계]

이번 작업은 Super Admin 모드를
출시 후 실제 운영 가능한 수준으로 완전히 재구성하기 위한
전수 조사/설계 단계다.

아직 코드 수정 금지.
OTA/Render 배포 금지.

부분 UI 수정 수준으로 접근하지 말 것.

현재 Super Admin 화면이 임시/불완전/죽은 기능이 섞여 있을 수 있으므로

1. 현재 전체 기능 스캔
2. 실제 API/DB 연결 여부 확인
3. 죽은/placeholder 기능 제거 후보 분리
4. 현재 SWIMNOTE / X 구조와 새로운 요금제 반영
5. 운영자 관점에서 IA 재설계
6. 필요하면 Super Admin 화면 자체를 새로 만드는 안까지 제출

목표:

PC/태블릿에 Super Admin 대시보드를 항상 띄워놓고
전국 수영장을 실제로 운영/통제할 수 있는 수준.
