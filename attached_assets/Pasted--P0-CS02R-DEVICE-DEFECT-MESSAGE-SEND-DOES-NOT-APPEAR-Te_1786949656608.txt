==================================================
4. CASE CREATE FLOW
==================================================

Lazy case 생성 구조 확인.

첫 메시지에서:

caseId 없음
→ POST /support/cases
→ caseId 저장
→ 같은 send flow 안에서 message POST

가 반드시 이어져야 한다.

React state setCaseId()가 async라는 이유로
바로 다음 코드에서 stale caseId(null)를 사용하면 안 된다.

예:

const createdCaseId = response.id;
setCaseId(createdCaseId);
await sendMessage(createdCaseId, ...);

형태처럼
실제 반환 id를 직접 사용.

이 stale-state race 여부를 반드시 검사.
