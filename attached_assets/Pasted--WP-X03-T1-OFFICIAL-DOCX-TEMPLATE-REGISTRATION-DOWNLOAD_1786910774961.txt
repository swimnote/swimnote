[WP-X03-T1 — OFFICIAL DOCX TEMPLATE REGISTRATION / DOWNLOAD VERIFICATION]

목적:

WP-X03에서 구현한 자동 생성 임시 DOCX 템플릿을
SWIMNOTE 공식 확정 Word 템플릿 v1.0으로 교체/등록한다.

이번 작업은 템플릿 파일 등록 및 다운로드 검증만 한다.

X Setup 구조,
DB schema,
upload flow,
Super Admin review flow는 변경하지 않는다.

==================================================
0. OFFICIAL SOURCE FILES
==================================================

사용자가 전달하는 아래 2개 파일을
내용 수정 없이 공식 source file로 사용한다.

1.
SWIMNOTE_X_커리큘럼_작성양식_v1.0.docx

2.
SWIMNOTE_X_홈페이지_제작자료_양식_v1.0.docx

중요:

Replit에서 양식 내용을 새로 생성하거나
재작성하지 않는다.

전달받은 DOCX binary 자체를 공식 파일로 등록한다.

==================================================
8. TEMPLATE CONTENT INTEGRITY
==================================================

R2 등록 후 다운로드된 파일이
전달받은 원본 DOCX와 동일한지 확인.

최소:

- file size
- SHA-256
- filename
- MIME
- Word openability

확인.

서버가 DOCX 내용을 다시 생성하거나
변환하면서 formatting을 변경하면 FAIL.
