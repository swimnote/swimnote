[앱] SWIMNOTE 일반모드 관리자 설정 — 공통 Settings Rule 적용

현재 일반모드 관리자 설정 화면을
이미 확정한 SWIMNOTE 공통 설정 원칙에 맞게 재정리합니다.

기준:
앞서 완료한 X모드 관리자 설정의 IA/UI를 기준으로 하되,
일반모드에는 X모드 전용 상태/세팅 영역을 표시하지 않습니다.

이번 작업은 UI/IA 정리 ONLY.

기능 삭제/통합 금지.
API/DB 수정 금지.
기존 route/toggle/storage/권한 로직 유지.

1. 공통 Settings Rule
━━━━━━━━━━━━━━━━━━━━━━

모든 설정 화면 공통 기준:

- 최상단 프로필/역할 요약
- 해당 역할에서 자주 쓰는 핵심 기능은 첫 화면 직접 노출
- 문의함 / 문의하기는 관리자 화면에서 반드시 직접 노출
- 나머지는 4개 안팎 분류로 수납
- 첫 화면과 분류 내부 중복 최소화
- 쿠팡식 익숙한 리스트 구조
- section container + hairline divider
- White / Navy / Neutral
- 큰 카드와 shadow 최소화
- 기능은 보존하고, 실제 통합/삭제는 별도 단계

10. 디자인
━━━━━━━━━━━━━━━━━━━━━━

현재 일반모드 설정 Header는
일반모드 기존 theme을 유지.

본문은 공통 Settings UI:

- White / very light neutral
- navy/charcoal text
- monochrome line icon
- hairline divider
- section container
- shadow 거의 없음
- cyan/mint outline 반복 제거
- chevron 통일
- section 간 여백 충분히

X모드와 IA는 동일하지만
일반모드 Header/theme은 기존 mode-aware 스타일 유지.

━━━━━━━━━━━━━━━━━━━━━━

- isSubAdmin 조건

- 역할 전환
- defaultTeacher

- 기타 permission 조건

전부 보존.

UI 정리 때문에 권한 없는 메뉴가 새로 보이면 안 됨.
