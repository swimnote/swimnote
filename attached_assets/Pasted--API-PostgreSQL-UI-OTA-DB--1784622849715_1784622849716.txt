학부모 앨범 API:

GET /api/photos/parent-view?student_id=:studentId

현재 이 API는 다음 PostgreSQL 오류로 500을 반환합니다.

operator does not exist: date <= text

원인:

student_class_history.enrolled_at
student_class_history.left_at

위 컬럼은 DATE 타입이고,

class_diaries.lesson_date

위 컬럼은 TEXT 타입입니다.

현재 DATE와 TEXT를 직접 비교하고 있습니다.

3. 정확한 수정 내용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

photos.ts의 반 전체 사진 조회 SQL과 개별 사진 조회 SQL에서 아래 조건을 찾으세요.

현재 코드:

AND sch.enrolled_at <= cd.lesson_date
AND (sch.left_at IS NULL OR sch.left_at > cd.lesson_date)

다음과 같이 수정하세요.

AND sch.enrolled_at <= cd.lesson_date::date
AND (
  sch.left_at IS NULL
  OR sch.left_at > cd.lesson_date::date
)

확인된 예상 위치:

1. photos.ts L775–776 부근
   - 반 전체 사진 쿼리

2. photos.ts L806–807 부근
   - 개별 사진 쿼리

줄 번호는 현재 코드 상태에 따라 달라질 수 있으므로,
줄 번호만 믿지 말고 실제 SQL 조건을 기준으로 수정하세요.

중요:
- sch.enrolled_at::text 방식으로 바꾸지 마세요.
- DATE 컬럼을 TEXT로 변환하지 마세요.
- cd.lesson_date TEXT를 ::date로 변환하세요.
- lesson_date는 이미 YYYY-MM-DD 형식 이상 데이터가 0건으로 검증되었습니다.
