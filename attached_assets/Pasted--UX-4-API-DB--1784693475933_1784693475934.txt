# 선생님 앱 수정 지시문 (UX + 일지 삭제 + 뒤로가기)

이번 작업은 아래 4가지 문제만 수정합니다.

다른 기능, 디자인, API, DB는 변경하지 마세요.

OTA 또는 Publish 금지.
완료 후 보고만 하세요.

==================================================
1. 문장 불러오기 모달 - 실제 템플릿 목록 영역 확대
==================================================

현재 문제

모달 높이는 조금 커졌지만

실제로 커진 것은

- 검색창
- 상단 영역
- 빈 여백

뿐입니다.

정작 선생님이 계속 보면서 선택해야 하는

템플릿 목록(List)

영역은 거의 한 줄 정도밖에 보이지 않습니다.

이 상태에서는 실제 사용이 매우 불편합니다.

--------------------------------------------------

목표

문장 불러오기를 열면

거의 화면의 80~90% 높이까지 올라와야 합니다.

그리고

템플릿 목록이

최소

7~8줄 이상

동시에 보여야 합니다.

--------------------------------------------------

수정 방향

모달 내부를 다시 구성하세요.

현재

제목

검색

필터

목록

미리보기

버튼

구조에서

검색 결과(List)가

남은 공간 대부분을 사용하도록 수정하세요.

예시

=================

핸들

제목

검색

레벨

-----------------

↓↓↓↓↓↓↓↓↓↓↓↓↓↓

템플릿 목록

(7~8줄 이상)

↓↓↓↓↓↓↓↓↓↓↓↓↓↓

선택된 문장

취소 / 완료

=================

목록이 flex:1을 사용하도록 확인하세요.

2. 모달 높이 추가 확대
==================================================

현재도 절반 조금 넘는 수준입니다.

원하는 높이는

화면의 약 85%입니다.

키보드가 올라와도

SafeArea 아래부터

키보드 바로 위까지

거의 꽉 차게 사용하세요.

뒤 화면은

위쪽에 조금만 보이는 정도면 됩니다.

==================================================

↓

↓

홈으로 이동하는지

원인을 먼저 찾고 수정하세요.

4. 지난 일지 삭제가 목록에 남는 문제
==================================================

현재 문제

삭제되었습니다.

메시지는 나오지만

선생님 지난 일지 목록에는

삭제한 일지가 계속 남아 있습니다.

즉

삭제 성공

↓

목록 갱신 실패

상태입니다.

--------------------------------------------------

이 문제는

임시로 숨기지 말고

원인을 찾아 수정하세요.

가능성

- 서버 삭제는 성공
- 삭제 후 목록 API 재조회 안 함
- React Query invalidate 누락
- diarySet만 갱신
- diaries 배열 미갱신
- optimistic update 오류
- 캐시가 최신이 아님
- soft delete 필터 문제

실제 원인을 찾으세요.
