[추가 지시 — BASE → X/TRIAL 기능·데이터 보존]

매우 중요.

SWIMNOTE X 또는 X 무료체험으로 전환한다고 해서
기존 일반 SWIMNOTE 기능이 사라지거나
다른 구조로 바뀌면 안 된다.

최종 원칙:

SWIMNOTE X
=
기존 SWIMNOTE 전체 기능
+
X 추가 기능

X TRIAL
=
기존 SWIMNOTE 전체 기능
+
무료체험에서 허용된 X 기능

2. 기존 데이터 100% 유지
━━━━━━━━━━━━━━━━━━━━━━

- students

X 진입 시 데이터 migration 때문에
기존 row 삭제/재생성/초기화 금지.

━━━━━━━━━━━━━━━━━━━━━━
3. 같은 기능은 같은 데이터 사용
━━━━━━━━━━━━━━━━━━━━━━

예:

BASE에서 작성한 Diary
→ X에서도 그대로 조회 가능.

BASE에서 등록한 회원/반
→ X에서도 그대로 사용.

BASE에서 기록한 출결/보강
→ X에서도 그대로 사용.

BASE Parent가 보던 과거 일지/사진
→ X 전환 후에도 그대로 조회.

X 전용 데이터만 별도로 추가.

━━━━━━━━━━━━━━━━━━━━━━
4. X 화면 때문에 BASE 기능 누락 금지
━━━━━━━━━━━━━━━━━━━━━━

X mode/theme를 적용하면서:

- 기존 CTA 사라짐
- 기존 메뉴 사라짐
- BASE 전용 component로 잘못 redirect
- X 전용 화면이 기존 기능을 대체하면서 기능 축소

되는 경우 찾고 최소 수정.

X는 기능 축소가 아니라 기능 추가다.

━━━━━━━━━━━━━━━━━━━━━━
5. TRIAL에서도 동일
━━━━━━━━━━━━━━━━━━━━━━

X 무료체험 중에도:

BASE 전체 기능은 무조건 계속 사용 가능.

커리큘럼이 없어서 제한되는 것은
오직 curriculum-dependent X 기능뿐.

예:

trial + curriculum 없음

가능:
- 회원
- 반
- 출결
- 보강
- 일지
- 사진
- 공지
- 일반 AI Diary
- 기타 기존 SWIMNOTE 기능

제한 가능:
- Local Curriculum progress
- curriculum-linked Growth
- curriculum-dependent Report
- curriculum-dependent Parent AI

무료체험이라는 이유로
기존 SWIMNOTE 기능을 막으면 FAIL.

━━━━━━━━━━━━━━━━━━━━━━
6. TRIAL/X 종료 후 BASE 복귀
━━━━━━━━━━━━━━━━━━━━━━

trial 종료 또는 X entitlement 종료 후:

BASE 기능과 기존 데이터는 그대로 남아야 한다.

X-only 기능만 잠금.

절대 삭제 금지:

- X 사용 중 작성한 일반 Diary
- 회원정보
- 출결
- 사진 metadata
- 학부모 연결
- 기존 운영 데이터

X 전용 결과 데이터도
임의 삭제하지 말 것.

접근정책만 변경.

━━━━━━━━━━━━━━━━━━━━━━
7. 전환 회귀 테스트
━━━━━━━━━━━━━━━━━━━━━━

TEST A

BASE
→ 회원/반/출결/일지 데이터 존재
→ X TRIAL 시작
→ 동일 데이터 전부 조회 가능

TEST B

BASE
→ X PAID
→ 기존 BASE 메뉴/기능 누락 0

TEST C

TRIAL
→ 72시간 종료
→ BASE 복귀
→ 기존 회원/반/출결/일지 그대로

TEST D

X PAID
→ force off 또는 entitlement 종료 상태 시뮬레이션
→ BASE 기능 그대로 유지

TEST E

Parent:
BASE에서 작성된/수신된 과거 Diary
→ X
→ 동일 조회
→ BASE 복귀
→ 동일 조회

PASS 조건:

- BASE → X 기능 손실 0
- BASE → TRIAL 기능 손실 0
- 기존 데이터 손실 0
- X → BASE 복귀 후 BASE 기능 정상
- X는 BASE 기능 위에 추가되는 구조 유지
