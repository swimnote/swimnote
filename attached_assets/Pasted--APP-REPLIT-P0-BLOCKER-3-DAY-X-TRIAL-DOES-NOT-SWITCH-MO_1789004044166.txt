[P0 BLOCKER — 3-DAY X TRIAL DOES NOT SWITCH MODE ON iOS/ANDROID]

실기기 확인 결과:

- iOS: "3일 무료체험" 실행 후에도 계속 SWIMNOTE mode
- Android도 동일 증상 관찰
- 따라서 Android stale build 문제만이 아니라 shared production bug

Android 243 build는 이 버그 해결 전 보류.

목표:
3일 무료체험 버튼을 누르면 즉시 canonical mode가 x_trial로 전환되고
앱 전체에서 X Trial 상태가 반영되어야 한다.

2. TRIAL START SERVER CONTRACT
━━━━━━━━━━━━━━━━━━━━━━

정상 시작 시 반드시:

x_trial_started_at = NOW
x_trial_ends_at = NOW + exact 72 hours
x_trial_used = true

그리고 paid/manual/HQ/force-disabled 정책과 충돌 없이
canonical mode resolver가:

mode = "x_trial"

을 반환해야 함.

중요:
x_trial ≠ paid X
x_trial은 별도 mode.

trial 시작 후 mode가 swimnote/normal로 남으면 FAIL.

3. CANONICAL MODE RESOLVER 확인
━━━━━━━━━━━━━━━━━━━━━━

resolver 우선순위 재검증:

forced off 정책
paid X
manual X
HQ override
active X trial
BASE/SWIMNOTE

기존 확정 정책을 훼손하지 말고
active trial이 BASE보다 우선하도록 확인.

active trial 조건:

x_trial_used = true
AND x_trial_started_at IS NOT NULL
AND x_trial_ends_at > NOW

정확한 기존 resolver 구조에 맞춰 최소 수정.
