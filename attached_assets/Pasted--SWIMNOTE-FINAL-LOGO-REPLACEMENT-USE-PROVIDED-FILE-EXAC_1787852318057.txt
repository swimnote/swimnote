2. LOGIN SCREEN LOGO SIZE
==================================================

현재 로그인 화면은 약 410dp 폭 기준이다.

새 로고는 기존보다 가로형 비율이므로
너무 크게 키우지 않는다.

LOGIN LOGO 권장값:

- width: 210dp
- height: auto
- resizeMode: contain
- 화면 가로 중앙 정렬
- 원본 aspect ratio 절대 왜곡 금지

반응형 기준:

logoWidth = min(screenWidth * 0.51, 220)

즉:

390dp 화면 → 약 199dp
410dp 화면 → 약 209dp
430dp 화면 → 약 219dp

최대 220dp.

고정 height를 억지로 지정하지 말고
원본 이미지 비율에 맞춰 자동 유지한다.

3. SPLASH SCREEN LOGO SIZE
==================================================

Splash Screen은 로그인 화면보다 약간 작게 사용한다.

기준:

- 표시 폭 약 160dp
- 원본 aspect ratio 유지
- 화면 중앙 배치
- 배경색은 현재 production splash 배경 유지
- 새 로고 자체에 불필요한 배경/테두리 추가 금지

반응형 개념:

splashLogoWidth = min(screenWidth * 0.39, 165)

대략:

390dp → 152dp
410dp → 160dp
430dp → 165dp
