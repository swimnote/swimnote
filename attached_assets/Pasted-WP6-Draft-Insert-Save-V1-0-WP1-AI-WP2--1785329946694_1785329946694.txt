WP6 — Draft Insert & 기존 Save 연동 구현 및 검증

설계도 V1.0을 기준으로 작업한다.

현재 상태

- WP1 완료 (AI 모달)
- WP2 코드 완료 (Voice Recorder)
- WP3 조건부 완료 (Whisper STT)
- WP4 완료 (AI Engine Request/Response)
- WP5 완료 (Draft Review)

이번 WP에서는

교사가 수정한 Common Draft와 Student Draft를 기존 Teacher Diary 입력란에 삽입(Insert)하고,
기존 Save 플로우를 그대로 사용하는 것만 검증한다.

AI가 직접 저장하면 안 된다.
