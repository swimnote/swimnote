3. L4~L7 200 Node 정확한 Dedup
==================================================

200 Node 전체에 대해:

1차:
normalized atomic_skill

2차:
stroke + domain + skill_group

3차:
semantic/title/source_text

기준으로 그룹화.

각 그룹마다 보고:

- 현재 node_code 목록
- 현재 level_order 목록

- L1~L3 동일/유사 Node 존재 여부

A. MERGE_INTO_EXISTING
이미 L1~L3에 동일 기술 존재

L1~L4에 실제 독립 기술로 존재해야 함

C. REVIEW_REQUIRED
의미상 애매함
