WP8 — AI 학생리포트
============================================================

현재:
화면 진입 시 "서버 오류가 발생했습니다."

우선 실제 root cause 조사.

APP에서 에러를 숨기거나
빈 화면으로 우회하지 말 것.

------------------------------------------------------------
WP8-1. 정책 변경
------------------------------------------------------------

기존:
매월 5일 자동 생성
→ 학부모 자동 발급

변경:

매월 5일
→ 전월 재등록 대상 학생 리포트 자동 생성

생성 완료
→ 관리자에게 발송 준비 완료 PUSH

관리자
→ AI 학생리포트 화면에서 확인
→ 발송 버튼

그때
→ 학부모에게 공개/발급
→ 학부모 PUSH

핵심:

AUTO GENERATE
≠
AUTO SEND

관리자가 발송 버튼을 누를 때
AI를 새로 호출하는 구조가 아님.

리포트는 미리 생성되어 있어야 함.

------------------------------------------------------------
WP8-2. 관리자 PUSH
------------------------------------------------------------

수영장 단위 대상 리포트가 모두 생성 완료되면
관리자에게 딱 1회 push.

의미:

"지난달 AI 성장리포트 발송 준비가 완료되었습니다.
리포트를 확인한 후 발송해 주세요."

중복 알림 금지.

idempotency 방식 조사.
