==================================================
2. TEXT MAPPING RULE
==================================================

각 text usage를 먼저 분류한다.

TITLE / STRONG HEADING
→ C.textStrong

NORMAL BODY / PRIMARY INFORMATION
→ C.textPrimary

SUPPORTING INFORMATION / SECONDARY
→ C.textSecondary

HINT / LOW PRIORITY / META
→ C.textMuted

DISABLED
→ 기존 disabled token

절대 규칙:

C.textMuted를
본문/버튼/중요 정보에 사용하지 않는다.

textMuted는 contrast 3.5:1 수준이므로
hint / metadata / low-priority 용도만.

==================================================
4. BACKGROUND / SURFACE MAPPING
==================================================

THEME_MUTABLE page background:

→ C.background

soft section / neutral grouped area:

→ C.backgroundSoft 또는 C.brandMist

card / modal / raised surface:

→ C.surface / C.card

selected soft area:

→ C.brandSoft
단 selection color change가 기능 의미와 연결되어 있으면 이번 WP에서 보류.

==================================================
5. WHITE USAGE RULE
==================================================

#FFFFFF를 전부 제거하지 않는다.

다음은 white 유지 가능:

- classColor chip 위 text
- semantic colored button 위 text
- image overlay
- photo/lightbox overlay
- feature-fixed component
- contrast가 필요한 고유 UI

일반 card/surface로 쓰는 #FFFFFF는
현재 구조상 C.surface(#FBFCFC)로 바꾸는 것이 적절한지 확인.

무조건 치환 금지.

13. HARDCODE CLEANUP STRATEGY
==================================================

대량 blind replace 금지.

파일별로:

CURRENT_COLOR
ELEMENT_ROLE
CLASSIFICATION
TARGET_TOKEN

을 판단한 후 수정.

예:

#64748B
+ subtitle
+ THEME_MUTABLE
→ C.textSecondary

#64748B
+ hint
+ THEME_MUTABLE
→ C.textMuted

같은 HEX라도 의미가 다르면
다른 token으로 매핑한다.

==================================================
15. VISUAL TARGET
==================================================

Normal SWIMNOTE 최종 느낌:

- 눈부시지 않는 Sage-tinted background
- card는 배경과 자연스럽게 구분
- black 글씨처럼 과하게 쨍하지 않음
- 하지만 흐릿하지 않음
- supporting text hierarchy 명확
- 화면마다 gray/white 톤이 제각각 보이지 않음
- 고급스럽고 차분한 수영 운영앱

과도하게 초록색으로 만들지 않는다.

이번 WP에서 Sage brand 색 면적을 늘리는 게 목적이 아니다.

배경/텍스트의 톤과 매너를 정돈하는 작업이다.
