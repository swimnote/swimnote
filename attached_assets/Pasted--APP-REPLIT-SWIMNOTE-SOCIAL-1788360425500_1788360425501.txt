0. 최종 회원가입 구조 LOCK
============================================================

학부모 일반가입은 딱 3가지 분기만 허용.

A. same pool + same phone 기존계정 없음
→ 현재 일반회원가입 그대로 진행

B. same pool + same phone 기존계정 있음
AND kakao_id 없음
→ 기존 일반회원 중복가입 차단 그대로
→ 409 / 기존 로그인 안내

C. same pool + same phone 기존계정 있음
AND kakao_id 있음
→ KAKAO_MIGRATION_REQUIRED
→ 안내
→ 새 일반계정 생성
→ 기존 Kakao 계정의 학생정보/이용기록 자동승계
→ 새 일반계정으로 로그인

이 외 별도 social signup 분기 추가 금지.
