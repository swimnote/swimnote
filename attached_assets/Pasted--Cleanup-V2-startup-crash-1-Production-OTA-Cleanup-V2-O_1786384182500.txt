[긴급 복구 승인 — Cleanup V2 startup crash 1줄 수정 + Production OTA 재배포]

원인 확정:

Cleanup V2 OTA abebbe54 이후 앱 시작 시

ReferenceError:
Can't find variable: isActive

발생.

정확한 위치:

artifacts/swim-app/app/_layout.tsx

RootNav 내부:

useEffect(() => {
  runMediaCleanupV2(isActive).catch(() => {});
}, []);

문제:

isActive는 RootNav scope에 존재하지 않는다.

isActive는 UploadProgressModal 내부의
useUploadQueue() destructuring 변수일 뿐이며
RootNav에서는 접근 불가능하다.

따라서 Metro bundle은 생성되었지만
실기기 runtime에서 ReferenceError 발생
→ ErrorBoundary
→ ErrorFallback
→ "Something went wrong"

현재 Cleanup V2 자체는 실행되기 전에 crash하므로
기존 3.26GB cache나 사용자 데이터는 건드려지지 않았다.

1. 긴급 수정 범위
━━━━━━━━━━━━━━━━━━━━━━

수정 파일:

artifacts/swim-app/app/_layout.tsx

1개만.

현재:

useEffect(() => {
  runMediaCleanupV2(isActive).catch(() => {});
}, []);

변경:

useEffect(() => {
  runMediaCleanupV2(false).catch(() => {});
}, []);

이유:

현재 UploadQueueContext는 in-memory only이며
앱 startup 시점에는 active upload가 존재하지 않는다.

Cleanup V2 startup 호출에 false를 전달하여
기존 설계의 "업로드 중이면 ImagePicker cleanup skip"
gate를 startup 상황에 맞게 처리한다.

이번 긴급 복구에서
UploadQueue 구조를 리팩터링하거나
RootNav에 useUploadQueue를 새로 연결하지 않는다.

최소 수정 1줄 원칙.
