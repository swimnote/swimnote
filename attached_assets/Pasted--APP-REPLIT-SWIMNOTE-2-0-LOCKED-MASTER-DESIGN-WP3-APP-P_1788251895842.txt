27. Trial API 오류 처리
==================================================

raw error code 노출 금지.

매핑:

TRIAL_ALREADY_USED
→ "이 센터는 무료체험을 이미 사용했습니다."

TRIAL_ALREADY_ACTIVE
→ mode refetch 후 현재 Trial 화면 표시

TRIAL_NOT_AVAILABLE_FOR_PAID_X
→ 현재 X 이용 상태 표시

TRIAL_NOT_AVAILABLE_FOR_PREVIOUS_X_BUYER
→ 무료체험 숨김 + X 플랜 선택

TRIAL_FORCE_DISABLED
→ "현재 X 체험을 이용할 수 없습니다."

FORBIDDEN
→ 일반 권한 오류 UI

POOL_NOT_FOUND
→ 안전한 오류 + retry
