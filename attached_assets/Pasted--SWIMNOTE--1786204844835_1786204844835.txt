[SWIMNOTE 선생님 소식 알림 설정 추가]

현재 계획한 선생님 알림함 구조:

[소식] [쪽지함] [학부모 요청]

소식 항목:
- 일지 좋아요
- 감사합니다
- 일지 댓글
- 향후 Instagram 공유

여기에 선생님 알림 설정을 추가한다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 기본 원칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

소식 이벤트 자체는 서버/알림함에 정상 기록한다.

하지만 선생님이 설정에서
유형별 알림 수신을 끌 수 있게 한다.

알림 OFF가
원본 이벤트/기록 삭제를 의미하면 안 된다.

즉:

소식 기록
≠
Push 수신
≠
홈 빨간점 표시

를 분리한다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 선생님 알림 설정 항목
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

설정 > 알림 설정에 다음 항목 추가:

[소식 알림]

- 좋아요
- 감사합니다
- 일지 댓글
- Instagram 공유

각각 ON/OFF 가능.

향후 Instagram 공유 기능이 아직 없으면
설정 항목은 공유 기능 구현 시 활성화해도 됨.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. 기본값
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

초기 기본값 권장:

좋아요: ON
감사합니다: ON
일지 댓글: ON
Instagram 공유: ON

단 기존 사용자 설정 구조가 있다면
현재 notification preference convention을 따른다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. OFF 시 동작
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

예:

좋아요 알림 OFF

학부모가 좋아요
→ 소식 DB 기록은 유지
→ 소식 탭에서는 과거/현재 기록 조회 가능
→ Push 발송 안 함
→ 홈 빨간점/unread 합산에서도 제외 가능

즉 사용자가 "알림을 껐다"는 의미를
실제 방해 알림 차단으로 적용한다.

감사합니다/댓글/Instagram도 동일.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 소식 탭 기록은 유지
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

알림 설정을 OFF했다고 해서
소식 탭에서 해당 이벤트를 완전히 삭제하지 않는다.

소식 탭은 활동 기록이다.

설정은:
- Push
- 홈 unread/red dot

제어용으로 사용.

소식 자체는 확인 가능하게 유지.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. 댓글은 별도 중요 이벤트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

일지 댓글은 좋아요/감사합니다보다
선생님 대응 필요성이 높다.

따라서 댓글 OFF도 사용자가 직접 선택 가능하게 하되
기본값은 ON 유지.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. 기존 알림 설정과 통합
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 앱에 이미 알림 ON/OFF 설정 화면이나
notification preference DB/API가 있다면
그 구조를 반드시 재사용한다.

새 설정 시스템을 따로 만들지 않는다.

기존 설정에:

teacher_news_like
teacher_news_thanks
teacher_news_comment
teacher_news_instagram

또는 현재 naming convention에 맞는 값을 추가.

실제 schema/API 확인 후 최소 확장.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. 홈 빨간점
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

홈 total unread 계산 시
사용자가 OFF한 소식 유형은
빨간점/unread count에 포함하지 않는다.

하지만 쪽지/학부모 요청 unread는
소식 설정과 무관하게 유지.

즉:

totalUnread =
  enabledNewsUnread
+ messageUnread
+ parentRequestUnread
+ parentRequestMessageUnread

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. 전체 알림 끄기와 개별 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기존 "전체 알림 끄기"가 있으면
상위 스위치로 유지.

전체 OFF:
→ 모든 Push/소식 빨간점 비활성

전체 ON:
→ 개별 항목 설정 적용.

기존 정책이 다르면
현재 설정 구조를 우선한다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. 구현 완료 조건
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CASE 1
좋아요 ON
→ 소식 기록 + 빨간점 + 설정에 따른 Push

CASE 2
좋아요 OFF
→ 소식 기록 유지
→ 빨간점 제외
→ Push 없음

CASE 3
감사합니다 ON/OFF 정상

CASE 4
댓글 ON/OFF 정상

CASE 5
Instagram 공유 기능 구현 후 ON/OFF 적용 가능

CASE 6
쪽지 unread는 소식 OFF와 무관

CASE 7
학부모 요청 unread도 소식 OFF와 무관

CASE 8
설정 변경 후 앱 재실행해도 유지

CASE 9
기존 알림 설정 회귀 없음
