1. Growth Report Like API
━━━━━━━━━━━━━━━━━━━━━━

구현:

GET /parent/growth-reports/:reportId/reactions

응답 shape는 기존 Diary와 동일하게:

{
  "myReactions": ["like"]
}

또는 비활성:
{
  "myReactions": []
}

POST /parent/growth-reports/:reportId/reactions

request:

{
  "reaction_type": "like"
}

동작:
- 현재 like 없음 → INSERT → active=true
- 현재 like 있음 → DELETE → active=false

response:

{
  "active": true | false
}

기존 Diary의 toggle UX와 동일하게 구현.
