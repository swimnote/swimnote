[SWIMNOTE Instagram Story V3 — 최종 디자인 마감 지시]

현재 Instagram Story 기능은 실기기 검증까지 완료됐다.

이번 작업의 목적은 기능 변경이 아니다.

현재 Story를
"앱이 자동 생성한 정보 카드"
느낌에서

"브랜드가 직접 편집해서 만든 깔끔한 Instagram Story"

느낌으로 최종 디자인 마감한다.

기능 로직은 절대 건드리지 않는다.

1. 최종 디자인 철학
━━━━━━━━━━━━━━━━━━━━━━

Story는 "일지 보고서"가 아니다.

우선순위:

1. 수업 사진
2. 짧고 따뜻한 한줄평
3. 수영장 브랜드
4. SWIMNOTE 브랜드

정보를 많이 보여주는 것이 목적이 아니다.

Instagram에서 학부모가 자연스럽게 공유하고,
외부 사람이 보았을 때

"사진이 좋다"
→ "어디 수영장이지?"
→ "SWIMNOTE는 뭐지?"

정도로 자연스럽게 인식되는 디자인을 목표로 한다.

대놓고 광고 배너처럼 만들지 않는다.

━━━━━━━━━━━━━━━━━━━━━━
2. 전체 디자인 스타일
━━━━━━━━━━━━━━━━━━━━━━

핵심:

- Editorial
- Minimal
- Premium
- Clean
- Modern

금지:

- 초등학생 습작 같은 UI
- 버튼을 여러 개 붙여놓은 느낌
- 캡슐형 박스 남발
- 둥근 박스 남발
- 불필요한 테두리
- 과한 그림자
- 색상 남발
- 이모지 자동 삽입
- "한줄평" 같은 불필요한 라벨
- 카드 UI처럼 보이는 장식
- 앱 화면을 그대로 캡처한 듯한 디자인
- 광고 배너 같은 디자인

흰색/밝은 배경을 기본으로 하고
네이비를 브랜드 핵심색으로 사용한다.

민트는 반드시 필요한 포인트가 아니면 사용하지 않는다.

하드코딩 금지.

RIGHT:

너무 작거나 연한 회색 금지.

명확하게 보이게 한다.

5. SWIMNOTE Branding

사진 > 한줄평 > branding 순서를 유지한다.

7. 사진 — 가장 중요
━━━━━━━━━━━━━━━━━━━━━━

사진이 Story의 주인공이다.

현재보다 사진 영역을 최대한 확대한다.

텍스트 영역을 줄여 확보된 공간을
사진에 우선 배분한다.

사진 개수:

1~10장 모두 실제 사진 표시 원칙 유지.

+N 방식 금지.

단 여러 장일 때
"작은 버튼 10개를 늘어놓은 것"
같아 보이면 실패다.

사진 사이 gap을 작고 정교하게 사용하여
전체가 하나의 photo collage처럼 보이게 한다.

사진별 과한 border radius 금지.
사진별 테두리 금지.
사진별 그림자 금지.

전체 사진 블록 자체가 하나의 편집된 이미지처럼
보이도록 한다.

contentFit="cover" 유지.

원본 비율을 찌그러뜨리지 않는다.

사진 1장일 때는
특히 사진을 크게 사용한다.

사진 2~4장 역시
가능한 한 사진의 존재감을 크게 한다.

5~10장은 collage 방식으로 정돈한다.

8. AI 한줄평으로 변경
━━━━━━━━━━━━━━━━━━━━━━

현재 Story Summary는
"일지를 압축한 보고서" 느낌이 강하다.

Story에서는 이를 버린다.

목표:

"오늘 아이를 직접 지도한 자상한 선생님이
학부모에게 짧게 남기는 한마디"

느낌.

길이:

목표 50~90자 수준.

화면상 약 2~3줄을 기본 목표로 한다.

최대 길이도 현재 200자대보다 크게 줄인다.

단 정확한 maxChars는
Story 실제 width / Pretendard / fontSize / lineHeight 기준으로
계산 후 결정한다.

━━━━━━━━━━━━━━━━━━━━━━
9. AI 한줄평 Prompt 규칙
━━━━━━━━━━━━━━━━━━━━━━

서버 story-summary Prompt를 다음 철학으로 수정 제안한다.

[필수 규칙]

- 원문에 실제 존재하는 사실만 사용한다.
- 원문에 없는 성취를 만들지 않는다.
- 원문에 없는 칭찬을 만들지 않는다.
- 원문에 없는 성장/향상을 만들지 않는다.
- 원문에 없는 다음 계획을 만들지 않는다.
- 수영 전문지식을 새로 추가하지 않는다.
- 사실관계를 왜곡하지 않는다.

말투:

- 자상한 수영 선생님
- 학부모에게 오늘 수업을 짧게 전하는 느낌
- 자연스럽고 부드러운 존댓말
- 따뜻하지만 과장하지 않음
- 보고서체 금지
- 업무보고체 금지
- 평가표 말투 금지
- 광고문구 금지
- 기계적인 AI 요약체 금지
- 이모지 자동 추가 금지

부정적인 내용이 있더라도
사실을 숨기지 않고
부드럽고 발전적인 표현으로 바꾼다.

예:

원문:
"킥을 짧게 차는 것이 잘 안됨"

가능:
"오늘은 킥의 박자를 조금 더 익혀보는 시간을 가졌어요."

금지:
"오늘 킥이 정말 많이 좋아졌어요."
→ 원문에 향상 사실이 없으면 생성 금지.

원문:
"접영 글라이딩 연습함"

가능:
"오늘은 접영 글라이딩을 중심으로 차근차근 연습했어요."

원문:
"발목 킥 추후 연습 예정"

가능:
"다음 시간에는 발목 킥도 함께 연습해볼 예정이에요."
