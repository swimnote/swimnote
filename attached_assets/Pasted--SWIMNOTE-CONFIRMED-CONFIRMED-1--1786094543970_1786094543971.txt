3. 지난 보강 미표시 — 실제 수신 숫자만 화면에 임시 표시
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GET /teacher/makeups?status=waiting 성공 시
받은 data를 변경하지 않고 다음 숫자만 state에 저장:

totalCount
waitingCount
expiredCount

예:

const total = data.length;
const waiting = data.filter(...status waiting...).length;
const expired = data.filter(
  m => m.status === "expired" || m.is_expired === true
).length;

중요:

이 계산은 진단 표시용이다.

데이터 filter/삭제/재정렬에 사용하지 않는다.

보강 대기 탭 상단에 임시로 작게:

진단: 전체 3 · 일반 1 · 지난 보강 2

처럼 표시.

학생 이름/ID 표시 금지.

이 한 줄만으로:

expired=0
→ 서버/API 단계에서 지난 보강이 안 내려옴

expired>0인데 카드 없음
→ 앱 render/layout 단계 문제

를 즉시 확정 가능.
