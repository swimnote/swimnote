[SWIMNOTE 학부모 홈 UI 정리 — 첨부 이미지 기준 정확 재현]

이번 작업은 학부모 홈 화면의 UI 배치만 정리하는 작업입니다.

첨부한 이미지를 최종 목표 화면으로 사용하십시오.

중요:
첨부 이미지는 단순 참고 이미지가 아니라
현재 학부모 홈 화면의 목표 레이아웃입니다.

단, 특정 iPhone 화면의 픽셀 좌표를 그대로 복사하는 방식은 금지합니다.
화면 크기와 비율이 다른 iPhone/Android 기기에서도
겹침·잘림·화면 이탈 없이 같은 구조와 비율로 보이도록
Responsive Layout으로 구현하십시오.

기존 버튼 기능, navigation, API, 데이터, 상태관리, 일지 렌더링,
알림, 사진, AI 기능 등 동작 로직은 절대 변경하지 마십시오.

3. AI 버튼 영역
━━━━━━━━━━━━━━━━━━━━━━

학생 선택 영역 아래에

[ AI 성장 리포트 ]   [ AI 커리큘럼 검색 ]

두 버튼을 한 줄에 배치합니다.

첨부 이미지와 동일하게:

- 동일한 높이
- 동일한 시각적 비중
- 네이비 border
- 흰색 배경
- 기존 AI 아이콘 유지
- 네이비 텍스트
- 버튼 내부 아이콘 + 텍스트 중앙 정렬

두 버튼 사이에는 일정한 gap을 둡니다.

중요:

고정 width 숫자로 화면을 억지로 맞추지 마십시오.

부모 container width를 기준으로

flex: 1
+
gap

방식으로 두 버튼이 사용 가능한 폭을 나눠 가지게 하십시오.

작은 화면에서도 두 버튼이 서로 겹치거나
화면 밖으로 나가면 안 됩니다.

텍스트 때문에 버튼이 깨지지 않도록
필요하면 fontSize/minWidth/padding을 합리적으로 조정하십시오.

기능과 onPress는 기존 그대로 유지합니다.

6. Responsive Layout — 매우 중요
━━━━━━━━━━━━━━━━━━━━━━

이번 UI를 특정 기기 해상도 전용으로 만들지 마십시오.

반드시 다음 환경을 고려하십시오.

- 작은 iPhone
- 일반 iPhone
- 큰 iPhone
- Android 소형 화면
- Android 일반 화면
- Android 큰 화면

금지:

- 전체 화면을 absolute position으로 배치
- 특정 화면 width를 전제로 한 좌표
- marginLeft 수십~수백 px로 위치 강제
- 아이콘마다 absolute 좌표 지정
- 기기별 임의 좌표 분기
- 첨부 이미지 해상도에 맞춘 고정 width
- 화면 높이에 맞춘 고정 top 위치

사용:

- SafeArea
- flexDirection
- flex
- gap
- paddingHorizontal
- alignItems
- justifyContent
- minWidth / maxWidth가 필요한 경우 제한적으로 사용
- Dimensions/useWindowDimensions가 정말 필요한 경우에만 사용

기본 원칙:

화면 폭이 변하면
콘텐츠가 자연스럽게 사용 가능한 폭 안에서 재배치되어야 합니다.

특히 작은 화면에서 다음을 검증하십시오.

상단:

수영장 이름
+
알림
+
SWIMNOTE
+
사진
+
설정

이 서로 겹치지 않아야 합니다.

학생 선택 영역이 화면 밖으로 나가지 않아야 합니다.

AI 성장 리포트 / AI 커리큘럼 검색 버튼이
서로 겹치지 않아야 합니다.

버튼 텍스트가 border 밖으로 나오면 안 됩니다.

SWIMNOTE 안내 배너 텍스트가 잘리지 않아야 합니다.

일지 영역이 상단 UI에 가려지면 안 됩니다.

세로 스크롤은 기존대로 정상 작동해야 합니다.

8. 큰 화면 보호
━━━━━━━━━━━━━━━━━━━━━━

큰 화면에서는 단순히 모든 요소가 과도하게 늘어나지 않도록 하십시오.

첨부 이미지의 시각적 비율을 유지합니다.

특히:

- 버튼 높이
- border radius
- icon 크기
- font 크기
- vertical gap

을 화면 폭에 비례해 과도하게 확대하지 마십시오.

화면이 넓어지는 것은 주로
좌우 콘텐츠 공간이 증가하는 방식으로 처리합니다.
