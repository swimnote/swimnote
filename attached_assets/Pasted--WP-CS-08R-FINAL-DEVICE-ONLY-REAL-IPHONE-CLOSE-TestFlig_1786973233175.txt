7. REAL DEVICE TEST 5 — GROUNDED LLM
==================================================

복합 질문 사용.

단 실제 Frontend Map / ACTIVE Knowledge에
근거가 존재하는 질문으로 선정.

예:

"출결 화면에서 이미 기록한 내용을 수정하려면 어디에서 해야 하나요?"

주의:

현재 evidence가 지원하지 않는 사실
("즉시 반영되나요?" 등)을 질문해서
모델이 추측하도록 유도하지 않는다.

MODEL =
SOURCE_IDS_COUNT =
CONFIDENCE =
UNSUPPORTED_CLAIM_FOUND =

llm_used=true
model=gpt-4o-mini
source_ids > 0
근거 밖 주장 없음.
