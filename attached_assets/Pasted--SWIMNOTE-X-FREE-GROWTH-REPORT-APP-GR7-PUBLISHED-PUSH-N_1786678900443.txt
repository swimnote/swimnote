17. PUBLISH / NOTIFICATION FAILURE ISOLATION
==================================================

Growth Report publish 자체와
external Push delivery를 구분.

권장:

1. PUBLISHED DB commit
2. Notification record/enqueue
3. Worker가 Push delivery

Report publication 자체를 rollback하지 않는다.

하지만 Notification 생성 실패를
조용히 무시하지 않는다.

retryable delivery 구조 사용.
