→ 레벨 1~4 빈 템플릿 생성

문제:

원래 의도:

① SwimNote 기본 템플릿 복원
② 완전 초기화

두 기능이 필요함.

수정:

버튼을 2개로 분리

[SwimNote 기본 템플릿 복원]

* 기본 제공 템플릿 전체 재생성
* 현재 템플릿 삭제 후 기본 템플릿으로 복원
* 확인창 필수

[전체 초기화]

* 레벨 구조만 유지
* 모든 템플릿 삭제
* 완전 빈 상태
* 확인창 필수

현재 “기본 구조 생성” 버튼은 제거

1. “기본 구조 생성” 제거
2. “SwimNote 기본 템플릿 복원” 추가
3. “전체 초기화” 추가
4. 관리자 템플릿 = 전체 공통
5. 선생님 템플릿 = 개인 전용
6. 관리자 변경 사항은 전체 선생님에게 반영
7. 선생님 변경 사항은 본인에게만 적용
8. 선생님 변경 사항이 관리자 템플릿에 영향 주지 않음
9. 관리자 UI와 선생님 UI 통일
10. 템플릿 불러오기 시 공통 + 개인 템플릿 함께 표시
