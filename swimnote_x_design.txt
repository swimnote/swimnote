==================================================
1. 스윔노트 X 개요
==================================================

스윔노트 X는 프리미엄 가맹 수영장 전용 서비스입니다.
기존 스윔노트 앱 안에 X 모드가 활성화되는 방식입니다.
별도 앱이 아니라 같은 앱에서 모드 업그레이드입니다.

활성화 조건:
- 슈퍼관리자가 특정 수영장에 X 지정
- 해당 수영장 앱 로그인 시 X 모드 자동 활성화
- 관리자 / 선생님 / 학부모 전체 역할에 X 기능 추가

가맹비: 1,500만원

3. 역할별 X 추가 기능
==================================================

[슈퍼관리자]
- X 수영장 지정 / 해제 토글
- 커리큘럼 업로드 (수영장별)
- 일지 템플릿 업로드 (수영장별)

[수영장 관리자]
- 커리큘럼 확인
- 일지 이력 조회
- 홈페이지 관리
- 웹 대시보드 이용

[선생님]
- 수업 완료 체크 → AI 자동 일지 생성
- 음성 인식 → 문장 완성 (일반과 동일)

[학부모]
- AI 자동 일지 수신
- 커리큘럼 게이지 (진행도 %)
- 우리 아이 AI 정밀 분석
- 앞으로 남은 교육과정 안내


==================================================
4. 학부모 AI 전략 (일반 포함)
==================================================

일반 스윔노트 학부모도 기본 AI 요약을 받습니다.
이유: 데이터 수집 + X 가맹 유도 마케팅 도구

선순환 구조:
- 일반 학부모 AI 오픈 → 질문 데이터 누적
- X 수영장 학부모는 정밀 분석 + 게이지 수신
- 일반 학부모가 X 수영장 부러워함
- 학부모가 수영장에 X 요청
- 수영장이 가맹 문의

가맹비 1,500만원 정당화:
- 학부모 재등록률 10% 상승 기준
- 회원 100명 × 월 수강료 10만원 × 10명 유지
- = 월 100만원 추가 매출 → 1년이면 1,200만원 → 가맹비 회수


==================================================
5. AI 일지 생성 흐름
==================================================

선생님 수업 완료 체크
→ API: 학생 정보 + 현재 커리큘럼 번호 + 수업 내용 전달
→ GPT-4o mini 호출
   - 스윔노트 AI 베이스 프롬프트
   - 수영장 커리큘럼 컨텍스트
   - 오늘 수업 내용
→ 일지 텍스트 생성
→ AI가 달성 단계 번호 감지 → curriculum_progress 업데이트
→ 학부모에게 푸시 알림 + 일지 전송


==================================================
6. 커리큘럼 게이지 작동 방식
==================================================

커리큘럼은 번호로 관리됩니다.
AI가 일지 내용을 파악해서 자동으로 게이지를 채웁니다.
선생님은 수업 완료 체크만 하면 됩니다.

예시:
커리큘럼 업로드 시:
1. 물에 적응하기
2. 발차기 기초
3. 자유형 팔 동작
...

AI가 일지 분석 →
"오늘 자유형 팔 동작 연습 완료"
→ 3번 달성 감지 → 게이지 3/전체단계 자동 업데이트

학부모 화면:
자유형 기초  ████████░░  80%
배영 입문    ████░░░░░░  40%
전체 진행률  ██████░░░░  60%


==================================================
7. 우리 아이 AI 분석 (X 전용)
==================================================

학부모가 질문하면:
- 학생 누적 일지 전체 분석
- 현재 실력 수준 설명
- 앞으로 얼마나 더 배워야 하는지 안내
- 다음 목표 커리큘럼 안내

출력 예시:
"현재 자유형 기초는 완성 단계입니다.
 호흡 연결이 아직 불안정하며
 25m 완주까지 약 4~6주 예상됩니다.
 다음 목표: 호흡 타이밍 안정화"

8. 일지 템플릿 시스템
==================================================

템플릿은 수영장별로 분리 관리합니다.
슈퍼관리자가 수영장별로 엑셀 업로드합니다.
카테고리도 업로드 시 자동 생성됩니다.

엑셀 양식:
카테고리          템플릿 문장
자유형            팔 동작이 안정적으로...
배영              킥 동작 연습이 필요...

운영 프로세스:
수영장 → 파일 전달 → 슈퍼관리자 업로드
→ 해당 수영장에만 적용
→ 앱에서 즉시 사용

10. 스윔노트 AI 엔진 설계
==================================================

핵심 원칙:
- AI는 새로운 교육 내용을 만들지 않는다
- AI는 DB에서 검색해서 상황에 맞게 설명한다
- 인터넷 수영 정보 절대 사용 금지
- 출처: 스윔노트 교육과정 / 템플릿 DB / 학생 수업기록만

번호 체계:
- 상위 번호 = 교육과정 번호 = 게이지 기준 (책 순서 그대로)
- 하위 번호 = 티칭 관점 10개 (게이지 영향 없음)
- 상위 번호 완료 시에만 게이지 증가

하위 번호 10개 관점 (영구 고정):
1  POSTURE        자세와 정렬
2  BALANCE        균형과 부력
3  RELAXATION     힘 빼기 / 긴장 조절
4  BREATHING      호흡
5  DIRECTION      움직임 방향
6  TIMING         타이밍 / 리듬
7  PROPULSION     추진 / 힘 전달
8  RANGE OF MOTION 관절 가동범위
9  COORDINATION   동작 연결 / 협응
10 CONSISTENCY    반복 안정성 / 숙련도

수영장이 달라져도 관점 10개는 변하지 않습니다.
바뀌는 것은 교육과정 내용뿐입니다.

AI 일지 작성 흐름:
선생님 음성 → STT
→ 학생 현재 교육과정 조회
→ 현재 상위 번호 조회
→ 10개 관점 중 가장 적절한 관점 선택
→ 템플릿 검색
→ 일지 생성
→ 선생님 확인
→ 학부모 전송

학부모 AI 흐름:
학부모 질문
→ 학생 현재 교육과정 조회
→ 학생 일지 분석
→ 현재 반복 중인 관점 확인
→ 앞으로 남은 교육과정 조회
→ 현재 상태 / 다음 목표 / 예상 학습 방향 설명

│   ├── 일지 생성 API
│   └── 학부모 상담 API

    ├── 영상 입력
    └── 동작 분석 → 교육과정 번호 매핑

API 엔드포인트:
POST /diary/generate       일지 생성
POST /parent/consult       학부모 상담
POST /progress/analyze     진도 분석

배포: Render.com (현재 API 서버와 동일 방식)
접근: API 키 발급 방식 (비공개 엔진)

확장성:
- 스윔노트 소아용 교육과정 DB

- 마스터즈 수영 DB
→ 엔진 하나로 모든 수영 서비스에 적용 가능

외부 판매:
- 타 수영 앱이 사용 원하면 API 키 발급
- 사용량 기준 과금 또는 연간 라이선스

12. 템플릿 데이터 전략
==================================================

베이스 데이터: 스윔노트가 직접 제작 (약 2만개 목표)
분류 체계: 상위번호 × 10관점 × 상황(3단계)

상황 3단계:
ACHIEVED    이번 수업에서 잘 됨
PRACTICING  연습 중 / 진행 중
NEEDS WORK  개선 필요

현재 보유: 10개 카테고리 350개 (기존 스윔노트 템플릿)
목표: 2만개 (GPT로 분류체계 기반 확장)

수영장별 커리큘럼:
- 슈퍼관리자가 엑셀로 업로드
- 스윔노트 AI 베이스 + 수영장 커리큘럼 = 최종 일지
- 베이스 업그레이드 시 전체 수영장 자동 개선
