---
name: 신규 수영장 가입 PUSH 계약
description: 가입 성공·논리 dispatch·실제 단말 전달을 구분하는 승인된 범위
---

신규 수영장 가입의 알림은 최초 업무 이벤트에만 논리 dispatch를 허용한다. 결과를 알 수 없는 provider 요청은 자동 재시도하거나 이벤트 replay로 재발송하지 않는다.

**Why:** 사용자가 같은 가입의 중복 발송 방지를 우선하도록 승인했다. Provider 응답을 잃은 요청은 이미 수락되었을 수 있어 재시도가 중복을 만들 수 있다.

**How to apply:** 후속 변경에서 자동 재발송 정책을 임의로 추가하지 않는다. Provider accepted와 실제 단말 표시를 구분하고, 실제 유효성은 다음 자연 발생 가입에서 확인한다. 운영 가짜 가입·수동 PUSH로 증거를 만들지 않는다.

일반 logout은 현재 단말 cleanup 성공 후 로컬 인증을 지운다. 기존 계정 탈퇴·권한 회수의 강제 보안 logout은 cleanup 오류로 막지 않는다.

**Why:** 다른 단말 보존과 현재 단말 제거를 함께 지키되, 이미 무효화된 인증으로 cleanup을 요청할 수 없는 경우 기존 보안 차단을 훼손하면 안 된다.

**How to apply:** Cleanup 요청이 인증 오류의 자동 logout callback을 재귀적으로 호출하지 않게 유지한다. 일반 logout 실패를 성공으로 숨기지 않는다.
