---
name: 서버 핫리로드 실패 패턴
description: tsx watch 모드에서 라우트 변경이 반영되지 않을 때
---

`tsx --watch` (또는 nodemon + ts-node) 환경에서 파일 변경 후 서버가 자동 재시작됐다고 표시되어도, 실제로 이전 버전 라우터가 메모리에 남아 있을 수 있음.

**증상:** 코드상 라우트가 정확히 등록되어 있는데, 서버 로그에 해당 핸들러 진입 로그가 전혀 없고 404 반환.

**Why:** tsx watch의 모듈 캐싱 또는 재시작 타이밍 문제로 구 버전 라우터가 유지됨.

**How to apply:** 라우트 추가/변경 후 서버 응답이 이상하면 `restart_workflow`로 강제 재시작 → 최신 코드 로드 확인.
