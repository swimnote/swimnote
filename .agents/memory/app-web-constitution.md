## 핵심 원칙

1. **앱 우선**: 앱이 기준, 웹은 앱을 따름. 웹 기준으로 기능 설계 금지.
2. **공유 콘텐츠 단일 소스**: `lib/app-content/src/index.ts` — 앱 기능 변경 시 여기도 같이 수정.
3. **웹 디자인 변경**: 웹 파일만 수정.
4. **수영장 홈페이지**: 소개 섹션은 수영장별 개별 제작, 나머지 탭·대시보드는 코드 공유 자동 반영.
5. **테스트 환경**: 샘플 수영장(`sample@swimnote.kr`) 기준으로 확인 후 push.

**Why:** 앱+웹 동시 운영 시 콘텐츠 불일치 방지, 유지보수 단순화.
**How to apply:** 앱 기능 추가/변경 작업 시 `lib/app-content/src/index.ts` 영향 여부 먼저 확인.
