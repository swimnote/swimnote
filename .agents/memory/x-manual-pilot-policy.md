---
name: 시범사업 X 수동 부여 정책
description: 무결제 시범사업에 사용할 기존 권한 경로와 커리큘럼 선행 조건
---

시범사업 수영장도 기존 수동 X 사용권 경로를 사용한다. 순서는 가입 → Pool Local Curriculum 준비·활성 → X 플랜 선택·수동 부여이다. management override를 시범사업 경로로 대체하거나 RevenueCat 결제 상태를 위조하지 않는다.

**Why:** 사용자는 무결제 시범사업을 기존 Growth Report 등과 연결된 manual 권한으로 운영하도록 명시했으며, Local Curriculum prerequisite 유지와 새로운 entitlement 설계 금지를 확정했다.

**How to apply:** 향후 시범사업 부여·회수 작업도 이 운영 순서를 지킨다. 신규 수영장에 즉시 X를 제공하기 위해 커리큘럼 조건을 우회하지 않는다.
