---
name: 다중반 독립 수업 경계
description: 주당 횟수, 반 소속과 과거 출석의 의미에 대한 제품 결정
---

한 학생의 수업 슬롯은 독립적인 반 소속으로 해석한다. 서로 다른 선생님이 각자 담당하는 반도, 한 선생님이 담당하는 여러 반도 같은 학생에게 동시에 성립한다. 주당 횟수와 반의 수가 일치하지 않는 운영을 새 제한으로 막지 않는다. 대표반은 전체 소속이나 다른 반의 관리 권한을 대신하지 않는다.

**Why:** 사용자가 기존 소속 관계를 유지하는 방식을 승인했다. 대표반 하나만 보는 권한 판단이나 주당 횟수에 맞춘 임의 절단은 두 번째 수업을 누락하거나 다른 반의 권한을 잘못 준다.

**How to apply:** 일반 모드와 X 모드에 같은 반·학생 권한 계약을 적용하고, 각 반의 출석·일지는 독립적으로 다루되 학생의 교육 이력은 동일한 학생에게 누적한다. 새 슬롯/요일별 교사 모델은 별도 제품 결정 없이 도입하지 않는다.

과거 출석에서 반 또는 수업 종류가 불명확한 행은 신규 정규 출석으로 자동 해석하지 않는다.

**Why:** 과거 행에는 중복과 미확정 값이 공존한다. 대표반으로 보정하거나 첫 번째 행을 골라 덮어쓰면 원래의 증거를 훼손한다.

**How to apply:** 신규 기록에는 명시적 반과 수업 종류를 요구한다. 과거 불명확한 기록은 읽을 수 있게 유지하되, 그 의미가 확정되지 않으면 명확한 행 식별 또는 별도 운영 승인을 요구한다.
