## 핵심 원칙 (절대 불변)

1. **사용자가 명시한 항목만 수정한다.**
   - "이것을 수정하라"고 명시한 파일·코드·설정만 건드린다.
   - 명시되지 않은 파일·로직·DB·서버는 절대 수정하지 않는다.

2. **작업한 것을 뒤로 가지 않는다.**
   - 이미 완료·배포된 작업을 롤백·되돌림·재작업 금지.
   - 이전 버전으로 복원하거나 merge를 되돌리는 행위 금지.

3. **서버는 사용자가 명시하지 않는 한 건드리지 않는다.**
   - Render.com 서버, photos.ts, mediaService.ts 등 API 서버 코드 수정 금지.
   - DB schema / migration 수정 금지.
   - 서버 관련 수정은 사용자 명시 승인 후에만.

4. **사전 보고 + 승인 후 작업.**
   - 수정 전 반드시 파일·내용·범위를 제출하고 검수 대기.
   - 승인 없이 Commit / Push / OTA / Render 배포 금지.

## Why

사용자가 2026-08-08 명시: "현재까지 작업한거 지금부터는 절대로 뒤로가거나 하는일없어 서버도 건드릴거없고 내가 수정한다는것만 수정하는거야"

이 지시는 모든 WP, 모든 작업에 적용되는 최상위 원칙이다.
task-constitution.md, constitution.md보다 이 원칙이 우선 적용된다.

## 적용 시점

- 모든 작업 시작 전 이 파일을 확인한다.
- 사용자 요청에 명시되지 않은 파일이 수정 대상에 포함되려 할 때 즉시 멈추고 보고한다.
- "혹시 이것도 같이 수정하면 좋을 것 같다"는 판단으로 추가 수정 금지.
