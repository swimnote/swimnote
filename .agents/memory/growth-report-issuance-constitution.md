# 무료 월간 AI 성장리포트 발급 정책

발급월 M의 분석월은 M−1이다. 해당 분석월에 수영장 반 재원 이력이 유효하고, 다음 달 1일까지 계속 재원이어야 한다. 분석월 중도 등록도 인정수업 3회와 유효 학생 개인 일지 1건을 충족하면 대상이다. 예정수업에서 결석을 뺀 횟수에 완료 보강을 더하며, 예정수업이 아닌 단순 출석기록은 추가 수업으로 세지 않는다. 월 데이터는 KST의 반개방 구간으로 고정한다.

매월 1일 전월 cycle을 준비하고 1~4일 분석·재시도·복구한다. 월간 자동화의 마지막 역할은 5일에 관리자에게 완성된 리포트와 월 1회 준비 알림을 제공하는 것이다. 관리자 확인·검토·승인·개별/일괄 발송, PC 관리자 화면, 이후 학부모 발행·표시·PUSH는 기존 구현을 그대로 사용한다. 자동생성을 이유로 이 영역의 UI/API/권한/상태 머신/발행 정책을 재설계하지 않는다. 월간 scheduler/worker가 관리자 대신 발송하거나 직접 학부모에게 공개해서는 안 된다. 기존 발행 유효성 조건과 PUBLISHED 보존은 유지한다.

**Why:** 2026-10-01 사용자가 과도하게 확장된 변경을 선별 복구하도록 지시하고, 이번 개발 범위를 1~5일 자동생성·복구·관리자 준비 알림으로 한정했다. 기존 관리자와 학부모 시스템을 새 구조로 대체하면 정상 승인·발송 경로가 끊길 수 있다. 학생별 독립적인 월별 결제·재등록 증거는 없으므로 active 상태만으로 재등록을 추정해서는 안 된다.

**How to apply:** 무료 월간 AI 성장리포트의 후보 생성·분석·재시도·restart 복구·관리자 준비 알림에만 필요한 최소 변경을 적용한다. 자동화 flag는 준비·분석·복구·관리자 알림까지만 제어하며 학부모 공개 권한을 부여하지 않는다. 기존 수동 승인/발송·학부모 알림의 변경은 별도 명시 요청 없이 수행하지 않는다. 유료 AI 인사이트 전략 리포트나 다른 보고서에 확대 적용하지 않는다.
