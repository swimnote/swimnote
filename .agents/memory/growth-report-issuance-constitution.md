# 무료 월간 AI 성장리포트 발급 정책

발급월 M의 분석월은 M−1이다. 해당 분석월에 수영장 반 재원 이력이 유효하고, 다음 달 1일까지 계속 재원이어야 한다. 분석월 중도 등록도 인정수업 3회와 유효 학생 개인 일지 1건을 충족하면 대상이다. 예정수업에서 결석을 뺀 횟수에 완료 보강을 더하며, 예정수업이 아닌 단순 출석기록은 추가 수업으로 세지 않는다. 월 데이터는 KST의 반개방 구간으로 고정한다.

매월 1일 전월 cycle을 준비하고 1~4일 분석·재시도·복구한다. 5일은 관리자 검토 개방 및 월 1회 준비 알림의 시점이며 학부모 자동 공개일이 아니다. 학부모 공개·feed·PUSH는 관리자의 명시적 개별/일괄 발송 후에만 허용한다. 발행 직전에 학생 active/nondeleted·발급조건·결과 품질을 공통 검증한다. 발급 후 퇴원해도 이미 공개된 월간 보고서는 보존한다. 배치 준비 완료와 분석 결과 준비 완료 및 발행 완료를 구분한다.

**Why:** 2026-10-01 사용자가 관리자 확인 후 발행 정책을 확정해 이전 5일 자동 공개 지시를 명시적으로 대체했다. 준비완료 알림과 학부모 발행을 혼동하면 검토 전 보고서가 공개된다. 학생별 독립적인 월별 결제·재등록 증거는 없으므로 active 상태만으로 재등록을 추정해서는 안 된다.

**How to apply:** 무료 월간 AI 성장리포트의 후보 생성·분석·준비 알림·모든 발행 경로·퇴원 처리에서 동일한 정책을 사용한다. 자동화 flag는 준비·분석·복구·관리자 알림까지만 제어하며 학부모 공개 권한을 부여하지 않는다. 유료 AI 인사이트 전략 리포트나 다른 보고서에 확대 적용하지 않는다.
